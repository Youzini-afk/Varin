# 虚拟案卷与身体接触：W01 / W07、W09 / W11

2026-10-30 · 当前设计合同；场景代码与身体资源分别验收，不以程序测试冒充视觉通过。

## 1. 选择与所有权

W01/W07采用**独立虚拟案卷 + 不同的全身表演**。凳袋/实物夹是曾研究的助手方案，不是用户要求；不再作为呈示动作的默认前提。原因是执行董事负责接住与交代，实体夹的取放/携带不能反客为主。虚拟案卷不是用图标代替身体，也不是假装被掌托着的纸。

- W01：单臂向自身中线收进、胸口坐正，稳定手全程稳机。
- W07：双前臂内聚、胸肩收束，继而立起前送；双手沿电脑外侧下撤让位，不横向摊掌。
- 主身体句不随项目A/B/C或左右屏边镜像；场景布局独立解算，不依赖固定右掌、电脑点或B位置。
- 保留同一脸/发/空心菱形吊坠/服装/凳/电脑母版；不能为了露手变更盖角、底座厚度或骨段长度。膝腿持续托机，骨盆坐骨承重。
- 小队保持B 2.5D：负责人围Varin，children围各自负责人；厚度、压扁底面、软影与遮挡不被虚拟卡替代。

## 2. 身体与场景相位

| 句子/阶段 | 身体任务 | 场景任务 |
|---|---|---|
| W01 0–160ms | 稳机、吸气收一拍 | 新委托事实立即可查 |
| 160–420ms | 胸口立正，表达肘从电脑外侧起 | 委托卡在安全空区显现 |
| 420–700ms | 掌斜朝自己，单臂内收一次 | 卡自行收束，不贴手、不吸入电脑 |
| 700–920ms | 认真看用户，手不翻掌 | 焦点负责人仅在真实委托事实下短收拢 |
| 920–1350ms | 降肘落手，袖口停 | 卡淡出装饰层，项目信息保留 |
| W07 0–180ms | 停当前动作、髋带胸略前收 | 显示准确“本轮结果”范围 |
| 180–480ms | 双前臂从盖两侧上行、内聚 | 独立案卷收拢层次，仅焦点项目 |
| 480–680ms | 双肘收近、手保持间隙 | 案卷落定，不模拟持物接触 |
| 680–1080ms | 胸肩立起前送、双手沿盖外侧下撤，一手先稳机 | 案卷独立展开主结果面，不伪造附件 |
| 1080–1320ms | 温和前意、看用户，手已低位 | 卡保持；没有“已读/已验收”徽章 |
| 1320–1800ms | 回舒适正位，袖发余势停 | 卡淡出装饰层，结果仍可查 |

以上时长是原画起点。现有cue名只是表现接口，`management-receive/delegate`不证明新业务写入，`gather`不证明额外综合报告生成。新作者可用ACCEPT_INWARD/ACCEPT_SETTLE/PRESENT_CLEAR；仍兼容现有cue，不复用旧身体姿态充数。

场景在角色保守外框与所有小队装饰边界之外找空位，正常案卷放不下则紧凑卡，再不够就省略装饰卡；不遮脸/手/电脑、不挤走小队事实。卡只能局部收展，不能走跨人物的“从队伍送到掌上”路径。案卷上的项目标识绑定真实subject key，不依赖inspection方向。

短句期间只有一个焦点项目可做强调，其他负责人/children停止工作摆动但保留身份、问题/权限与状态。事实改变即时呈现，不排队补演。没有焦点业务句时仍可有有限且稀疏的小队工作节拍。

## 3. 中断、事实与准入

- 抓起：根立即移动；身体顺向降臂，一手先支撑电脑、另一手再补，交接前膝腿仍承托。虚拟卡退场，因为它本来不是手持物。落座不重演旧句，重复抓起不重播开盖。
- 问题/权限/异常优先显示；旧句只完成安全回收，不阻塞事实、不通过动作解决请求。隐藏、菜单、切scope/模式、失联、新run替代均丢弃过期装饰，不补播。
- reduced motion使用静态稳态与静态信息，不强制跑一套图标动画。
- W01仅来自当前已初始化观察里的fresh accepted delegation：精确关系、稳定根、游标新鲜、匹配协调路由、未终止/取消。初次加载与历史事实不触发。
- W07仅来自已观察到的精确run完成边沿及Bot协调资格；有child继续工作就保持其执行事实。完成不等于Varin已读、批准、综合出新报告，也不等于整个项目完成。Agent工作区只通知，不套用管理句。
- 先验收512/360/实际最小尺寸四拍剪影，关闭场景仍辨W01/W07且与W05/W08/W09不同；双手离机必须有真实腿托证据。再验收屏边、并发、权限打断、半程抓起与重复落座。未通过不扩大生产。

W03物理整理可保留为独立本地接触研究，不能因此先给全部母版加凳袋。实体夹若再次进入候选，仍须证明袋内/空袋、取出/接手/放回、持夹抓起与电脑共同承托、部分入袋时中断及落座归袋全链；不能把虚拟卡当作丢失实体夹的替代。既有实物草图不是默认交付方案，不在本合同中维护第二套W07。

## 4. W09修订：低位间隙不可被电脑吃掉

原稿的“双手在低位分开一点”在360px极可能仅剩脸。改成**一手示意自己先停，身体前倾把话留给对方**，与W07双臂汇拢后落手让位区分。

1. 起势150ms：当前动作停住，胸肩从工作态向用户前倾一点；直颈，头不歪。
2. 表达200ms：表达手沿电脑侧缘抬到胸前偏侧、电脑上沿之外，手指自然微曲，手背偏向镜头，指尖轻靠近自己的胸前衣料但不碰吊坠。不是抚胸宣誓，也不是摸脸。
3. 留话250–400ms：手从胸前向前离开一小段然后停住，**不翻掌、不指人、不横摆**；肘仍贴身。上身保持前倾，嘴小幅问询后闭合，目光停在用户。
4. 等待：手真实落到低位，胸肩保留轻微前意再自然回正。疑问眉只一拍，不持续表情锁定。

360px目标：可见一个近胸的弯手轮廓，和W08竖起食指、W10双手撤退、W07双臂收束后落手让位明确不同。让评审看无字幕视频说出“她在等我接话”，而非看清特定手语。

中断：从胸前离手后落肘；手接近衣料不形成抓布，避免新增复杂接触。早期回收不必做完前伸。若实际前倾会挡住手，手的横向位置调整在角色自身局部，不与项目位置绑定。

**禁止沿用名称而仍用旧图**：修订是完整的新肩肘/手路径，不是把同一个present.png换成微曲手指。

## 5. W11修订：释然是张力曲线，不是笑脸

从不同起点进入必须有实际桥。由R开进入时只制造很小预紧；由本来认真收紧的监督/异常关注进入时，不再多耸一次肩。

| 阶段 | 身体 | 手与支撑 | 眼神 | 初始时长 |
|---|---|---|---|---|
| T0 接到确切结果 | 当前动作停住，胸口小幅提起；肩上提仅到自然吸气位置 | 双手低位安放，指尖从松到稍聚；电脑不动 | 从电脑回用户，尚不先笑 | 120–180ms |
| T1 张力顶点 | 肩胸短暂保持，颈不缩、脸不沉进领口 | 手不举起，不攥拳 | 眼神清楚、嘴角尚中性或开始软化 | 80–120ms |
| T2 吐气释放 | 胸口和肩线向下回到舒适位，上背自然放松；下巴随胸极小回落 | 指尖松开，肘略沉；袖褶随落肩变化 | 轻笑与短缓眨发生在释放中后段，不抢在身体前 | 280–380ms |
| T3 余势 | 肩停，侧发/袖边迟一拍落定，骨盆仍承重 | 手恢复轻搭，没有附加招手 | 眼睛重新睁开、浅笑自然减弱 | 180–250ms |
| T4 稳态 | 同一R开自然身体，不能比之前永久缩小/塌下 | 支撑稳定 | 正常陪伴 | 非循环 |

可见性要求：肩线变化来自胸肩/肘和衣料的连续运动，不能靠整人竖向挪2px或脸换微笑。512/360两档都检查“紧一下—松下来”的弧；幅度不足先优化肩肘/袖褶关系，不放大头部和身体弹跳。

中断：T0/T1被新任务打断就停止释放庆祝的语义，沿当前支撑自然回工作正位；T2被打断完成余下落肩但收去笑意，再接新事实。失败/未知没有T2笑意；取消不是释然完成。不能为了完成动作延迟显示新问题。
