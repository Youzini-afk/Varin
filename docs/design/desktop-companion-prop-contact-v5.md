# W03 / W07 接触可行性与 W09 / W11 修订

2026-10-30 · 接触设计候选，不是已存在素材或已批准外观。本文补充 [v5 动作语言](desktop-companion-motion-language-v5.md) 的物件接触、问题可见性与释然动作弧。

## 立即采用的结论

1. **删除原稿中无条件的“固定收纳位”。** 当前黑凳没有袋、槽或桌面，电脑占据膝上主要区域，现有长发覆盖凳侧。不能把夹瞬移到腿上，也不能让手穿过电脑拿物。
2. 如果要保留实物整理/呈交，必须增加一个**从休止帧就可见、始终存在的凳侧薄袋和一本横开小便笺夹**，先接受其对母版外观、长发遮挡、去凳衍生的影响。用户此前允许外部元素发挥，因此可把这一合理小配件纳入设计候选；它不改变角色服装，也不假称已获视觉接受。必须连同中立帧、长发遮挡及凳体一起验证，不能先安装。
3. **优先验证实物方案A，而非为了省资源退回更多空手手势。** W03/W07的物件接触能提供真正不同的身体任务。下文无道具方案仅作为对照与实物确实不可行时的备选，尤其W07双臂展开仍有“变成双手摊掌”的高风险，不作为默认替代。
4. W09原“低位两手小间隙”很容易被电脑挡住，不能直接进入生成；改为屏幕两侧上方可见的“将话留给你”，不是放大成双掌摊开。
5. W11必须画出**现有工作张力→短预紧→吐气释放→落稳**，不是换微笑脸，也不是把肩膀永远提高后再落下。

## 1. 空间基准：先画同画布工程草图再选分支

以已审512方画布正面母版为准。以下坐标只是摆位草图的起点，必须在真实轮廓上量取，不是伪造的现有锚点：
- 电脑盖大致占画面中下部左至中间，顶边是斜线；正面可见的是盖背，不是供用户阅读的屏幕。
- 白袖在两侧形成宽轮廓，画面右侧长发从肩后流经凳侧；黑凳的右侧可见面积有限。
- 工作道具不能默认在电脑后面被镜头看见，也不能把电脑当透明图层。两手在键区做毫米级变化，360px下通常读不出。
- 所有候选需按真实电脑轮廓画两条线：不可穿越的盖板实体轮廓；可从上方越过的自由空间。手/夹从盖后到盖前必须有绕边或越顶的路径，不能单靠图层顺序切换。

### 必做几何样张（不需要先画完整动作）
G0 R开 + 可见道具袋；G1一手抓夹上沿；G2夹完全离袋；G3两手接住夹；G4夹在胸前且不挡脸；G5原位放回。

把这六张都缩到360px和实际桌宠最小尺寸。任何一张若需改电脑尺寸、拉长手臂、掰开长发消失一大片，实物方案立即退回，不靠更多插帧挽救。

## 2. 实物方案A：凳侧袋 + 横开便笺夹（有条件可行，不是默认已有）

### A0 配件合同

**袋**：与黑凳同色系的薄扁软袋，固定于面向镜头的外侧凳边，不改凳座宽高和腿托几何。上口在自然垂手可及高度，不放到脚边。袋不能在工作句出现、闲置句消失。示意位置为画面右侧凳前缘附近；先实测袖口和长发后选择最终边，不镜像角色补救。

**夹**：一本很薄、横向打开的小便笺夹，闭合体积约为角色掌宽的1.5–1.8倍，不是A4报告。无可辨识项目字/文件缩略图、无发光菱形、无凭空增页。只表示她自己的整理工具，不证明报告已生成。平面宽度草图可从512画布的65–80px起试，厚度2–4px；360px时宽度约46–56px，可见但不能盖脸。

**收纳**：夹竖插入袋，约上1/3露出以便抓取，袋口承托下部。夹的装订/开合轴固定；取出后转为横向的旋转由手腕及接手交代，不一帧换长宽。

**遮挡层**：凳/袋后部 → 后层长发（具体前后以真实安装位置决定）→ 袋前壁与夹 → 取物手/袖。不能说“所有头发永远在袋后”：若既有一缕发跨过凳前缘，必须保留其连续遮挡或制作让手从发前绕行的路径。袋的位置应选在不用掀整片长发的区域。找不到该区域，就判此侧不可用。

**去凳与拖动**：袋属于凳，不跟Varin一起飞起。平时夹在袋内，提起时留在凳上；若夹正被拿着，采用A5的“先一手稳机，夹转到基座下共同承托”恢复路径。不能许诺“根移动时快速插回原凳袋”，因为凳已相对离开；也不能让夹自动吸附电脑。袋必须有含物/空袋两状态，夹是否仍在手中由真实接触阶段决定，不按动作标签猜测。A5未通过机械草图之前，实物方案不能进入全套可交付资源。

这不是小问题。允许正常动作好看但拖动时丢物，不符合现有全阶段中断要求。不要在manifest里用字段掩盖。

### A1 取出（W03/W07共用机械入口）
1. 0–160ms：稳定手轻定住电脑底座；胸肩保持正面，视线短落向袋口。
2. 160–350ms：取物侧肘向下后方松开，肩只略下沉；手沿袖口外可见路径接近露出的夹边。手臂不是拉长，骨盆仍承重。
3. 350–500ms：拇指与手指夹住露出的边沿，先建立接触，夹尚在袋内；衣袖不能覆盖到看不见所有接触。
4. 500–720ms：夹沿袋长轴上提，完全越过袋口前不横移/旋转。袋前壁可轻形变，但凳不变。
5. 720–900ms：夹清空袋口后才向身体前侧带回，避开长发，手腕逐渐转为横向。另一手此刻仍稳电脑。

**可取消**：抓到但未拔出→松指回手；拔出不足一半→沿原轴插稳再松；已完全拔出→不能倒播硬塞，需要真实放回入口。

### A2 支撑交接与对齐（W03）
1. 夹移到电脑上沿以外的胸前自由空间，禁止平铺在键盘上假装多出桌面。必须先在侧方越过盖顶，再向中心靠近。
2. 稳定手确认电脑由双腿承托，离底座后从另一侧绕盖上沿到夹下方，掌根托住夹的下边；另一手保留夹持，存在短暂双手共同接触。
3. 夹保持闭合。托夹手作为固定端，另一手拇指/指腹沿封边轻对齐一次，再短压一次；不凭空生成散页，不让夹沿大腿打击造成电脑弹跳。
4. 身体略内聚，眼神落在边沿，双肘近身。明确是两手与同一物件的对齐，不是两个掌面交替展示。
5. 对齐后交接回取物手；另一手回电脑底座，再放夹。

**电脑稳定前提**：底座接触双腿的面积和重心投影必须在支撑多边形内；原盖角不变，两腿不同时调整。不能仅写“腿托稳定”就无证据释放双手。画草图检查顶盖重心造成的后翻趋势，必要时放弃双手离机，不改变电脑角度来凑。

### A3 双手托出（W07）
1. 从A2的双手共持开始，夹在胸前偏低、电脑盖顶上方；夹正面不写真实工作成果。
2. 胸肩坐正，肘在身体两侧略打开，双手抓持下两角；手掌大部分朝夹，不朝用户空摊。
3. 将夹向前送一个小距离，不越过膝盖；在正面视角通过肘略展开、夹透视变化和胸肩前意表达深度，**不通过把夹放大20%**。
4. 眼神从夹回用户，停约300ms；夹最高边不得超过下巴，不能挡嘴、脸或全条项链结构。暂时遮住吊坠一部分可以物理成立，但回收后必须是同一吊坠，不要求透视穿过道具。
5. 先回收夹到胸前，肘再收近；接A4。不是双手往外一摊道具就消失。

**可取消**：送出中沿当前高度撤回；不可立刻落到袋口，必须重新单手接持后绕电脑侧边。

### A4 放回
1. 取物手重新掌握夹上/侧边；另一手逐渐卸力，确认夹由取物手持稳后离开。
2. 另一手回电脑底座建立接触；夹沿电脑外侧下移，到袋口上方才转回竖向。
3. 夹下沿进入袋口，逐渐下插，袋底/侧壁承担重量；手不能在夹还悬空时先松开。
4. 释放夹、手离开、肘回位、肩松开，袖摆最后落稳。夹露出比例与G0相同。

### A5 任意阶段拖动：随电脑带走，不向已经离开的凳袋塞回

采用“夹随电脑一起托住”的独立恢复句，不增加角色衣服上的插槽，也不让夹自动吸附。凳袋为空时留在凳上；便笺夹跟随人物，以真实手掌压持在电脑底座下方，释放落座后再放回凳袋。

**共同携带位 Pcarry**：薄夹横向贴在电脑底座下表面的前侧可托区域，至少露出一条稳定的小边，方便确认它没有消失。一只手掌同时从下方托住夹与电脑，另一手稳电脑另一侧；夹尺寸必须小于可托底座区域，不能撑开电脑/双腿。夹与电脑不熔成同一物体，颜色/边缘分离。这个动作是短时收纳，不让夹长驻遮住电脑标记。

- D0 夹仍在袋内：普通托机离凳；夹留袋，不临时带走。
- D1 已抓住但未离袋：先松指，手沿当前可见路径收回托机；袋和夹留凳。根照常随拖动，不待手回位。
- D2 夹已完全离袋/单手持夹：另一手已在电脑底座。持夹手沿电脑侧边把夹下移，并转为横向送到基座下前沿；稳机手不离开，腿在这短恢复段仍与底座保持接触。夹到位后持夹手从下方托住两件，另一手补足第二支点，然后才进入腿部完整悬空姿态。根位置已在移动，身体局部承重交接不要求窗口停住。
- D3 双手对齐/呈交中：先由取物手单独接稳夹，另一手先下移稳电脑；随后走D2。不能两手仍高举夹时把膝腿收起、让电脑独自漂浮。
- D4 夹刚进入袋口但未释放：若袋口还具有接触关系，先沿袋轴落稳再松手；若根运动已使接触不成立，必须保留持夹事实并回D2，不用瞬间拉长夹/手去追凳。此分支按实际阶段选择，需要专门原画；不能由程序猜一张图。
- D5 释放落座：先骨盆接凳、腿重新承托电脑；由另一手稳底座，持夹手将夹从底座下抽出（明确先卸夹上的压力），绕外侧送回袋。夹插稳、手放开后才恢复普通休止。若落座时又被抓起，保留夹在手或Pcarry的真实状态，回对应D2/D3，不重复取袋。

**必要验证**：Pcarry必须先做三张机械草图：夹从侧面接近底座、夹进入底部承托区、双手共同托起。如果宽袖遮住整个交接、电脑必须抬到离腿很远、或手无法同时托住两物，则该收纳路径失败，不能文字通过。设计时可微调夹尺寸/袋位，不可改角色手臂长度或电脑底座。

**未完成即不通过**：此处给的是明确可画的恢复方案，不宣称它已经成立；它补上了原先“插回已离开的凳袋”的逻辑错误。

### A6 可执行判断

常规取放在空间上**可能成立**，但依赖新增袋及重画遮挡；现阶段不能证明。优先验证A5的Pcarry接触链，将它与六张常规几何草图一起作为实物方案准入门槛。只有它们都成立，才进入完整W03/W07生成；不能把A当“只多画几张纸”的低成本任务。无道具方案不是更推荐或更省事的默认项。

## 3. 对照备选B：不新增配件，不假装持物（不优先）

### B-W03 分项理清：看着自己的手把事情理顺

**意图更名**：将“物理整理纸件”改为“分项整理思路”。Bot主管/秘书可以这样理清条目；Agent执行状态仍不调用。

空间：表达手与辅助手出现在电脑靠近身体一侧的上方、胸前偏一侧的空区；手指峰值低于下巴，至少有一只手完整露出电脑轮廓。必须把手轮廓画到屏幕外，不能继续藏在键区。手只在自身近处，不指项目坐标。

1. 起势150ms：胸肩内聚一点，目光先看自己的手；电脑继续由双腿托住，不动膝。
2. 抬手200ms：辅助手前臂沿电脑外侧抬起，手背斜向镜头、掌心朝自己，伸出两根自然弯曲的手指（不是V字拍照）。另一手从低位跟到手旁。
3. 分项350ms：表达手食指指腹依次轻碰辅助手的两处指节，第一拍稍长、第二拍短。每拍有真实接触再离开，不戳空；双手轮廓为一个紧凑的近身小组。
4. 理顺150ms：第二次碰触后两手暂时近拢、目光停一下；不合掌、不祈祷、不变鼓掌。
5. 收势350ms：表达指先离开，双手按先后回低位，至少一手先重新稳机，肩再展开回正。

**区别**：不是W04触下巴，不是W05单次垂直定拍，不是L07抓袖；它有两手、指节接触、两段不等长节拍和内聚重心。不能为了避手部难度把它简化为两下空点。

**中断**：接触前可直接降手；碰触中先离指再降；拖动时两手就在电脑上方，向两侧下降托机，不携带道具，不需返回凳位。

**风险/准入**：512源的指节接触缩到360后仍应看得见双手互相作用，不要求看清“数二”；若只能看到静止小团手，增大前臂整体抬起/分离幅度，不把细节夸成大手。若实际最小尺寸下不成立，就不交付该句，先保持W06安静，不借其他手势标“整理”。

### B-W07 汇拢后邀看：宽的双臂句，不持报告

**意图更名**：“汇总已可看，邀请用户查看”，不能声称“她递出了一份实物”。具体成果仍在信息层，动作本身是交流行为。

1. 起势180ms：手从低位离开，胸肩坐正；双肘近身，眼神在自己的工作区短收一下。
2. 汇拢220ms：两前臂来到电脑两侧可见处，双手以手背/侧面为主，在胸前下方短向中线靠拢，但不碰成合掌；不穿电脑、不假装夹纸。
3. 邀看350ms：胸口打开，两肘向外展开到明显宽于W09的轮廓，双手分别移到电脑上沿两端之外，掌面保持斜向内下方，像给面前的工作留出一个看得清的框。**没有手腕翻掌，没有横向往返摆动。** 只展开一次，双臂同步但非机械镜像。
4. 呈意停留250ms：眼神正视用户；肩胸舒展而非耸肩，双手不是“我不知道”的耸肩摊手。
5. 收势350ms：肘先向身体靠回，双手沿电脑外侧落低；先一手重新稳机，另一手松放，肩自然落定。

**区别**：W01只有一手向内收；W05是窄的单手向下定拍；W08是窄的单指竖向；W09是近身暂停留话；W07为宽、双臂、胸口打开、向外一次展开后落下。若四拍剪影仍读成两个掌的“摊手”，立即返工手腕朝向/肘高度，不接受“这是双掌所以不同”的辩解。

**中断**：汇拢中直接降臂；展开中缩小幅度沿外侧下落，不反复收开；拖动沿外侧直接收拢托机。没有道具消失/凳相对移动问题。

**保留意见**：这是对当前空间约束的稳健替代，不比有完整接触的实物呈交更具象。必须先用四拍剪影与W09并排审阅。如果仍混淆，宁可把Bot汇总表现为W11克制释然并明确共享，不声称已有独立“呈交”动作；不能再套旧present。

## 4. W09修订：低位间隙不可被电脑吃掉

原稿的“双手在低位分开一点”在360px极可能仅剩脸。改成**一手示意自己先停，身体前倾把话留给对方**，避免和新W07双臂展开冲突。

1. 起势150ms：当前动作停住，胸肩从工作态向用户前倾一点；直颈，头不歪。
2. 表达200ms：表达手沿电脑侧缘抬到胸前偏侧、电脑上沿之外，手指自然微曲，手背偏向镜头，指尖轻靠近自己的胸前衣料但不碰吊坠。不是抚胸宣誓，也不是摸脸。
3. 留话250–400ms：手从胸前向前离开一小段然后停住，**不翻掌、不指人、不横摆**；肘仍贴身。上身保持前倾，嘴小幅问询后闭合，目光停在用户。
4. 等待：手真实落到低位，胸肩保留轻微前意再自然回正。疑问眉只一拍，不持续表情锁定。

360px目标：可见一个近胸的弯手轮廓，和W08竖起食指、W10双手撤退、W07双臂宽展开明确不同。让评审看无字幕视频说出“她在等我接话”，而非看清特定手语。

中断：从胸前离手后落肘；手接近衣料不形成抓布，避免新增复杂接触。早期回收不必做完前伸。若实际前倾会挡住手，手的横向位置调整在角色自身局部，不与项目位置绑定。

**禁止沿用名称而仍用旧图**：修订是完整的新肩肘/手路径，不是把同一个present.png换成微曲手指。

## 5. W11修订：释然是张力曲线，不是笑脸

从不同起点进入必须有实际桥。由R开进入时只制造很小预紧；由本来认真收紧的监督/异常关注进入时，不再多耸一次肩。

| 阶段 | 身体 | 手与支撑 | 眼神 | 初始时长 |
|---|---|---|---|---|
| T0 接到确切结果 | 当前动作停住，胸口小幅提起；肩上提仅到自然吸气位置 | 双手低位安放，指尖从松到稍聚；电脑不动 | 从电脑回用户，尚不先笑 | 120–180ms |
| T1 张力顶点 | 肩胸短暂保持，颈不缩、脸不沉进领口 | 手不举起，不攥拳 | 眼神清楚、嘴角尚中性或开始软化 | 80–120ms |
| T2 吐气释放 | 胸口和肩线向下回到舒适位，上背自然放松；下巴随胸极小回落 | 指尖松开，肘略沉；袖褶随落肩变化 | 轻笑与短缓眨发生在释放中后段，不抢在身体前 | 280–380ms |
| T3 余势 | 肩停，侧发/袖边迟一拍落定，骨盆仍承重 | 手恢复轻搭，没有附加招手 | 眼睛重新睁开、浅笑自然减弱 | 180–250ms |
| T4 稳态 | 同一R开自然身体，不能比之前永久缩小/塌下 | 支撑稳定 | 正常陪伴 | 非循环 |

可见性要求：肩线变化来自胸肩/肘和衣料的连续运动，不能靠整人竖向挪2px或脸换微笑。512/360两档都检查“紧一下—松下来”的弧；幅度不足先优化肩肘/袖褶关系，不放大头部和身体弹跳。

中断：T0/T1被新任务打断就停止释放庆祝的语义，沿当前支撑自然回工作正位；T2被打断完成余下落肩但收去笑意，再接新事实。失败/未知没有T2笑意；取消不是释然完成。不能为了完成动作延迟显示新问题。
