# Bot 工作台：界面、交互与动效

状态：2026-10-30 设计已评审，桌面端主体已实施（见第 12 节）。可交互原型：[bot-preview/index.html](bot-preview/index.html)（浏览器直接打开，纯前端，数据是示例，不连接 Host）。原型复用 [motion-preview/motion.js](motion-preview/motion.js) 的弹簧与动效级别，手感与 [动效与交互](motion-and-interaction.md) 一致。

原型左下角的“原型实验室”是评审工具，不属于产品，提供以下控制：

- **场景**：交办一件事、子任务需要你、回报回到原会话、记住一件事、休息 / 叫醒、电脑断开 / 恢复、重置。
- **显示**：窗口尺寸（桌面 / 窄窗口 / 手机）、主题、动效级别（完整 / 简化 / 关闭）、×4 慢放。
- **形象状态预览**：直接切换形象的各个状态。

形象是 Varin 趴在窗台上的正面 Q 版，画法、分层与各状态的动作见 [Varin 形象](varin-figure.md)。

产品语义与运行机制见 [长期总助手](bot-assistant.md) 和 [Bot](../bot.md)。本文只定界面：布局、每个区域的内容与状态、交互、动效、窄窗口与移动端，以及界面需要的数据。

## 1. 设计判断

1. **Bot 模式负责交流和统筹，执行现场留在工作台。** Bot 派发的子任务都是真实会话，工作台已经提供协作面板、文件、终端和权限。Bot 模式不再做第二套执行视图，所有“去看看”都跳到工作台的原会话，再一键回来。
2. **部件全部来自工作台。** 标题栏、侧栏、会话正文、派发成员行、右侧面板、滑动指示条、换字和晶格波都是现有部件，Bot 模式只改变它们装的内容。用户在两种模式之间不用重新学习。
3. **一个 Bot 通常就够用。** 侧栏默认收起，界面看起来是“和一个人聊天，旁边一张关于它的看板”。多 Bot 的入口一直在，但不占默认空间。
4. **注意力有顺序。** 需要你的事放在最显眼的位置，并说清楚去哪处理；正在进行的事只给一句话；已经发生的事按时间放进动态，想查时再看。界面上不出现计数徽标墙和状态字段表。

## 2. 布局

```

│ 侧栏      │ 会话                              │ ┌ Bot 区（固定）────┐ │
│ （默认收起）│                                  │ │  形象 · 名字 · 状态 │ │
│ Bot       │                                  │ ├ 概览 动态 记忆 日程 ┤ │
│  └ 会话   │                                  │ │ 页签内容（独立滚动）│ │
│    └ 分支 │            输入框                 │ └───────────────────┘ │
└──────────┴──────────────────────────────────┴───────────────────────┘
```

| 区域 | 尺寸 | 默认 | 说明 |
| --- | --- | --- | --- |
| 标题栏 | 高 46 | 显示 | 与工作台相同结构 |
| 侧栏 | 宽 268 | 收起 | `Ctrl B` 开合，状态按用户保存 |
| 会话正文 | 弹性，列宽 ≤ 720 | 显示 | 与工作台共用阅读设计 |
| 右侧面板 | 默认 360，可拖 300–560 | 展开 | 宽度和开合按用户保存；双击拖柄恢复 360 |

### 2.1 标题栏

- **左侧**：侧栏开关、模式切换器“Bot ▾”。侧栏收起时，如果别的会话收到了回报，开关上出现一个小圆点。
- **中间**：当前会话标题，下方小字是 Bot 名；分支会话显示“Varin · 从「旅行安排」分支”。
- **右侧**：Host 状态（Local）、右侧面板开关。面板收起时，如果有事等你，开关上出现暖色圆点。

## 3. 侧栏：Bot 和会话

结构与工作台的“项目 → 会话”相同，这里是“Bot → 会话 → 分支会话”。

- **顶部**：“新建会话”在当前 Bot 下创建会话，旁边是搜索（会话标题与正文）。
- **Bot 行**：小形象（20px，静止，不播放循环动作）、名字，右侧淡字是状态（休息中、等你）。当前 Bot 展开，其他 Bot 折叠。右键菜单：新会话、档案、让它休息 / 叫醒、置顶、归档、删除。
- **会话行**：缩进在 Bot 下面。右侧的图标会原位换出：运行中细圈、有新回报圆点、等你暖色圆点。分支会话再缩进一级，前面有分支线。每个会话都是 Bot 名下独立的会话，会话也可以再分支出会话。
- **底部**：新建 Bot、设置。
- 选中胶囊和悬停胶囊沿用工作台侧栏：选中用可打断的 glide 弹簧滑到目标行，悬停用 snap 跟随。

会话共用所属 Bot 的身份、档案、记忆和日程。子任务的回报回到发起派发的那个会话，侧栏因此能准确标出哪个会话有新内容。

## 4. 会话正文

会话正文沿用工作台的阅读设计，Bot 模式只多出以下几点：

- **派发**：“已分派 N 个任务”和成员行沿用工作台组件（头像、名字、任务、状态）。悬停时，右侧状态原位换成“在工作台打开 ↗”。点击后跳到工作台的原会话（见第 6 节）。
- **记忆**：Bot 在会话里记住或修订记忆时，沿用工作台的记忆工具行，写出记住的原文，例如“✓ 记住了 · 依赖升级前先锁版本”。点击后切到右侧记忆页签并高亮该条。
- **轮末操作**：复制、分支、重试在整轮结束后出现在最后，不夹在正文和派发之间。
- **回报**：子任务的回报以子 Agent 消息的形式出现在发起派发的会话里，带“发送者 → 接收者”路由，默认折叠两行。
- **静默处理**：Bot 处理了回报但没有对你说话时，正文里什么都不出现，记录进右侧“动态”。
- **新会话首屏**：Bot 形象（64px）、“和 Varin 聊点什么”、四条起始建议、居中的输入框。第一次发送时，输入框用 travel 停靠到底部（与工作台 3.1 相同，整个产品只有一个输入框实例）。
- **输入框**：附件、`@` 引用（事项、项目、会话、记忆）、模型（读写档案里的模型）、发送 / 停止。Bot 在休息或 Host 未连接时，输入框置灰，占位文字说明原因。Bot 正忙时，新输入沿现有队列排在输入框上方。

## 5. 右侧面板

### 5.1 Bot 区

面板顶部固定的一块，切换页签、切换会话时都不动。只有切换到另一个 Bot 时它才变化。

- **形象**：横跨整个 Bot 区，高 216px，窗沿从左到右贯穿面板，形象趴在上面（见 [Varin 形象](varin-figure.md)），她的团队坐在两侧的窗沿上。状态合同见 5.7。
- **名字**：20px 粗体，旁边一个小圆形编辑按钮（铅笔），点名字或按钮都打开档案页。
- **状态行**：一句话，按优先级取当前状态（见 5.7），行首是一个同色实心圆点，图形从圆点里镂空（等你确认是盾牌，有问题是问号，工作是脉冲，休息是月亮，醒来时转圈）。状态变化时原位换字。休息时行尾出现“叫醒”。
- **右上角菜单**：档案、新会话、让它休息 / 叫醒、设置。
- 窗口高度低于 720 时，Bot 区收成 64px 的横排（形象 40px、名字、状态），高度用 glide 过渡；横排不显示编辑按钮，点名字进档案页。

### 5.2 页签

页签是概览、动态、记忆、日程，做成一条圆角胶囊里的四个等宽图标段（列表、历史、记忆、日历；记忆是对话气泡里夹一枚实心书签，表示从对话里留下来的东西），名字放在悬停提示里，也是各段的无障碍名称。选中段由一个滑块标出，滑块用 glide 滑动，可以中途改道；段与段之间是细竖线，挨着选中段的两条让开。内容切换时，旧内容 110ms 向反方向淡出，新内容从切换方向进入 8px，前 6 项每项错开 18ms。不在当前页签时，如果有新的“需要你”，概览页签上出现暖色小点；如果有新动态，动态页签上出现中性小点，看过后清除。小点按 Bot 分别记录，切换 Bot 时跟着换。

### 5.3 概览

每块一句话，点任意一块就切到对应页签，并让对应条目闪一下高亮。

| 块 | 内容 | 点击 |
| --- | --- | --- |
| 需要你 | 有才出现，最多 3 张卡：头像、执行者、它在等什么、“去处理 ↗” | 跳到工作台原会话里的权限卡或问题卡 |
| 进行中 | 头像叠放、“2 项在进行”、最新一条实时动作 | 切到动态 |
| 刚刚 | 最近一次回报：谁、何时、回到了哪个会话 | 切到那个会话并定位到回报 |
| 记忆 | 最近记住的一段原文和它的来源 | 切到记忆并高亮该条 |
| 日程 | 下一次触发的时间与名称 | 切到日程 |

新 Bot 没有任何工作时，概览只显示一句“交给 Varin 的事会出现在这里”。

### 5.4 动态

动态是工作的全貌：派发了什么、执行了什么、收到了什么、你在工作台做了什么。

- **范围切换**：全部会话 / 本会话。因为回报回到原会话，“本会话”可以准确只列出从当前会话发起的工作。
- **进行中**：每项工作一行，包括头像、执行者、任务、所属会话（在“全部”时显示）和状态（等你、正在…、排队中、已暂停）。点击跳到工作台。
- **时间线**：按天分组，每条是时间加一句话，涉及的人名加粗。
  - 记录这些事：派发、再次交办、返回结果、暂停 / 停止、你在工作台的改动（青色圆点）、静默处理（“处理了 2 份回报，没有打扰你”，可展开查看是哪几份）、记住或修订记忆、日程触发。
  - 点击一条：派发和回报跳到工作台或原会话，记忆类跳到记忆页签。
- 停止相关的几种状态分开表达，例如“已让它停下，还没确认停住”。

### 5.5 记忆

- 顶部是搜索框和“当前 / 全部”切换。“全部”包括已不再适用的条目和修订历史。
- 每条记忆是一整段原文，下面一行写日期和来源。已不再适用的条目淡显，带标签。
- 点击一条，它原地展开（3.8 的高度过渡），显示：
  - 来源列表：日期、所在会话、原话摘录、“打开原话”。
  - 修订记录。
  - 三个操作：编辑、不再适用、忘掉。
- **编辑**：原地换成文本框，保存后作为一次用户写入。
- **忘掉**：先原地换成确认句：“忘掉后，之后的对话不会再用到这段，相关概述会重建。已经发出的请求无法撤回。”确认后文字淡出，条目高度收起，下方条目同帧上移。

### 5.6 日程

- **接下来**：左列是时间（等宽数字），右列是名称和目标会话。
- **重复规则**：每天、每周等，已暂停的标出。
- 点一行原地展开：规则、目标会话、错过时“跳过 / 补一次”。编辑沿用现有日程对话框。
- 底部是“新建日程”。也可以在会话里直接说“每天 9 点告诉我…”。

### 5.7 形象状态合同

形象组件收到一个状态，自己负责姿态和状态之间的过渡。美术为每个状态提供一个姿态，可选一段循环动作。

| 状态 | 判定（优先级从高到低） | 姿态 / 动作 | 状态行 |
| --- | --- | --- | --- |
| 离线 | Host 未连接 | 去色、眼睛暗，不播放循环 | 电脑没连上 · 只能查看 |
| 休息 | Bot 处于休眠 | 闭眼、面罩变暗、zz | 休息中 · 叫醒 |
| 唤醒中 | 正在唤醒 | 睁眼动作 | 正在醒来… |
| 等你 | 有权限或问题等你 | 看向你、暖色光晕呼吸；进入时轻跳一次（settle） | 写作在等你确认 |
| 思考 | 她自己的会话正在生成 | 眼睛看向斜上方，慢慢左右 | 正在想… |
| 工作 | 有子任务在运行 | 眼睛向下、轻轻上下浮动 | 写作正在编辑 · 12 分钟 / 2 项工作在进行 |
| 倾听 | 你正在输入 | 眼睛略微睁大 | 在听 |
| 空闲 | 其他 | 偶尔眨眼 | 空闲 |

- 小尺寸（侧栏 20px、标题栏返回按钮 14px）只显示姿态，不播放循环动作。
- 不可见时暂停循环。“简化”级别只保留姿态切换的淡入淡出。
- 状态行是系统根据真实状态写的中性陈述，不使用第一人称，不冒充模型发言。
- 结果不是状态：回报、回复、完成只是叠在当前姿态上的一次反应（5.7.3），不再有 3 秒的“有结果”。

#### 5.7.1 她自己的回合

Bot 区的大形象在上表的基础上细化（`stagePose`）：离线、休息、唤醒、等你保持原样；否则她自己的回合优先，其次是你在输入，最后是看着窗沿上的团队。

| 姿态 | 判定 | 动作 / 道具 | 状态行 |
| --- | --- | --- | --- |
| 准备 | Run 已接收、准备或排队 | 前倾，耳边一个省略号气泡 | 正在准备… |
| 思考 | 模型在推理 | 同“思考” | 正在想… |
| 回复 | 模型在输出文字 | 沿用“工作”的打字动作 | 正在回复你 |
| 查看文件 | `file_read`、`document_read` 等 | 双手捧一张纸，高亮逐行下移 | 正在查看 workbench.md / 正在查看 3 个文件 |
| 检索 | `file_search`、`file_list`、`code_retrieval`、`language_*` | 放大镜沿窗沿扫过 | 正在检索 |
| 网页 | `websearch`、`webfetch`、`browser_*` | 一个小浏览器窗口，页面滚动 | 正在查看网页 |
| 编辑 | `file_write`、`file_edit`、`apply_patch` 等 | 窗沿上一张纸，拿笔逐行写 | 正在编辑 notes.md |
| 命令 | `process_*`、`script_*` | 窗沿上一个小终端，敲键后输出滚动 | 正在运行命令 |
| 记忆 | `memory` | 手按太阳穴，一张便签飞进来化成光圈 | 正在翻记忆 |
| 计划 | `todo` | 一张清单卡，逐项打勾 | 正在更新计划 |
| 其他工具 | 其他真实工具（MCP 等） | 窗沿上一个她在转的小齿轮 | 正在使用 figma |
| 看着团队 | 在协调成员（`dispatch`、`send` 等），或团队在工作而她没有回合 | 眼睛停在刚有动静的成员身上，偶尔点一下头 | 同“工作” |

- 工具按运行时登记的确切名字分类，不看参数和文字（`botStageTools`）；文件名只取基本名。
- 准确的工具名来自中间打开的会话自己的投影（`ThreadConversation` 的 `onActivity`）。后台会话只有 Host 注意力读里的粗阶段：推理、输出、调用工具，这时道具是齿轮、状态行不写名字。
- 多个同类调用一起跑时写数量；最后一个调用决定道具。

#### 5.7.2 窗沿上的团队

她的会话直接交办的成员是负责人，负责人再交办的是它的子 agent。数据只来自 Host 的注意力读（`ThreadsAPI.attention()`，整台 Host 一份不含正文的快照）：委派关系、当前执行、回报和交付游标、需要你的项。

- **座位**：负责人按到场顺序左右交替坐在她两侧。
  - 每侧先“探头”：从窗沿后露出头，双手搭在窗沿上。
  - 排不下就“并坐”：小一号并排。
  - 还排不下的收进“+n”堆。留在堆外的顺序：在等你的、刚有动静的、正在干活的、其他。堆里有人等你时堆上亮一个暖色点。
- **子 agent**：探头时最多 3 个小脑袋坐在负责人前面；并坐时是窗沿上的小色点，最多 3 个，或 2 个加“+n”，都不超出负责人的座位。
- **头顶小记号**：思考是三个点，回复是带光标的气泡，用工具是一颗星，等待是沙漏，准备是带点的气泡，等你是暖色感叹号加扩散的圈。
- **动作**：派发时她朝那一侧抬手甩出一张卡，卡落到座位上成员才出现；再次交办是纸飞机。子 agent 的派发和回报只在负责人和子 agent 之间飞小卡、小信封。负责人回报时信封飞到她面前的窗沿上，最多叠 3 封，再多显示数量；她的回合确认收到时把信封收进来。成员需要你时她指过去，然后看回你。
- 编辑按钮放在名字旁边，把窗沿让给团队。窗口高度低于 720、手机底部面板这些横排里不显示团队，概览照常列出。
- 只演真实发生的事：第一次读到某个 Bot（或存储换代）只建立基线，之前发生的不回放；页面隐藏、滚出视野或“简化”动效时只摆好座位，不补演。

#### 5.7.3 结果分级

每个结果先按离你多近、分量多大定一个基础级别，再按当时的情况只往下调（`botStageReactions`）。成员各自的进度只改它们头上的记号，不牵动她。

| 级别 | 她的反应 | 基础来源 |
| --- | --- | --- |
| 0 只在成员处 | 她不动 | 负责人派发子 agent、子 agent 回报负责人 |
| 1 看一眼 | 只动眼睛，看向那个成员 | 负责人回报落到窗沿、负责人离场 |
| 2 点头 | 收下回报时双手一拢、点头；有失败时皱眉 | 她收下回报、你处理掉一件等你的事 |
| 3 呈现 | 转向你，双手托出一张卡；有失败时表情认真 | 她回复了你，或请求完成 |
| 4 完成 | 收敛的举手和几颗星星 | 请求完成，而且大（2 位以上负责人、用了子 agent 或超过 2 分钟）、全部成功 |

- 回复和完成的区别：她的回合以可见的回复结束时，还有成员在为这个会话工作就是“回复”，没有了就是“完成”。安静结束的回合不算。
- 有事等你或出错时只保留 0；处理掉等你的事仍然点头。你正在输入时最多看一眼。
- 同类结果间隔不到 1.2 秒合并成一次；1.5 秒内已经看过一眼就不再看。
- 热情值最多 4 格，每 15 秒恢复 1 格；点头花 1 格，呈现 2 格，完成 3 格，不够就降一级。对你说的话（回复、完成）最低保留点头。
- 状态行同时用 2.6 秒点名这一刻：交给了调研、调研返回了结果、调研没有完成、收下了 2 份报告。离线、休息、等你时不覆盖。

### 5.8 档案页

点名字或菜单里的“档案”，档案页从右侧推入，盖住页签内容；Bot 区和页签栏保持原位，滑块淡出。档案页包含：

- 名字、标签
- 合作指令（多行，写成一段话）
- 模型
- 后台记忆整理开关
- 让它休息 / 叫醒
- 归档、删除（危险区）

有改动时底部出现固定操作栏“放弃 / 保存”。关闭前沿用现有草稿守卫。设置页的 Bot 列表点进来也是这一页，不再嵌套对话框。

### 5.9 拖宽与收起

- **拖柄**：面板左缘 8px 宽的感应区，悬停时显出一条细线。
- **拖动**：宽度 1:1 跟手。超出 300–560 时有阻尼，越界部分只走 30%。松手后用 glide 回到边界。
- **拖到收起**：拖到 240 以下松手，面板收起。
- **键盘**：拖柄可以获得焦点，左右方向键每次调 16px，Enter 开合。
- **按钮开合**：宽度由 glide 驱动，正文在开始时一次排到最终宽度。面板内容贴着前缘出来，带 28px 视差。打开时内容很快变实，关闭时一直保持可读，到最后 200ms 才淡出（与工作台 3.10 相同）。

## 6. 跨模式：去工作台，再回来

- **去**：点派发成员行、动态里的工作、需要你卡片上的“去处理”，都会切到工作台。晶格波从点击的位置向外铺满窗口，约 380ms；铺满的那一帧提交工作台并打开原会话，再从同一点向外揭开，约 400ms。
- **在工作台**：标题栏多一个返回按钮“← Varin · 日常”（14px 形象、Bot 名、来源会话）。会话标题下方写“由 Varin 交办”。工作台侧栏里，Bot 交办的会话照常列在所属项目下，带一个小 Bot 标记。
- **回来**：点返回按钮，晶格波从四周收回到这个按钮，回到 Bot 模式。恢复原会话和阅读位置，刚才点过的那一行闪一下高亮，告诉你是从哪里出发的。
- 在工作台的操作沿原 owner 生效，包括批准权限、给子 Agent 发消息、停止任务。这些变化带来源回到 Bot，显示在动态里。

实现：`openThreadFromNavigation` 让 Bot 的会话留在 Bot 外壳，带 `parent_thread_id` 的子任务进入默认工作台。Bot 外壳不再列出工作，也不在中间区挂子任务会话。

## 7. 动效编排

令牌沿用 motion 稿：snap、glide、travel、settle 四个弹簧，淡入 160ms，退场 110ms，交错 18–24ms。同一时刻只有一个主角动作。

| 交互 | 主角动作 | 其余变化 |
| --- | --- | --- |
| 右侧面板开合 | 宽度 glide，正文一次排版后平移 | 内容 28px 视差，透明度按 5.9 |
| 拖宽 | 1:1 跟手，越界阻尼 | 松手 glide 回到边界或收起 |
| 页签切换 | 滑块 glide，相邻竖线让开 | 内容方向性交叉淡入，前 6 项交错 |
| 概览块到页签 | 按压缩到 .98（snap），切页签 | 目标条目背景高亮约 900ms 后淡去 |
| 档案页进出 | 从右侧 24px 推入（travel） | 滑块淡出 / 回位 |
| 切换会话 | 旧内容向列表反方向 110ms 淡出，新内容按回合交错进入 | 标题按同一方向换字，选中胶囊 glide |
| 切换 Bot | Bot 区：旧形象缩到 .9 淡出，新形象 settle 落位 | 名字、状态换字，页签内容交叉淡入 |
| 新派发 | 会话里的成员行 settle 进场，头像轻转落位 | 动态里的新行 FLIP 插入，概览数字原位换字；形象甩出一张卡，成员在窗沿上落座（5.7.2） |
| 有事等你 | 形象轻跳并亮起暖色光晕 | 概览顶部卡片用 settle 长出，下方同帧下移；页签或面板开关的圆点用 settle 弹出 |
| 回报回到别的会话 | 侧栏会话行图标换成圆点（settle） | 概览“刚刚”换字；信封飞回窗沿，形象按 5.7.3 分级反应 |
| 记忆展开 / 忘掉 | 高度 glide，下方同帧跟上 | 忘掉时文字退场：淡出加 2px 模糊 |
| 去工作台 / 回来 | 晶格波 | 标题栏随外壳一起被替换 |
| 新会话首次发送 | 输入框 travel 停靠 | 起始建议依次下沉淡出 |

降低动效沿用 motion 稿第 5 节：“简化”只保留 ≤160ms 的透明度变化，晶格波改为交叉淡入；“关闭”直接切换。形象在“简化”下不播放循环动作。

## 8. 窄窗口与移动端

| 宽度 | 侧栏 | 右侧面板 |
| --- | --- | --- |
| ≥ 1280 | 推开正文 | 推开正文 |
| 1024–1279 | 打开时浮在正文上 | 推开正文 |
| 760–1023 | 浮层 | 浮在正文右侧的悬浮卡片（圆角 14、阴影），不挤压正文；默认收起，点正文区域收起，回到宽窗口时恢复原来的开合 |
| < 760（手机） | 从左边缘滑出的抽屉 | 底部面板 |

手机上：

- **标题栏**：中间是紧凑的 Bot（形象 26px、名字、状态行），点它打开底部面板。
- **底部面板**：Bot 区在面板顶部，页签在下面，可以拉到半屏或全屏。拖动跟手，松手按速度（> 0.5px/ms）或位移（> 35%）决定收起，否则 glide 回弹。
- **触感**：只在提交点轻触：发送、切换会话、去工作台。
- **通知**：点开后落到对应会话的对应消息，或者落到需要你处理的那张卡片。

## 9. 深色与可访问性

- 颜色全部取自工作台令牌（`--bg`、`--fg`、`--muted`、`--warning`、`--link` 等），深浅两套共用一份结构。暖色只给“需要你”，青色只给“新”和“你的改动”。
- 页签是 `tablist`，方向键切换；拖柄是 `separator`，带 `aria-valuenow`；状态行是 `aria-live="polite"`，只播报有意义的变化（等你、成员返回了结果、离线）。
- 所有可聚焦控件在 `:focus-visible` 时显示焦点环；Esc 关闭档案页和弹层。

## 10. 界面需要的数据

| 界面 | 需要 | 现状 |
| --- | --- | --- |
| 侧栏会话 | Bot 名下的多个独立会话及其分支；每个会话的运行中、新回报、等你 | 现在一个 Bot 只有一个入口会话；需要新增 Bot 会话关系（Catalog 中 Bot 拥有的普通会话） |

| 概览 / 动态 | 进行中的工作（执行者、任务、来源会话、状态）；时间线事件（含静默处理、用户介入） | Catalog `runtime.bot.activity.read` 按 Bot 汇总分页，Host `/activity` 透传 |

## 12. 实施状态

代码在 `packages/ui/src/workbenches/bot/`。外壳 `BotWorkspaceShell` 通过 `MainLayout` 的 `renderSecondaryPanel`、标题栏的 `navigationSubtitle`/`panelControl` 接入，侧栏、会话正文和晶格波沿用工作台部件。

已实施：

- 多会话：Bot → 会话 → 分支的侧栏（`BotNavigator`），新建会话、按标题搜索、运行中 / 新回报 / 等你标记，选中与悬停胶囊。侧栏开合按 Bot 单独保存，离开 Bot 时恢复工作台原来的开合；窗口窄于 1280 时侧栏浮在正文上，点外面或选中会话后收起，这时的开合不计入偏好。
- 右侧面板（`BotPanel`）：停靠时与会话正文连成一个面，不留缝、不做卡片圆角，会话顶边延续过来，两者之间只有一条淡分隔线；窄窗口浮层仍是带描边的卡片。Bot 区（形象与窗沿上的团队、名字旁的编辑按钮、带状态圆点的状态行）、胶囊式图标页签与滑块、内容方向性交叉淡入和前 6 项交错，概览块到页签的高亮，页签小点（按 Bot 记录已看过的位置）。拖宽 1:1 跟手、越界 30% 阻尼、240 以下松手收起、双击恢复 360、拖柄方向键与 Enter；窗口高度低于 720 时 Bot 区收成横排；760–1023 宽度浮成卡片，点正文收起。
- 页签内容：概览（需要你、进行中、刚刚、记忆、日程）、动态（全部 / 本会话、正在跟进的事项、进行中、按天分组的时间线）、记忆（搜索、当前 / 全部、原地展开来源与修订、编辑、不再适用、带确认的忘掉）、日程（接下来、重复规则、原地展开，编辑与新建沿用日程对话框）。
- 档案页从右侧推入：名字、合作指令、模型、后台记忆整理、休息 / 叫醒、归档与删除；有改动才出现“放弃 / 保存”，离开前确认。其他 Bot 的档案仍用原对话框，不切换当前会话。
- 形象（`BotFigure`，`varinFigureRig`）：第 5.7 节的状态与优先级；40px 以下只取头部并保持姿态，页面隐藏或滚出视野时停止循环，“简化”只保留姿态切换的淡入。
- 舞台（5.7.1–5.7.3）：`useBotStage` 在 Bot 工作台显示时开一条 Host 注意力观察（与桌宠同一个 `CompanionAttentionCoordinator`），`botStageDirector` 把快照和打开会话的实时工具调用换成她的回合、团队座位和这一刻发生的事，`botStageRenderer` 在形象的窗沿图层里画团队、飞卡片并按 `botStageReactions` 分级反应。
- 跨模式：派发成员行悬停换成“在工作台打开”，需要你卡片与动态里的工作都进入工作台原会话；工作台标题栏显示返回按钮和“由 Bot 交办”，返回后点亮出发时的面板条目。会话里的记忆工具行可以打开记忆页签。工作台侧栏把 Bot 交办的会话列在所属项目下，带小 Bot 标记；Bot 自己的会话不进入工作台侧栏。
- 新会话首屏用形象和“和 Bot 聊点什么”，起始建议与输入框停靠沿用工作台。阅读位置沿用会话时间线自己的视口记录。
- 手机：标题栏中间是紧凑 Bot（`BotMobileTitle`：26px 静止形象、名字、状态行），点它开合底部面板，标题栏右侧不再单列面板按钮；这时工作台的主页签条让给它，与桌面 Bot 标题栏只显示会话标题一致。底部面板（`MobileBottomSheet`）打开到 55% 高度，可拉到全屏；松手按 0.5px/ms 或 35% 位移决定换档或收起，否则回弹；点暗色正文收起。面板里的 Bot 区固定用横排。
- 动态：读取 Host 按 Bot 汇总的分页（见 [Bot](../bot.md)），工作变化稳定约 600ms 后重读最新一页，“更早的动态”向下续页。新一页与已加载部分在 cursor 上相接才合并，否则只保留新一页。后台回合显示为“处理了 N 份回报，没有打扰你”，可展开查看是哪几份并跳到对应工作；日程触发、你在工作区的改动和历史调整各有自己的句子。没有记录时间的旧事实留在原位置，不显示时刻。
- 形象：所有未归档 Bot 的需要你、进行中、正在回复都来自 Host 推送的 `presence`，侧栏里未选中的 Bot 也会显示等你或工作中。

尚未实施或与本稿不同：

- “离线”取线程目录观察失败；“在听”仍由界面本地判定。
- 后台会话（不是中间打开的那个）的工具只有粗阶段，道具一律是齿轮。
- 外部 Harness 的回报和被跟进普通会话的完成不进入动态时间线，只在后台回合的输入里出现。
- 侧栏搜索只匹配会话标题。
