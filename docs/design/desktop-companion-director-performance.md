# Varin 动作重设计：连贯的身体表演，而不是姿态切换

状态：2026-10-29，**当前重设计稿，尚未实现**。用户否定了交付视频的整体联动、身份一致性和方向绑定；当前 `1303a698…` 包已运行不等于视觉获认可。本文替换旧叠加矩阵，旧稿由 Git 保留；源图、manifest、验收记录不删除、不重写。

本轮目标：让她作为同一个有重量、有支撑、会回应的人自然动起来。动作不必追着某个项目位置转头或指人；具体项目由准确的信息层说明，人物承担通用的注意、整理、呈交、等待与陪伴。

## 1. 交付画面的具体问题

审阅依据：已交付视频 `varin-current-complete.mp4`（SHA256 `73c33a9c52b817c40812baea62391671f96d33d3d34fc9c9687c1f4f30119340`）的实际帧、峰值图及伴随逐曝光记录。该片是显式演示事实，不是真实业务运行；本文不声称视频或proof已归档到repo。

- 4.2–5.2秒的倾听主体只有 TURN→LEAN→同TURN→rest。脸和头胸明显换姿，支撑身体缺少同一股运动中的起势、承重调整与收势；中间画存在不等于动作已连起来。
- 20秒轻关注先由监督握机手切到键区手，再播两张近身姿态，随后又换回监督手。一次很轻的回应被两次手位往返包围，桥比意图更显眼。
- 分别生成、局部注册头胸，虽然保住了外围像素，却把应该响应的肩、肘、衣袖和发束锁住；一动便像在固定身体上换一个低头的脸。
- 多组原画各自看起来可用，但脸型投影、胸肩体积、袖口宽度与接缝不是同一条运动连续推演的结果。静态同框和外部mask一致不能证明动态身份稳定。
- 前倾、接收、倾听、提醒频繁共用“头变低”的读法，缺少手臂、胸肩、重心共同构成的动作差别。增加状态名、表情名或加速切图无济于事。
- 30秒理发到smooth便被拖起。它验证了中断路径，却没完整展示日常动作如何放手、回位、安静下来；示范片不能把所有表演剪成峰值集锦。
- 把负责人搬到报告槽来配合固定左右头姿，是为既有原画服务的补救。真实队形、人数、边界变化复杂，不应继续让主身体依赖项目坐标。

**纠偏原则：先形成共同的坐姿与接触关系，再制作完整的运动句。SHA、逐源抓放覆盖和播放器可达性是安全条件，不是审美验收的替代品。**

## 2. 一个人，两种工作关系，共用身体语言

| 域 | 她实际在做什么 | 通用身体表演 | 对象如何表达 |
|---|---|---|---|
| Bot统筹 | 接住安排、组织负责人推进、理解汇报、递交需要用户决定的事 | 坐正接住、收拢整理、面向用户呈意、安静关注 | 项目/负责人身份和已知关系由小队及内容层说明，不要求她指向具体B |
| Agent桌宠提醒 | 用户直接与主agent工作；她提醒用户注意问题、授权、结果与异常 | 停一下、抬起表达手、温和呈意、收手等候 | 提醒带确切来源；不演她接单、分派、审批或重新汇总主agent工作 |
| 共用陪伴 | 自然坐着、回应靠近与轻点、日常整理、困醒、真实提放 | 同一支撑下的身体反应、少量生活动作 | 不伪造离席/回来、业务确认、允许或完成 |

人物不做项目索引器。没有“项目A朝左、B朝右”的身体合同；不自动逐队巡看，不要求每个布局都有一套yaw/pitch。必要的正视用户是交流对象，不是追踪屏幕坐标。

具体来源由稳定头像、短名、锁/问号和队内有限动效表达；真实更新先显示，Varin在安全边界一次通用回应。选项目不再必走左右LISTEN或负责人移动到手边流程；不让纸件飞穿身体假接触，不用外围热闹掩盖身体缺陷。

## 3. 先统一舒服的坐姿与支撑，而不是锁死双手

### 3.1 两个机械端点，一种身体习惯

**共同休止位可复用真正相容的已有原画，也可从候选中选定；必须通过实际接触与跨句动态验证，不能因图已存在就声称支撑问题已解决。**

- 保留开盖、闭盖两个真实机械端点；镜头、骨盆座位、腿长、电脑尺寸与凳体比例一致。
- 监督、提醒、轻互动共用同一开盖休止姿态；不再为了hover先从“握屏幕边”换成“敲键盘手”。
- 默认电脑底座由大腿承重，稳定手与表达手按实际姿态验证后统一分工，不是用户强制的左右侧别。每套连续动作以选定原画中真实成立的接触分工为准；不能中途无交接换手或镜像掩盖问题，也不永久紧抓竖直屏幕。
- 这套支撑关系须用真实全身/上身连贯原画确认；若与现精确机械端点手位不同，制作可靠的代际入口/开合接续，不能直接换掉既有端点像素。新五族之间只回共同新休止位；不再分别退回旧listen-rest/open-user而每次重走旧桥。“一次接续”指新家族入口，不是每个动作前后又接一次。
- 闭盖沿用相同身体习惯与手的归位区域。开合只改变必要的手接触与盖板角度，不顺便改变脸型、坐高或衣装。
- 普通动作中电脑可稳定放在腿上，表达手能离开，肩肘才能自然行动；稳定不等于胸肩、手腕、衣袖全部不许动。

### 3.2 身体如何有重量

- 骨盆坐稳，坐骨不来回漂；小前倾从髋与下胸开始，胸口向前、上背略跟随，不能只把头向下替换。坐稳不等于髋胸大腿整片像素冻结：逐拍校核胸口与屏幕间隙、扶机腕肘随动、大腿承托与衣料遮挡，必要区域一起重画；电脑不能因重心变化倾覆，手不能沿机身滑穿。
- 稳定手先轻压底座，肘角相应改变，再允许表达手离开。手掌离开原接触点后，袖口才垂下来；手回位先到达、再承重，肩最后放松。
- 头颈跟着胸肩保持自然长度。可以小幅俯仰，但下巴、耳位、发际线必须属于同一头骨的连续运动；不以整头旋转或独立脸片代替。
- 肩上的发束随肩先动，外侧长发稍后跟上，末端再轻轻停稳；不是全头长发同时摆动，也不是头已前倾而全部发束钉死。
- 袖子因肘弯而改变褶线、因前臂落下而下垂；腰带、吊坠和衣襟保持同一连接位置。吊坠只允许很小的滞后，不能换形、变实心或在胸前游走。
- 腿脚主要安静。若有真正舒适调整，需交代重心及膝踝关系，不能单独晃靴子伪造全身灵动。

## 4. 紧凑而完整的五个动作族

以下是共用动作语法，不是五个动作覆盖所有事实。每族可以有短、标准、保持版本，但必须来自同一运动路径，而非独立生成许多相近峰值。短版/半句不能简单裁峰值、加速或倒放标准句：分别有真实安全停靠点和完整落手回程，才允许编排调用。下文时长只是常速审片初值，服从真实动作路径，不是固定播放指标。

### A. 安放自己：自然坐、放松、困醒

**自然坐与短放松**
1. 开始：骨盆稳坐，电脑落在腿上，稳定手保持接触；表达手从稍紧的搭放逐渐松开。
2. 中段：胸肩轻轻落下来，肘部随之放松；头维持直颈，眼睛正常睁开，表情不替代身体松弛。
3. 收尾：手指安放、袖口落定，肩旁发束最后停稳，进入长安静段。
4. 持续：在完全相同头位上稀疏眨眼、短眼笑即可；不永久摆头、不每几秒重播放松，不缩放整人做呼吸。

**一次生活整理**
- 理侧发保留完整意图：稳定手压住电脑→另一手脱离→肘抬起→指尖到达一小缕侧发→轻顺下→先离开发丝→肘下落→手归位→袖发停稳。
- 现P3是画面左手抬起、右手扶机，但并不自动兼容任何新的休止手位与身体。必须确认稳定手真实到位、电脑承托和起落路径一致；若需换手，先真实承接支撑再让另一手离开，返回也交代支撑交还，必要接续须真实原画。旧P3只作接触素材和动作参考，不能因手侧相同或有五张新图就直接套用。
- 小整理与真正肩背舒展都进入本轮完整覆盖，按各自接触和受力链分组制作，不用同一挥手换名凑数。舒展必须有背部/肩胛/肘的完整路径；现哈欠不冒充伸展，尚未画好的环节明确留作待制作，不先在运行时借用错误动作。

**困意与醒来**
- 困意从身体放松开始：双手先安放、胸肩缓慢卸力，最后眼睑才沉下来，头仅一次轻微自然俯仰；不能把清醒身体直接配闭眼脸。
- 醒来先睁眼重新定位，再恢复胸肩支撑，手握稳电脑，最后回舒服正位；不突然弹头，也不按整句倒放。
- 仅明确安全长idle允许小憩。新输入/任务立即解除休闲资格，信息即时显示，身体走真实醒来接续。

### B. 回应你：靠近、轻点、重复轻点、回来招呼

**标准关注句，约0.8–1.3秒起落**
1. 开始：原接触关系不换；稳定手轻定住底座，胸口稍坐起，表达手从松搭变为有意的轻搭。
2. 中段：上身小幅向用户靠近，肩肘共同跟进，颈部自然延伸，眼神再形成明确注视；不是突然换一张低头脸。
3. 峰值：短停一拍，眉眼柔和；头部体积、电脑与腿的关系保持。手可以轻抬一点表达“注意到你”，不必须挥手。
4. 收尾：胸口先回舒适坐位，肘和手归位，头随胸肩回正，发梢最后停；收势不直接切回母版。

- 忙中采用这条路径的短幅度版，保持相同手位，不先走另一族手势桥；过渡忙碌时延后社交，不打断重要交接。
- 闲时轻点可让表达手在身体前方做一次小招呼，再回位；手势面向用户，不对准鼠标或项目。
- 重复轻点只一次轻俏皮变化：前次已收好后，表达手短暂停住，眉眼略带笑意，再放松回去。不是不停切不同脸、不是被越点越生气。
- 现P1/P2只是姿态/表情参考。P2同头位眼笑可保留；P1的头胸注册不能直接作为新联动通过证据。
- 回来招呼仅由可靠本地活动触发，短欢迎与同族共用起落；普通焦点变化、重连或历史事件不补播欢迎。

### C. 收拢并呈意：通用管理，不指具体负责人

**一条清楚的“接住—理清—交代”身体句，约1.4–2.2秒**
1. 接住：稳定手先保持电脑，表达手从底座近侧松开；肘在身体前侧抬起，掌心微向内，胸肩稍坐正。动作发生在自己身前，不伸向某个队位。
2. 理清：前臂作一次短而缓的内收，掌心靠近胸前下方但不碰吊坠；肩肘与手共同收束，头仍自然面用户，可短看自己的工作区域而不追项目。
3. 呈意：肘略向前送，手腕展开为面向用户的开放掌；胸口随前臂有很小的向前意图，头颈跟随，不只有孤零零一只手移动。
4. 收好：手腕先回中性，前臂沿自己身前落下，掌指到达归位区，再放松肩；袖口、侧发随后停稳。

- 接收新安排使用“接住”半句，之后可以真实进入理清/监督；不每条更新都完整演一遍。
- 分派、协调、听取汇报使用这条通用句的不同节拍：交代突出一次开放掌，理解汇报突出短收拢后稳定关注；不再以左右LEAN说明“正在听B”。
- 汇总成果用完整内收→呈意，内容显示真实范围；没有实物接触原画时，摘要停靠工作区，不把纸卡黏在掌心假抓。
- 平稳监督用共同自然坐姿，不持续输入、不轮询式转头、不反复播放收拢。小队自己的工作动效承担执行过程。
- 这族真正缺的是肩肘前臂统一运动的进入、内收转腕、展开、归位与停稳画，而非又一张开掌峰值。

### D. 提醒并等候：问题、授权、结果与意外

**通用提醒句，动作明确但不催促**
1. 起势：原正在做的小动作停下来，表达手从归位区松开，胸肩坐稳；不是惊跳或突然低头。
2. 呈现：前臂抬到胸口以下的舒服高度，掌心向用户开放，眼神明确看用户，给信息一个短而完整的呈现拍。
3. 等候：前臂真实落回，身体保持可交流的正位，标记和内容继续可查；不是永久举手、不断眨眼催回答。
4. 收尾：确切事项更新后，短确认注意，再回同一自然端点；若还有其他事项，维持安静可用而不整句重播。

- 问题：眉眼一次温和疑问即可，头不长期歪；授权：停手更明确、呈掌更平稳，不点头盖章。
- 结果可查看：在同一呈意路径上加短眼笑，不把每个结果做成庆典；失败/未知：收起笑意，短认真停顿，依然温和陪用户看清内容。
- “用户看过”只收掉招呼动作，未回答/未授权的事实继续存在；本地轻点不能变成批准、已解决或业务确认。
- Bot中这是主管转呈，Agent中这是桌宠提醒用户去原工作台处理；身体可共用，信息来源与角色关系不可混淆。
- 多项同时出现只一段通用呈现，不排队把身体拉去多个方向，不以动画时长延迟真实内容。

### E. 受打断仍是同一个人：收手、抱稳、提起、落座

- 普通新事项：从当前动作阶段收束到最近可交流的支撑位，不强制每次“完整回母版→重新起手”。同一手位下能顺接时用实际转接画，不能靠名字相同就直切。
- 掌在半空：先收腕、肘落、手到达，再恢复承重；不要直接闪回键盘手。手正在接触发丝：先松开发丝，再落手，不能把接触阶段直接删掉。
- 真拖动成立：根位置及时跟随实际输入，同时当前手臂走真实脱离并抱稳电脑；身体不等待完整闲置句才被提起，也不在悬空时继续做理发/挥手。
- 抱稳后身体因承重改变而进入真实悬空姿态，袖发有合理滞后；电脑仍为同一刚体，不能连带改变脸型、腿长、靴子大小。
- 落座：凳体/身体接触→骨盆承重→膝腿和胸肩落稳→表达手放回→发袖停稳。不能用整人上下缩放或最后一帧硬切模拟缓冲。
- 释放后恢复最新事实，不重播拖动前的项目交接或休闲动作；醒来、拖放和主动输入重置休闲资格。

### 五族的具体动作覆盖与共享边界

**下表是完整制作目标，不是已完成数量。** 同一行可以含同路径的幅度/表情变体；不同业务标签不各造一套动画。`E` 是准备与进入，`H` 是有意义的动作中段或可停靠保持，`X` 是真实收势与重新接触。`R开/R闭` 只是待统一的新开/闭盖休止位的设计简称，不是已经存在的资源 ID。每句还须制作它允许被中断的出口，不能只交一个峰值和回母版跳切。

#### A族：安放、生活与困醒

| 句子/变体 | 准入与意图 | E → H → X | 可共享与必须独立的来源 |
|---|---|---|---|
| A1 安静共处：自然睁眼、稀疏眨眼、轻眼笑 | 平稳工作或安静陪伴；不把眨眼当执行进度 | 从共同端点自然安放 → 长安静段，间或同头位真实眼睑/嘴变化 → 保持原支撑，不每次起落全身 | 共享R开/R闭各自的同头位脸部变化；不同头骨角度不能共用贴脸。身体不循环缩放呼吸 |
| A2 松一口气、舒适坐稳 | 普通稳定时的偶发身体调整；不是完成庆祝 | 表达手松搭、胸肩卸力 → 肘自然垂落、肩背舒服停一拍 → 手指到位、袖发停稳 | 与A1共享终点；胸肩/肘袖的松弛链独立，不由闭眼或低头替代 |
| A3 微调坐姿 | 久坐后的低频生活变化，不推断“用户累了” | 先稳电脑 → 小幅调整髋胸受力、腿保持可信承托 → 骨盆重落稳、再松肩 | 需真实骨盆/膝腿/衣摆遮挡来源；不能只移动靴子或平移整人。与提起落座不是同一受力链 |
| A4 顺一小缕侧发 | 明确安静，手能安全释放 | 稳定手到位 → 抬肘到达发缕、轻顺下 → 先脱离发丝、再落肘归手、发梢停稳 | 可参考旧P3接触顺序；接发、顺下、脱离须独立真实来源。不能将旧手侧相同当新端点兼容证明 |
| A5 小整理：顺平一处袖口 | 明确安静；与理发交替的少量生活变化 | 大腿稳定承托电脑、必要手支撑先转移 → 短捋袖口/抚平一处褶线 → 松开布料、归手、再恢复原支撑 | 需布料被碰触与释放、手支撑转移原画；不能拿理发改名。若双手支撑尚不成立，先修接触，不能无支撑地做完 |
| A6 真正小舒展 | 安静且可进入闭盖承托；不是哈欠的同义版本 | 先完成真实闭盖/安放 → 单臂小幅伸展、肩胛打开、胸背跟随 → 肘缓收、肩回落、手归位 | 独立肩胛/背部/肘腕受力链；电脑仍由大腿可靠承托，另一手可辅助稳定；具体接触随原画核清，不用夸张变形替代舒展。舒展是本轮完整目标之一，不用现哈欠顶替 |
| A7 困意、轻哈欠、小憩、醒来 | 仅可靠可见活动及全局事实满足现有安全长idle资格；没有“未选任务=可睡” | 放松、真实掩口哈欠并收手 → 眼睑渐沉、短自然点睡后安静小憩 → 睁眼定位、胸肩重新承重、手稳电脑、回R闭 | 哈欠掩口、困意卸力与醒来承重分别有真实链；可共享闭盖端点，不能倒放入睡当醒来。可只困而不睡；无整夜循环点头 |

A族的丰富来自真实不同的身体意图，而非随机挑十张脸。长安静仍占主要时间；不串成“眨眼→理发→理袖→伸展→打呵欠”的定时表演巡回。各生活动作完整制作后，才由低频、非机械重复的编排择一使用。

#### B族：回应用户，轻而有变化

| 句子/变体 | 准入与意图 | E → H → X | 可共享与必须独立的来源 |
|---|---|---|---|
| B1 注意到你：忙中短关注／闲时稍靠近 | 真实人物命中区停留；不是鼠标追踪或项目朝向 | 原手位下坐起 → 眼神聚焦、胸肩稍靠近，忙时只短幅度 → 胸肩回坐、肘手归位、发袖停稳 | 同一运动路径的两个幅度，均有完整回程；忙中短版不能裁峰值。开/闭盖端点各自验证，不为回应强开关盖 |
| B2 单次轻点：微笑／短招呼 | 真正完成的非拖动点击；不抢管理关键接触 | 保持电脑承托、轻注意 → 同头位微笑；明确闲时可小抬手招呼 → 手真实落回、安静 | 微笑可与B1共享；抬手招呼需自己的释放/回位链。关键交接中可舍弃，不攒到之后补播 |
| B3 再轻点一次：克制俏皮 | 上次回应已结束，持续互动且明确闲置；每burst至多一次变化 | 既有支撑下手轻停、神情稍活 → 轻抬眉/闭嘴小笑，读作“注意到啦” → 放松恢复 | 可共享B2的支撑与同头位眼笑，不依靠连切表情；开闭盖分别有相容源。忙/待决不播俏皮，不翻白眼、不假生气或点头批准 |
| B4 欢迎与再次互动 | 用户实际开启/恢复后合资格的真实本地互动；普通失焦、重连不算回来 | 从当前可靠端点注意用户 → 闲时一次小招呼，忙时短关注 → 手归位，恢复最新事实 | 与B1/B2共享动作素材，靠真实场景节拍区别，不另造“大欢迎姿势”；不宣称用户离席、在线或完成工作 |
| B5 注意自然退去 | 指针离开、一次回应结束、用户转去操作；不是业务解决 | 未起势则取消候选；已进入则走当前短回收 → 短自然安静 → 回原支撑 | 共享对应B句X，但需随实际阶段选入口；不能鼠标出界就瞬切母版，也不强行保持一段已无对象的挥手 |

#### C族：Bot的真实统筹，不追项目位置

|---|---|---|---|
| C1 接到安排 | 已核验Bot根及真正新派发边缘；首屏/复连不补演 | 共同支撑下坐正 → 表达手在自己身前短内收，表示接住安排 → 落手或进入可靠的C2接续 | 可共享C族前段；必须有半句独立落手出口。不真的抓纸，不向A/B递物 |
| C2 收拢整理／认真权衡 | 有实际Bot工作或待决上下文；不声称生成了计划、报告或完成审核 | 表达手释放、前臂内收 → 一次短而完整的收拢、认真停顿 → 手腕松回、安静监督 | 与C1/C3共用一致接触路径；内收转腕与肩肘随动需真实中间。不能用持续低头脸循环冒充思考 |
| C3 交代推进 | 真实Bot分派/协调语境，不是每个工具请求 | 从已成立的内收位或R开进入 → 面用户的一次开放掌，意图清楚但不指队位 → 腕回正、肘落、手重新到位 | 可共享C2→开放掌段，须有从R开直接进入的完整准备；信息层标具体负责人，不靠指尖导航 |
| C4 了解进展／持续跟进 | Bot检查或真实工作进展；不是Agent检查就听汇报 | 稳定支撑下短注意 → 安静认真保持，可有一次短收拢 → 放松回监督 | 复用C2的短幅度及A1保持；不新增左右LEAN，不等负责人跑到手边，不随token反复点头 |
| C5 汇拢并呈交 | 可核验的工作结果/待决范围；未结算工作仍保留 | 一次内收整理 → 通用开放掌面用户、短停清楚表达 → 真收腕落手、回稳态 | 与C2/C3共享连贯路径，完整句的收势另有来源；没有真实artifact时不画接报告。失败/取消/未知不统一庆祝 |

C1–C5是同一语法的使用情境，不是要求五套独立峰值。只有真正支持不同进入、保持、退出的路径才可叫短句/完整句；旧素材能到相似掌形不代表能无桥互接。

#### E族：真实提放的完整使用覆盖

| 情况 | 真实输入与连续路径 | 保持/恢复要求 | 独立来源边界 |
|---|---|---|---|
| E1 按下但未拖动 | 保留当前姿态，实际达到拖动阈值才进入抓取；正常pointerup才可能轻点 | 不预先悬空，也不按下即吞掉业务事实 | 输入所有权沿现原生逻辑；不是新增手势识别业务 |
| E2 从开/闭盖及表达中提起 | 根位置及时跟手；接触先脱离、表达手回支撑、电脑真实抱稳，再进入悬空 | 最高优先，不等完整社交/管理句播完 | 开盖、闭盖、手在发/袖、掌在半空的逐阶段入口须各自闭合；不能用一张通用抱机图覆盖所有来路 |
| E3 悬空跟手与反向 | 抱机支撑持续，身体承重稳定，袖发有限滞后 | 不在空中继续挥手/理发；不因鼠标反向镜像角色或旋转整个人 | 悬空保持与移动/停止后随有真实一致来源；电脑是同一刚体 |
| E4 刚提即早放 | 从实际尚未完成的抓取阶段直接进入可信下降/回座路径 | 不强制到完整悬空峰值再回来，不向下瞬移 | 起提各安全阶段的早放出口独立核验，不笼统倒放整段抓取 |
| E5 未落稳又重抓 | 按真实当前凳/骨盆/膝与电脑接触重新解除承托、抱稳提起 | 根跟手不迟滞；半落座不继续硬播落座句 | 触座前、刚触座、承重后、手未归位等关键阶段要有正确再抓接续 |
| E6 落座与异常取消 | 身体/凳接触 → 骨盆和膝腿承重 → 电脑到位 → 手归位 → 袖发停稳；失焦/取消按现真实所有权结束 | 恢复最新工作/提醒/安静资格，不重演原句；小队现在是隐藏后恢复，不冒称已做动画避让 | 完整落座与被中断的落座均要看；跨显示器/缩放约束不等于全平台已验收 |


## 5. 哪些必须画，哪些应该安静保持

| 运动段 | 必须有真实原画的变化 | 可以保持的部分 |
|---|---|---|
| 坐起/靠近/回坐 | 髋上方胸肩、肩肘、颈部随动、必要发束位置；清楚的起势与减速收尾 | 骨盆座位、非活动腿、正确接触下的电脑刚体 |
| 手离开/接触/归位 | 手掌接触释放、腕肘转向、袖口受重力、到达后的重新承重 | 已经稳定的另一只手；不能冻结该手必须响应的腕肘 |
| 内收转开放掌 | 前臂弧线、手腕旋转、手指展开、胸肩的小意图 | 不涉及转动的脸部轮廓；不是必须每张换表情 |
| 表情短回应 | 同头位真实眉眼/嘴变化；有头部运动时随整头几何重画 | 发饰、头骨体积与脸部比例；不能拿中性眼贴到不同yaw |
| 发袖后随 | 发束连接连续、接触后释放、末端减速停稳 | 不受动作影响的长发部分，不整片同步摇摆 |
| 机械开合/抓放 | 固定铰链几何、手与盖板接触、腿/髋承重变化 | 同一电脑纹理和尺度，不由每次生图重新设计 |

真实中间需求按关节路径和小尺寸常速判定，不硬限两三张，也不把输出24/60fps当成补足运动。长保持无需复制几十张相同源；峰值长停不能替代中间的连续变化。

### 跨句关系：以接触和意图接续，不做全状态排列组合

先记录每段的手接触、电脑盖角、髋胸承重和可停靠点，再决定能否共享；动作名相近不是共用入口的证据。下面是必须连起来审的路径，不要求每个业务状态与每个动作都各画一条桥。

| 从哪里 → 去哪里 | 自然接续 | 不允许的捷径 |
|---|---|---|
| R开/R闭 → A1/A2安静 | 在当前端点下安放、放松；长保持占主导 | 为一次眨眼开关盖、换手、重新播放整段入场 |
| 安静 → B注意/轻点 → 安静 | 同一盖角和手位的轻坐起、回应、真回坐；结束后有真实安静停留 | 小回应前后各走一遍显眼的旧手位桥；每tap重启 |
| B1注意 → B2轻点／B3重复变化 | 若仍在同句，只保持或自然收完；随后新的合格输入可一次变化 | 缓存鼠标事件，回应一结束就自动连播积压的招呼 |
| C接住 → C整理 → C交代/呈交 | 同一前臂运动连续推进；半句停在有完整退出来源的支撑位 | 强制每半句回母版再起手；用峰值静帧串成三阶段 |
| C监督/理解进展 → B忙中短回应 → 监督 | 选择同支撑短句；保留真实项目上下文，回稳态而非重演业务入场 | 为看用户先换成侧听再转回来；把轻点消费成派发或交付 |
| C内收/开放掌 → D待决提醒 | 若同手位已有真实接续，可沿自然腕肘收放面用户呈意；否则先落到最近可靠支撑 | 仅因都叫“呈掌”就切图；等动画结束才显示新权限/问题 |
| D呈意/等待 → B社交 → D仍可查看 | 一次短注意，不重启催答；未决内容保持，身体可回舒适位 | 用户点桌宠就清请求；为了表示“还在等”永久举手 |
| A理发/理袖 → D提醒 | 信息先更新；先解除发丝/衣料接触，再归手或接可信开放掌 | 瞬间丢掉接触手、把上一句的手直接贴到新位置 |
| A舒展 → C/D工作 | 保留稳定手，先收肘回肩、恢复承托，再进入工作或提醒的准备 | 伸展最高点直接切成开盖工作；突然改身体体积或手侧 |
| A困意/小憩 → 新事实/真实活动 | 信息即时；走适配当前困意程度的睁眼、承重恢复；需要开盖再接真实开盖链 | 全段倒放、猛弹头；醒来即因旧计时再次入睡 |
| 任意普通句 → E抓取/早放/重抓 | 根随真实指针，逐阶段释放接触/抱机；普通动作意图丢弃，不排队 | 为保全一段艺术表演延迟拖动；悬空继续原生活动作 |
| E落座 → 最新稳态 | 确立凳/腿/电脑接触后，按当前事实走R开/R闭或D提醒 | 回放拖动前的旧结果、旧欢迎、旧派发；落座截图代替整段验证 |
| 任意句 → 隐藏/重新可见/模式变化 | 停止可见时间积累、清过期短意图；恢复最新事实与相容支撑 | 快进补播隐藏事件；把Bot/Agent模式切换演成用户重新交办 |

**并发与换句规则**：事实立即显示；只有一个身体句子。相同类型的新事项不因计数增加重新起势；其他普通变化到最近自然接续点再选择最新仍有效的意图，不排队回放。紧急事项可取消普通意图，但不允许手穿电脑或从发丝接触直接闪回。安全回收不是锁住信息或用户操作的理由，也不任意规定“业务至少保持几秒”。原生抓放始终最高优先。

### 制作覆盖怎样判定完整

- 每个已制作句子交付：起势、完整运动路径、有意义的保持、减速收势、重新接触，以及实际可达阶段的普通回收/抓放入口。共享端点只减少重复画，不免除独立接触段。
- 每族都有完整常速句和跨句片段后才算覆盖；A1安静、B1关注和一个C峰值做完不能代表五族完成。表中未完成项继续保留为制作任务，不在运行时用不相容动作顶名。
- 至少连贯审查：安静→一次生活整理→长安静；安静→小舒展→恢复；注意→轻点→一次重复变化→安静；困意→小憩→真实唤醒；Bot接安排→整理→交代→平稳跟进→呈交；Agent新问题/授权→查看但未解决→社交→真实单项回应；异常关注→仍有另一项目工作；抓取→早放→重抓→落座→最新提醒。每段既看完整落手，也看必要打断，不剪成峰值合集。
- 浅/深背景与默认小尺寸的整句观感先于数量；同一身份的胸肩、头骨、袖手、电脑与发束连续成立。新源产生新SHA后重新补相应回收，不拿旧闭包或技术通过冒充新视觉合格。


## 6. 制作方法：按整句统一作画，不再按状态逐张拼人

1. 建立统一人体/服装/道具检查页：头骨、耳位、眼距、肩宽、腰带、吊坠、袖口、手腕、骨盆、膝靴与电脑铰链；不是只看发色和脸好不好看。
2. 同一动作先画从开始到结束的全身关键路径，接触点与重心在每一拍都可说明；在此基础上补真实中间和停稳画。表情最后服务动作，不先生成几张脸再找身体安放。
3. 同一运动句的原画作为一组连续参考来修改，镜头/比例统一；不独立抽取每张“最好看”的头胸拼到锁死底板上。
4. 局部mask只保护真正静止区域；运动包络必须包含旧/新位置及应随动的肩、袖、发，不得把“outsideMaskExact”当理由切断关节运动。
5. 电脑、凳等刚体可使用受控几何与独立图层，但手的接触关系由真实原画决定。不能用旧差rig、整体缩放、整头旋转、交叉淡化或光流形变掩盖缺帧。
6. 一条完整动作包括准备、运动、中段意图、减速、重新接触和安静停稳；回程不是一概倒放。身体可先回、发袖后停，因而需要真实收势来源。
7. 内部先校准共同休止位与一条完整动态路径，确立全身联动和一致性的作画标准，再按同标准持续展开全部五族；这是生产质控，不是只做一小段就停。所有动作族成套制作，不要求用户逐片审批。内部失败就回修相应身体链，不用堆新动作掩盖旧问题。
8. 普通源确认后再补逐曝光普通回收与抓放；来源/prompt/实际SHA/manifest保存可复现，但技术闭包始终与视觉结论分开。
9. 制作持续按实际失败点重抽、修订和整句对照，不因一批不合格就用拼接脸片降低标准，也不把失败等同于终止整套制作。raw、大量候选、试片和未选试验留在仓库外；只有最终选定的必要源与其必要可复现材料进入 Git，提交前只纳入选定的生产材料。现冻结历史来源不因本轮反复抽卡被批量覆盖或改写。

## 7. 动态评价：整句、跨句、打断都要看

- 默认桌宠尺寸先无道具字幕观看：能否一眼辨认“注意你 / 收拢交代 / 提醒等你 / 放松”？若只能读字幕才懂，不能称表演成立。
- 正常速度检查胸肩、头颈、肘腕是不是同一股运动，是否有突然低头换脸、先换手再微笑、僵硬回母版；慢放只用于找原因，不能代替常速判断。
- 固定镜头往返检查头骨和身体体积、发饰/吊坠形状、电脑尺寸/铰链、袖口与手指连接。合理透视变化必须连续，不能以“这是yaw”解释年龄或体积跳变。
- 无滤镜、无大面积特效、无镜头移动遮掩；至少同时看浅/深桌面、真实小尺寸，以及不带周边符号的纯人物。
- 每族展示一次完整起落和充分安静停留，再展示连续使用；不把20个峰值拼成“丰富”的预告片。
- 跨族检查：监督→轻回应→监督；整理→提醒→等候；问题未解决时轻点；手在发上时提起→落座。允许必要机械准备，不允许多余桥抢走主要意图。
- 每个活动阶段都检查中断：停留中的稳定姿态立即可退，接触中的手先真实脱离；紧急信息先显示，身体不能锁住用户操作。
- 小队位置、项目数、屏幕边缘变化时，人物动作仍成立。取消布局目标后，不应剩下“手指着空地方”的表演。

## 8. 现有资产的保留与使用边界

- `production-v2/shared`、`lid/frames/closed-rest-rigid-v2.png`：身份、机械端点和尺寸参照；是否作为新共同休止位须按上述支撑关系校准，不静默替换现端点。
- `production-v2/question-permission`：同头位表情、开放掌、真实手回收可作为素材；删去全局方向绑定的使用假设，不删除来源文件。
- `production-v3/companionship`：哈欠、困醒、闭盖回应和手释放等有价值，但需用整句动态重新看，不因旧静态方向认可直接沿用全部峰值。
- `production-v3/director-performance`：现左右LISTEN不再作为通用管理默认；GATHER的手形/接触可参考，外侧指向不映射到具体项目位置。
- `production-v3/local-interaction-v2` 与 `closed-tap-playful`：保留表情与实际源证据；不能用脸域注册证明新身体联动已做好。
- `production-v3/quiet-hair-touch`：保留小发缕接触、脱离与手回位来源；完整句和被打断的句分别审，不能只播到峰值。
- `production-v3/relocation` 与既有普通回收manifest：继续保留精确来源覆盖。新的运动组产生新SHA时增量闭合，禁止拿旧测试结果冒充新身体已通过。

这些资产不会白做：身份、接触点、机械模型和部分真实手势继续利用；需要撤回的是“许多可达姿态等于自然动画”的生产与评价方法。当前规划覆盖整套动作族，后续按统一身体语言深入制作，不再围绕项目方向扩大姿态库。
