## 1. 设置的信息架构

后续方案拟保留现有设置模态外壳与 220px 导航，保留「使用偏好、AGENT、开发与项目、连接与扩展」的目录体系。
先在既有页面中调整内容关系、密度和依赖展开。字段 ID、搜索词、scope 和能力可用条件保持可追溯。

| 导航组 | 页面与归属 |
| --- | --- |
| 使用偏好 | 通用、外观、聊天、对话默认、通知、语音、快捷键、存储、历史与恢复 |
| AGENT | 模型服务、agents、Varin bot、系统提示词、记忆、记忆与知识嵌入、工具与执行、网络检索和文档等现有入口 |
| 开发与项目 | 沿现有页面注册与平台能力保留 |
| 连接与扩展 | 沿现有 Host、扩展和 MCP 页面注册保留 |

现有 HTML 稿具体展开聊天、模型服务、网络检索和文档、对话默认、存储五类页面；其他入口保留且明确在评审范围之外，不编造空页面。
最终目录迁移时逐项核对现有 Desktop/Web/mobile 页面、权限和搜索 registry，不能因重新分组丢失功能。
页面名称变动只改导航文案和分组，不重新命名协议字段、覆盖来源或凭据引用。

### 1.1 页面与字段层级

页面标题说明用户正在管理什么。下面用简短范围信息说明当前 Host、作用域与覆盖关系；说明文字紧邻它解释的决定。
常见偏好直接操作；选中某种能力后，在原位置展示依赖设置；环境与实现参数进入明确命名的配置详情。

| 字段类型 | 使用形态 |
| --- | --- |
| 一个独立偏好 | 紧凑横排标签与开关 |
| 少量互斥选择 | 可读的选项与简短影响；长选项纵向排列 |
| 模型/服务及其依赖 | 选择后局部展开配置，依赖与主体相邻 |
| 长路径、规则、提示词 | 标签在上，适当宽度的输入或原位编辑 |
| 对象集合 | 服务/规则列表，选中后进入对象详情 |
| 有实际影响的操作 | 数据分类、影响说明与对应动作，保留可恢复性语义 |

所有普通行不强制占满同一个两列模板。宽页面使用合理阅读宽度，局部对齐形成关系；空白用于区分章节，而非拉开标签与输入。
帮助说明可展开，关键条件、费用/数据去向、校验失败和操作后果直接可见。
设置搜索保留别名，能展开高级区、选中相关对象并定位具体字段；搜索结果不只停在页面顶端。

### 1.2 配置状态

| 已知事实 | 用户文案 |
| --- | --- |
| 功能关闭 | 已关闭 |
| 用户启用但依赖未选 | 待配置 · 选择辅助模型 |
| 配置已被 owner 保存 | 已配置；只表达配置事实 |
| 已有有效运行观测 | 可用或不可用，并提供观测来源/时间 |
| 当前平台明确不支持 | 当前 Host 不支持，解释可用环境 |
| 正在写入设置 | 保存中，保留当前输入 |
| 保存被拒绝 | 保存失败，具体原因与重试，草稿保留 |
| 配置被项目覆盖 | 当前项目使用覆盖值；可查看有效值与来源 |

不开新后台探测来给每项设置染绿色。模型已选择或密钥已保存不自动等于连接成功。
开关可以表达用户意图，同时用「待配置」清楚解释尚未生效；也可以由需要原子提交的编辑单元在依赖齐全后一起保存。
最终选择依照已有 owner 合同，不由通用组件擅自改写后端设置。

### 1.3 范围、保存和生效

页头显示本页真实作用域。只有支持 project scope 的字段才出现项目编辑入口；Host 全局页不能伪装成任意范围切换。
项目覆盖显示有效值及来源，重置动作叫「使用继承值」，并能看到继承后会变成什么。

即时偏好沿既有保存机制，在真实确认后短暂提示已保存。服务等多字段编辑作为明确的编辑单元，使用保存/取消；错误留在该单元。
混合页面不设置一个让人误以为能提交全部字段的全局保存按钮。离开未保存单元沿用既有 draft/navigation guard。
下一次请求、新会话、重启 Host 后生效等时机靠近有关配置，不能一概写成即时生效。
切换 Host 不把原 Host 的迟到保存响应写入新页面，范围改变时保留或明确处理草稿。

## 2. 五类代表设置页

### 网络与文档

「网页搜索」呈现开关、当前服务、数据去向。默认服务的 Exa/Parallel 路由有简短可读说明；自定义选择展开自身凭据或地址。
「读取动态网页」解释需要运行网页脚本的读取能力。当前环境无法使用时直接解释，Electron/offscreen 等实现信息放在帮助中。
「文档阅读」先说明基础文本能力，再呈现模型辅助与扫描件/复杂版式支持。
模型未选择时显示待配置，并就地提供选择。OCR 语言与扫描件识别放在一起；可执行路径进入「组件路径」详情，仍可搜索直达。
不把隐私、外部搜索提供方或实际费用条件隐藏在只有排障者才会打开的位置。

### 聊天

显示模式有明确效果预览：对话优先、时间顺序、回答优先。对话优先保留普通过程一行与独立子任务。
思考显示与展开是不同选项；展开设置说明其在当前显示模式中的作用。视觉密度、字体与动态效果属于阅读偏好。
预览在实际实现时复用正式组件和静态演示数据，不发模型请求，也不创建隐藏执行对象。

### 模型服务

先选择服务或账号，再管理模型与用途。模型的协议、路径、参数在具体模型详情中呈现。
对话、辅助阅读、检索等用途显示已选对象或待配置，不要求用户先理解全部 provider 字段。
连接状态来自明确观测，配置状态与连接状态分开。编辑失败保留草稿；切换对象不能误把密钥或参数保存给另一个服务。
使用位置可导航到对应能力，避免同一个用途在多个页面维护独立副本。

### 存储

沿现有 inventory 分类展示：恢复与工作状态对象、独立工作副本、对话与附件、记忆与知识向量、共享模型资源、其他应用数据。
设备、工作区范围与共享范围分开选择，未知统计保留未知，不能换成前端随意合并的几类。
清理动作绑定对象、预计释放范围与实际影响。无可靠统计时显示未知，不用 0 B 代替。
删除会话应包含其可释放关联资源；共享引用、正在占用、可重试失败需有明确结果，不把逻辑删除当成空间已回收。
预览中的清理只是交互演示。正式实现继续使用原存储/清理 owner，不让 UI 创建清理计时器或文件删除路径。

### 对话默认

保留全局/项目信任与继承语义。重试直接对应现有 ModelRetrySettings：enabled、maxRetries、initialDelayMs、maxDelayMs 与 rules。
规则保留 field、match、pattern、action 及顺序。可以改善平铺密度与原位编辑，但不新增第二套匹配配置。
保存与规则测试继续使用原运行时入口，HTML 稿只提供编辑和状态示例。

## 3. 实现边界

保留 `settings-catalog` 的稳定字段与作用域、`metadata/search` 的导航和发现合同。
共享 primitive 负责对齐、键盘、帮助展开和保存反馈；领域页面负责能力依赖、有效配置与解释。
调整 FieldRow/StackedField 的使用位置，不通过给所有行增加更多布尔参数来制造万能模板。
保存仍由现有 owner 完成；新增状态文案必须对应真实的 draft、ack、scope 或观测事实。
Desktop/Web/mobile 共用语义，各自选择适合空间的布局。
