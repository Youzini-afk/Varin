Varin 形象提案 · 圈圈

二次元桌宠保留给喜欢它的人；Bot 的默认形象换成一眼能懂、谁都觉得可爱的软糖小团子。造型从 Varin 本身长出来：桌宠角色左侧唯一的圈丸变成头顶斜飘的一枚珠光圈，Logo 的两片互扣折带化成圈上的两段色。动效参考了 Grok bot 头像工作室 的软糖质感和指针跟随，所有动作都用弹簧驱动，状态之间连续过渡。本页是可交互的设计稿，不是正式资源。

三个方向

三张卡片共用同一套表情和弹簧动效，只换身体和标志物，循环播放全部状态，方便直接比较。推荐 A。

造型拆解（方向 A）

  1. 软糖身体：上圆下宽的团子轮廓，站得稳、显得亲切；径向渐变加左上高光和底部透光，做出软糖/黏土的体积，区别于 Agent 的平涂头像。
  2. 珠光圈：来自桌宠角色左侧唯一的圈丸。斜飘在左上，造成不对称的剪影，14px 也认得出来。圈由两段互扣的珠光色组成，呼应 Logo 的两片折带。它是最主要的表情道具：思考时绕身体公转，工作时变成进度环，等你时转暖色，有结果时迸出光点，睡觉时落在头顶。
  3. 眼睛：两枚炭黑竖胶囊，带一粒高光，颜色取 Logo 的 #20272a，和 Agent 头像的深色眼睛同一家族。表情只靠眼睛形状、开合、视线和少量腮红/嘴，不画复杂五官。
  4. 层级：Varin 有圈；负责人 Agent 穿披肩、扣菱形扣；子 Agent 是原本的平涂小团子。三者在同一行里一眼能分清。

状态与动作（方向 A）

状态姿态动作圈

动效规则：身体用欠阻尼弹簧（有轻微回弹），视线和眼睛用接近临界阻尼的弹簧，颜色和光晕慢慢渐变；进入动作（跳一下、压一下、伸懒腰）叠加在弹簧之上，状态切换不会跳帧。窗口不可见时暂停；“减少动态”只保留姿态之间的淡入淡出，不放粒子。
