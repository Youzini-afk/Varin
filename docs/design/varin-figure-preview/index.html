Bot · 默认形象

它的脸，
就是 Varin 的标志。

Varin 的标志是两段折角笔画互相扣住。把两笔横收起来，剩下两笔竖就是一双眼睛。所以它醒着时是一块会眨眼、会看你的软方块；睡着时把横笔放回去，变回 App 图标。颜色交给它的团队：派出去的 Agent 都是彩色的，围着它转。

01 · 想法

从标志里长出来

不另外造一个吉祥物。标志里的两笔竖本来就在左右两边，像一双眼睛；横笔是它的“手”，需要时伸出来，收起来就是一张脸。

  1. 身体是 App 图标那块圆角方块：上窄下宽一点，站得稳；缎面质感加细颗粒，像一块软陶，而不是塑料泡泡。
  2. 眼睛是标志的两笔竖：左笔炭黑，右笔在拼成标志时带一点鼠尾草灰，和标志一致。思考时两笔变回标志并转动，就是它的加载动画。
  3. 表情只用这两笔：笑眼、闭眼、眯眼、眨眼都由同一对笔画变形而来，没有额外的五官，14px 也看得清。
  4. 颜色交给团队：Varin 本身只有一种颜色；它派出去的 Agent 用产品里真实的彩色头像，工作时围着它转，有结果时撒出彩色纸片。
02 · 状态

九个状态，一套动作系统

对应 Bot 工作台的形象状态合同。状态之间都是连续过渡：身体用弹簧，眼睛用变形，外轮廓有果冻回弹。

03 · 小动作

有性格的瞬间

这些不是状态，是叠在状态上的一次性动作：打招呼、派发、庆祝、戳一下。派发时，一个真实的 Agent 头像从它头顶被抛出去。

04 · 颜色

每个 Bot 一种颜色

多个 Bot 时各选一种颜色，形状和表情不变。原色就是 App 图标本身。

05 · 放进产品

在侧栏、标题栏和 Bot 区里

40px 以下只显示姿态，不播循环：休息时就是一个小 App 图标，等你时右上角有提醒点。Agent 仍是平涂头像，Varin 是唯一有体积的那个，主次一眼分清。

06 · 动效规则

丝滑来自哪里

身体：欠阻尼弹簧

刚度 260、阻尼 16，落地有一次轻微回弹。蹲、跳、落三段都有预备和缓冲，不做匀速位移。

轮廓：果冻模态

外轮廓叠加 2、3、4 阶振动，落地、被戳时激发，约两秒衰减；平时只随呼吸轻微起伏。

眼睛：形变而不是切换

同一对笔画在竖眼、笑眼、闭眼和标志之间插值，接近临界阻尼，没有两种眼睛叠在一起的残影。

窗口不可见时暂停；“减少动态”下只保留姿态之间的平滑过渡，不放纸片、不做果冻回弹。小尺寸只画静态姿态。所有动作都由同一个参数集驱动，正式实现可以直接换成 Rive 状态机或保留 SVG。
