# Varin 形象：趴窗台

状态：已实现为 `BotFigure`（`packages/ui/src/workbenches/bot`）。可交互预览见 [varin-figure-preview/index.html](varin-figure-preview/index.html)，需要用浏览器打开，动作靠脚本运行；预览里能手动触发全部一次性动作，产品里只用其中几个。

## 形象

- **来源**：确认过的正面 Q 版参考图，预览目录里的 `reference.webp` 是缩小的对照图。Varin 的二次元角色按 Grokbot 那类 Q 版头像的思路重画：大头、平涂、无描边、细节少，同时保留 Varin 自己的眼睛、腮红和小嘴。
- **构图**：正面，头和肩露在窗台上方，两只圆球手搭在窗台沿上。窗台就是形象位的下边。
- **保留的标志**：银灰长卷发和呆毛、她左侧（画面右边）的丸子头和黑缎带、Varin 标志发夹、雾蓝高领毛衣、白外套和黑色肩带、菱形袖饰、方形吊坠。
- **背景**：形象自带深色的“窗内”。浅色主题下也保持深色，银色头发在两种主题里都清楚。

## 分层

头发、脸、五官和发夹由参考图描出，坐标是参考图的 1254 像素空间（`varin-art.js`，应重新生成，不手改）。丸子头下的扎发结和下面那缕头发照原图描出。结看上去是一整块，绑带、结、下垂的飘带和向右的结耳之间没有拼接缝；结耳在那缕头发后面，被压住一角。衣服在预览里用干净的形状重画：敞开的白外套、带卷边和罗纹的高领毛衣、肩带，两只袖子是圆弧形的前臂，在手下面结束，和中间的毛衣分开；高领上方露出一点脖子，下巴在脖子上投一道浅影。按动作需要拆成以下几层：

- **整体**：身体、脸和头发作为一个整体，以窗台中点为支点做下沉、弹跳、压扁和倾斜。窗台以下的部分向下延长了，倾斜时底边不会离开窗台。
- **五官**：五官单独一层，可以整体平移，在刘海下面滑动来表现转头。
  - 眼睛：描出来的睁眼可以眨、看向四周、放大、半闭。另有闭眼、笑眼、`><` 三种手画形状，换形时先合上再张开，不做交叉淡化。
  - 眉、腮红和害羞线各自独立。
  - 嘴有九种：微笑、张嘴、大笑、o、哈欠、平、猫嘴、撅嘴、睡觉。
- **头发配件**：左边的呆毛按它自己的轮廓拆出来，以发根为支点，跟着身体的速度晚一拍摆动，休息时耷拉下来；上面那缕弯下来的头发不跟着动。扎发结的绑带不动，下垂的飘带和向右的结耳各自晚一拍摆动；两者都压在同色的绑带下面，摆动时看不到接缝。
- **双手**：两个圆，带投在窗台上的影子和外下侧的暗部，可以离开窗台做手势。
- **前景效果**：
  - 状态相关：等你的提醒徽标、思考气泡、休息时飘的 z、工作时从手边冒出的小菱形、有结果时撒的星星和菱形纸屑。
  - 动作相关：戳一下时的爱心、疑惑时的问号，以及头发上扫过的一道光泽。

## 状态合同对照

对应 [Bot 界面](bot-ui.md) 第 5.7 节。

| 状态 | 表现 |
| --- | --- |
| 空闲 | 呼吸，偶尔眨眼、四处看；指针在附近时目光跟随；隔一阵做个小动作（眨眼、点头、歪头、甩呆毛、敲窗台） |
| 倾听 | 凑近一点，眼睛放大、带星光，双手往中间收；目光像读你打的字一样从左扫到右，跟着打字节奏轻轻点头 |
| 思考 | 歪头、托腮，眼睛看向左上方并慢慢左右移，左上角三个气泡依次亮起 |
| 工作 | 低头看窗台，两只手轮流敲，手边冒出小菱形 |
| 等你 | 进入时跳一下；暖色光晕呼吸，右上角出现提醒徽标，隔一会儿举手挥一挥 |
| 有结果 | 先压一下再弹起，笑眼、大笑、举起双手，撒星星和菱形 |
| 休息 | 沉到窗台下，下巴枕在手上，闭眼，呆毛耷拉，飘 z |
| 唤醒中 | 冒上来，揉一只眼、打哈欠，伸懒腰，眨两下眼，头发闪过一道光 |
| 离线 | 去色，只露出眼睛以上，眼睛变暗，手收到窗台下，不播放循环 |

一次性动作：预览里有挥手、点头、摇头、疑惑、眨眼、戳一下、躲起来再探头、欢呼、害羞、吃惊、打哈欠。产品里空闲时偶尔眨眼、点头、歪头、甩呆毛、敲窗台；点一下形象会被戳一下，休息和离线时不响应。

## 动效规则

- 身体和手用欠阻尼弹簧，五官接近临界阻尼。弹跳和压扁通过给弹簧施加速度来触发。
- 40px 及以上用完整构图并播放动作（Bot 区 112px、新会话首屏 64px、收起的 Bot 区 40px）。40px 以下（侧栏、手机标题、返回按钮、会话标记）只取头部，保持静态姿态，徽标和 z 会放大。
- 页面隐藏或形象滚出视野时停止逐帧绘制。界面动效为“简化”时只显示姿态，姿态变化淡入；为“关闭”时直接切换。没有 `requestAnimationFrame` 的环境（测试）只画静态姿态。
- 形象出现时直接处在当前姿态，之后的状态变化才有过渡。

## 实现

- `varinFigureArt.ts`：描出来的分层矢量，坐标是参考图的 1254px 空间。预览目录里的 `varin-art.js` 是同一份数据的副本，改形象时两边一起更新。
- `varinFigureRig.ts`：姿态、弹簧、动作和特效，直接操作一个 SVG，帧走共享的 `requestFrame`。
- `BotFigure.tsx`：React 外壳。`BotFigureState` 合同和各处尺寸不变，形象改为正方形。
- 所有 Bot 共用这一个形象；二次元桌宠保持现状。
