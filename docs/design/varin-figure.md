# Varin 形象：圈圈（提案）

状态：2026-10-31 提案，尚未实施。可交互设计稿见 [varin-figure-preview/index.html](varin-figure-preview/index.html)（用浏览器打开，动作需要脚本）。

## 为什么要大众形象

二次元桌宠角色受众窄，继续保留，给喜欢它的人用作可选桌宠。Bot 的默认形象要让第一次见到的人也觉得可爱、好懂。现在 Bot 区的形象是占位画法（`BotFigure`），状态合同（[Bot 工作台设计 §5.7](bot-ui.md)）已经定好，正式美术只需替换画法。

参考：[Grok bot 头像工作室](https://grokbots.ai/studio) 提供 8 种形状、16 种表情、12 种颜色和 15 段动画，造型是有高光的软糖/黏土质感，眼睛跟随指针。Meta Muse 的 Jolly 和 OpenAI Dots 也都用了圆润、可自定义的吉祥物。我们取它们的大众口味和丝滑动效，造型从 Varin 自己的元素长出来，不照搬。

## 推荐方向 A：圈圈

- **身体**：上圆下宽的软糖团子，站得稳、显得亲切。径向渐变、左上高光、底部透光做出体积，和 Agent 的平涂头像区分开。
- **珠光圈**：来自桌宠角色左侧唯一的圈丸，斜飘在左上，剪影不对称，14px 也认得出。圈上的两段珠光色呼应 Logo 两片互扣的折带。圈是主要的表情道具。
- **眼睛**：两枚炭黑竖胶囊加一粒高光，颜色取 Logo 的 `#20272a`，与 Agent 头像的深色眼睛同一家族。表情只靠眼睛形状、开合、视线和少量腮红/嘴。
- **颜色**：默认雾蓝（`#7aa7ef`，Varin 主题重点色），另有 11 种可选。多个 Bot 各选一种颜色就能区分，圈始终保留，表示“这是 Bot”。
- **层级**：Varin 有圈；负责人 Agent 穿披肩、扣菱形扣；子 Agent 是平涂小团子。

### 状态合同对照

| 状态 | 姿态 | 动作 | 圈 |
| --- | --- | --- | --- |
| 空闲 | 正视，偶尔眨眼 | 慢呼吸，偶尔看看四周，指针靠近时目光跟随 | 在左上轻轻浮动 |
| 倾听 | 眼睛略睁大，微微前倾 | 呼吸更轻更快 | 稍微抬起、变亮 |
| 思考 | 看向斜上方 | 眼睛追着绕行的圈 | 缩小后绕身体公转，绕到背后被挡住 |
| 工作 | 眼睛向下 | 轻快地上下点动，像在敲键 | 原位稍稍抬起，变成转动的进度环 |
| 等你 | 看向你 | 暖色光晕呼吸，进入时轻跳一下 | 转成暖橙色并脉动 |
| 有结果 | 眯眼笑、腮红 | 轻压一下再回弹 | 翻转一圈，迸出彩色光点 |
| 休息 | 闭眼，身体沉下去 | 很慢的深呼吸，zz 飘起 | 落到头顶歇着 |
| 唤醒中 | 睁眼 | 眨两下眼，伸个懒腰 | 从头顶弹回原位 |
| 离线 | 去色，眼睛半闭变暗 | 不播放循环 | 变灰不动 |

另有小动作：眨眼、打招呼（圈像挥手一样摆动）、派发（圈里飞出一颗光点落到负责人身上）、庆祝、彗星（圈带拖尾绕一圈）。

### 动效规则

- 身体用欠阻尼弹簧（轻微回弹），视线和眼睛接近临界阻尼，颜色与光晕慢慢渐变；进入动作叠加在弹簧上，状态切换不跳帧。
- 眼睛在睁开、笑眼和闭眼之间是形变过渡：竖胶囊先压扁，弧线再接上，不做两种形状的叠影。
- 40px 以下只显示姿态、不播循环，换用更深的珠光圈和略大的眼睛；窗口不可见时暂停；“减少动态”只保留姿态之间的淡入淡出，不放粒子。

## 其他方向

- **B 折纸**：Logo 的两片折带直接做成身体的两半，最像品牌，适合官网和启动画面；小尺寸时接缝看不清，可爱度较低。
- **C 团子**：奶白毛绒团子加雾蓝针织围边、发圈和扣饰，最接近 Muse / Dots 的大众口味，但最容易撞型，Varin 的辨识度最弱。

## 确定方向后的落地

- 替换 `BotFigure` 的画法，保持 `BotFigureState` 合同和现有尺寸（Bot 区、侧栏 20px、标题栏 14px）。
- 每个 Bot 可选颜色需要在 Bot 记录上保存一个颜色值，属于产品决定，确认后再加。
- 二次元桌宠角色保留；是否让桌宠也提供圈圈形象另行决定。
