# Varin 形象：趴窗台

状态：已实现为 `BotFigure`（`packages/ui/src/workbenches/bot`）。可交互预览见 [varin-figure-preview/index.html](varin-figure-preview/index.html)，需要用浏览器打开，动作靠脚本运行；预览里能手动触发全部一次性动作，产品里只用其中几个。

活动表现（她自己回合的工具道具、负责人和子 agent 上窗台、结果分级）也已实现，规则见 [Bot 界面](bot-ui.md) 5.7.1–5.7.3。[varin-figure-preview/stage.html](varin-figure-preview/stage.html) 是它的设计稿，用模拟数据播放同样的剧本，便于调整。

## 形象

- **来源**：确认过的正面 Q 版参考图，预览目录里的 `reference.webp` 是缩小的对照图。Varin 的二次元角色按 Grokbot 那类 Q 版头像的思路重画：大头、平涂、无描边、细节少，同时保留 Varin 自己的眼睛、腮红和小嘴。
- **构图**：正面，头和肩露在一条窄窗沿上方，两只圆球手搭在窗沿上。
- **保留的标志**：银灰长卷发和呆毛、她左侧（画面右边）的丸子头和黑缎带、Varin 标志发夹、雾蓝高领毛衣、白外套和黑色肩带、菱形袖饰、方形吊坠。
- **没有边框**：产品里形象直接站在页面上，背景透明，没有方块或卡片；窗沿用界面表面色，随浅色和深色主题变化。状态光晕只是身后一圈淡淡的光，在框内就淡出。小尺寸的头像在下巴以下渐隐，不出现硬边。预览页为了展示仍放在深色卡片里。

## 配色

和桌宠一样跟随真实主题的重点色（`colors.primary.base`，见[桌宠配色](desktop-companion.md)第 7 节），8 个色系只是组织样张的方式，不是 8 套皮肤。

- **换色**：高领毛衣（含卷边、罗纹、领内和阴影）、两只袖子和袖口亮线、袖上的菱形、发夹的浅色那片，以及工作时冒出的小菱形、完成时撒的星星、工具道具和呈现卡片上的雾蓝、派发的卡片、空闲和倾听时身后的光晕。
- **不变**：眼睛、眉毛、银发、肤色、腮红、白外套、黑色扎发结与肩带、发夹的黑色那片、金色吊坠。等你、思考等状态的语义光色也不跟着换。
- **算法**（`varinFigurePalette.ts`）：每个原色保留明度，色相换成重点色的色相，饱和度按重点色本身的饱和程度缩放，超出 sRGB 时降低饱和度而不是截断。重点色接近中性时（黑白主题）得到有层次的灰。Varin 自己的明暗主题保持画好的雾蓝不变。主题切换时只重设这些颜色，姿态和动作照常进行。

## 分层

头发、脸、五官和发夹由参考图描出，坐标是参考图的 1254 像素空间（`varin-art.js`，应重新生成，不手改）。丸子头下的扎发结和下面那缕头发照原图描出。结看上去是一整块，绑带、结、下垂的飘带和向右的结耳之间没有拼接缝；结耳在那缕头发后面，被压住一角。衣服在预览里用干净的形状重画：敞开的白外套、带卷边和罗纹的高领毛衣、肩带，两只袖子是圆弧形的前臂，在手下面结束，和中间的毛衣分开；高领上方露出一点脖子，下巴在脖子上投一道浅影。按动作需要拆成以下几层：

- **整体**：身体、脸和头发作为一个整体，以窗台中点为支点做下沉、弹跳、压扁和倾斜。窗台以下的部分向下延长了，倾斜时底边不会离开窗台。
- **五官**：五官单独一层，可以整体平移，在刘海下面滑动来表现转头。
  - 眼睛：描出来的睁眼可以眨、看向四周、放大、半闭。另有闭眼、笑眼、`><` 三种手画形状，换形时先合上再张开，不做交叉淡化。
  - 眉、腮红和害羞线各自独立。
  - 嘴有九种：微笑、张嘴、大笑、o、哈欠、平、猫嘴、撅嘴、睡觉。
- **头发配件**：左边的呆毛按它自己的轮廓拆出来，以发根为支点，跟着身体的速度晚一拍摆动，休息时耷拉下来；上面那缕弯下来的头发不跟着动。扎发结的绑带不动，下垂的飘带和向右的结耳各自晚一拍摆动；两者都压在同色的绑带下面，摆动时看不到接缝。
- **双手**：两个圆，带投在窗台上的影子和外下侧的暗部，可以离开窗台做手势。
- **前景效果**：
  - 状态相关：等你的提醒徽标、思考气泡、准备时耳边的省略号气泡、休息时飘的 z、工作和回复时从手边冒出的小菱形。
  - 动作相关：戳一下时的爱心、疑惑时的问号、完成时的几颗星星，以及头发上扫过的一道光泽。
- **工具道具**：纸、放大镜、浏览器窗口、带笔的纸、终端、便签、清单卡、齿轮，各自淡入淡出，跟着手走（见 bot-ui 5.7.1）。只有 40px 以上的完整构图有道具。
- **舞台图层**（只有横跨面板的宽形象有）：她两侧窗沿上方的团队层（和她一样在窗沿处裁切，宽度不限）、窗沿上的一层（子 agent 色点、“+n”、回报信封）、手前的一层（呈现卡片）、飞行层（卡片、纸飞机、信封）。她自己的特效始终是最上层。

## 状态合同对照

对应 [Bot 界面](bot-ui.md) 第 5.7 节。

| 状态 | 表现 |
| --- | --- |
| 空闲 | 呼吸，偶尔眨眼、四处看；指针在附近时目光跟随；隔一阵做个小动作（眨眼、点头、歪头、甩呆毛、敲窗台） |
| 倾听 | 凑近一点，眼睛放大、带星光，双手往中间收；目光像读你打的字一样从左扫到右，跟着打字节奏轻轻点头 |
| 思考 | 歪头、托腮，眼睛看向左上方并慢慢左右移，左上角三个气泡依次亮起 |
| 工作 | 低头看窗台，两只手轮流敲，手边冒出小菱形 |
| 等你 | 进入时跳一下；暖色光晕呼吸，右上角出现提醒徽标，隔一会儿举手挥一挥 |
| 准备 | 前倾、眉毛上扬，耳边一个省略号气泡，三个点轮流跳 |
| 回复 | 和工作同一个打字动作 |
| 看着团队 | 目光停在刚有动静的成员身上，头跟着转一点，隔几秒轻点一下头 |
| 工具 | 每种工具一个姿势加道具，见 bot-ui 5.7.1 |
| 休息 | 沉到窗台下，下巴枕在手上，闭眼，呆毛耷拉，飘 z |
| 唤醒中 | 冒上来，揉一只眼、打哈欠，伸懒腰，眨两下眼，头发闪过一道光 |
| 离线 | 去色，只露出眼睛以上，眼睛变暗，手收到窗台下，不播放循环 |

一次性动作：预览里有挥手、点头、摇头、疑惑、眨眼、戳一下、躲起来再探头、欢呼、害羞、吃惊、打哈欠。产品里空闲时偶尔眨眼、点头、歪头、甩呆毛、敲窗台；点一下形象会被戳一下，休息和离线时不响应。舞台另有：向左 / 向右甩出卡片、指向一侧再看回你、双手收拢回报、点头、托卡呈现（失败时表情认真）、皱眉、收敛的举手。这些属于发生的那一刻，她的姿态在醒着的状态之间切换时继续播完，进入休息、唤醒、离线时取消。

## 动效规则

- 身体和手用欠阻尼弹簧，五官接近临界阻尼。弹跳和压扁通过给弹簧施加速度来触发。
- 40px 及以上用完整构图并播放动作（Bot 区横跨面板、高 216px，窗沿贯穿面板；新会话首屏 64px；收起的 Bot 区 40px）。40px 以下（侧栏、手机标题、返回按钮、会话标记）只取头部，保持静态姿态；徽标、思考气泡和 z 在头部裁切范围内重新排布。
- 页面隐藏或形象滚出视野时停止逐帧绘制。界面动效为“简化”时只显示姿态，姿态变化淡入；为“关闭”时直接切换。没有 `requestAnimationFrame` 的环境（测试）只画静态姿态。
- 形象出现时直接处在当前姿态，之后的状态变化才有过渡。
- 状态切换取消上一状态尚未触发的延迟手势，已发出的粒子自然结束。离线姿态过渡结束后停止动画帧，恢复在线后继续；隐藏页面或面板不积累动画时间。
- SVG 保留分层节点，仅更新变化的属性。目光使用缓存的布局坐标，指针、滚动和尺寸变化后统一测量，不在每一帧的弹簧计算中读取布局。静态头像切主题时也会更新光晕，动态形象保留原来的颜色过渡。
- 形象和团队共用一个帧循环；帧内触发新手势不会另开循环。舞台隐藏或角色进入休息、唤醒、离线时，未开始的舞台动作取消，飞行物直接归位，回来不补演。
- 报告与收取按真实事件顺序、所属会话分开处理；确认收取时仍在飞行的信封落地后直接收拢，不留在窗沿，也不影响其他会话的报告。切换 Bot 或 Host 时先隔开旧舞台，再展示新的快照。

## 实现

- `varinFigureArt.ts`：描出来的分层矢量，坐标是参考图的 1254px 空间。预览目录里的 `varin-art.js` 是同一份数据的副本，改形象时两边一起更新。
- `varinFigureRig.ts`：姿态、弹簧、动作、道具和特效，直接操作一个 SVG，帧走共享的 `requestFrame`。宽形象另外开放舞台图层、目光 `lookAt` / `focus` 和每帧回调。
- `botStageRenderer.ts`：在舞台图层里画团队和飞行物，跟着形象的帧走，形象停帧它也停。
- `varinFigurePalette.ts`：按当前主题的重点色给换色部位取色，OKLab 换算沿用桌宠配色解析器的实现。
- `BotFigure.tsx`：React 外壳。接收一个姿态（`BotFigurePose`，即状态加舞台细化），Bot 区的宽形象另外接收团队和时刻（`stage`）。
- 所有 Bot 共用这一个形象；二次元桌宠保持现状。
