# Varin 形象：标志即面孔（提案）

状态：2026-10-31 第二版提案，尚未实施。可交互设计稿见 [varin-figure-preview/index.html](varin-figure-preview/index.html)，需要用浏览器打开，动作靠脚本运行。

## 为什么重做

第一版是带光环的渐变软糖，太接近参考对象（[Grok bot 头像工作室](https://grokbots.ai/studio)），没有从 Varin 自身长出来。参考里真正值得学的是两点：身体本身会变成状态符号（思考时变成三个点、提醒时变成感叹号），以及主体单色、颜色交给运动中的彩色元素。第二版按这两点，用 Varin 自己的元素重新设计。

## 想法

Varin 的标志是两段折角笔画互相扣住。两笔竖本来就在左右两边，像一双眼睛；两笔横是它的“手”。

- **身体**：App 图标那块圆角方块，上窄下宽一点，站得稳；缎面加细颗粒，边缘有一圈随倾斜流动的珠光。
- **眼睛**：标志的两笔竖。左笔炭黑；拼回标志时右笔带一点辅色，和标志一致。
- **表情**：笑眼、闭眼、眯眼、眨眼都由同一对笔画变形而来，没有额外的五官。
- **标志时刻**：睡着时横笔放回去，它就是 App 图标；思考时两笔拼成标志并一顿一顿地转，就是加载动画。标志转半圈后与原样相同，所以转完可以无缝松开变回眼睛。
- **颜色交给团队**：Varin 本身只有一种颜色。工作时，正在跑的子任务化成产品里真实的彩色 Agent 头像绕着它转；有结果时撒出团队颜色的纸片；背景光随状态换色（等你偏暖，思考偏蓝紫，休息偏暗）。
- **每个 Bot 一种颜色**：8 种颜色，形状和表情不变；原色就是 App 图标。

## 状态合同对照

| 状态 | 表现 |
| --- | --- |
| 空闲 | 正视，偶尔眨眼、看看四周，指针靠近时目光跟随 |
| 倾听 | 眼睛睁大，身体前倾，跟着打字节奏轻轻点头 |
| 思考 | 眼睛拼成标志，一顿一顿地转 |
| 工作 | 低头专注，像在敲键；在跑的子任务化成彩色 Agent 绕着它转 |
| 等你 | 看着你，暖色光晕呼吸，右上角亮起提醒点，隔一会儿轻敲两下 |
| 有结果 | 眯眼笑，压一下再弹起，撒出彩色纸片 |
| 休息 | 变回 App 图标，身体沉下去慢慢呼吸 |
| 唤醒中 | 标志松开，眨两下眼，伸个懒腰 |
| 离线 | 去色，眼睛压成两道短线，身体歪着，不播放循环 |

一次性小动作：打招呼、眨眼、派发（把一个真实 Agent 头像抛出去，眼睛一路跟着）、庆祝、标志、戳一下（被点到的地方凹下去，然后笑）。

## 动效规则

- 身体用欠阻尼弹簧，落地有一次轻微回弹；蹲、跳、落都有预备和缓冲。
- 外轮廓叠加 2、3、4 阶果冻振动，落地或被戳时激发，约两秒衰减。
- 眼睛在竖眼、笑眼、闭眼和标志之间插值，接近临界阻尼，不做两种形状的交叉淡化。
- 40px 以下只显示静态姿态：侧栏里休息时就是小 App 图标，等你时右上角有提醒点。
- 窗口不可见时暂停；“减少动态”下只保留姿态之间的平滑过渡，不放纸片、不做果冻回弹。

## 确定后的落地

- 替换 `BotFigure` 的画法，保持 `BotFigureState` 合同和现有尺寸（Bot 区、侧栏 20px、标题栏 14px）。动作参数集可以直接转成 Rive 状态机，也可以保留 SVG 实现。
- 每个 Bot 可选颜色需要在 Bot 记录上保存一个颜色值，属于产品决定，确认后再加。
- 二次元桌宠角色保留为可选桌宠。
