# Varin：重新分配身体动词，而不是给摊掌换标签

设计重修 · 2026-10-30 · 本稿取代旧五族方案中允许不同交流意图共用摊掌的设计。动作姿态研究已开始，尚未成为运行时资产；不代表视觉验收。

## 结论先行

当前问题不只是挥手次数太多，而是**接任务、整理、交代、提问、授权、汇总共用相似的手臂轮廓，身体没有不同的意图**。解决方式不是再画几张表情，也不是把挥手全部改成点头；应先把动作分成视觉上不同的句子，再设计它们之间的真实接续。

新主语法：**接住安排＝坐正收进；听汇报＝前倾静听；整理＝低位对齐；交代＝短促定拍；呈交＝双臂汇拢、胸肩前送、落手让位；问题＝留出一个空位；授权＝双手撤回；提醒＝挺身短举指；异常＝动作刹住；结果＝肩胸释然；监督＝安静看顾。** 招手只保留给明确的欢迎，不再给工作状态使用。动作没有指向项目坐标的前提。

“完整”指所有真实语义都有恰当表演或有意的安静，不是每个状态都必须演一段，更不是每个后端状态各生产一张脸。

## 2. 角色与舞台合同

### Varin
- Bot：主管兼秘书；接住安排、组织推进、听进展、整理、向用户递交决定和成果。不把她演成每次亲自搜索、敲代码、运行实验的人。
- Agent：陪伴与提醒；提示用户去当前 agent 工作区查看问题、权限、结果或异常。**不接单、不派工、不代用户批准、不冒充执行或汇总者。** 下文标 Bot 的句子不得在 Agent 中以换名方式调用。
- 任何身体表演都不证明业务已经完成。已读不等于已答，点头不等于授权，释然不等于所有项目完成，未知不等于失败。

### 小队 B 2.5D
- 每个项目以小团子负责人为中心，周围是更小的 child agent；负责人不是放大的 child 复制品。厚度、底部压扁、地面软影、有限遮挡建立立体感；不是漂浮 emoji。
- 尺度建议先以负责人高度为 1，child 为 0.42–0.55；Varin是主体。这个比值是候选，不是修改已批准几何的授权。
- 分派只由小队在真实事件上做一次内部聚拢/分开；负责人确认后，child 各回自己的近邻位置。不要让小队飞到 Varin 手边接不存在的纸。
- 小队承载具体项目与执行差异，Varin承载人际交流差异。她面前固定的工作区不是某项目的坐标。左右换位、人数改变时，主身体句不变。
- 平稳执行可以是 child 低位小幅工作与负责人偶尔检查；没有真实进展不假忙。等待就静止，未知就保留中性。无全队同步弹跳、常驻闪光、飞线、连续旋转状态图标。

### 一致性锁定
1. 唯一 master：同脸型、眼距/眼色、额发分区、辫髻与发饰、发色层次、服装拼接、袖口、腰带、靴型；同一个**空心菱形吊坠**，不能变成实心/双吊坠。固定的是形制、链长和连接结构；胸肩运动允许合理的小幅摆动、遮挡与透视变化，不能随换脸无因漂移。
2. 画布/镜头/角色比例固定；凳座几何、身体骨段长度、电脑底座厚度与铰链结构固定。普通交流中骨盆有真实坐骨支撑，不无因滑移；坐姿调整和提放则必须允许骨盆、髋膝随承重关系实际移动，绝不把整个身体冻结。画面裁切不得各帧按人物包围盒自动缩放。
3. 正面自然直颈是默认。俯仰从胸肩和髋带起，疑问不得靠持续歪头；左右摇摆、耳位忽上忽下不算活泼。
4. 电脑底座由大腿承重，默认一只手轻稳底座、另一只手松放低位。双手离开前必须已证明电脑在腿上稳定，不能悬浮。默认手侧一经选定不镜像交换。
5. 真实动作会改变袖褶、胸肩、侧发遮挡，不用固定外围mask把全身锁死。发梢/袖口落后主动作少许，停止后也真正停下；不是每帧都在飘。
6. 后续原画从同一结构母版连续推演，不独立生成人脸后贴回。关节和衣褶允许形变，身份和刚体不允许漂移。

## 3. 表演节制与共用接口

- 每句必须有 **A 起意 → B 身体 → H 手/接触 → E 眼神 → S 收势**。下表完整写这五项；X 是中断出口。
- 参考短句 0.8–1.4 秒、交流句 1.3–2.4 秒、生活句 2–4 秒。先验证运动，再调节时长；不得为塞进视频加速。
- 静置是长段，动作是标点。保持不能循环整条句子；停在支撑真实的稳态，只有稀疏眨眼和极弱自然呼吸。禁止整人缩放呼吸。
- 只共享兼容的起点、接触段、落手；下表规定的主要轮廓、重心、手的功能不能互换。
- 建立 `R开`、`R闭`、`R听`（略前倾）、`R等`（双手离键）、`R持物`、`R托机`。它们是待制作的结构合同，不是现成文件名。开合盖是机械句，不借动作突变盖角。
- 通知事实先呈现；身体完成短回收不应阻塞信息。过期的欢迎/庆祝/生活动作丢弃，不补演。
- 无动作字典能无字幕传达“哪个项目、何种权限、失败代码”。验收要求看懂**交流类别与态度**，具体事实仍由信息层准确呈现，不拿这一限制为重复表演辩护。

## 4. 工作与交流：每条是不同的身体句

### W01 接住安排（Bot；accept / director-intake）
- A：呼吸收一小拍，低位稳定手先确认电脑承托。
- B：骨盆不动，胸口从舒适坐姿立起来，肩线向前略合；不是头独自点一下。
- H：表达手从低位向身体中线收进一次，掌朝自己、手指自然合拢，止于腹前，**不转成向外摊掌**。
- E：看用户，短认真停留；嘴角温和，不用闭眼大笑。
- S：手沿内侧落到低位，胸口保留工作态，袖口停稳。
- X：未内收可直接落回；内收到一半顺势收完低位路径再落，不倒播。后接 W02/W03 只需实际肩肘桥。
- 独特读法：向内收＋坐正，“我接住了”。独立虚拟委托卡只在外部安全区自行收束，不贴手、不飞到电脑；只由新accepted delegation触发，历史记录、选中项目、普通run started都不算接单。

### W02 听汇报（Bot；director-listen，废除左右身体索引）
- A：手停止小动作，注意先稳定。
- B：从髋小幅前倾，胸肩一起向前，头颈保持长度；膝脚安静。允许头随真实躯干重心自然倾动，但不独立歪头代替身体前倾。
- H：双手都低位安放，肘自然随胸肩前移；**整句不举手**。
- E：眼神聚焦前方，不扫队位；可一次缓眨，听完才极轻垂直颔首，不持续点头。
- S：胸口先回，头跟回，手仍安放，不另播摊掌。
- X：从当前倾度直接减幅回 R开；有紧急提醒先止住前倾，再挺身，不闪切。
- 独特读法：双手静＋上身靠近。与W01的立直内收明显相反。

### W03 整理/准备（Bot；organizing / prepare）

本句实物整理仍是独立待验证候选，不是W01/W07的前提，不授权修改母版。现有母版没有凳袋；须先证明常驻收纳、取放及拖动接触，不能凭空加入道具。见[接触与虚拟案卷合同](desktop-companion-prop-contact-v5.md)。
- A：目光先落向自己固定的工作区，肩放低。
- B：上身略向工作区收拢，胸部保持正面，重心不偏向某个项目。
- H：在电脑侧方可见的低位，用指腹把**同一个薄便笺夹**的边沿对齐两次，第二次更短；另一手稳住夹/电脑。不是拍空气。夹是她的日常工作道具，不代表已产出报告。
- E：目光跟随低位边沿，完成后回前方。
- S：便笺夹放回固定收纳位，手离物再落下，肩回舒适位。
- X：物件接触期先固定/放稳再松手；不可把夹瞬间删除。若空间无法成立，本句退回机械分镜重新设计，不进入生产，也**不能回退摊掌或借生活擦袖冒充整理**。
- 独特读法：低位双手对齐的短节拍。道具原画不合格前此动作标“待制作”，不模拟完成。

### W04 权衡（Bot；think）
- A：整理停止，肩轻收，手先离开工作接触。
- B：上身轻微后收，不低头伏在屏幕上；脊柱仍直。
- H：一手低位稳机，另一手食指第二指节轻靠下巴侧下方，肘贴近身体；不挡嘴、不托整张脸。
- E：目光略离开焦点到自身前方近处，再回用户；眉间只轻收，不扮侦探。
- S：指节先离下巴、肘落、手归位，胸肩回正。
- X：从接触点先离脸再降臂；突然抓起时仍要完成脱离，不能手穿脸。
- 独特读法：内聚的小三角轮廓与后收，区别听汇报的前倾无手。

### W05 交代推进（Bot；dispatch）
- A：先坐正，表达肘从低位松开。
- B：胸肩向前给一个短而清楚的“定下来”的节拍，幅度克制。
- H：手指自然并拢，掌侧朝前，在自己身前做**一次短垂直落拍**，止在电脑上沿之外的安全空区；不伸向小队、不横向摆、不挥两次。
- E：前方稳定目光，动作到点时保持清楚，不怒目、不发号施令式夸张。
- S：落拍后顺势降臂回低位，肩松开。负责人/child仅按真实分派更新。
- X：起势可直接取消落拍并回收；下落中沿路径落到低位，不补拍、不逆弹。
- 独特读法：一拍垂直收束。不能用在Agent执行状态。

### W06 持续看顾（Bot supervise；Agent execution-observe及一般执行观察）
- A：进入稳定工作坐姿一次。
- B：直颈、胸肩自然，保留重量；不逐队巡看。
- H：安放低位，不打字、不摆掌。
- E：自然前方/自身电脑之间偶尔短移焦，稀疏眨眼。
- S：事实变更时从当前稳态接下一句，不额外收尾。
- X：已是安全支撑态；只需新句实际起势。
- 独特读法：有意的安静。reading/editing/browsing/checking等Agent内部执行类别不各逼Varin演工具动作。

### W07 汇拢并呈示（仅Bot；director-gather-present / output）
- A：当前小动作停住，髋带胸略前收，先确认双腿稳定承托同一电脑。
- B：两前臂从电脑外侧上行并向中线收拢，双肘靠近，形成紧凑轮廓；胸肩随后立起并向用户略前送。骨盆保持坐骨支撑，膝脚不假忙。
- H：手背/掌侧朝镜头，双手自然弯曲但不合掌、不夹持空气。呈示时双手沿电脑两侧**向下撤回**让出观看空间，一手先重新稳机；不以横向展开双掌作为峰值。
- E：从自己的工作前方转看用户，温和清楚地停一拍。不是表演已经读完/批准结果。
- 场景：独立虚拟案卷在角色与小队之外的安全区汇拢、展开；始终与手/电脑分离，不代表实体纸、不投掌上接触影。仅一个真实项目的本轮结果；其他小队安静但状态仍可见。
- S：胸肩回舒适位，手落稳、袖发余势停止；案卷退回静态信息层或淡出装饰层，不清除结果事实。
- X：汇拢中沿外侧直接降手；前送中缩短胸肩前意，先稳机再归位。抓起时根立即随输入，两手完成真实托机交接后才收腿；虚拟案卷退场，不追凳袋、不补播过期句。
- 独特读法：双臂收束→胸肩交代→落手让位，与W01单臂内收坐正不同。关闭场景后仍须可辨；当前场景实现不代表新身体资源已通过视觉验收。
- 事实边界：只呈示已观察的精确thread/branch/run从非终态转为completed且有Bot协调资格的结果。仍有child工作时不演全队完成；失败、取消、未知不调用成功呈示。

### W08 提醒注意（Bot转呈 / Agent提醒；director-notify-attention）
- A：当前小动作停一下，肩胸收住。
- B：坐得稍高、胸口打开，头仍直。
- H：表达手在身体近侧抬起，食指温和立起一次，其他手指松弯；高度不超过下巴，不摇指、不戳用户。
- E：明确正视，眉轻抬，嘴唇微启即可。
- S：食指先自然收拢，肘落，手回低位；信息保持可查，身体不持续招呼。
- X：半抬直接收指落肘；已到峰值不必补足停留。提醒被看见不意味着事项消失。
- 独特读法：窄的单指竖向轮廓＋挺身。不是通用庆祝或权限句。

### W09 有问题等你补一句（query）

以下低位手方案仅保留作原设计记录；实际制作采用[接触补充方案第4节](desktop-companion-prop-contact-v5.md#4-w09修订低位间隙不可被电脑吃掉)的可见近胸留话动作。必须在实际桌宠尺寸验证，不能让电脑把身体表达遮掉。
- A：注意从工作区转向用户，吸气很轻地停住。
- B：胸肩略向前，肘靠身，直颈；没有头歪。
- H：两手在低位原安放处短暂分开一点，留下一个清楚的小间隙，手背偏上、掌不翻向外；像给对方留一句话的空间，不是双手摊开“我不知道”。
- E：眼睛专注、眉头中央轻抬，嘴形成很小的问询后闭合。
- S：手留在低位安全处，身体保持可交流的前倾，再自然回正；不一直维持疑问脸。
- X：分开的低位手可以直接收拢安放；不能接授权确认点头。问题仍在就仅保持事实提示。
- 独特读法：低位小空隙＋前倾询问；与W08的高窄手、W10的后撤双手相区别。

### W10 需要你的授权（permission）
- A：正在做的动作**明确停住**，不继续输入。
- B：胸肩向后留出一点距离，保持端正，不躲闪。
- H：两手从键区撤到自己腿上/电脑两侧固定安全位，手指轻合；清楚表示“我停在这里等你决定”。不举掌、不盖章、不合十祈求。
- E：认真看用户，眉眼中性温和，不预先点头。
- S：双手安放进入 R等，长等待期间不重复撤手。
- X：撤手中沿同一路径安放；收到拒绝也只回普通可用状态，不失落。真实允许后才可进W12。
- 独特读法：双手退场＋胸肩留白；不用锁图标替代这一真实停手过程。

### W11 结果可看 / 本轮完成（Agent结果提醒；completion / output-emphasis）

释然需要预紧到释放的完整张力变化，静态微笑不能代替。具体 T0–T4 按[接触补充方案第5节](desktop-companion-prop-contact-v5.md#5-w11修订释然是张力曲线不是笑脸)制作；已有张力起点不再多耸一次肩。
- A：先确认真正结果边缘，正在用力的肩胸停一拍。
- B：呼气般轻落肩，胸口从紧绷恢复舒展；允许一次极小的坐姿回弹，不能整人跳。
- H：双手仍低位，其中表达手指轻松展开再安放，不抬到胸前。
- E：眼神回用户、嘴角小笑，最多短眼笑后睁眼；没有持续闭眼自满。
- S：落肩完成便安静，不再接欢迎挥手。失败/未知不得调用。
- X：未笑就取消庆祝；中段自然收笑回中性，身体走落肩余程。新工作马上按最新事实进入。
- 独特读法：释放张力，而不是展示掌心。Bot若真实呈交用W07，不同时叠加庆祝。

### W12 理解了 / 真实决定已收到（understood / permission-allowed）
- A：先等对应真实回答或决定回执；本地轻点不触发。
- B：一次小幅胸颈共同下沉再回正，像认真记下；不鞠躬。
- H：手保持安全安放，完全不举手。
- E：看用户，颔首底部短眨可选，回正时睁眼。
- S：回 R开，不附带开工表演，不暗示已执行成功。
- X：下沉中完成最短回正，不连续再点；可直接接新事实的起势。
- 独特读法：单次确认颔首。只在这个类别使用，不拿点头填满其他句子。

### W13 异常 / 已知失败（failure）
- A：当前动作刹住一拍，不受惊跳。
- B：肩胸略收、上身略向电脑前收，头随胸而非突然换脸。
- H：手停在当下接触后安全安放，不攥拳、不挠头、不摊掌。
- E：视线落到工作区，笑意收掉，随后回用户，眉眼认真但不焦虑。
- S：稍回直立并保持可帮助的姿态；不长期沮丧。
- X：先解除当前接触，沿最短路径到 R开；新进展不立即开心庆祝。
- 独特读法：有重量的停止＋查问题；与W11释然明确相反。

### W14 结果未知/需要核对（unknown-effect-check / disconnected）
- A：先停下对进展的期待，不制造失败表情。
- B：身体保持直立，比W13更少内缩，稍延长静止。
- H：稳定手仍在，表达手轻离开键区后安放；不再输入试探。
- E：一次从自己的电脑到用户的焦点切换，眉眼保持审慎中性。
- S：回安全观察，事实仍未知便不演恢复。
- X：从当前安放位直接进入最新可信句，不补演旧报告。断联与效果未知具体含义由信息层区别，不谎称身体能编码网络状态。
- 独特读法：审慎留白，而非失败收缩；可共享该安静类，不宣称两套独立动作。

### W15 排队/外部等待/退避（queued / external-wait / retry-wait）
- A：确认当前无需她主动工作，动作减速。
- B：胸肩回舒服的直坐，不瘫倒。
- H：表达手盖在另一只手附近的低位安放区，避开键区；不玩手指/敲桌催促。
- E：目光自然，偶尔眨眼，不周期性望来望去。
- S：维持安静，真实进展才解除等待；倒计时归零不等于成功。
- X：手从相邻安放处解开到下一句起点即可；无等待循环尾巴必须播完。
- 独特读法：低位静置等待。三者共享是诚实的安静类别，不能统计成三套动作。

### W16 取消/收束（cancel-settling）
- A：当前动作放缓，先去掉尚未执行的后续意图。
- B：胸肩停止前送，逐渐回中性。
- H：按当前实际状态释放/放稳/落手，不生成一个固定“取消手势”。
- E：从工作区回自然视线，表情中性。
- S：回对应安全态，等待真实业务终止信息；动画收束不证明任务停止。
- X：这本身就是阶段化退出，可被真实拖动接管。不是所有动作统一闪回同一张R。
- 独特读法：收住正在做的事；需要每句不同出口，不另拍假通用姿态。

## 5. 日常与机械：不同接触链，不用工作手势冒充生活

### L01 安静陪伴（idle-closed / relax-idle / quiet-open-blink）
- A：上个动作真实落定后进入，不另做起手。
- B：骨盆承重、肩胸自然，颈部正直；微呼吸由胸腹局部体现，不伸缩整张图。
- H：电脑/大腿上的手保持真实搭放，偶尔指尖自然松开但不周期抓握。
- E：睁眼常态，稀疏正常眨眼；瞳孔不无目的乱滑。
- S：无需循环收势；下一动作从实际安放态起。
- X：随时是安全起点；闭盖收到工作先走真实开盖，不凭状态瞬开。
- 读法：安稳有人陪，绝不把每几秒的晃头当生命感。

### L02 注意到靠近（hover-response / open-hover-response）
- A：目光先稍集中，肩胸微提。
- B：上胸轻向用户靠近，幅度小于W02，髋仍稳。
- H：双手原位，不举手；指尖从松搭变成有意搭放。
- E：看用户，嘴角一点柔和，眼睛保持开。
- S：胸肩退回，眼神放松，手位不换。
- X：指针离开便走当前短回收；无须补足峰值、无须回键区桥。
- 读法：短暂的“注意到你”，不是欢迎挥手，也不是同意。

### L03 轻点回应（tap-response）
- A：小幅收肩，像被轻轻叫到而非惊吓。
- B：胸肩向上轻回正一次，不弹凳、不摇头。
- H：表达手在低位轻按自己的另一只手背一次，保留接触，手肘不外展。
- E：看用户，浅笑，最多一次短眨。
- S：按压解除，双手恢复松搭，肩回落。
- X：按着时先解除接触再走下一句；连续轻点合并，不堆积拍手。
- 读法：一个近身小回应，与hover无手动作、欢迎的外侧短招手不同。

### L04 重复轻点（tap-repeat-response）
- A：前一次已经落定后才有资格，先短静止一拍。
- B：肩线轻收又松开，直颈；不缩成害怕姿态。
- H：双手仍低位，指尖轻交叠，**不再抬臂**。
- E：眼睛柔和眯一点，再恢复正常；一瞬“我知道啦”的轻俏皮，不翻白眼、不生气。
- S：指尖松开，回日常安放。
- X：随时从低位解开；被工作打断就取消俏皮尾音，不补演。
- 读法：静一拍的小调皮，不增加夸张动作奖励连点。

### L05 欢迎（welcome；唯一允许短招手的类别）
- A：已有可靠欢迎事件，表达手先离开接触，胸口坐正。
- B：上身轻向前、肩随臂打开，骨盆不动。
- H：在近侧抬至肩下，一次小弧度招手，**只有一个往返**；手掌不长期对镜头，不用于结果/授权/提问。
- E：眼神面向用户、浅笑；不用大张口。
- S：手腕先回中性、肘落、触达低位、肩放松。
- X：半抬可直接落回，已摆则完成当前方向后收腕；欢迎被新事项打断后丢弃。
- 读法：明确社交招呼，因此从工作动作词汇中彻底隔离。

### L06 顺侧发（quiet-hair-smooth）
- A：稳定手确认电脑，目光短落到发侧而非追踪鼠标。
- B：同侧肩轻抬，胸肩微补偿，头保持接近正位。
- H：另一手抬到固定的一缕侧发，用指腹沿发丝轻顺一小段；不是揉头顶，不换发型。
- E：眼睑自然柔和，顺完回前方。
- S：指尖先离发，肘下降，手归位，发束末端最后落定。
- X：接触中必须先离开发丝，再收臂/托机。不能发丝随手黏住或突然消失。
- 读法：明确发丝接触，手的轨迹不与招手共用。

### L07 理袖口（quiet-sleeve-smooth）
- A：双手低位相遇前确认电脑腿托稳定。
- B：肩线略向内，胸口轻收，脊背不弯成团。
- H：一手指腹抓理另一袖口边缘，短沿布料抚平一次；两腕/袖口真实遮挡。
- E：看袖口，整理结束看回前方。
- S：先放开布料，两手分回各自低位，肩舒展开。
- X：先释放布边再分手，不能抓布姿态直接切托机。
- 读法：低位交叉双臂＋布料接触，与W03道具平行对齐有不同剪影和材质行为。

### L08 调整坐姿（quiet-seat-adjust）
- A：双手先稳住电脑两侧；脚踝准备而非先踢腿。
- B：骨盆小幅卸重再重新坐实，膝盖随髋调整；胸肩补偿，凳不变形。
- H：两手持续保护电脑，不一边调整一边挥手。
- E：短看自己的坐姿区域，再回自然视线。
- S：骨盆承重→膝踝安稳→双手回轻搭→袖发落定。
- X：卸重时先落坐承重再接普通动作；实际拖起则直接进当前承重匹配的托机分支。
- 读法：重心来自坐骨与膝踝，不是整图上下跳。

### L09 肩背舒展（quiet-stretch）
- A：只在闲置；电脑腿托稳定，双手从低位脱离。
- B：背部轻伸、胸口打开，肩胛向后，颈部不折向后。
- H：双肘低位向两侧后方打开，前臂自然弯曲，手不高举过头；避免屏幕/长发穿插。
- E：一次短闭眼舒适表情即可，睁眼时开始回收；不是哈欠。
- S：胸背先回中性，肘向前归位，手接回低位，肩最后放松。
- X：途中减小展开幅度后前收，不能倒放整句、不能直接把已后伸的手切到键盘。
- 读法：对称肩背开合，属于真正全身支撑调整，而不是一只手举高。

### L10 入睡（rest-sleep entry）
- A：仅安全长闲置，双手先安放、电脑处于已批准安全机械态。
- B：胸肩逐渐卸力，头仅随身体一次小幅自然前沉；不反复点头。
- H：维持低位支撑，不松脱电脑、不把手穿到腿里。
- E：眼睑后于身体渐沉，一次短哈欠可选但不得循环；默认无需夸张张嘴。
- S：进入稳定小憩姿态，发袖落定后只极弱呼吸。
- X：尚未睡稳就按当前眼睑/肩位进入醒来路径；不强迫先闭眼完成睡眠。

### L11 小憩保持（rest-sleep hold）
- A：承接L10稳定端点。
- B：无周期性大点头，骨盆/电脑稳固。
- H：手固定安全搭放。
- E：闭眼自然，眉不反复跳动。
- S：外部事件结束此保持，不播放哈欠作结束。
- X：新任务/本地输入进入L12，真实拖动根立即跟随并结合醒来托机。

### L12 醒来（wake exit）
- A：先睁眼重新定位，不先弹身体。
- B：胸肩渐恢复支撑，再回直颈舒适坐姿。
- H：先轻稳电脑，确认承托后才允许其他表达。
- E：短朦胧到清楚，不能用脸突然换尺寸表现醒。
- S：进入 R开/R闭当前机械端点，再接最新事实，不补欢迎/旧闲置。
- X：中途拖动直接托机；高优先信息即时出现，身体继续最短醒来支撑路径。

### M01 开合盖（机械专用，不当语义手势）
- A：稳定手扶底座，另一手准确接触盖边。
- B：胸肩随伸手略前倾，大腿承重。
- H：围绕同一铰链转盖，手在实际盖边随行；开与合的承重/离手段分别画，不盲目倒放。
- E：看接触点，结束回前方。
- S：盖到稳定角度后手离边归位，胸肩回正。
- X：每个可中断盖角都必须有固定/托机出口；没有中间机械源就不可在中途切换盖角。工作事实不等机械动画显示。

### M02 提起、悬空、落座（relocation）
- A：真实拖动根立即随输入，不等表演；当前接触先释放，双手先后托住电脑。
- B：从坐骨承重转为悬空的膝腿收拢，脚自然垂下；不是整人缩放。电脑仍是同一刚体。
- H：保持两手托底/稳边，有交接顺序；不能一帧同时改变所有接触。
- E：轻注意、可短眨，不恐惧、不大惊叫。
- S：释放时凳座接触→骨盆承重→膝脚回稳→一手放松→另一手回轻搭→衣发落定。
- X：早放按当前实际阶段落座，不先强制演完整悬空；再抓从当前坐下程度重新托稳，不闪回峰值。所有新源需自己的去凳/早放/再抓入口。
- 读法：承重关系改变是主体。电脑角度、鞋和脸不能在提放中换版本。

## 7. 中断是表演的一部分，不是末尾补一张母版

每条制作单都须包含：A0未离接触、A1已离接触、B中段、P峰值/保持、S正在返回这五类实际状态；若动作不具有某状态，明确“不适用”，不能虚构统一五帧。对每个实际原画SHA提供：
1. 普通更新：去掉过时意图，走到最近安全支撑态；能直接顺接的必须有实际接续原画。
2. 更高优先提醒：当前接触先解开，不必回母版再起第二条长桥；信息即时显示。
3. 拖动：根立即移动，手臂脱离/收物/托机；去凳图与当下身体一致。
4. 早放：依据托机/悬空/落座当前阶段走最短真实落座。
5. 再抓：依据当前承重再次提起，不突然跳回全悬空。
6. 隐藏/降动效：不在危险接触半途冻结；恢复读取最新事实，不追播历史。

持物、接触发丝、抓袖、触脸、开合盖、坐姿卸重各有不同恢复序列。**“统一回R开”只是目的地，不是通用动画。** 动作间不可用透明度交叉淡化掩盖手/脸/电脑跳变。

## 8. 无字幕辨识与身份一致性的真正验收

### 第一关：先把意图拍对（姿态研究进行中）
- 先做不带表情、不带字幕/状态图标的小尺寸动作分镜。W01、W02、W05、W07、W08、W09、W10、W11、W13放在同一页；只有静态峰值不够，必须显示A/B/P/S四拍。
- 每对动作至少在**剪影、重心方向、手的接触对象、节奏组织**中有两项实质差异。不接受“同一手臂路径＋眉毛/停留时长”的区别。
- 关键对比：接单向内 vs 呈交双手向前；倾听前倾静手 vs 权限后留撤手；提醒竖指 vs 问题低位空隙；结果释然落肩 vs 异常收紧查阅；整理并行低位对齐 vs 理袖交叉接触布。
- 拿掉道具如果只剩同一摊掌，说明设计失败；道具应有拿、接触、放的完整身体行为，不能贴图代演。拿掉表情仍应区分主要交流类别。

### 第二关：同一个人实际连续地做
- 同画布叠看结构，不按角色bbox独立缩放。脸部各关键角度有统一头骨/眼线/耳位参考；保持发饰与髻的位置逻辑。
- 空心菱形吊坠形制、链长、连接关系连续；随胸肩产生的摆动/透视必须物理一致，不要求逐像素钉住；衣襟/腰带不漂，袖口厚度不忽窄忽宽；膝和靴子不因动作“美化”变长。
- 检查所有手物接触：接触先成立才承重，先卸力/离开才移动；电脑铰链和凳座是固定几何，不为好看改变。
- 正常速度至少检查：安静→接单→倾听→整理→分派→监督；监督→问题→等待→确认；监督→权限→拒绝/允许→新事实；监督→结果；理发/整理道具/触脸→拖起→早放→再抓；睡眠中途→任务。
- 动作间脸型/头大/肩宽不能突然“更可爱”。单张画漂亮但跨句不是同一人即退回。

### 第三关：不靠说明文字给自己打分
- 提供去字幕/去图标版本，按正常桌宠尺寸、正常速度、含完整收势和安静间隔观看。让评审描述“她刚刚做了什么”，不要给预设动作名称诱导。
- 需要辨识的是接住、听、整理、交代、呈交、提醒、提问、停手待决定、释然、查问题；不要求从身体猜“权限类型/哪个项目”。
- 若反复被说成“又在挥手/又在摊手/又在点头”，该类别返工；不能用字幕证明它不同。
- 先审核心C/D新句，再审日常与组合，再做完整视频。完整视频展示所有句子各一次并留自然安静，而非把几十个alias轮流贴在同素材上。
- 机器证据只证明来源、闭包、覆盖和播放器正确；视觉辨识/身份一致/角色语义另列验收，不能互相代替。

## 9. 制作顺序与明确的不做

1. 先统一R开/R闭与可见工作区机械草图，验证W01单臂内收、W07双臂收束后落手让位的区别与电脑承重。虚拟案卷独立于人物；W03实物夹仅另行研究收纳/接触，不作为整套动作的先决条件。未通过剪影与支撑验收不批量生成。
2. 先审九个最容易混淆的工作句四拍分镜；通过后才绘完整中间与接触退出。
3. 用同一master逐句连续绘制，不分给不同模型独立重建脸；不同作者也必须遵守同一结构参考与连续校核。
4. 再补日常与拖动闭包，最后按同一代次做完整预览。当前v4不因局部新图好看就混合替换。
5. 本稿约束后续制作，不是视觉验收或安装记录。未制作的动作继续制作；不自动替换选定包，不把文档写完当视觉任务完成。

**不做：** 用更多脸救同一摊掌；用左右指向救任务关系；给每个工具状态造亲自工作假象；用闪图标替代演戏；所有静置都加小动作；大幅歪头卖萌；让道具无中生有；所有动作末尾硬切R；拿SHA覆盖率宣称用户已认可。
