# 固定开盖坐姿道具研究

独立保存炭灰小凳、笔电底座与机盖，不重复复制[人物stage 1](../stage1/README.md)。返回[资产索引](../../README.md)。当前是默认色真实美术研究，**不是最终rig或生产动画**；人物身份仍以已选Q版母版为准。

## 文件与恢复

- `props-atlas-original.png`：1254×1254原始道具atlas，原字节保留。
- `props/*-atlas.png`：同画布的3个独立提取道具；`props/{chair,laptopBase,laptopLid}.png`：配准到人物1382×1382画布的3层。
- `props-manifest.json`：区域、缩放/平移或透视系数，以及临时铰链两端(480,755)–(690,795)。
- `props-placement-qa.png`：与stage 1互斥人物层合成的静帧，已作视觉检查；不代表动态接触、开合或浏览器性能已通过。
- `inventory.json`：来源SHA/字节与入库SHA/字节分别保存。所有PNG均未改动；脚本只修正文案和相邻人物资源路径，不改像素算法。

安装Python的Pillow、NumPy、SciPy后，运行`python extract_props.py`。脚本从相邻`../stage1/layers-partition-v1/`读取人物层，在本目录重建6层道具、mapping和QA；需先保留当前Git修订以便核对。凳/盖用等比缩放和平移，底座用四点平面透视配准。

## 遮挡与范围

合成次序：后发→凳→其余人物层→电脑底座→双手→机盖。该机位可见右手接键面，左手被机盖遮挡；凳右侧座面和后腿可见。每条动态动作仍须检查掌根、铰链、座面深度与遮挡，不能照搬一张静帧的z序到所有姿态。

本资源只支持固定开盖坐姿研究。闭盖内外面、抓盖/抱机手、真正抬头角度、独立视线、自然闭眼、隐藏面及大姿态仍需补绘/校准。08提起规则不变：人抱闭盖电脑，凳留在世界坐标淡出/淡入；本包尚未完成这些动作资源。

图片许可沿用[资产索引的边界说明](../../README.md#完整性与许可边界)，本次保存不新增素材许可承诺。
