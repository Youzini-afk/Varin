# 外观连续性参考

以 `open-neutral.png` 的实际画面为人物结构参考，不用动作名称或口头简化替代看图。姿势/透视/衣料受力可以变化，身份与服饰结构保持同一套。

- 蓝色眼睛、原眼睑构造与脸型；真实表情不要求脸部像素冻结，也不能不断改成更圆更幼的新脸。
- 同一额发分区、发髻、黑蓝发饰；可自然随胸肩运动，不额外增加发饰或改变发量。
- 金色细链、空心菱形吊坠；可随重心摆动，不改成实心宝石或另一种连接结构。
- 每侧肩带是一组扣件，包含上方矩形调节部分及下方圆/D形连接部分。不要误简化成一个平矩形，也不要增生任意多环；动作遮挡不要求所有部件都同时露出。
- 衣袖、白外套蓝色图案、腰带、黑裙蓝内里与靴子遵守同一构造。褶线随动作变，图案、徽牌不得无故消失或增生。保留原徽牌的蓝色图形，不另编姓名。
- 凳子采用配方中的冻结原图；参考图里模型重绘的凳体不是几何依据。
- 电脑开/合端点必须属于同一个实际机械过程。闭盖图漂亮不代表与开盖铰链兼容；校准动作输入以当前机械研究为准，不能硬切两个独立生图端点。

只把实际正常 alpha 合成下可见的杂边当视觉问题。曾见的多数强洋红 raw-RGB 像素实际 alpha 不超过5/255，不能据透明像素RGB误判；可见白斑、轮廓漂移则必须修。
