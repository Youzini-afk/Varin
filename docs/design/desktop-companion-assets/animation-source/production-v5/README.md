# v5 动作重修工作源

本目录只保存当前保留的外观参考、姿态锚点、提醒、等待授权、电脑开合与提放工作源；不包含抽图试稿、失败版本、对照视频或自动安装结果。完整动作、中间帧与提放衔接继续制作，公开运行包没有替换。

- `reference/open-neutral.png`：用于约束人物脸型、服装、发饰与吊坠的高分辨率工作参考。其生成的凳子不作为几何依据。
- `foreground/open-neutral.png`：安放双手的中立前景。
- `foreground/listen-crest.png`：胸肩随髋前倾、双手低位安放的倾听姿态。
- `foreground/reminder-crest.png`：近身短举食指的提醒姿态；不用于接单、授权或结果。

这些前景都是完整人物原画，不拆头脸或肢体来驱动。凳子应遮住的区域保留透明缺口，不能把这个前景直接当成悬空去凳人物；真正提起时需要另画显露后发的同姿身体。固定凳来自既有 `production-v2/relocation/frames/world-stool-grounded-v4.png`，使用相同像素与位置，避免逐帧重画凳体造成抖动。

用已有工具重建512画布的坐姿图，产物放在仓库外：

```sh
python tools/desktop-companion-animation/pack_sequence.py \
  docs/design/desktop-companion-assets/animation-source/production-v5/seated-preparation.json \
  /tmp/varin-v5-seated-sources --prepare-seated
```

这里只做整幅等比缩放和固定凳底图合成，不按每帧包围框缩放，不贴脸，不做非刚性变形。输出 `prepared.json` 记录实际显示PNG的SHA；后续提起映射必须引用该SHA，不能误用原始前景SHA。中立姿态提供一张同姿完整去凳身体 `detached/open-neutral.png`，用于进入提起时的候选对照；提放的side/support/return也提供同姿去凳图。其他尚未登记的counterpart保持缺失，工具不自动补图或接入播放器。

已检查中立、倾听、提醒三姿态在灰/暗底上的凳面接触和遮挡。这个检查不代表完整动作已通过；升降手、回位、身体重心和真实打断还须连起来审。更多不同的身体动词及道具接触按 [v5动作语言](../../../desktop-companion-motion-language-v5.md) 和 [接触方案](../../../desktop-companion-prop-contact-v5.md) 制作。

中立去凳图采用新绘制的完整后发，不用旧凳腿形状裁切后发，也不采用会留下接缝的限域underpaint组合。360px灰/暗底检查中，脸、手、膝与双靴保持同姿读取；实际提起/落座时序尚须随完整动作连接检查。

## 提醒整句

`motions/reminder.json` 保存离键、低/高抬手、短举食指、松指、落肘、接近键区、落手的初始曝光与阶段退出顺序。`sourceId` 解析到本目录 `seated-preparation.json` 的生成图；不是把原始前景当显示图。00/末尾共享中立，峰值共享既有提醒锚点，其他六张各有自己的真实原画。

该句仅用于提醒注意，不再拿去改名作接单、授权、问题或结果。单句已有360px持帧审阅；落肘段的速度与同姿提放仍继续校核，不通过定格图数量宣称顺滑。这里没有保存试稿、失败中位图、GIF/视频或派生图集。

## 等待授权整句

`motions/permission.json` 将撤手、双掌落膝等待、恢复分别保存。五张选定新原画保存在 `foreground/permission/`，起点和终点引用现有中立源，不重新生成休止母版；没有把提醒的举指或摆手改名充数。撤手中段通过键区投影只短暂经过，不驻留或循环敲键；360px曝光序列未出现重复按键/回弹，末段自然恢复键区接触。

等待由真实待处理请求保持，预览的1200ms不等于运行时自动结束；恢复动作不表示批准，桌宠点击也不批准请求。这里保存制作工作源，不提前接入运行包。五张同姿去凳工作图已登记；可见脸、手、腿与电脑维持原姿，凳后后发单独补全。完整承托/中断路径及正常速度的后发连续性仍须随播放器验证。

## 电脑开合

`foreground/closed-neutral.png` 是按同一电脑铰链校准的闭盖共享端点，`motions/lid-opening.json` 与 `lid-closing.json` 分别保存完整起手、转盖接触和收手。两个方向共用相容的机械接触姿态，各有自己的进入/收束，开态仍回到原 `neutral`。

只保存15张选定新源，没有保留第三手失败稿、旧静止电脑变形版本或对照视频。开放端的五个静止阶段及最后握盖姿态已重新校准为同一电脑外框/底座；360px相邻原画检查不代替完整播放器和逐阶段提放验证。旧日常闭盖动作必须先对齐此端点，不能只改姿态名硬接。

## 提起与落座

`motions/lift-open.json` 记录双手靠近、共同承托、小幅悬空、落座承重及回键的选序，包含提前放下/重抓的制作说明。三组新坐姿前景及同姿去凳图、中立共享对与两张悬空原画构成当前工作链；落座末段已向同一中立的后发/裙片轮廓收束。

拖动越过阈值时native窗口立即跟随，不等待角色收手或抬腿；悬空650ms仅是预览曝光。这里的阶段注解不是另一个运行时API，必须由既有播放器的实际显示SHA、grab/release与世界凳契约接入。未覆盖任意新姿态，也未宣称原生快速提放验证通过。

## 问题与本地互动

`motions/query.json` 保存近胸留话、落手与真实问题未答时的稳态；`motions/local-response.json` 保存靠近关注、轻按另一手背、重复轻点的指尖交叠，分别有退回、离手、解指路径。两组共用既有中立原文件，新增12张坐姿源及其同姿去凳图，不混入错误手势/漏衣片的尝试稿。

这些动作不批准请求、不代答、不制造任务完成。已在本地候选用既有播放器检查逐曝光提放与最新意图接续；候选检查不等于生产选定，全部动作的正常速度及原生世界凳/root视觉仍须完成。

轻点峰值采用240ms的轻闭眼回应；重复轻点采用180ms的克制半眯眼/小抿嘴，保持低位按手背与交指的区别。不是持续困倦或夸张怒颜，两组同姿去凳图同步修订。旧选定峰值由Git保留历史，不在当前目录堆放。

## 接手、查看、呈示与释然

本次增加39张精选前景/同姿去凳源，准备配方共63个坐姿条目。`motions/w01-director.json`、`forward-attention.json`、`w07-director.json`、`result-relief.json` 分别保存单臂内收坐正、双手低位前倾、双臂汇拢后落手让位、肩胸张力释放；不复用摆手中段。W01/W07只对应Bot的真实协调事实，Agent结果提醒使用独立释然句。

`motions/director-routes.json` 区分普通收势与提起承托。W07中段可沿实际降臂路径直接进入承托，不强制先跳回键区；释然T1被打断时经过T2回中立，不补播T3笑容。W01的H/R/S保持同一个ACCEPT_SETTLE场景阶段，身体仍分别收势。`selected-provenance.json`记录来源与校核边界。

这些是精选制作检查点。实际候选已做同姿入口、提前放下、重抓与最新事项恢复检查；正常速度的一致性、原生窗口/凳子位置及完整皮肤仍需继续验收。这里不包含诊断播放器、试生成或自动准入运行包。
