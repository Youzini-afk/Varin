# Closed companionship source suite

This selected source set extends the approved closed-laptop rest master. It contains physical art, authored exposure, and source-keyed withdrawal paths; it is not a stand-alone runtime installation.

## Physical phrases

- Closed response: low hand release, wrist rise, restrained palm acknowledgement, lowering and settled rest. Tap, repeated tap and welcome currently share this restrained physical phrase; they are not three distinct new drawings.
- Quiet idle: sparse half/closed/half eyelids inside a stationary rest loop. Blinking is not an idle leisure action.
- Hair smoothing: hand release, contact and smoothing, withdrawal, settled rest.
- Sleeve smoothing: hand crossing, sleeve brush, release, settled rest.
- Seat adjustment: supported weight adjustment and settling.
- Stretch: shoulder/chest opening, crest, arm unloading, settled rest.
- Sleep: yawn/relaxation entry, separate doze hold, then awareness, supported wake, unloading and settled rest. The sleep loop contains only the doze hold, never another yawn.

Every ordinary closed phrase joins the byte-identical approved R at `../../production-v2/lid/frames/closed-rest-rigid-v2.png`. The one-millisecond R samples mark connections, not diagnostic waiting periods. Actual rest-loop durations are intentional. The four leisure action names are distinct from their eventual UI triggering policy.

## Source and interruption contract

`manifest.json` defines 13 clauses, 11 action names and an explicit withdrawal route for every selected non-master source SHA. Routes stop at actual closed R rather than replaying the complete performance. `detached-index.json` maps exact seated source hashes to same-pose chairless counterparts for the combined pickup/landing graph. Do not match a detached pose by a semantic action label alone.

`source-provenance.json` records original input SHA, declared cell rectangle, uniform scale and output SHA. Three-panel originals are mechanically extracted into declared square cells, then uniformly resized as a whole canvas to 512. No per-pose bounding-box fit, frozen-body masking, alpha repainting, or geometric pose correction is applied. Chairless counterparts are image-model edits, not pixel-identical subtraction; `outsideMaskPixelExact` is deliberately false.

Only selected sources belong here. Raw trials, rejected bridges, contact sheets, diagnostic lead/trail holds and browser review output remain outside the publish set. Combined runtime and native interaction validation belongs to the integration stage; source review alone is not an assertion that every application path has shipped or been visually accepted.

The selected `social-palm` frame received one localized builtin imagegen cleanup of a neighboring-cell border fragment. Its existing chairless counterpart was visually rechecked and retained. `sourceSHA256` identifies the current seated selection; `generatedFromInputSHA256` retains the actual pre-cleanup input used to generate that counterpart, not the newer selection hash. This does not assert pixel-identical character preservation.
