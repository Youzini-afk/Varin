# C/D expression source increment

Six selected 512 RGBA drawings: question, restrained result eye-smile, and serious rest, each with its same-pose stool-free counterpart. Only this source subset and portable relative manifests belong in the repository; raw generations and review pages remain local.

`manifest.json` provides three physical expression clauses and actual-source recovery. Query and result reuse the adjacent coordination wrist-return, keyboard-hover and keyboard-contact; serious rest adds no arm gesture. `unknown-effect-check` may share serious rest, but is a semantic suggestion, not proof of a failure. These are not approval/resolve gestures.

All pairs were reviewed full-size and at 360 px. Stool-free drawings preserve the instantaneous expression and laptop/hand/leg contact; newly visible hidden hair is expected, not pixel-exact preservation outside a mask. Source hashes and full-canvas scaling are recorded. Runtime selection and pickup joins remain integration responsibilities.
