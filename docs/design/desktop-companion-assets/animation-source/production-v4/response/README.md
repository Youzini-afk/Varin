# 开盖回应原画

本组包含十一张选定全身姿态及各自同姿去凳版本：完整关注七张、忙中短回应两张、一次俏皮收肩两张。三条物理句见 `sequences.json`，均从实际开盖母版进入并回到它；母版复用相对 `production-v2` 路径，不另复制，也不使用较早比例漂移的 R1 研究稿。

完整回应包含注意、抬臂、旋腕展开、呈掌、降臂、悬停和落键。忙中回应双手留在电脑区域，只作短关注与放松，不借完整招呼峰值顶替。俏皮收肩通过已相容的半收肩姿态和共同落键收回，排除改变电脑、腿靴和凳体的失败收势稿。

每条句子首末母版的 1ms 是图连接标记，不播放审图用静置书挡。长安静由待命状态负责，内部真实动作曝光保留。`ordinaryRecoveryByActualSource` 给出十一种实际姿态的有限回收；新事实即时更新，不能等待动画才显示。一次重复点击只产生一次适合的变化，不能排队补演历史点击。动作不批准权限、清除问题或表示工作完成。

`detached-index.json` 以真实坐姿 SHA 对应同姿去凳 SHA。去凳来自相应原画的生图编辑，不声称凳外像素逐点相同。`source-provenance.json` 保留原源 SHA、明确画格与固定全画布缩放参数。已有 512 坐姿文件保持原字节；去凳整张等比导出至 512，不作人物包围框逐帧缩放、局部底板粘贴、形变或 alpha 重绘。与抓放链共用的悬停/落键文件保持同一 SHA，可由抓放源直接引用。

本包仅保存选定必要生产源，没有原始抽卡池、失败稿或试片。运行时动作别名由整套整合指定：完整回应适用于本地关注，通知使用独立提醒原画；俏皮句不抢占尚需闭盖来源的通用重复点击映射。整套抓放、早放、重抓及跨族实际运行验收仍由集成步骤完成，本包不自动安装到公开资源。
