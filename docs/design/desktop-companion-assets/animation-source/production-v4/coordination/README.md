# 通用统筹与提醒原画

本组保留十个全身物理姿态及各自同姿去凳版本。角色、电脑和座位沿实际批准的开盖母版；原母版通过相对路径复用，不另复制。内收整理、面用户呈意、旋腕落手与短回收共享真实原画，左右项目别名不驱动定向视线或指点。

`manifest.json` 记录完整统筹、直接提醒和普通回收；`detached-index.json` 将真实坐姿SHA对应到同姿去凳SHA。中段展开取消沿转腕直接落手，不重新抬回胸前整理。所有提醒只表达可查看事项，不批准权限、不清除问题，也不表示所有项目完成。

原画已作360px浅深底、完整起落及十对同姿去凳检查。去凳图由对应源图重新编辑，不能声称凳外像素完全相同。`source-provenance.json` 保留实际源哈希及固定整画布导出参数；没有局部冻结底板、形变补帧或alpha重绘。PNG为可重打包的生产源，不附试片、失败候选及中间尝试。

本组尚未安装到公开运行资产。完整新抓放图、跨族中断及正常应用入口验收完成后，再由明确选择步骤发布运行包；单独编译成功不等于这些环节已通过。

首末规范R仅为1ms图连接标记，不排队播放审图用800/1100ms静止书挡；自然静置交给当前待命状态。动作内部实际准备、展开与回落曝光保留，接触恢复仍有其真实短暂沉降。
