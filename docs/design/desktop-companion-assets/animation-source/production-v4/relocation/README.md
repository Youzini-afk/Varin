# 开盖同角度提起与放下

这组正式源准备保留10张独立绘图，复用response的悬停/触键及对应去凳4张，并复用production-v2实际R和去凳R。无需为提起强制合上电脑；手部由键盘转向底座两侧，腿部承重蜷起，再经首次触凳、坐稳、收腕、悬停、触键返回。

`pickup-manifest.json`包含16个现有player语义节点、9条当前阶段释放路径和7条同姿立即去凳重抓路径。路径是完整有序续接列表。立即拖动的是窗口根位置，不等手部准备完；提前放手不先播放完整悬空高潮。最后R为连接标记，结束后采用最新意图，不重播已取消互动。

`source-provenance.json`记录全画布512导出及真实SHA。没有逐姿包围框缩放、脸部替换、冻结身体遮罩或alpha修补。新中点v2在正常360明暗底检查中保留了真实收腕连接；袖尖随手回落合理，腰侧饰带/裙片仍有细微原画形状漂移，不把逐源检查等同于最终整句播放验收。

真实图已通过当前runtime解析器的16节点逐阶段释放/重抓检查，C/D来源恢复连接进入本图而非旧关盖路径。这里保存可复现的完整源及候选图，不是公开安装或最终视觉验收；完整动作、并发打断及正常原生窗口检查在整套源联合构建后进行。旧closed提起路径保持，未选用无明显改善的closed-load-half试稿。
