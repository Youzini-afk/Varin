# v4 shared-body production brief

Status: independent internal production; current public1303 and all v2/v3 artifacts unchanged. New drawings must pass whole-phrase visual continuity before technical integration. This is calibration for the entire family, not a one-clip user approval gate.

## Shared support model
Open laptop rests on both thighs at the same camera/projection. Current drawn shared pose uses image-right hand at near base/thigh as steady support; image-left hand releases from lower hinge/base edge to express. This is a consistent production choice, not a user-required handedness. Do not mirror or switch support midway. Pelvis seated, upright relaxed neck, same skull/hair/clothes/hollow diamond. Open and closed variants need compatible body habits and a real mechanical connecting sequence, not renamed old anchors.

## Five-family production coverage
1. Settle/companionship: supported sit → chest/shoulder release → hand and sleeve settle → quiet hold; later sparse blink and genuine yawn/doze/wake. Side-hair action must follow the same actual support hand and explicit handoff if that support changes. No additional collar/stretch variants until shared motion is coherent.
2. Respond to user (current full calibration): common rest → attention and stable-hand contact → chest/shoulder sit up as free arm begins lifting → small open-palmed greeting facing user → free arm lowers as chest returns → hand lands → shoulder/hair/sleeve finish settling → common rest. Busy short variant must have its own true turnaround and landing, not cropped/accelerated peak.
3. General management: same rest → free hand release → small inward gathering in front of torso → forearm/wrist opens toward user → true lowering/contact/settle. No project-side targets; owners and exact facts live in information layer.
4. Reminder/wait: stop current minor activity → supported sit → one open-palmed presentation → lower arm fully → attentive quiet. Question/permission/result/exception vary restraint/face and factual content, not a different physical owner or directed finger-point.
5. Interruption/relocation: current contact-aware withdrawal → secure laptop → genuine airborne support → seat contact and body loading → hands settle. New facts display immediately; no replay of stale event. Root follows real drag while the current body safely secures its load.

## Current response source plan
R0 new shared comfortable rest; R1 notice/support; R2 arm launch/body intention; R3 small greeting peak; R4 lowering; R5 hand arriving; R6 shoulder/cloth settling; R0 quiet. Add a true intermediate if wrist path/skull/shoulder continuity fails. No hard frame quota. Anatomical contact, actual viewport consistency and full return take precedence over number of assets.

## Production and acceptance
Use built-in imagegen with actually viewed source/reference images, whole coordinated pose edits. Preserve raw exact prompts/input SHA. No Python image editing, independent face patches, rigid body rotation, mesh puppet or crossfade substitute. For comparison boards only, embed unaltered original PNGs in code-native HTML; display scaling is uniform viewport presentation, never an animation motion trick.
Each incoming draw is checked for same skull/face age, shoulder/neck mechanics, elbow/wrist route, support-hand contact, chest/screen clearance, unchanged computer/seat scale, identity accessories, hair roots and sleeve continuity. A bad generation is rejected, not masked into acceptance.
Internal review checks full finite phrase at small desktop size with quiet lead-in/out, then cross-family transitions and interrupts. Source hash coverage comes after visual continuity; it is not evidence of natural movement. Continue all five families under the established shared standard without requiring the user to approve every short clip.
