# 持续表现时间线

本目录用五个已审短段派生三条可打断的持续时间线，不新增原画，也不增加应用执行状态：

- 输入：原手部动作之间安排不同长度的停顿，9.87秒一轮。
- 浏览：保留滚动与停手观察，12.56秒一轮。
- 安静陪伴：安静微动作之间低频揉眼、伸展，160.44秒一轮。

在本目录运行 `python3 derive_continuous_performances_v1.py` 可重建三条时间线。所有输入清单、原始图集与精确曝光均在目录内；输出仍通过同一个播放器和真实安全姿态响应新任务或拖动。减少动态效果时只暂停可省略的重复表现，必要落座与状态转换继续。

`rebuild-qa.json` 记录11个重建产物与工作版本逐字节一致；`continuous-performance-controller.json` 和 `oneshot-early-release.json` 是针对时间线与中断语义的有限验证。它们不等同于所有操作系统的原生窗口验收。主交付资源位于 `packages/web/public/companion-assets/`，此目录只负责持续时间线来源。
