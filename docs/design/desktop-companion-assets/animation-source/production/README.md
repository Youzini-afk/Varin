# 全帧原画生产资产

本目录保存持续制作中的源画、可复现提取、时序和内部QA，尚非可发行桌宠动画。制作范围沿[完整方案](../../../desktop-companion-animation-production.md)，不以局部关键姿态替代全部32类和连接。

- [面向用户候选](user-attention/README.md)：六组36张提取关键画，持续补中间画与配准。
- [坐姿工作候选](seated-work/README.md)：输入与开盖12张关键画，支撑/道具与动作衔接仍在修订。
- [公共开盖坐姿基准](shared/seated-open-canonical-v1.png)：内部选定的固定512²视口、头身和电脑比例来源。使用身份母版和已选第一工作板的风格指导；不代表用户另行接受了完成动画。

跨族QA已发现此前各自生成的头身/电脑比例不同，不能靠整图缩放连接。后续工作统一公共基准，非运动部位允许保留原像素，运动部位实际补绘；不把错误比例或僵硬切片当成成品。保留这些源候选用于重导、修订和回溯，不能直接启用为运行资源。

逐画持续时间显式记录，不设每秒60张独立原画目标。逐帧是当前主制作方式，不禁止经实际视觉验证有效的其他技术。所有图片角色素材权利与仓库代码许可分别处理。
