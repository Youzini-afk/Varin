# 运行衔接派生

在本目录运行 `python3 derive.py` 和 `python3 derive_recovery.py`，从相邻已归档的原画重建16组规范化时序、姿势边界及图片。生成的图片全部复用原像素，仓库不再重复保存副本。两份索引由脚本生成。

`integration-contract.json` 记录精确匹配边界和安全回收语义；安全点只允许回到登记的同一姿势，不允许任意状态瞬移。取消请求、运行终止和实际执行器停下仍是不同事实。`neutral-recovery` 只表示中性回收，不能证明执行器已停止。

父级在独立目录仅使用已归档生产源执行两个脚本，102个生成文件与工作源逐字节相同。此重建验证不替代浏览器动态审阅或原生窗口验收。
