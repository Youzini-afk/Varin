# 面向用户的全帧原画候选

本批保存六组完整角色关键原画：许可、提问/点头、闭盖欢迎、开盖完成、开盖与闭盖轻点关注，共36张提取PNG。**这是可恢复的生产中间资产，不是已通过的连续动画或桌宠成品。**

来源、提示词、提取脚本、显式原画时序与QA记录保留在本目录。`inventory.json`记录59个源文件的SHA256。配准、人物/电脑一致性和中间动作仍继续制作；尚未验收的原画不进入生产播放。

原始组图在`sources/`，提取关键画与时序在`frames/`。图集与HTML可由仓库`tools/desktop-companion-animation/`重导，不重复归档。提取图保留自身版本，后续修订由Git和新资源版本跟踪。
