## 追加报告复核

新增的两项实验修复在当前 `7124288b` 上仍存在，回归先在未修改实现上失败，再迁移指定补丁的新增部分：

- 源截止计时器在读取等待中先中断 controller，会越过 pump 的 `deadlineStopped` 标记，整次 views 调用丢失已准备材料。现在按实际源截止判断，保留已有版本窗口并报告 partial/searchIncomplete；同时覆盖后续图关系补查中断。用户取消、提前中断与截止后主动取消仍不会变成成功结果。
- Pi 同一 worker 的请求队列等待 `harness.embed` 的完整网络请求，外层调度并发因此被串行化。现在按队列顺序接纳批次，再释放网络等待；批次预约、配置/会话顺序与取消隔离保留，不改变并发设置。

本地 41 项 query-run/服务检查、22 项 HostController/BackgroundInference 检查通过。实验的 112.10 秒候选阶段、3.51 秒 finish 和 9 个文件/16 片段收据已核对；收据只有完成材料，尚不足以单独确定其余 C# 候选在哪一步等待。没有增加文档过滤规则，也未执行真实付费请求或轮询 CI。

## 验证与边界

- 前四项：60 项 Host 定向测试、7 项 HTTP 适配器测试；TypeScript 和 Lint 通过。
- 分页：Host/来源相关 36 项测试、10 项 Pi read 测试。包含多 GB 合成来源的有界读取、二进制、超长行、Unicode 和取消；未创建多 GB 真实文件，也未声称修复了未被证实的一般内存泄漏。
- 目录和覆盖：真实 Rust 内核计算验收 12 项通过，包含父 Git 忽略/目录选择/独立子仓库和 Scala 实际索引、召回、版本校验；语义运行时、配置路由和文件搜索 41 项通过；界面类型和翻译一致性检查通过。
- Scala 验收使用父 Git 忽略目录中的真实文件，串联原生目录枚举、文本单位、语义索引与检索；已授权的显式文件解析不重复应用 Git 可见性过滤。CI 发现最小 session 测试宿主漏接新分页接口，Host 现可从同一 PathAuthority 组合分页能力，真实 session 外部文件读取复验通过。
- 后续 Windows CI 暴露路径别名问题：Git 返回长路径，而临时目录采用 8.3 短路径；计算服务原先直接用字符串求相对路径，混用时误报越界，导致 Scala 索引失败。已用真实 Windows 8.3 临时目录和 Node 24.21 复现两处失败；服务改为先解析根与调用目录的实际身份，Git 根断言也比较实际身份。相同短路径环境下完整原生内核验收通过（26 项协议测试、25 文件共 220 项行为测试），新增用例同时验证目录别名、返回路径和真正越界的链接；Host 类型检查和修改文件 Lint 通过。
- 未重复运行研究线的完整付费模型测评或真实 Coffee 请求；它们的既有供应商证据来自原报告。此次验证覆盖产品接缝和实际源码召回，不代表 Agent 答案质量测评。
