# Agent 上下文准备问题复核与修复

Status: implemented; locally verified, remote CI pending.
Last updated: 2026-10-01

2026-10-01（北京时间）。基准为 Varin-FC 报告中的 `7c7e17f9`；复核当前 Varin 后，在本仓库直接修复。

## 实际处理

| 报告项 | 当前判断和处理 |
| --- | --- |
| 取消被同会话队列堵住 | 仍存在。`harness.cancel` 走独立控制路径，Router 继续校验会话、worker generation、Run 和请求身份。测试先保持慢请求未完成，再证明取消能到达。 |
| 无项目会话漏用全局配置 | 仍存在。推理采用已有 session 配置域；全局推理状态不创建 Documents 根或语义索引。资源身份和文件权限保持原契约。 |
| HTTP 重排文档格式 | 改为字符串数组，返回 index 对应本地 ID。保留重复/越界索引、冲突 ID 和非有限分数检查；未新增供应商试探或付费调用。 |
| 临时嵌入错误停扫 | 同批正文可取消重试，支持秒数和日期形式的 Retry-After。默认两次追加尝试可配置；超过 Node 单次计时能力的等待分段执行，认证/参数错误不走同样重试。 |
| read 分页前搬运整个文件 | 工具把行范围和既有 Pi 输出预算传入 Host。磁盘从一个已授权句柄按块读，返回前复核路径、文件身份、大小和时间；虚拟分支持有 pin 并读对象切片；草稿只编码片段；已物化别名检查受管子目录。二进制类型在全量文本解码前返回，支持的图片仍走 Pi 图片处理。 |
| 父 Git 忽略目录看似空 | 原有 `respectGitignore=false` 已可用；默认 Git 可见语义符合原实现，不能归为权限漏洞。增加实际 Git 根/根目录忽略诊断和设置页的目录级包含选项。内核按选定目录而非更宽的 Documents 根解析 Git 可见范围，独立子仓库也遵循自己的 Git 根。 |
| 语义覆盖依附语法名单 | 解除关联，Scala 和其他已识别但无语法的文本语言使用现有原生文本分块。源码版本继续验证，文本分块明确带 fallback，结构关系仍报告未支持。进度分别显示可见、可结构解析、文本分块、未支持和实际已发布数量。 |

只迁移了报告指定的 `fastctx-native-host.patch`，未迁入旧实验宿主、压缩替身或历史评测补丁。

## 验证与边界

- 前四项：60 项 Host 定向测试、7 项 HTTP 适配器测试；TypeScript 和 Lint 通过。
- 分页：Host/来源相关 36 项测试、10 项 Pi read 测试。包含多 GB 合成来源的有界读取、二进制、超长行、Unicode 和取消；未创建多 GB 真实文件，也未声称修复了未被证实的一般内存泄漏。
- 目录和覆盖：真实 Rust 内核计算验收 12 项通过，包含父 Git 忽略/目录选择/独立子仓库和 Scala 实际索引、召回、版本校验；语义运行时、配置路由和文件搜索 41 项通过；界面类型和翻译一致性检查通过。
- 未重复运行研究线的完整付费模型测评或真实 Coffee 请求；它们的既有供应商证据来自原报告。此次验证覆盖产品接缝和实际源码召回，不代表 Agent 答案质量测评。
- 早期压缩/权限服务缺失、4K 输出设置和首次遗漏 scope 仍按测评配置错误处理；本轮没有重写压缩、增加统一输出限制或改变文件授权边界。
