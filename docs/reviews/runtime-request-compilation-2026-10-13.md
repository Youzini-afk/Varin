# 请求编译与摘要材料的副本开销

## 实现

请求语义快照仍由执行引擎持有，存储格式不变。适配器共用借用式历史投影，在协议家族和可信连接身份
匹配后读取私有续接数据；版本和模型约束仍由原适配器校验。Codex 从原视图提取指令，不再复制整个视图。

工具输出、外部证据和采样材料的已有文字及媒体借用原快照。新生成的回执文本、媒体块和消息数组直接
进入最终请求 JSON；不再通过 `json!` 重复复制已构造的值。Google 和 Pi 消息协议不再生成随后丢弃的
data URL，Mistral 转移原图片 URL。文本回执保留原 JSON 字段顺序和来源，媒体仍按协议编码或明确拒绝。

摘要材料准备直接取走已拥有的有序 parts，原数据留作元数据摘录；删除先复制媒体再清空的中间对象。
工具结果继续作为带来源的数据进入摘要，不恢复其可执行身份。

## 验证

主代理完成 `varin-runtime`、`varin-kernel` library 编译检查；kernel 保留原有 9 条 warning。
独立 hack 运行适配器 **34/34**、摘要材料 **2/2**：复用媒体、工具配对、Chat 去重和 Codex 指令
分离测试，扩展外部/采样输出，补执行回执和续接边界矩阵、混合摘要材料。检查包含完整回执字符串、
媒体顺序、原来源及不产生可执行工具，不只比较解析后的 JSON。
另复验真实 Catalog 的两轮模型/工具交换重开，以及摘要与原历史尾段编译，两项通过；合计 **38 项**。

独立 Cargo 探针以 `9151938a` 的 runtime crate 为基线，与当前 crate 编译运行。每个协议家族使用
64 轮文字对话、两份 1 MiB 媒体、工具回执、外部/采样材料及签名原文；生成约 3.35 MB 请求。
**10 个家族的完整请求字节长度及 SHA-256 均一致**。同一 debug 探针预跑两次、计数 16 次，结果为：

| 每次请求编译 | 修改前 | 修改后 |
| --- | --- | --- |
| 累计申请的分配字节 | 16.52–22.17 MB | 3.44–3.71 MB |
| 带分配计数的平均耗时 | 4.27–6.96 ms | 0.98–2.03 ms |

分配字节减少 78.6%–84.5%，不是进程峰值内存。时间包括计数器与结果释放，仅是本机这个样本的
编译成本，不是统计性能基准或模型端到端延迟。探针和原始输出保留在本地 `artifacts/provider-wire-probe/`
及 `artifacts/provider-wire-probe-{before,after,comparison}.json`，未增加常驻评测系统。

## 边界

这是单次请求及材料准备内部的副本优化。最终请求仍持有实际发送的完整 JSON，HTTP 编码和存储仍有
真实成本；尚未实现跨 ModelStep 的稳定前缀复用。容量估计和非 Git 目录捕获的增量账本也没有由此完成。
本地编译及受控协议验证不能代表付费供应商、整体长会话或平台性能验收。
