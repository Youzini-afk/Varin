# Worktree Sessions

Open the project’s **Worktrees** view and create a worktree conversation. Varin creates a Git branch and folder, applies the project’s setup commands, then opens a native Thread for that folder. The project must be a Git repository.

Review, commit and integrate changes in the Git view. A worktree isolates files from other checkouts; commands can still have effects outside it.

If conversation creation fails or its result is unknown, the worktree remains on its original Host. Inspect it before retrying. Archiving or deleting a Thread does not itself remove the Git worktree. Manage worktrees and branches separately in the project’s worktree/Git controls.
