# Quickstart

1. [Install](/install/) the desktop app and open it (or self-host with Docker / build from source on the same page).
2. Open **Settings → Model services**, add a model channel (API key, cloud credential, or local service like Ollama / LM Studio), and enable a chat model.
3. Start talking in the **Varin** assistant view, or switch to **Workbench** / **IDE** from the top switcher when you want direct task or file control.
4. For file work, open the folder selector below the composer to choose a local directory, registered project, or connected remote device. Chat-only work needs no workspace.
5. Send your message. You can paste/drop images, PDFs, or arbitrary files, quote specific passages back into your draft, and follow tool activity or delegated teammates inline.

To use Varin from your phone or another computer, pair your device with the running Host and protect any network-exposed Host with a strong UI password.
