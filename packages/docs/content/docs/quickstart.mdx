# Quickstart

1. Follow Install to prepare Node.js, Bun and Rust, then run `bun install --frozen-lockfile` and `bun run dev` from the checkout.
2. Open the printed Vite URL. For desktop, use `bun run electron:dev` instead.
3. Open Settings → Model channels, connect a model channel and choose a model.
4. Create a conversation. It is a native Thread with its own branches and history.
5. For file work, expand Workspace, choose the source Host, folder and access mode, then prepare it. Chat-only work does not require a source.
6. Write your message and send. You can attach images or PDFs and review tool activity in the conversation.

For a phone, pair the device with the running Host. Internet access requires an available configured relay or your own secured remote-access route. Protect any network-exposed Host with a strong UI password.
