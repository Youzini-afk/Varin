# MCP Servers

Open **Settings → MCP** on the Host that should own the connection. Choose the configuration source, add a server, and enter its command/arguments/environment for a local process or URL/headers for a remote service. Only trust servers whose code and data access you understand.

Save the document, then use Connect or Reconnect and inspect the status and tool counts. Sign in when the server supports authorization. Global and project sources are shown by their actual paths; project configuration requires project trust. You can edit structured fields or the raw configuration.

Saving configuration is separate from the resources already captured by an active Thread. Inspect the conversation’s resources and explicitly refresh its snapshot when you need updated tools. Permission, question and sampling requests appear in the native conversation.
