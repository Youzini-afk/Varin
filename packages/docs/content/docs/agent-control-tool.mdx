# Agent tools

Native conversations expose tools according to their accepted model, source, role and permissions. Ask for the outcome you need; available tools remain subject to their own authorization checks.

- `dispatch`, `child_status`, `child_report` and `wait_child` coordinate delegated tasks.
- `threads` and `read_thread` discover and inspect conversations in the current task family. They do not grant access to every conversation or to another task's files.
- `follow_up` registers and manages instructions triggered by time or observed conditions.
- `goal_report` reports an explicitly established continuing goal as complete or blocked.
- `resource_read` reads admitted instruction and skill resources; `memory` manages notes within the agent's admitted scopes.

Tool visibility is not permission to write files, run processes or contact external services. Read-only conversation access does not start the target model or grant execution control. Inspect original task results and statuses in the conversation before treating accepted work as finished.
