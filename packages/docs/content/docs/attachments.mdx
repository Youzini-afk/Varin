# Attachments, images & PDFs

Use the composer's attach menu, paste from the clipboard, or drag and drop files directly into a conversation.

- **Arbitrary files**: Varin stores uploaded files as immutable, version-pinned attachments without format whitelists. Agents can read them directly or forward the exact original version to delegated teammates without copying file text into prompts.
- **Images & annotation**: Vision-capable models receive attached images natively (if your current model does not accept images, Varin warns you before sending and lets you switch models or send the image as a readable file). Click any attached image to annotate it with arrows, shapes, text, numbered callouts, or opaque redactions before sending.
- **Original PDFs & Office files**: Uploaded PDFs and Office documents keep their original bytes so agents can inspect text, structure, or rendered pages without replacing the original file.
- **Idempotent delivery**: Sending, queueing, and retries carry the exact frozen attachment snapshot; later changes on disk never alter already-submitted input. If delivery status is uncertain, use **Retry delivery** rather than re-uploading.
