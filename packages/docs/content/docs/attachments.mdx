# Images and PDFs

Use **Attach images** or **Attach PDFs** in the conversation composer. Pasting or dropping supported files also works. Images require a model that accepts image input.

A PDF upload keeps the original PDF as a retained Thread material. Open its attachment chip to read it, browse pages and select a region to add to your draft when image input is supported. The original is available in the reader; an extracted representation does not replace it.

Sending, all three queue modes and child continuation carry the selected material snapshot. Later file changes do not change that input. If delivery is unconfirmed, use **Retry delivery** for the same request rather than uploading again. You cannot change pending attachments until the original outcome is resolved. Changing Host, Thread or branch never transfers a pending upload to the new selection.
