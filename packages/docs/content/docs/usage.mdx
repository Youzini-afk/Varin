# Session token usage

Open **Usage** in the header services menu to see the current conversation’s token consumption, grouped by provider and model.

- **Input**: uncached input tokens.
- **Output**: generated output tokens.
- **Cache read**: input tokens reused from the provider cache.
- **Cache write**: input tokens written to that cache.

Totals come from the native Pi session journal, including messages before compaction, inactive branches and recorded auxiliary calls. Usage without model information has its own row. Each child conversation has its own statistics.
