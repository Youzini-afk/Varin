# Projects

A project is a folder on the connected Host. Use the project picker or folder browser to open it; Settings → Projects controls its name, color, icon and project actions. The project you browse and a conversation’s execution source are separate: changing projects does not retarget a running Thread.

In a conversation, expand **Workspace**, select the source Host and folder, then choose:
- **Read-only file snapshot**: fixed files for reading, listing and searching
- **Isolated editable copy**: a captured working copy for edits and commands; changes are not copied back automatically
- **Live workspace**: saved files and commands in the actual folder; edits affect it immediately

Press **Prepare workspace** and inspect the result before sending. Snapshot modes can include this window’s editor drafts on the same Host. Live workspaces use saved files only. Remote paths belong to the selected source Host. Editable copies and live commands are not security sandboxes.
