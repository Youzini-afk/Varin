# Updates

How you update Varin depends on how you installed it. In every case you can check your current version at **Settings → About**.

## Desktop app

The desktop app checks for updates against GitHub releases. When one is available, Varin tells you, downloads it when you choose, and installs it when you choose the update restart action. You're always in control — nothing installs without your say-so.

On Linux, updates require a writable packaged AppImage, not an extracted or repackaged copy. On macOS, install Varin.app in `/Applications` before applying an update.

On Android, install the APK from a newer release over the existing app; your pairing is kept.

## Web / CLI

If you installed a published CLI, update it from **About** with the check and update buttons, or from the terminal:

```bash
varin update
```

Varin detects how it was installed (npm, pnpm, yarn, or bun) and runs the right update for you. The `@varin/web` package is not on the public npm registry yet, so this path applies only after a release is published.

Source checkouts update with Git. Docker deployments update by pulling a new image digest.
