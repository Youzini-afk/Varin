# Private Relay

部署前提：Varin 不附帶中繼服務，也沒有預設端點。在伺服器上把 `VARIN_RELAY_URL` 設為你自己執行或信任的 `ws://` / `wss://` 中繼；設定之前 **任何地方** 不可用，伺服器也不會連線任何中繼。以下配對與加密行為適用於中繼已設定且可存取的情況。

Varin Private Relay 讓你已配對的裝置可以從任何地方存取你的伺服器 — 行動網路、咖啡館的 Wi-Fi、另一座城市 — 無需開放埠、搭建隧道，也不會把你的機器暴露到網際網路上。伺服器的中繼端點設定完成且可用後，在[連線裝置](/zh-tw/connect-devices/)中選擇 **任何地方** 配對裝置即可使用。

## 工作原理

你的伺服器向所設定的中繼伺服器發起一條出站連線並保持存活。當你的某台裝置不在你的網路中時，它也連線到中繼，中繼在兩者之間轉發加密流量。你的機器上沒有任何東西在監聽來自網際網路的入站連線。

當直接連線可用時 — 比如你回到家、處於同一個 Wi-Fi — 你的裝置會優先直連，完全跳過中繼。

## 中繼能看到什麼、看不到什麼

中繼是一個「盲信使」，而不是中間人：

- **端到端加密。** 你的裝置和伺服器直接協商加密金鑰。中繼只轉發它沒有金鑰的密封流量 — 它無法讀取你的程式碼、提示詞或密碼。
- **只有你的裝置能連線。** 裝置必須持有*你的*伺服器透過 [一次性配對](/zh-tw/connect-devices/) 簽發的權杖。沒有人能透過中繼發現你的伺服器，也無法在沒有你建立的權杖的情況下連線它 — 而且你可以隨時撤銷任何權杖。
- **配對連結只能使用一次。** 配對 QR code 只能生效一次，未使用也會過期，所以洩露的舊連結毫無價值。
- **在你選擇開啟之前，什麼都不會共享。** 在你啟用中繼或透過它配對裝置之前，中繼保持關閉；你可以隨時停用它 — 透過它連線的裝置會立即斷開。

## 何時執行

中繼自行管理生命週期 — 沒有需要你記住的開關：

- **按需啟動。** 建立一個 **任何地方** 配對就會開啟中繼；只要還有已配對裝置依賴它，伺服器重啟後它也會自動恢復。
- **自動停止。** 一旦沒有任何裝置或待完成的配對在使用中繼 — 比如你撤銷了最後一台透過中繼配對的裝置 — 它會自動關閉。

**Settings → Devices and access → 用戶端存取 token** 會列出每台已配對裝置，並標明它是否透過中繼連線。撤銷裝置會使它的權杖在直連和中繼存取中都失效；其他已配對裝置不受影響。

## 用中繼還是隧道？

- 用**中繼**讓自己已配對的裝置存取自己的伺服器。伺服器的中繼端點設定完成且可用後，無需埠轉發或另行搭建隧道。
- 當你需要一個普通的**公開 URL**時使用 [隧道](/zh-tw/tunnels/) — 比如在一台無法配對的機器上用普通瀏覽器開啟 Varin，或者在 [UI 密碼](/zh-tw/security/) 保護下共享存取。

撤銷權杖不會改變直連 Host 的認證策略：開放的 Host 或其他有效憑證仍可能允許存取，也不保證所有現有連線或程序都已停止。
