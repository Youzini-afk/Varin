# 圖片與 PDF

使用對話輸入框中的 **Attach images** 或 **Attach PDFs**，也可貼上或拖放受支援的檔案。圖片需要支援影像輸入的模型。

上傳 PDF 會將原始檔案保留為 Thread 材料。點選附件標籤可閱讀、翻頁；模型支援影像輸入時，可選取區域加入草稿。閱讀器可讀取原件，提取後的表示不會替換原始 PDF。

傳送、三種排隊模式和子對話續接都會攜帶所選材料快照。之後檔案變化不會改變該次輸入。送達未確認時，用 **Retry delivery** 重試原請求，不要重新上傳。原結果確定前不能修改待確認附件。切換 Host、Thread 或分支不會將待處理上傳轉移到新選擇。
