# 附件、圖片與 PDF

使用輸入框的附件選單、從剪貼簿貼上，或直接將檔案拖放到對話中。

- **任意檔案**：Varin 會將上傳的檔案儲存為不可變、版本鎖定的附件，不設格式白名單。Agent 可以直接讀取這些檔案，或將完全一致的原始版本轉發給委派的協作成員，而無須將檔案文字複製到提示詞中。
- **圖片與標註**：支援視覺的模型會原生接收附加的圖片（若目前模型不支援圖片輸入，Varin 會在傳送前提醒你，並讓你切換模型或改以可讀檔案傳送圖片）。傳送前點擊任意已附加的圖片，即可用箭頭、形狀、文字、編號標註或不透明遮罩進行標註。
- **原始 PDF 與 Office 檔案**：上傳的 PDF 與 Office 文件會完整保留原始位元組，讓 Agent 能在不取代原檔案的前提下檢視文字、結構或渲染頁面。
- **冪等送達**：傳送、排隊與重試都會攜帶完全一致的凍結附件快照；磁碟上後續的檔案變更絕不會影響已提交的輸入。如果送達狀態不確定，請使用 **重試送達（Retry delivery）**，不要重新上傳。
