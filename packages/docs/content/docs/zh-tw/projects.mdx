# 專案

專案是已連線 Host 上的資料夾。透過專案選擇器或資料夾瀏覽器開啟；在「設定 → 專案」中管理名稱、顏色、圖示和專案操作。目前瀏覽的專案與對話執行使用的來源彼此獨立：切換專案不會改變正在執行的 Thread 的來源。

在對話中展開 **Workspace**，選擇來源 Host 和資料夾，再選擇：
- **唯讀檔案快照**：固定檔案，僅供讀取、列舉和搜尋
- **隔離的可編輯副本**：捕獲工作副本以修改檔案和執行命令；修改不會自動複製回原目錄
- **即時工作區**：使用實際目錄中的已儲存檔案和命令，修改立即作用於該目錄

點選 **Prepare workspace**，檢查結果後再傳送。快照模式可包含同一 Host 上本視窗的編輯器草稿；即時工作區只使用已儲存檔案。遠端路徑屬於所選來源 Host。可編輯副本和即時命令都不是安全沙箱。
