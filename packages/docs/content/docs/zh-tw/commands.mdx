# 命令

**設定 → 命令** 列出目前資源庫中有效且啟用的技能、說明和檔案路徑。在訊息開頭輸入 `/skill:name`，再用空格分隔後續要求，即可顯式呼叫。

也可以展開對話中的 **Instructions and skills**，點選 **Add /skill:name to draft**。這只向草稿插入命令，不會傳送訊息。名稱包含空格的技能不能使用此語法。

對話使用已捕獲的技能版本。修改資源庫後，點選 **Refresh instructions and skills** 準備新的上下文快照。進行中的請求和已受理的技能輸入保留原始材料。設定頁展示的是資源庫，不代表舊對話已經更新。

資源編輯見 [技能](/zh-tw/skills/)。工作台快速鍵另行設定。
