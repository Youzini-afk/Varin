# 通知

開啟「設定 → Varin → 通知」，並在各裝置上允許通知。原生對話在回覆完成、執行失敗、需要批准或回答問題時發出通知。完成類通知遵循完成通知設定，需要你處理的請求單獨傳送。

實際送達取決於桌面、瀏覽器推播或行動推播服務與系統權限，Host 必須持續執行。支援導航的通知渠道會開啟原 Thread 和分支。

標題直接使用 Thread 標題，未命名時為「Varin」；正文是固定狀態文字，不含 Agent 回覆。APNs 同樣如此，因此對話標題可能顯示在 iPhone 鎖定畫面上。原生事件不使用舊的可編輯訊息模板，也未實現應用程式圖示徽章同步。
