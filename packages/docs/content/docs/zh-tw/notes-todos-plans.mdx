# 專案筆記、待辦與計劃

每個專案都有自己的草稿空間，用於存放筆記、待辦清單和已儲存的計劃。它們屬於專案，而不屬於任何單個會話，因此當你在會話之間切換時它們會一直保留。在右側邊欄的 **Context** 標籤頁中可以找到它們（在行動裝置是一個專用標籤頁）。

## 筆記

一個自由格式的筆記框，用於記錄任何你想記住的關於專案的內容。它會在你輸入時自動儲存。

## 待辦

一個簡單的清單。新增條目、勾選完成、透過拖動重新排序，並清除已完成的條目。

每個待辦都有一個 **send** 選單，讓你可以把它交給 Agent：

- 傳送到目前會話
- 用它開啟一個新會話
- 用它開啟一個新的 [worktree 會話](/zh-tw/worktrees/)（僅當專案是 git 儲存庫時）

## 計劃

一個用於將較長的計劃儲存為檔案的地方。你可以：

- 從 Markdown 或文字檔案匯入計劃
- 開啟一個計劃在側面板中閱讀
- 刪除你不再需要的計劃

完成後你應該會回到 Context 標籤頁，並看到筆記已儲存、待辦已勾選或計劃已列出 — 這就是它生效的標誌。
