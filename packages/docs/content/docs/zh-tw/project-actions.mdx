# 專案操作

專案操作是一個你儲存一次、點選即可執行的 shell 命令 — 你的開發伺服器、一次建置、一次測試執行。每個專案都保留自己的清單。在 **Settings → Projects → Project Actions** 中設定它們。

## 新增操作

1. 開啟 **Settings → Projects** 並找到 **Project Actions** 部分。
2. 新增一個操作，給它一個名稱，選擇一個圖示，並輸入要執行的命令。
3. 儲存。

如果某個命令只在特定作業系統上才有意義，你可以將該操作限制在某些作業系統上。

## 執行操作

操作位於應用程式標題列的一個選單中。點選其中一個，Varin 就會在你專案資料夾的終端機中執行它，並將你切換到終端機檢視，讓你可以觀察輸出。從同一選單可以停止它。

## 自動開啟開發伺服器

為已儲存的操作開啟**自動開啟 URL**。填寫固定位址後，它會在「瀏覽器」面板中開啟；未填寫時，Varin 會開啟該操作終端機輸出中偵測到的位址。桌面版還可以使用設定好的 SSH 埠轉發。
