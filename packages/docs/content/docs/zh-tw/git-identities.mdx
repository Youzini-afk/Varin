# Git 身份

git 身份是你的提交所署名的姓名和郵箱。如果你在個人儲存庫和工作儲存庫之間往返，你可以儲存多個身份並為每個儲存庫應用正確的那個，而不必依賴單一的全域設定。在 **Settings → Git** 中管理它們。

## 新增身份

1. 開啟 **Settings → Git** 並選擇 **New**。
2. 輸入用於提交的 **name** 和 **email**。
3. 選擇它如何與遠端進行鑑權：
   - **SSH** — 讓它指向一個 SSH 金鑰
   - **token** — 使用某個主機已儲存的憑證
4. 可選地給它一個顏色和圖示，以便易於識別。

你係統的全域身份也會顯示，為唯讀。

## 為儲存庫應用身份

應用身份會將它寫入該儲存庫的 **local** git 設定 — 它只影響該儲存庫，不影響你的全域設定。SSH 身份還會設定 SSH 命令以使用你的金鑰；token 身份會為該主機設定憑證儲存。

你可以匯入 Varin 從你現有 git 憑證中發現的身份，並將它們儲存為 token 身份。
