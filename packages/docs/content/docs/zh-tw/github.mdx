# GitHub Issue 與 PR

連線 GitHub 後可在 Varin 管理 PR。需要 Agent 處理 issue 或 PR 時，將相關上下文加入原生對話，並明確選擇工作區來源。

## 連線 GitHub

1. 開啟 **Settings → Git**。
2. 在 GitHub 下，選擇 **Connect**。Varin 會顯示一個連結和一個短碼。
3. 開啟連結，輸入短碼並批准。

連線後，你的帳號會顯示在 GitHub 部分下。你可以連線多個帳號並在它們之間切換，或隨時斷開連線。

## 開啟並管理拉取請求

在 [git 檢視](/zh-tw/git/) 的 **PR** 標籤頁中，你可以建立拉取請求、更新它、將草稿標記為就緒或合併它。Varin 可以從你的變更產生 PR 標題和描述。
