# 連線裝置

透過掃描一次性 QR code，把另一台裝置 — 行動應用程式、桌面應用程式，或另一台機器上的瀏覽器 — 與你的 Varin 伺服器配對。這是連線裝置的建議方式；無需開放埠，也無需輸入位址。

## 配對裝置

1. 在執行 Varin 的機器上，開啟 **Settings → Devices and access → 用戶端存取 token**，然後按 **新增裝置**。
2. 給裝置起一個名字（例如 *My iPhone*），方便你以後辨認。
3. 選擇你會在哪裡使用這台裝置：
   - **僅本機** — 供同一台電腦上的應用程式使用
   - **僅家用網路** — 透過 Wi-Fi 直接連線；離開此網路後無法使用
   - **任何地方** — 在家和外出都可用；外出時流量經由 [Private Relay](/zh-tw/private-relay/) 傳輸，這是一條端到端加密的隧道。伺服器用 `VARIN_RELAY_URL` 設定好中繼後才可選
4. 按 **建立 QR 代碼**。
5. 在另一台裝置上掃描該 QR code：
   - **行動應用程式** — 在連線頁面（或實例清單中）點選 **掃描 QR code**
   - **桌面應用程式** — 改為複製連線連結，並在 **Settings → Remote Instances → 直接遠端執行個體 → 匯入連線** 中貼上

裝置一連上，對話方塊就會自動關閉，裝置也會出現在清單中並顯示即時狀態。就這麼簡單 — 配對完成。

## 配對為何安全

- **QR code 只能使用一次。** 一旦被某台裝置兌換就立即失效；從未使用也會自行過期。
- **每台裝置都有自己的權杖。** 掃描 QR code 不會暴露你的 UI 密碼，一台裝置的權杖也無法用來冒充另一台裝置。
- **控制權始終在你手上。** 每台已配對的裝置都會顯示名稱、平台和連線狀態 — 你可以隨時撤銷任何一台。
- **外出流量端到端加密。** 使用 **任何地方** 時，網路之外的流量經由 [Private Relay](/zh-tw/private-relay/) 傳輸，中繼無法讀取任何經過它的內容。

## 管理已配對的裝置

**Settings → Devices and access → 用戶端存取 token** 會列出已配對裝置，線上時顯示綠點，並標明它是透過區域網路還是中繼連線的。

- **撤銷** 會使該裝置權杖在直連和中繼認證中失效。如果你改變主意，用新的 QR code 重新配對即可。
- **清除已撤銷** 用來整理清單。

撤銷權杖不會改變直連 Host 的認證策略：開放的 Host 或其他有效憑證仍可能允許存取，也不保證所有現有連線或程序都已停止。

使用同一已儲存裝置身分重新配對時，可以重用既有項目。清除用戶端資料或使用新身分配對可能新增項目；撤銷前請核對名稱。

## 從命令列連線

如果伺服器以 headless 方式執行（沒有開啟 UI），可以在那台機器的終端機裡建立連線連結。

針對同一網路中的裝置：

```bash
varin connect-url --port 3000 --qr
```

針對需要從**任何地方**連線的裝置 — 相當於在對話方塊中選擇 **任何地方**：

```bash
varin connect-url --relay --qr
```

`--relay` 連結與對話方塊一樣同時攜帶兩條路由：當裝置能存取伺服器時，透過你的區域網路直接連線；外出時則回退到 [Private Relay](/zh-tw/private-relay/)。中繼會自行啟動：執行中的實例會在一分鐘內接管該連結，已停止的實例則會在下次啟動時接管。命令和伺服器一樣讀取 `VARIN_RELAY_URL`，請設為同一個中繼；沒有設定時 `--relay` 會報錯退出，而不是印出一條外出時無法使用的連結。

> 直連路由只有在伺服器確實監聽你的網路時才有效。預設情況下 Varin 只監聽本機 — 用 `--lan` 啟動它，才能透過 Wi-Fi 存取。當連結的直連路由無法被其他裝置使用時，命令會發出警告（`[LAN_UNREACHABLE]`）；此時 `--relay` 連結仍然可用，只是始終透過中繼連線。

印出的連結和 QR code 與設定對話方塊裡產生的完全一樣 — 一次性使用、會過期、可撤銷。
