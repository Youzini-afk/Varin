# 上下文

開啟右側欄的 **Context**，檢視目前 Thread、分支、執行狀態、上下文資料及保留的歷史。可展開或複製單條記錄，更早的記錄透過對話歷史導航存取。

對話中的 **Instructions and skills** 展示捕獲的資源版本及診斷。點選 **Refresh instructions and skills** 為後續請求準備新快照，不改寫進行中的請求或已受理輸入。

**Context summaries** 展示目前檢查點和摘要任務。在對應操作可用時，可以應用已完成且仍適用於目前檢查點的摘要、取消未結束摘要或恢復其準備。摘要準備完成不等於已經應用。

消耗量見 [用量](/zh-tw/usage/)，這些回執不是模型剩餘上下文的百分比。需要獨立任務和歷史時，請新建對話。
