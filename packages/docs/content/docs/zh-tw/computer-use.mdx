# Computer Use 與瀏覽器資源

Varin 將 **桌面控制** 與 **瀏覽器存取** 與你的檔案工作區相互分離，讓你可以精確指定每項任務使用哪台機器或哪個瀏覽器。

## Computer Use（桌面控制）

- Agent 可以觀察視窗、查詢原生 UI 控制項（Windows UIA、macOS Accessibility、Linux X11 AT-SPI）、擷取螢幕、傳送鍵盤／滑鼠輸入以及等待 UI 條件達成。
- 每台實體桌面同一時間僅允許 **一個活躍控制者**，同時允許多個唯讀觀察者。
- 開啟對話旁的 **電腦** 分頁，即可即時觀看操作過程、立即接管控制權，或在準備好後交還控制權。關閉檢視器只會停止觀察——不會取消任務。
- 透過 [工作連線](/zh-tw/connect-devices/) 接入的遠端桌面會在目標裝置上執行各自的本機平台驅動程式。

## 瀏覽器資源

開啟 **設定 → 瀏覽器**，管理目前 Host 或已連線 Host 上的可用瀏覽器：

- **內建桌面瀏覽器**：內嵌於 Varin 桌面應用程式中（詳見 [桌面瀏覽器](/zh-tw/desktop-browser/)）。
- **CDP 連線**：透過 Chrome DevTools Protocol 連線到現有的 Chromium 執行個體，可選配請求標頭與檔案交接目錄。
- **日常使用的 Chrome / Edge**：在設定中下載按需啟用的 **Browser Connector** 擴充功能，將其與你的 Host 配對，再明確分享希望 Varin 檢視或操作的分頁。

在瀏覽器檢視中，**檢視瀏覽器** 僅切換你目前觀察的對象；**讓目前工作使用** 才會將該瀏覽器指派給目前對話。你可以隨時在工作台或瀏覽器擴充功能中暫停 Agent 寫入並接管已分享的分頁。
