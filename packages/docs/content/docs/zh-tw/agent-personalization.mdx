# Agent 記憶與系統提示詞

在 **設定 → 記憶** 中新增、編輯、刪除筆記，或在全域、專案、對話範圍之間移動。對話中的記憶面板使用同一編輯器，Agent 的 `memory` 工具也使用同一組分範圍筆記。子任務不會自動繼承父對話的筆記。

儲存後的筆記立即可讀。活躍對話接收新筆記事實，但不會改寫已凍結的系統記憶字首；成功應用上下文摘要時才推進該快照。

在 **設定 → 系統提示詞** 編輯指令段落。資訊密度、語言風格和自主程度選項插入可繼續編輯的文字。全域、專案、對話覆寫依次生效；**恢復預設** 僅清除目前範圍的修改。已儲存的設定在安全的請求邊界生效，已準備請求保持不變。

預覽展示組合後的指令和記憶快照。最近請求檢視可用時展示已準備的系統文字，不代表服務商已接收。檔案指令和技能使用各自捕獲的資源，修改後應點選 **Refresh instructions and skills**。

Bot 的指令和記憶仍在 **Varin Bot** 單獨管理。普通 Agent 的筆記和提示詞覆寫不會注入 Bot。
