# 持續目標

持續目標屬於一個 Thread 分支，用於繼續其最近一次執行。普通訊息不會自動建立目標。

1. 先傳送訊息以建立工作。
2. 在 **Continuing goals** 中點選 **Create goal**。
3. 填寫完整明確的目標及可選的輸出 token 預算，點選 **Start goal**。

每個分支只能有一個未結束目標，最近一次執行也可以已經結束。普通最終回覆僅結束目前執行；Agent 可透過 `goal_report` 明確報告目標完成或受阻。面板展示實際狀態和阻塞原因。

可編輯、暫停、恢復、完成或取消目標。這些操作改變後續授權；已發出的請求和獨立程序仍需等待真實結果。**Stop run** 也會暫停對應目標；策略暫停仍需單獨恢復。已完成或取消的目標需要新建目標才能繼續授權工作。

預算在後續派發前檢查服務商報告的輸出量。留空表示不限額，零表示不能繼續派發輸出；進行中的工作可能超額。估算、缺失和待返回用量分別展示。有預算時，已結束推理的用量不完整會阻止進一步推理。輸入、快取和推理欄位可能重疊，不應直接相加。

Application Host 必須保持執行。定時工作見 [計劃任務與後續任務](/zh-tw/scheduled-tasks/)。
