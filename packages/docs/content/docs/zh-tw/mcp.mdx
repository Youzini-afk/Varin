# MCP Servers

在需要擁有連線的 Host 上開啟「設定 → MCP」。選擇設定來源並新增伺服器：本機程序填寫命令、參數與環境變數，遠端服務填寫 URL 和請求標頭。僅使用你瞭解其程式碼和資料存取範圍的伺服器。

儲存設定檔，再連線或重新連線，並檢查狀態與工具數量。支援授權的伺服器可登入。全域與專案設定顯示實際路徑；專案設定需要專案信任。可編輯結構化欄位或原始設定。

儲存設定與活動 Thread 已捕獲的資源是兩回事。需要新工具時，檢查對話資源並顯式重新整理快照。權限、問題與取樣請求會顯示在原生對話中。
