# 外部 Agent

Varin 可以直接在你的工作區中執行外部 CLI 與 SDK Agent——包括 **Codex**、**Claude Code**、**Pi**，以及相容 **ACP** 的工具（如 OpenCode、Gemini CLI、Cursor Agent、Cline、Kiro CLI 等）——同時保留它們各自的帳號、模型與工具。

## 啟用並連接外部 Agent

1. 開啟 **設定 → 外部 Agent**，選擇要執行該 Agent 的 Host（本機或已連線的遠端 Host）。
2. 啟用自動偵測到的程式，或點擊 **新增 Agent** 從目錄中挑選，或設定自訂 ACP 命令。
3. 對於支援託管安裝的產品（npm 套件或官方 ACP 發行套件），可直接安裝到 Varin 的私有 Host 目錄中，無須修改你的全域環境。
4. 在目標裝置上使用該外部程式自帶的登入命令完成登入；Varin 絕不會儲存或修改外部 Agent 的憑證。

## 直接對話與委派

- **直接對話**：在新建對話的輸入框中選擇已啟用的外部 Agent。後端會在你開始輸入或開啟其模型／模式選擇器時按需延遲啟動，並在送出第一則訊息後鎖定。
- **依輪次調整選項**：在輸入框工具列中直接選擇模型、思考層級、模式以及（針對 Codex 的）原生權限層級。
- **委派任務**：直接請 Varin 或主導 Agent 將工作交辦給外部 Agent（例如「讓 Codex 修復這個問題」），無須先建立預設。外部任務會出現在同一工作概覽與協作面板中，支援檔案／圖片附件，也可使用隔離工作區。
- **重新連線與繼續**：如果連線在輪次中途斷開，點擊 **重新連線** 可恢復觀察，而點擊 **繼續** 則用於明確確認恢復並傳送排隊的後續訊息，不會在結果不確定時靜默重放中斷的輪次。
