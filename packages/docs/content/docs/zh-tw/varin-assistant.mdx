# Varin 助手

**Varin** 是你的長期個人助手檢視。你可以在這裡討論想法、將任務交辦給專業 Agent、在工作執行期間繼續聊天，日後回來時上下文與記憶依然完好無損。你也可以建立多位 Bot，各自擁有獨立的指令、模型、記憶、排程與外觀。

## 邊執行工作邊繼續對話

- 預設情況下，在 Varin 對話中傳送補充訊息會在目前步驟完成後立即引導進行中的輪次。按 **Alt+Enter**（或點擊傳送按鈕旁的排隊按鈕）可將訊息排在目前輪次結束後再處理。
- 在對話旁的側邊分頁中開啟 **工作詳情**、**檔案** 或 **電腦**，無須離開目前聊天。關閉側邊分頁絕不會取消執行中的工作。
- 同一個助手可維護多個對話與分支，它們共用同一份檔案、主目錄、記憶與排程。

## 群聊

- 從 Bot 側欄新建群聊，讓多位 Bot 在同一條共享時間線上協作。
- 透過 `@` 提及一位或多位 Bot，或直接回覆某個 Bot 的訊息來指定對方接話。未指定對象的訊息只會交給開啟監聽的成員；沒人監聽時，訊息留在群組裡，不會啟動 Bot。
- 群內支援共享檔案與搜尋歷史訊息；Bot 也可以按需查閱群組紀錄並聯繫其他成員。右側面板集中查看成員、活動和群排程，群排程沿用單聊的排程與定時接續功能。

## 記憶與事項

- 開啟右側面板的 **記憶** 分頁（或前往 **設定 → Bot** 並切到 **記憶**），即可檢視、編輯、整理或忘記該 Bot 跨對話記住的內容。
- 忘記記憶不會改動原始聊天紀錄；被忘記的內容只會從後續模型上下文中排除。
- **事項** 用於追蹤持續推進的主題，並直接連結到底層委派任務，方便你隨時跳入完整的 [Workbench](/zh-tw/views-and-collaboration/) 進行更細緻的控制。

## 排程與事件監聽

開啟右側面板的 **排程與監聽**，即可管理週期性排程以及來自已連線外掛的傳入事件監聽：

- 選擇傳入事件的處理方式：**立即處理**、依時間視窗**批次合併**、按**排程**執行，或**排隊**等待你的下一輪對話。
- 可隨時暫停、恢復或對任意監聽觸發 **立即處理**，不會刪除其歷史紀錄。

## 檔案、外觀與桌面桌寵

- 從 Bot 右側面板、左欄或 **設定 → Bot** 進入檔案，集中調整指令、模型、思考強度、記憶與外觀。
- 在 **設定 → Bot → 檔案 → 更換外觀** 中，可從 **16 個內建可動角色**（含 Varin）中選擇，或匯入自訂圖片與動畫素材包。建立 Bot 時，外觀保留 **隨機** 會自動挑選角色，名稱留空則會直接使用所選角色的名稱。
- 在桌面應用程式中，開啟 **設定 → 桌寵** 即可下載選用的桌面桌寵，即時跟隨所選助手的活動狀態。讓桌寵休眠只會關閉角色視窗，不會暫停你的助手。
