# 技能資源庫

在 **設定 → Skills** 瀏覽原生資源庫，並在使用者或已信任的專案範圍建立、複製技能。這裡沒有單獨的線上技能市場。

原生資源設定可以引用已安裝的技能目錄。讀取技能包不會下載或執行其中的程式碼。可執行的 Varin 擴充套件透過 **設定 → Varin Extensions** 單獨管理。

使用前檢查來源、有效性和唯讀狀態。修改資源庫後，在對話中重新整理 **Instructions and skills**。已經受理的輸入保留當時捕獲的技能版本。

參閱 [技能](/zh-tw/skills/) 和 [命令](/zh-tw/commands/)。
