# 快速開始

1. [安裝](/zh-tw/install/)並開啟桌面應用程式（或在同一頁面依指引透過 Docker 自託管／從原始碼建置）。
2. 開啟 **設定 → 模型服務**，新增模型渠道（API 金鑰、雲端憑證，或 Ollama / LM Studio 等本機服務），並啟用一個對話模型。
3. 直接在 **Varin** 助手檢視中開始對話；需要直接掌控任務或編輯檔案時，可從頂部切換器切到 **Workbench** 或 **IDE**。
4. 需要處理檔案時，開啟輸入框下方的資料夾選擇器，選擇本機目錄、已註冊專案或已連線的遠端裝置。純聊天無需工作區。
5. 傳送訊息。你可以貼上或拖放圖片、PDF 或任意檔案，將特定片段引用回草稿，並在對話內即時追蹤工具活動或派發出去的協作成員。

若要在手機或另一台電腦上使用 Varin，請將裝置與執行中的 Host 配對，並為任何對外曝露在網路上的 Host 設定強 UI 密碼。
