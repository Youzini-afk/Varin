# 快速開始

1. [安裝](/zh-tw/install/)桌面應用程式並開啟。想自行部署或從原始碼建置，按同一頁的其他部分操作。
2. 從原始碼執行時，開啟終端機輸出的 Vite URL；`bun run electron:dev` 則會啟動桌面應用程式。
3. 在「設定 → 模型渠道」連線模型渠道並選擇模型。
4. 建立對話。每個對話都是擁有獨立分支和歷史的原生 Thread。
5. 需要檔案操作時，展開 Workspace，選擇來源 Host、資料夾和存取模式並準備來源；純聊天無需來源。
6. 輸入訊息並傳送，可附加圖片或 PDF，在對話內檢視工具活動。

手機可與執行中的 Host 配對。跨網路連線需要設定且可用的中繼，或你自己的安全遠端存取通道。對外可存取的 Host 應設定強 UI 密碼。
