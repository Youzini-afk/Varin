# 模型渠道

開啟 **設定 → 模型渠道**，新增渠道，選擇型別和端點，再選擇該型別支援的認證方式。可用方式包括儲存 API 金鑰、登入、顯式環境變數、受支援的雲身份或匿名存取，具體以渠道為準。

按 ID 新增模型，或在支援發現的已儲存渠道中獲取候選模型。檢查並儲存所需模型；發現操作本身不會修改目錄。啟用渠道、模型及所需操作（如聊天），然後在對話輸入區選擇渠道和模型。

Application Host 管理渠道設定和模型帳號。憑證與模型後設資料分開儲存，不進入對話歷史。憑證缺失或撤銷不會自動切換到其他帳號。普通設定修改影響後續準備，已受理工作保留原來的選擇。

常駐指令見 [Agent 記憶與系統提示詞](/zh-tw/agent-personalization/)，附加工具見 [MCP](/zh-tw/mcp/)。模型可用不代表獲得檔案或工具權限。
