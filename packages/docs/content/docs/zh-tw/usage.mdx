# 分支 token 用量

開啟頂部服務選單中的 **Usage**，檢視目前 Thread 分支執行的工作，按模型、提供方、工作型別及計量狀態分組。範圍包括對話、上下文處理、規劃、MCP sampling 和已記錄的工具推理。

有資料時展示輸入、輸出、快取讀取、快取寫入及推理 token。服務商的統計口徑可能重疊，不要把所有欄位直接相加，也不要假設輸入量一定排除快取。

真實報告、估算、缺失和待返回用量保持區分，未知不是零；沒有派發記錄的請求單獨標註。子 Thread 和獨立輔助工作各有用量，不彙總所有分支，也不代表上下文佔用率。這裡不估算價格。

更新斷開時，面板會標註最後一次已記錄快照，點選 **Refresh** 重連。參閱 [上下文](/zh-tw/context/) 和 [持續目標](/zh-tw/session-goals/)。
