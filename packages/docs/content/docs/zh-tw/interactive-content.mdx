# 互動內容與引用

Varin 中的對話不只限於純文字——你可以直接操作結構化選項、檢視即時圖表，並將精確段落或工具結果引用回下一則提示詞中。

## 內嵌控制項與 HTML 成品

- **內嵌控制項**：助手可直接於段落之間嵌入單選／多選項、表單、分頁、折疊面板，以及指向任務、檔案或計劃的即時連結。選取選項時會在輸入框中準備好可編輯的訊息，絕不會擅自替你送出。
- **互動式 HTML/JS**：複雜的視覺化圖表、計算機與比較畫面會在與你目前 Varin 主題一致的隔離沙箱中內嵌渲染。按右鍵（觸控裝置點擊選單按鈕）即可檢視原始碼、展開至側邊欄、下載獨立 HTML 副本、重設狀態或引用目前檢視。

## 精確引用與可拖曳標記

- **引用任何內容**：跨段落選取文字、對特定區塊（程式碼、表格、段落）按右鍵、選擇 **引用整輪對話**，或引用某次工具呼叫、圖片與互動檢視。
- **輸入框標記**：引用與圖片會顯示為精簡的 `[Quote N]` 與 `[Image N]` 標籤，你可以在訊息中拖曳重新排序、點擊檢視詳情，或作為單次編輯整塊復原。從內文移除標記後，附件仍保留在附件列中；移除附件則會一併清除其所有標記。
- **圖片標註**：點擊草稿或聊天中的任意圖片，即可繪製箭頭、形狀、文字、編號標註或不透明遮罩。遮罩會以原始解析度直接燒錄至傳送的圖片中，不會附上未遮罩的原圖。
