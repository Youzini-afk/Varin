# Git 與 GitHub 工作流程

Varin 內建了 git 檢視，讓你可以審閱變更、提交並管理分支，而無需切換到終端機。從右側邊欄的 **Git** 標籤頁開啟它。

## 審閱與提交

git 檢視將你的變更分為 **staged** 和 **unstaged**：

- 點選檔案的 **+** 可暫存它，或點選 **−** 取消暫存
- 一次性暫存或取消暫存某個分組中的所有內容
- 點選檔案可檢視它的 diff

自行編寫提交資訊，或根據所選暫存變更產生。產生使用 Host 設定的工具模型，未設定時使用預設模型，無需開啟對話。提交前檢查產生內容。

## 分支與歷史

git 檢視也涵蓋了 git 日常的其餘操作：

- 建立、切換、重新命名和刪除分支
- 推播、拉取和獲取
- 瀏覽歷史和每次提交的 diff
- 暫存（stash）和恢復變更

## 拉取請求

連線 GitHub（參閱 [GitHub Issue 與 PR](/zh-tw/github/)），**PR** 標籤頁讓你可以開啟拉取請求、更新它、將其標記為就緒或合併它 — 並以與提交資訊相同的方式產生它的標題和描述。

## 處理衝突

如果一次合併、變基或整合遇到衝突，Varin 會顯示卡住的內容並讓你解決它 — 包括把它交給 Agent。
