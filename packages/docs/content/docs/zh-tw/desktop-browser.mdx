# 桌面瀏覽器

桌面應用程式可以在對話旁邊顯示瀏覽器頁面。連線本機桌面 Host 時，從瀏覽器工具結果開啟頁面，或使用啟用自動開啟 URL 的 [專案動作](/zh-tw/project-actions/)。頁面有獨立網址列、上一頁、下一頁和重新整理控制項。

## 檢查與標註

先選擇對話，再開啟 **inspect** 並點選元素。Varin 會把元素資訊和截圖加入該對話的草稿；傳送前請檢查。檢查元素會暫停 Agent 對該頁面的控制。

## 接管與恢復

使用頁面的控制按鈕接管頁面，或恢復 Agent 控制。關閉或隱藏面板不等於停止 Agent 的任務。此瀏覽器視圖沒有主控台篩選面板。
