# 桌面瀏覽器

桌面應用程式在對話旁內建了瀏覽器檢視，並與已設定的 CDP 端點以及透過 Chrome/Edge **Browser Connector** 分享的分頁並列管理（可在 **設定 → 瀏覽器** 中管理，詳見 [Computer Use 與瀏覽器資源](/zh-tw/computer-use/)）。

連線本機桌面 Host 時，可從瀏覽器工具結果開啟頁面，或透過設定了自動開啟 URL 的 [專案操作](/zh-tw/project-actions/) 啟動頁面。該檢視提供獨立的網址列與瀏覽控制項。

## 檢查與引用

選擇一個對話，開啟 **檢查（Inspect）** 並點擊頁面元素。Varin 會將元素詳情與螢幕擷取加入你的草稿，方便你在傳送前確認。檢查元素會暫停 Agent 對該頁面的寫入操作。

## 接管與恢復

使用頁面上的控制按鈕即可從 Agent 手中接管控制權，或將控制權交還給 Agent。**檢視瀏覽器** 僅切換你正在觀察的頁面；**讓目前工作使用** 才會將該瀏覽器指派給目前對話。關閉或隱藏面板絕不會取消 Agent 正在執行的任務。
