# 桌面瀏覽器

桌面應用程式內建了瀏覽器，因此你可以在聊天旁邊直接開啟任意頁面、指向元素來詢問相關問題，並捕獲頁面的主控台。從應用程式標題列的地球按鈕開啟它。


## 檢查與標註

開啟 **inspect** 並點選頁面上的任意元素。Varin 會捕獲關於它的說明 — 它是什麼、它的樣式、它所處的位置，以及一張截圖 — 並將其附加到你的聊天訊息中。這是告訴 Agent「就這個元素，就在這裡」的最快方式。

## 主控台捕獲

瀏覽器會收集頁面的主控台輸出 — 錯誤、警告和日誌 — 因此你無需開啟開發者工具即可篩選和閱讀它。
