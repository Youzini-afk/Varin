# Varin 使用指南

Varin 是你的個人超級智慧體：一個開源的 AI 智慧體，能操作你的檔案、瀏覽器與已連線的電腦，並在需要時協調其他 Agent 協作。無論是日常事務、程式開發、研究或辦公，都能使用你選擇的模型完成。

你可以在自己的電腦或伺服器上執行 Varin。桌面應用程式內建了 Application Host，網頁與行動用戶端都會連線到這個 Host。
