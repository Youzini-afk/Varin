# Varin 使用指南

Varin 是你的個人超級智慧體：一個開源的個人 AI 智慧體，能使用檔案、瀏覽器和連線的電腦完成工作，也能組織其他 Agent 協作。從日常事務到程式開發、研究和辦公，模型由你選擇。

你可以在自己的電腦或伺服器上執行 Varin。桌面應用程式自帶服務，網頁和行動用戶端連線到這個服務，我們稱它為 Host。先連接模型、交給 Varin 一個任務，再依需要接入工具和裝置。
