# 檢視與 Agent 協作

依需求選擇與 Agent 及檔案協作的精細程度。切換檢視只會改變介面呈現——執行中的任務、所選模型與工作區來源都會原封不動保留。

| 檢視 | 適用場景 | 核心聚焦 |
| --- | --- | --- |
| **Varin** | 持續對話與高層協調 | 助手對話、工作概覽、記憶、排程與側邊檔案／電腦分頁 |
| **Workbench** | 直接掌控任務與協作成員 | 專注對話、工具活動、協作面板、計劃與復原 |
| **IDE** | 親手編輯與偵錯 | Monaco 編輯器群組、差異比對、終端機、Git 與 Agent 對話並排顯示 |

## 任務焦點

在這些檢視之下，每個對話都會使用一種 **任務焦點**——**一般**、**程式開發**、**研究** 或 **辦公**——用來調整直接可見的工具與可用的 Agent 預設。其他能力仍可按需探索與呼叫。

## 委派與協作

- **自由派發或使用預設**：Agent 可指定特定模型、思考層級、任務焦點或已設定的預設來委派子任務。你也可以在 Agents 設定中啟用選用的 **派發模型選擇**。
- **協作面板**：開啟右側 **協作** 面板，在單一時間軸中追蹤任務派發、成員間訊息、最終報告與程式碼交接。點擊任意成員即可開啟其完整對話、傳送跟進訊息或停止該成員。
- **工作區模式**：
  - **共用**（預設）：協作成員直接在所選目錄中工作。
  - **隔離寫入**：分叉出一個獨立工作區（Windows 使用 WinFsp、Linux 使用 FUSE、macOS 使用 FSKit/macFUSE），並透過程式碼交換（`submit_code` / `update`）搭配衝突審查合併回原目錄。
  - **唯讀**：移除檔案修改類工具，方便安全檢視。
- **輸入框交接命令**：在輸入框中使用 `/` 命令可直接向指定成員傳送訊息、準備結構化交接、將對話匯出為 Markdown/JSON，或儲存筆記／記憶。
