# 技能

技能是包含名稱、說明和指令的 `SKILL.md` 資源，也可以附帶支援檔案。說明幫助 Agent 判斷適用場景。

在 **設定 → Skills** 中建立、檢視、編輯、複製或刪除技能，選擇使用者範圍或已信任的專案。編輯器顯示路徑、來源、有效性及是否可寫。唯讀資源可以複製到可寫範圍。使用專案資源前，請處理專案信任提示和診斷。

在訊息開頭使用 `/skill:name`，或在對話的 **Instructions and skills** 面板選擇技能。Agent 也可以透過 `resource_read` 讀取已准入技能及其支援檔案。技能內容不會授予額外工具或檔案權限。

儲存資源庫不會替換對話已捕獲的材料。點選 **Refresh instructions and skills** 後，後續請求使用新快照，已受理請求保留原版本。

參閱 [命令](/zh-tw/commands/) 和 [技能資源庫](/zh-tw/skills-catalog/)。
