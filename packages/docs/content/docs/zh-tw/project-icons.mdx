# 專案圖示

專案圖示讓你一眼就能區分各個專案。Varin 會嘗試為你查詢一個，你也始終可以設定自己的。在 **Settings → Projects** 中管理它。

## 自動發現

當你新增專案時，Varin 會在其中查詢 `favicon` 檔案，並將它用作專案的圖示。如果你的儲存庫已經附帶了 favicon，圖示通常會自動出現 — 無需任何操作。

## 設定你自己的

開啟 **Settings → Projects** 並上傳一張圖片（PNG、JPEG 或 SVG，最大 5 MB）。自訂圖片的優先順序高於自動發現的圖片。你也可以改為選擇一種顏色，或移除圖片以回退到自動發現。
