# Skills library

Use **Settings → Skills** to browse the native resource library and create or copy skills into user or trusted-project scope. There is no separate online skill marketplace on this page.

Native resource configuration can reference already installed skill directories. Reading a skill package does not download it or execute its code. Executable Varin extensions have their own **Settings → Varin Extensions** lifecycle.

Inspect the source, validity and read-only status before using a resource. After changing the library, refresh **Instructions and skills** in the conversation. Existing accepted inputs keep the skill version they captured.

See [Skills](/skills/) and [Commands](/commands/).
