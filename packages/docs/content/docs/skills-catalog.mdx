# Skills Catalog

The former standalone Skills Catalog is no longer available. To install skills distributed as a Pi package, open **Settings → Pi Packages**, enter a source supported by Pi PackageManager (an npm source, Git URL or local path), and choose user or project scope. Install only packages you trust: they can include executable extensions.

Use [Skills](/skills/) to create, edit and invoke the skills loaded by the active runtime.
