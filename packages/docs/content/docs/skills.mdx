# Skills

A skill is a `SKILL.md` instruction resource with a name and description. The description helps the agent select relevant instructions; supporting files can provide additional material.

Open **Settings → Skills** to create, inspect, edit, copy or delete skills. Choose user scope or a trusted project. The editor shows the file path, origin, validity and whether the resource is writable. Read-only resources can be copied into a writable scope. Resolve project-trust prompts and diagnostics before relying on a project resource.

Use a leading `/skill:name` message or the conversation's **Instructions and skills** panel to select a skill explicitly. The agent can also read admitted skills and their supporting files through `resource_read`. Skill text grants no extra tool or filesystem permissions.

Saved library edits do not replace captured conversation material. Use **Refresh instructions and skills**; later requests use the new snapshot while accepted requests retain theirs.
