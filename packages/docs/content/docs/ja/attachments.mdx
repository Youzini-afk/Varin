# 画像と PDF

会話入力欄の **Attach images** または **Attach PDFs** を使います。対応するファイルの貼り付けやドロップも可能です。画像には画像入力対応モデルが必要です。

PDF は原本のまま Thread の資料として保持されます。添付を開いてページを読み、画像対応モデルでは領域を選んで下書きに追加できます。抽出した表現がリーダーで読める原本を置き換えることはありません。

送信、3種類のキューモード、子会話の継続は選択した資料スナップショットを渡します。後のファイル変更はその入力を変えません。配信が未確認なら再アップロードせず **Retry delivery** を使います。元の結果が確定するまで保留中の添付は変更できません。Host、Thread、ブランチを変えても未完了のアップロードが新しい対象に移ることはありません。
