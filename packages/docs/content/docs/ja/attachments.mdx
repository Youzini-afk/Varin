# 添付ファイル、画像と PDF

入力欄の添付メニューを使うほか、クリップボードからの貼り付けや会話へのドラッグ＆ドロップでファイルを直接添付できます。

- **任意のファイル**：Varin はアップロードされたファイルを、形式ホワイトリストなしの不変・バージョン固定の添付ファイルとして保存します。エージェントはファイルを直接読み取ったり、内容をプロンプトにコピーすることなく正確な原本バージョンを委任先チームメイトへ引き継いだりできます。
- **画像と注釈**：視覚入力対応モデルは添付画像をネイティブに受け取ります（現在のモデルが画像に対応していない場合、Varin は送信前に警告を表示し、モデルを切り替えるか読み取り可能なファイルとして送信するかを選べます）。添付画像をクリックすると、送信前に矢印、図形、テキスト、番号付きコールアウト、不透明な黒塗り（リダクション）を書き込めます。
- **PDF 原本と Office ファイル**：アップロードされた PDF や Office ドキュメントは元のバイト列のまま保持されるため、エージェントは原本を置き換えることなくテキスト、構造、レンダリング済みページを確認できます。
- **べき等な配信**：送信、キュー追加、再試行はすべて凍結された同一の添付スナップショットを運びます。後からディスク上のファイルを変更しても送信済み入力には影響しません。配信状況が不確かな場合は、再アップロードせず **Retry delivery** を使用してください。
