# この会話のトークン使用量

ヘッダーのサービスメニューで **使用量** を開くと、現在の会話のトークン消費をプロバイダーとモデル別に確認できます。

- **入力**：キャッシュを使用しない入力トークン。
- **出力**：生成されたトークン。
- **キャッシュ読み取り**：プロバイダーのキャッシュから再利用した入力トークン。
- **キャッシュ書き込み**：キャッシュに保存した入力トークン。

集計は Pi のセッション記録に基づき、圧縮前のメッセージ、非アクティブな分岐、記録済みの補助呼び出しを含みます。モデル情報のない使用量は別に表示されます。子会話はそれぞれ個別に集計されます。
