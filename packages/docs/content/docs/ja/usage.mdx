# ブランチのトークン使用量

## Host 全体の使用量と推定費用

**設定 → Usage**（**Model services** の後）で、接続先 Agent Host の確定したリクエストを確認します。委任した作業や補助処理も対象です。期間を選び、モデル、チャネル、用途、会話別に比較できます。日付はデバイスのタイムゾーンに従い、デスクトップと Web では絞り込んだ明細を CSV 出力できます。日付付きの記録はこの機能の導入後から始まり、それ以前のブランチ記録は下記から確認できます。

価格は models.dev のカタログ、または **Model services** のモデル価格設定に基づきます。各リクエストは価格のスナップショットを保持し、後から現在価格で推定した場合は区別されます。価格やトークン数が不明でもゼロにはしません。サブスクリプションの API 換算額と外部 Agent の自己申告値は従量課金の費用と別表示で、ローカルモデルに API 料金はありません。USD の推定額は請求書ではなく、割引、中継サービスの上乗せ、税を含みません。

## ブランチの記録

ヘッダーのサービスメニューで **Usage** を開きます。選択ブランチで実行した会話、コンテキスト処理、計画、MCP sampling、記録されたツール推論を、モデル、提供元、種類、計測状態ごとに表示します。

報告があれば、入力、出力、キャッシュ読み取り・書き込み、推論トークンを表示します。提供元によって数値が重複するため、すべてを合計したり入力がキャッシュを除外すると仮定したりしないでください。

実測、推定、欠落、未完了を区別します。不明はゼロではありません。送信記録のないリクエストも表示します。子 Thread と独立した補助処理の使用量は別です。全ブランチ合計やコンテキスト使用率ではなく、料金も推定しません。

更新が切断された場合は最後の記録を明示します。**Refresh** で再接続してください。[コンテキスト](/ja/context/) と [継続目標](/ja/session-goals/) も参照してください。
