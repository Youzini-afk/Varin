# ブランチのトークン使用量

ヘッダーのサービスメニューで **Usage** を開きます。選択ブランチで実行した会話、コンテキスト処理、計画、MCP sampling、記録されたツール推論を、モデル、提供元、種類、計測状態ごとに表示します。

報告があれば、入力、出力、キャッシュ読み取り・書き込み、推論トークンを表示します。提供元によって数値が重複するため、すべてを合計したり入力がキャッシュを除外すると仮定したりしないでください。

実測、推定、欠落、未完了を区別します。不明はゼロではありません。送信記録のないリクエストも表示します。子 Thread と独立した補助処理の使用量は別です。全ブランチ合計やコンテキスト使用率ではなく、料金も推定しません。

更新が切断された場合は最後の記録を明示します。**Refresh** で再接続してください。[コンテキスト](/ja/context/) と [継続目標](/ja/session-goals/) も参照してください。
