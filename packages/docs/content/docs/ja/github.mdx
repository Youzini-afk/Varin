# GitHub Issues と PR

GitHub を接続すると Varin で PR を管理できます。イシューや PR をエージェントに依頼するには、関連する情報をネイティブ会話に追加し、ワークスペースのソースを明示的に選んでください。

## GitHub を接続する

1. **Settings → Git** を開きます。
2. GitHub セクションで **Connect** を選びます。Varin がリンクと短いコードを表示します。
3. リンクを開き、コードを入力して承認します。

接続されると、GitHub セクションにアカウントが表示されます。複数のアカウントを接続して切り替えたり、いつでも切断したりできます。

## プルリクエストを開いて管理する

[Git ビュー](/ja/git/) の **PR** タブから、プルリクエストの作成、更新、draft から ready への変更、マージができます。Varin は変更内容から PR のタイトルと説明を生成できます。
