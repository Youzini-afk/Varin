# Varin アシスタント

**Varin** は、継続的に利用できるパーソナルアシスタントビューです。アイデアを相談したり、専門エージェントにタスクを引き継いだり、作業の進行中も会話を続けたりでき、後から戻ってもコンテキストとメモリがそのまま保持されます。指示、モデル、メモリ、スケジュール、外観をそれぞれ持つ複数の Bot を作成することもできます。

## 作業の進行中も会話を続ける

- デフォルトでは、Varin の会話で追加メッセージを送ると、現在のステップが完了したタイミングで進行中のターンを軌道修正します。**Alt+Enter**（または送信ボタン横のキューボタン）を使うと、現在のターンの後に実行されるようメッセージをキューに入れます。
- チャットを離れることなく、会話の横にあるサイドタブから **Work details**、**Files**、**Computers** を開けます。サイドタブを閉じても、実行中の作業がキャンセルされることはありません。
- 1 つのアシスタントで複数の会話やブランチを保持でき、それらはすべて同じプロフィール、ホームディレクトリ、メモリ、スケジュールを共有します。

## グループチャット

- Bot サイドバーからグループチャットを始めると、複数の Bot が 1 つの共有タイムライン上で協力できます。
- 1 体以上の Bot を `@` メンションするか、特定の Bot のメッセージに返信して対象メンバーへ直接呼びかけられます。宛先のない投稿は、リスニングを有効にしているメンバーにのみ届きます。誰もリスニングしていない場合、投稿はグループに残るだけでターンは開始されません。
- グループ内でファイルを共有したり、過去のメッセージを検索したりできます。Bot も必要に応じてグループ履歴を参照し、他のメンバーへ連絡できます。右パネルではメンバー、アクティビティ、グループスケジュールをまとめて管理でき、スケジュールは個別会話と同じカレンダーとフォローアップ機能を利用します。

## メモリと案件（Matters）

- 右パネルの **Memory** タブ（または **設定 → Bot** から **Memory** タブへ切替）を開き、各 Bot が会話をまたいで記憶している内容の確認、編集、整理、忘却を行えます。
- メモリを忘れても元のチャット履歴はそのまま残ります。忘れた内容は、今後のモデルコンテキストから除外されるだけです。
- **Matters** は進行中のトピックを追跡し、紐づく委任タスクへ直接リンクしているため、より細かい制御が必要なときはいつでも [Workbench](/ja/views-and-collaboration/) 全体へ移動できます。

## スケジュールとイベント監視

右パネルの **Schedules & Watches** を開くと、定期スケジュールや接続済みプラグインからの着信イベント監視を管理できます。

- 着信イベントの処理方法を選択できます：**即時（immediately）**、一定期間で**バッチ処理（batched）**、**スケジュール（schedule）**実行、または次のターン向けに**キューへ追加（queued）**。
- 履歴を削除することなく、任意の監視を一時停止・再開したり、**Process now** で今すぐ処理を実行したりできます。

## プロフィール、外観、デスクトップコンパニオン

- 各 Bot のサイドパネル、サイドバー、または **設定 → Bot** からプロフィールを開き、指示、モデル、思考レベル、メモリ、外観をまとめて編集できます。
- **設定 → Bot → Profile → Change appearance** では、Varin を含む **16 体のアニメーション付きキャラクター**から選ぶか、独自の画像・アニメーションパックを読み込めます。Bot 作成時に外観を **Random** のままにすると自動でキャラクターが選ばれ、名前を空欄にすると選んだキャラクターの名前が使われます。
- デスクトップアプリでは、**設定 → Companion** を開いて、選択中のアシスタントの動きに連動するオプションのデスクトップコンパニオンをダウンロードできます。コンパニオンをスリープしてもキャラクターウィンドウが閉じるだけで、アシスタント自体は一時停止しません。
