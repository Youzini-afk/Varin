# Agent ツール

利用できるツールは、受理されたモデル、ソース、役割、権限によって決まります。必要な結果を伝えてください。各操作には個別の権限確認があります。

- `dispatch`、`child_status`、`child_report`、`wait_child` は委派した作業を調整します。
- `threads`、`read_thread` は同じタスクファミリーの会話を確認します。全会話や他のタスクのファイルを読む権限ではありません。
- `follow_up` は時刻や観察条件による指示を管理します。
- `goal_report` は明示的に作った目標の完了・阻害を報告します。
- `resource_read` は許可済み指示・スキルを読み、`memory` は許可された範囲のメモを管理します。

ツールの表示だけで書き込み、プロセス、外部サービスの権限は付与されません。会話の読み取りは対象モデルを起動せず、実行制御も与えません。受理を完了とみなさず、元の結果と状態を確認してください。
