# Agent のメモリと指示

**設定 → メモリ** でメモを作成、編集、削除し、全体・プロジェクト・会話の範囲間で移動できます。会話のメモリパネルと `memory` ツールも同じメモを使います。子タスクは親会話のメモを自動継承しません。

保存したメモはすぐに利用できます。進行中の会話は新しい事実を受け取りますが、固定されたシステムメモリの前置きは書き換えません。コンテキスト要約の適用に成功するとスナップショットが更新されます。

**設定 → システムプロンプト** で指示の各節を編集します。密度、文体、自律性の設定は編集可能な文章を挿入します。全体、プロジェクト、会話の順に上書きが適用され、**Restore defaults** は選択範囲だけを解除します。保存内容は安全なリクエスト境界で反映し、準備済みリクエストは変更しません。

プレビューは組み立てた指示とメモリを表示します。直近リクエストの表示は、提供元への到達を証明するものではありません。指示ファイルやスキルの変更後は **Refresh instructions and skills** を使ってください。

Bot の指示とメモリは **Varin Bot** で別管理され、通常の Agent のメモや上書きは注入されません。
