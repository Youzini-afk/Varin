# コマンド

**設定 → コマンド** には、選択したライブラリの有効なスキル、説明、ファイルパスが表示されます。メッセージの先頭に `/skill:name` を入力し、スペースの後に指示を書きます。

会話の **Instructions and skills** から **Add /skill:name to draft** を選んでも挿入できます。挿入だけでは送信しません。空白を含む名前にはこの構文を使えません。

会話は取り込み時点のスキルを使います。ライブラリ編集後は **Refresh instructions and skills** で新しいスナップショットを準備してください。実行中のリクエストと受理済みの入力は元の内容を保持します。設定の一覧が新しくても、既存会話が更新済みとは限りません。

編集方法は [スキル](/ja/skills/) を参照してください。ワークベンチのショートカットは別に設定します。
