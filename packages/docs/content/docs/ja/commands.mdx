# コマンド

**Settings → Commands** で、拡張機能とスキルが登録したコマンドを確認できます。説明、提供元、スコープ、呼び出し方を表示し、呼び出しテキストをコピーできます。

チャットのメッセージ先頭に `/` を入力してコマンドを選びます。引数が必要な場合は名前の後に入力します。拡張機能のコマンドは提供元のプラグインが処理し、`/skill:name` はそのスキルの指示を読み込みます。

使用できるコマンドは、選択したランタイム、ワークスペース、読み込まれたリソースによって変わります。提供元は **Settings → Skills** と **Settings → Pi Plugins** で管理します。
