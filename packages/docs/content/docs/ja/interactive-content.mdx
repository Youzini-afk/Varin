# インタラクティブ機能と引用

Varin の会話はプレーンテキストだけにとどまりません。構造化された選択肢を操作したり、ライブチャートを確認したり、正確な文章やツール結果を次のプロンプトへ引用したりできます。

## インラインコントロールと HTML アーティファクト

- **インラインコントロール**：アシスタントは段落の合間に、単一／複数選択、フォーム、タブ、開閉パネル、およびタスク・ファイル・計画へのライブリンクを埋め込めます。選択肢を選んでも勝手に送信されず、入力欄に編集可能なメッセージとして準備されます。
- **インタラクティブ HTML/JS**：複雑な可視化、計算ツール、比較表は、Varin のテーマに調和した隔離サンドボックス内でインライン表示されます。右クリック（タッチデバイスではメニューボタン）から、ソース確認、サイドバーへの拡大表示、スタンドアロン HTML のダウンロード、状態のリセット、現在の表示の引用ができます。

## 正確な引用とドラッグ可能なマーカー

- **あらゆる要素を引用**：複数段落にまたがるテキストを選択するほか、特定のブロック（コード、表、段落）を右クリックしたり、**Quote full turn** を選んだり、ツール呼び出し・画像・インタラクティブビューを引用したりできます。
- **入力欄のマーカー**：引用と画像はコンパクトな `[Quote N]`・`[Image N]` チップとして表示され、メッセージ内でドラッグして並び替えたり、クリックして確認したり、1 回の操作で元に戻したりできます。本文からマーカーを削除しても添付バーにファイルは残り、添付ファイルを削除すると対応するマーカーもすべて消去されます。
- **画像への注釈**：下書きやチャット内の画像をクリックすると、矢印、図形、テキスト、番号付きコールアウト、不透明な黒塗り（リダクション）を描き込めます。黒塗りは元の解像度のまま送信画像へ焼き込まれ、未マスクの元画像が添付されることはありません。
