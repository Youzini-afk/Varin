# コンテキスト

右サイドバーの **Context** で Thread、ブランチ、実行状態、コンテキストデータ、保持履歴を確認します。記録を展開・コピーでき、さらに前の履歴は会話の履歴ナビゲーションで確認できます。

**Instructions and skills** は取り込み済みの版と診断を表示します。**Refresh instructions and skills** は次のリクエスト向けに新しいスナップショットを準備し、実行中のリクエストや受理済み入力は変更しません。

**Context summaries** にはチェックポイントと要約処理が表示されます。状態に応じて、完了済みで現在も適用可能な要約の適用、未終了処理の取消、準備の再開ができます。準備完了と適用は別です。

[使用量](/ja/usage/) は消費量であり、残りコンテキストの割合ではありません。独立したタスクと履歴が必要なら新しい会話を始めてください。
