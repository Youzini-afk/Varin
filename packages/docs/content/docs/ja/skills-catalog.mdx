# スキルカタログ

以前の独立した Skills Catalog は利用できなくなりました。Pi パッケージとして配布されるスキルは、**設定 → Pi パッケージ** で Pi PackageManager が対応するソース（npm、Git URL、ローカルパス）を入力し、ユーザーまたはプロジェクトの範囲を選んでインストールします。実行可能な拡張を含む場合があるため、信頼できるパッケージだけをインストールしてください。

現在のランタイムが読み込むスキルの作成、編集、呼び出しについては、[スキル](/ja/skills/)を参照してください。
