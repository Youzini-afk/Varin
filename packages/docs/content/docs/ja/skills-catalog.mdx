# スキルライブラリ

**設定 → スキル** でネイティブのライブラリを確認し、ユーザーまたは信頼済みプロジェクトのスキルを作成・コピーします。このページに独立したオンラインマーケットはありません。

リソース設定からインストール済みスキルのディレクトリを参照できます。読み取りはダウンロードやコード実行を行いません。実行可能な拡張機能は **設定 → Varin Extensions** で別に管理します。

提供元、有効性、読み取り専用状態を確認してください。変更後は会話の **Instructions and skills** を更新します。受理済み入力は取り込み時点の版を保持します。

[スキル](/ja/skills/) と [コマンド](/ja/commands/) を参照してください。
