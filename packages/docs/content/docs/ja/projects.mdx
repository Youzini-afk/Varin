# プロジェクト

プロジェクトは接続先 Host のフォルダーです。プロジェクト選択やフォルダーブラウザーから開き、「設定 → プロジェクト」で名前、色、アイコン、アクションを管理します。閲覧中のプロジェクトと会話の実行ソースは別です。プロジェクトを切り替えても実行中の Thread のソースは変わりません。

会話の **Workspace** でソース Host とフォルダーを選び、モードを指定します。
- **Read-only file snapshot**：固定されたファイルの読み取り、一覧、検索
- **Isolated editable copy**：取得した作業コピーで編集とコマンド実行。変更は自動で元に戻されません
- **Live workspace**：実際のフォルダーの保存済みファイルを使用。編集は即座に反映されます

**Prepare workspace** を押し、結果を確認してから送信してください。スナップショットには同じ Host 上のこのウィンドウのエディター下書きを含められます。Live は保存済みファイルのみを使います。リモートパスは選択した Host のパスです。編集可能なコピーやコマンドはセキュリティサンドボックスではありません。
