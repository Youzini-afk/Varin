# モデルチャネル

**設定 → モデルチャネル** でチャネルを追加し、種類、エンドポイント、対応する認証方式を選びます。チャネルに応じて、保存した API キー、サインイン、明示した環境変数、対応クラウド ID、匿名アクセスを利用できます。

ID を指定してモデルを追加するか、対応する保存済みチャネルで候補を検出します。候補を確認して保存してください。検出だけではカタログは変更されません。チャネル、モデル、チャットなどの操作を有効にし、会話の入力欄でモデルを選びます。

Application Host が設定とアカウントを管理します。認証情報はメタデータと別に保存され、会話履歴には入りません。認証情報が失われても別アカウントには自動切替しません。設定変更は以後の準備に適用され、受理済みの処理は元の選択を保持します。

[メモリと指示](/ja/agent-personalization/) と [MCP](/ja/mcp/) も参照してください。モデルへのアクセスだけではファイルやツールの権限は付与されません。
