# プロバイダー、モデル、エージェント

Varin が何かをするには、少なくとも 1 つの AI プロバイダーが接続されている必要があります。このページでは、プロバイダーの接続、モデルの選択、エージェントの調整を扱います。

## プロバイダーを接続する

1. **Settings → Providers** を開きます。
2. **Add provider** メニューを開き、まだ接続していないプロバイダーを選びます。
3. プロバイダーに応じて、次のいずれかでサインインします。
   - **API key** — キーを貼り付けて保存します。
   - **Sign-in (device flow)** — Varin がリンクと短いコードを表示します。リンクを開き、コードを入力して承認します。接続の完了は Varin が行います。

プロバイダーが接続済みと表示されると、そのモデルがチャットで使えるようになります。

切断するには、そのプロバイダーを開き、サインインの削除を選びます。

## モデルを選ぶ

モデルは作業している場所で選びます。

- チャットでは、メッセージバーのモデルピッカーで、そのセッションのプロバイダーとモデルを設定します
- エージェントごとにデフォルトモデルを設定します（下記）

## エージェントを設定する

エージェントは名前付きのセットアップです。モデル、個性、許可される操作です。

1. **Settings → Agents** を開きます。
2. エージェントを選ぶか、新しく作成します。
3. 次のいずれかを編集します。
   - **description** — そのエージェントの用途
   - **model** — デフォルトモデル
   - **temperature** — 回答の創造性
   - **prompt** — 常に従う固定の指示
   - **tool rules** — 使えるツール

## サインインの保存場所

プロバイダーのサインインは、レンダラーではなく Pi の `AuthStorage` が保存します。API キーと OAuth トークンは、UI に送られるプロバイダーメタデータには現れません。ユーザー、プロジェクト、operator の `models.json` レイヤーは、それぞれのネイティブファイルに残ります。

同じプロバイダーを複数の場所で設定した場合、いちばん具体的な設定が勝ちます。信頼されたプロジェクトレイヤーが個人設定を上書きします。
