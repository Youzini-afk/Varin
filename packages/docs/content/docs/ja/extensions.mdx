# 拡張機能とプラグインセンター

Varin 本体の **Varin**、**Workbench**、**IDE** ビューをはじめ、ブラウザ・Office・言語統合も、サードパーティ開発者向けに公開されているものと同じ拡張機能システム上に構築されています。

## プラグインの発見とインストール

1. 拡張機能をインストールしたい Host で **設定 → Plugins** を開きます。
2. **Discover**（公開カタログ）から探すか、GitHub Release、npm パッケージ、Git URL、またはローカルのアーカイブ／フォルダーから直接インストールします。
3. プレビューでマニフェスト、バージョン、コンテンツダイジェスト、要求される権限（capabilities）を確認します。
4. インストールを確定します。新しくインストールされた拡張機能は、権限を確認して有効化するまで **無効（disabled）** の状態で開始します。
5. **Configure** をクリックするとプラグイン独自の設定ページが開きます（外部アカウントの接続など）。

## 信頼、権限、アップデート

- 権限の付与は拡張機能のバージョンとレルム（realm）ごとに審査され、アップグレード時に新しく追加された権限が自動承認されることはありません。
- Host 側の拡張機能は Host の OS アカウント権限下で実際のコードとして実行される点に注意し、信頼できる拡張機能のみを有効にしてください。
- 拡張機能を無効にしても保存済みデータは維持されます。アンインストール時は、ストレージ名前空間を残すか削除するかを選べます。
- **Advanced** では、カスタム HTTPS カタログ、サービスルーティング（カスタムモデルプロトコルや実行ドライバーを含む）、Workbench の構成を管理できます。

## 独自の拡張機能を作成する

公式 CLI を使って新しい拡張機能のひな形を作成できます。

```bash
npx @varin/extension-cli init ./my-extension \
  --id dev.example.my-extension \
  --name "My Extension"
```

SDK API と適合性テストの詳細は、リポジトリの[拡張機能作成ガイド](https://github.com/Astrmira/Varin/blob/main/docs/ops/varin-extension-authoring.md)と[動作サンプル](https://github.com/Astrmira/Varin/tree/main/examples/extensions)を参照してください。
