# ビューと Agent 連携

エージェントやファイルとどれくらい密接に作業するかを選べます。ビューを切り替えてもインターフェースが変わるだけで、実行中のタスク、選択中のモデル、ワークスペースソースはそのまま維持されます。

| ビュー | 適した用途 | フォーカスされる内容 |
| --- | --- | --- |
| **Varin** | 継続的な対話と全体調整 | アシスタントチャット、作業概要、メモリ、スケジュール、ファイル／コンピューターのサイドタブ |
| **Workbench** | タスクやチームメイトの直接制御 | 集中会話ビュー、ツール活動、コラボレーションパネル、計画、リカバリ |
| **IDE** | 直接の編集とデバッグ | Monaco エディターグループ、差分（Diff）、ターミナル、Git、エージェントチャットの並列表示 |

## タスクフォーカス

これらのビューの基盤として、各会話には **General**、**Coding**、**Research**、**Office** のいずれかの**タスクフォーカス**が設定されます。これにより直接表示されるツールと利用可能なエージェントプリセットが最適化され、その他の機能も必要に応じて見つけて利用できます。

## 委任とコラボレーション

- **自由ディスパッチまたはプリセット**：エージェントは、特定のモデル、思考レベル、タスクフォーカス、または構成済みプリセットを指定してサブタスクを委任できます。Agents 設定でオプションの**委任モデルセレクター（delegation model selector）**を有効にすることもできます。
- **Collaboration パネル**：右側の **Collaboration** パネルを開くと、ディスパッチ、チームメイト間のメッセージ、最終レポート、コードの引き継ぎを 1 つのタイムラインで追えます。任意のチームメイトをクリックすると、その会話全体を開いたり、追加指示を送ったり、停止したりできます。
- **ワークスペースモード**：
  - **Shared**（デフォルト）：チームメイトは選択されたディレクトリ内で直接作業します。
  - **Isolated write**：独立したワークスペースを分岐作成し（Windows は WinFsp、Linux は FUSE、macOS は FSKit/macFUSE を使用）、競合レビュー付きのコード交換（`submit_code` / `update`）を通じて変更を統合します。
  - **Read-only**：ファイル変更ツールを外し、安全に調査だけを行えるようにします。
- **入力欄の引き継ぎコマンド**：入力欄で `/` コマンドを使うと、特定のチームメイトへの直接メッセージ送信、構造化された引き継ぎの作成、会話の Markdown/JSON エクスポート、メモやメモリの保存が行えます。
