# 環境変数

Varin は起動時にこれらの環境変数を読みます。スタートアップサービスでは、`varin startup enable` がデフォルトで現在の環境をスナップショットするため、サービスに使わせたい変数を変えたあとは再実行してください。

Varin は Pi ランタイムを内蔵しています。別の OpenCode サーバーはなく、`OPENCODE_*` 統合変数もありません。

## Varin サーバー

### `VARIN_HOST`

Varin Web サーバーのバインドアドレス。他のマシンからのアクセスを許可するには `0.0.0.0` を使います。

### `VARIN_UI_PASSWORD`

ブラウザ UI のパスワード。localhost 以外にバインドするとき、トンネルを使うとき、リバースプロキシの背後で動かすときに使います。

### `VARIN_API_ONLY`

`true` または `1` にすると、Varin をヘッドレスモードで起動します。API ルートはデスクトップとモバイルクライアント向けに残りますが、ブラウザ UI は提供されません。

### `VARIN_DATA_DIR`

Varin のデータディレクトリを変更します。既定値は Linux が `$XDG_CONFIG_HOME/varin`（または `~/.config/varin`）、macOS が `~/Library/Application Support/Varin`、Windows が `%APPDATA%/Varin` です。

### `VARIN_COMPRESS_API`

API レスポンス圧縮を制御します。強制オンは `true` または `1`、強制オフは `false` または `0` です。

### `VARIN_SKIP_API_COMPRESSION`

`true` または `1` にすると API レスポンス圧縮を無効にします。こちらが `VARIN_COMPRESS_API` より優先されます。

### `VARIN_VERBOSE_REQUEST_LOGS`

`true` または `1` にすると、詳細な HTTP リクエストログを有効にします。

### `VARIN_UPDATE_API_URL`

更新確認 API のエンドポイントを上書きします。ほとんどのユーザーは未設定のままにしてください。

### `VARIN_PACKAGE_MANAGER`

自動検出が誤っているとき、更新操作が使うパッケージマネージャーを強制します。

## ターミナルと Git

### `VARIN_TERMINAL_SHELL`

Varin ターミナルセッションで使うシェル実行ファイルです。

### `VARIN_GIT_BINARY`

Varin の Git 機能が使う Git 実行ファイルです。

### `GIT_BINARY`

別の Git 実行ファイル上書きです。Varin 専用の設定には `VARIN_GIT_BINARY` を優先してください。

## 音声とトンネル

### `OPENAI_API_KEY`

OpenAI 互換サービスを呼び出す Varin 音声機能が使う API キーです。

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

`true` または `1` にすると、音声機能でリモートの OpenAI 互換 base URL を許可します。

### `NGROK_AUTHTOKEN`

Varin のトンネルコマンドが使う ngrok auth token です。`ngrok config add-authtoken <token>` で ngrok を設定することもできます。

## ランタイム補助

### `BUN_BINARY`

デーモンプロセスを起動するときに Varin が使うべき Bun 実行ファイルです。

### `BUN_INSTALL`

Bun のインストールルートです。Varin はデーモン起動と更新のために `bin/bun` を探すのに使います。
