# Worktree セッション

プロジェクトの **Worktrees** 画面から worktree の会話を作成します。Varin が Git ブランチとフォルダーを作成し、プロジェクトのセットアップコマンドを適用して、そのフォルダーのネイティブ Thread を開きます。Git リポジトリが必要です。

Git 画面で変更を確認、コミット、統合します。Worktree はファイルを分離しますが、コマンドは外部に影響することがあります。

会話の作成に失敗したり結果が不明だったりしても worktree は元の Host に残ります。再試行前に確認してください。Thread のアーカイブや削除だけでは Git worktree は削除されません。プロジェクトの worktree/Git 操作で別途管理してください。
