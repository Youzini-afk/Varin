# 通知

**設定 → Varin → 通知** を開き、各デバイスで通知を許可します。ネイティブ会話の応答完了、実行失敗、承認や回答が必要なときに通知します。完了通知は完了設定に従い、対応が必要な要求は別扱いです。

配信はデスクトップ、Web・モバイルプッシュとシステム権限に依存します。Host は起動したままにしてください。対応する通知チャネルでは元の Thread とブランチが開きます。

タイトルは Thread のタイトルで、なければ「Varin」です。本文は固定の状態文で、エージェントの返信ではありません。APNs も同様なので iPhone のロック画面に会話タイトルが表示される場合があります。旧編集可能テンプレートは使われず、アプリアイコンのバッジ同期は未実装です。
