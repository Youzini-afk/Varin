# Multi-run

Multi-run は選択したモデルごとにネイティブ Thread を作成します。プロジェクトとバッチ名を選び、プロンプトとモデルのグループを追加して開始します。モデル数に固定の5件制限はありません。

隔離を有効にすると実行ごとに Git worktree とブランチを作ります。無効の場合はプロジェクトの実フォルダーを共有し、同じファイルを変更する可能性があります。開始前にセットアップコマンドを確認してください。

各試行の状態を確認してください。失敗や未確認の結果でも作成済みの Thread と worktree は保持されます。元の要求を確認するには選択を変えず再試行します。Worktree 作成が未確認なら、元の Host の Git を先に確認してください。**Stop launching** は新しい起動を止めますが、受理済みの作業は続きます。
