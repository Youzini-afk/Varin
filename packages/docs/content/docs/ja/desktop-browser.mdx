# デスクトップブラウザ

デスクトップアプリには、設定済みの CDP エンドポイントや Chrome / Edge の **Browser Connector** 経由で共有されたタブと並んで、会話の横に内蔵ブラウザビューが表示されます（**設定 → Browser** で管理、詳細は [Computer Use とブラウザリソース](/ja/computer-use/)を参照）。

ローカルのデスクトップ Host に接続しているときはブラウザツールの結果から、または URL 自動表示を設定した[プロジェクトアクション](/ja/project-actions/)からページを開けます。ビューには専用のアドレスバーとナビゲーション操作が備わっています。

## 検査と引用

会話を選択し、**Inspect** をオンにして要素をクリックします。Varin は要素の詳細とスクリーンショットを下書きに追加するため、送信前に内容を確認できます。検査中はそのページへのエージェントの書き込みが一時停止します。

## 操作の引き継ぎと再開

ページの制御ボタンを使ってエージェントから操作を引き継いだり、制御を戻したりできます。**View browser** は視聴対象のみを切り替え、**Use for current task** はそのブラウザを現在の会話に割り当てます。パネルを閉じたり非表示にしたりしても、エージェントのタスクがキャンセルされることはありません。
