# デスクトップブラウザ

デスクトップアプリでは、会話の横にブラウザページを表示できます。ローカルのデスクトップ Host に接続している場合はブラウザツールの結果からページを開くか、URL 自動表示を設定した[プロジェクトアクション](/ja/project-actions/)を使います。ページにはアドレス欄、戻る、進む、再読み込みの操作があります。

## 検査と注釈

会話を選び、**inspect** を有効にして要素をクリックします。要素の情報とスクリーンショットがその会話の下書きに追加されます。送信前に確認してください。検査すると、そのページに対する Agent の操作が一時停止します。

## 手動操作と再開

ページの操作ボタンで Agent から操作を引き継ぐか、Agent の操作を再開できます。パネルを閉じたり隠したりしても、Agent のタスクを停止したことにはなりません。このブラウザビューにはコンソールのフィルターパネルはありません。
