# Worktrees と Git

操作の再試行前に元の Host とフォルダーを確認してください。エラーや応答の消失後も実際の worktree や Thread が残ることがあります。プロジェクトの Worktrees と Git 状態を確認し、別のフォルダー問題を直すために会話を削除しないでください。

フォルダーを移動した場合は Git worktree の登録を復旧・修復します。途中の merge、rebase、cherry-pick はローカル変更を確認してから続行または中止します。名前が使用中なら、別名を選ぶ前に既存の作業を確認します。

コミット文や PR 説明の生成は Host のユーティリティまたはデフォルトモデルを使います。チャネル、モデル、認証情報、ステージ済みファイルやコミット範囲を確認してください。アクティブな会話は不要です。前の要求の結果が不明なら、新しい要求の前に確認してください。
