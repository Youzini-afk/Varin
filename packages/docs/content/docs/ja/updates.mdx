# 更新

Varin の更新方法は、インストール方法によって異なります。どの場合でも、現在のバージョンは **Settings → About** で確認できます。

## デスクトップアプリ

デスクトップアプリは GitHub releases に対して更新を確認します。利用可能な更新があると Varin が知らせ、あなたが選んだときにダウンロードし、次回の再起動でインストールします。常にあなたが制御します。承諾なしにインストールされることはありません。

Android では、新しいリリースの APK を既存のアプリに上書きインストールします。ペアリングはそのまま残ります。

## Web / CLI

公開済みの CLI をインストールしている場合は、**About** の確認と更新ボタンから、またはターミナルから更新できます。

```bash
varin update
```

Varin はインストール方法（npm、pnpm、yarn、または bun）を検出し、適切な更新を実行します。`@varin/web` パッケージはまだ公開 npm レジストリにないため、この経路はリリース公開後にのみ適用されます。

ソースチェックアウトは Git で更新します。Docker デプロイは新しいイメージ digest を pull して更新します。
