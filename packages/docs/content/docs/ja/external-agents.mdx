# 外部 Agent

Varin は、**Codex**、**Claude Code**、**Pi**、および **ACP 互換**ツール（OpenCode、Gemini CLI、Cursor Agent、Cline、Kiro CLI など）といった外部 CLI / SDK エージェントを、それぞれのアカウント・モデル・ツールを維持したままワークスペース内で直接実行できます。

## 外部エージェントを有効にして接続する

1. **設定 → External Agents** を開き、エージェントを実行する Host（このデバイスまたは接続されたリモート Host）を選択します。
2. 自動検出されたプログラムを有効にするか、**Add Agent** をクリックしてカタログから選択するか、カスタム ACP コマンドを設定します。
3. マネージドインストールに対応した製品（npm パッケージまたは公式 ACP バンドル）では、グローバル環境を変更することなく Varin のプライベート Host ディレクトリへ直接インストールできます。
4. 対象デバイス上で外部プログラム自身のログインコマンドを使ってサインインします。Varin が外部エージェントの認証情報を保存・変更することはありません。

## 直接チャットと委任

- **直接チャット**：新規会話の入力欄で、有効にした外部エージェントを選択します。バックエンドは入力開始時やモデル／モードピッカーを開いたときに遅延起動し、最初のメッセージを送信すると固定されます。
- **ターンごとのオプション**：モデル、思考レベル、モード、および（Codex 向けの）ネイティブ権限レベルを入力欄のツールバーから直接選択できます。
- **委任**：プリセットを事前に作成しなくても、Varin やリードエージェントに「Codex にこれを修正させて」のように依頼して外部エージェントへ作業を引き継げます。外部タスクも通常の概要やコラボレーションパネルに表示され、ファイルや画像の添付、隔離ワークスペースの利用に対応します。
- **Reconnect と Continue**：ターン途中で接続が切れた場合、**Reconnect** は監視のみを再接続します。一方 **Continue** はリカバリを明示的に確認し、不確かなターンを勝手に再実行することなくキューに入っている追加メッセージを送信します。
