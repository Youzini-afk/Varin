# Varin 利用ガイド

Varin は、あなたのパーソナル・スーパーエージェントです。ファイルやブラウザ、接続されたコンピューターを使って作業を進め、必要に応じて他のエージェントと連携するオープンソースの AI エージェントです。日々の用事からコーディング、調査、オフィス業務まで、好みのモデルを選んで利用できます。

ご自身の PC やサーバー上で Varin を実行できます。デスクトップアプリには Application Host が組み込まれており、Web およびモバイルクライアントはその Host に接続します。
