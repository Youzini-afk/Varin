# Varin 利用ガイド

Varin は、あなたのパーソナル・スーパーエージェントです。ファイルやブラウザー、接続したコンピューターを使って仕事を進め、必要に応じて他のエージェントと協力する、オープンソースの AI エージェントです。日々の用事から開発、研究、オフィスワークまで、好きなモデルを選んで使えます。

自分の PC やサーバーで Varin を実行できます。デスクトップアプリはサービスを内蔵し、Web やモバイルのクライアントは Host と呼ばれるこのサービスに接続します。まずモデルを接続して Varin にタスクを任せ、必要に応じてツールやデバイスを追加してください。
