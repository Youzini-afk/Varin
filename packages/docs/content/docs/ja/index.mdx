# Varin ドキュメント

Varin はコーディング、研究、プロジェクト作業のための独立したワークスペースです。ネイティブ Rust Agent ランタイムは会話を Thread とブランチとして永続 Catalog に保存します。Application Host がデスクトップ、Web、モバイルのモデル、リソース、MCP サービスを接続します。

このドキュメントでは次のことができます。

- 作業方法に合ったアプリをインストールする
- ローカルまたはリモート利用のために Varin を開く
- 見た目をカスタマイズし、よくある問題を解決する

## Varin の用途

Varin は、コーディング、研究、その他のプロジェクト作業のうち、管制室があると便利な部分のためのものです。セッションの分岐、結果のレビュー、ターミナル管理、ツール進行状況の監視、プロジェクトアクションの実行、エージェントが作業している間に全体の状況を見える状態に保つことができます。
