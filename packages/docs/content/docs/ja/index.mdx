# Varin 利用ガイド

Varin は、すぐ使えるオープンソースの Agent Harness です。ツール、コンテキスト、実行、権限、復旧の仕組みが、選んだモデルのまわりにあらかじめ揃っているので、コードの開発、研究、オフィス作業、日常のタスクに使えます。デスクトップと Web アプリが作業領域を提供し、モバイルクライアントは自分の Host に接続します。
