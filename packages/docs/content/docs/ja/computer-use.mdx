# Computer Use とブラウザリソース

Varin は**デスクトップ制御**と**ブラウザアクセス**をファイルワークスペースから分離しているため、タスクがどのマシンやブラウザを使用するかを正確に選べます。

## Computer Use（デスクトップ制御）

- エージェントはウィンドウの観察、ネイティブ UI コントロールの照会（Windows UIA、macOS Accessibility、Linux X11 AT-SPI）、スクリーンショット取得、キーボード／マウス入力の送信、UI 条件の待機を行えます。
- 物理デスクトップごとに同時に操作できる**アクティブコントローラーは 1 つ**のみで、読み取り専用のオブザーバーは複数接続できます。
- 会話の横にある **Computers** タブを開くと、リアルタイムの動作を視聴したり、即座に操作を引き継いだり、準備ができたら制御を戻したりできます。ビューアーを閉じても観察が止まるだけで、タスク自体はキャンセルされません。
- [Work Connections](/ja/connect-devices/) 経由で接続されたリモートデスクトップは、対象デバイス上で独自のローカルプラットフォームドライバーを実行します。

## ブラウザリソース

**設定 → Browser** を開くと、現在または接続済み Host で利用可能なブラウザを管理できます。

- **内蔵デスクトップブラウザ**：Varin デスクトップアプリに組み込まれています（[デスクトップブラウザ](/ja/desktop-browser/)を参照）。
- **CDP 接続**：Chrome DevTools Protocol 経由で既存の Chromium インスタンスに接続します。任意のヘッダーやファイル受け渡し用ディレクトリも指定できます。
- **普段使いの Chrome / Edge**：設定画面からオプトインの **Browser Connector** 拡張機能をダウンロードして Host とペアリングし、Varin に表示・操作を許可したいタブだけを明示的に共有します。

ブラウザビューでは、**View browser** は自分が視聴する対象のみを切り替え、**Use for current task** はそのブラウザを現在の会話に割り当てます。共有タブへのエージェント書き込みの一時停止や手動引き継ぎは、Workbench とブラウザ拡張機能のどちらからでも行えます。
