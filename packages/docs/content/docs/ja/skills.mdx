# スキル

スキルは名前、説明、指示を持つ `SKILL.md` リソースです。補助ファイルも使えます。説明は Agent が適用場面を判断するために使います。

**設定 → スキル** で作成、確認、編集、コピー、削除ができます。ユーザー範囲または信頼済みプロジェクトを選びます。パス、提供元、有効性、書き込み可否が表示され、読み取り専用リソースは編集可能な範囲へコピーできます。プロジェクトの信頼確認や診断を確認してください。

メッセージ先頭の `/skill:name` または **Instructions and skills** で選択します。Agent は `resource_read` で許可済みスキルや補助ファイルも読めます。スキル本文が追加権限を与えることはありません。

保存だけでは会話の取り込み済み内容は変わりません。**Refresh instructions and skills** を使うと次のリクエスト向けに更新され、受理済みの処理は元の版を保持します。

[コマンド](/ja/commands/) と [スキルライブラリ](/ja/skills-catalog/) も参照してください。
