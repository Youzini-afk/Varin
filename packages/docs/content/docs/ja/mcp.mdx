# MCP サーバー

接続を管理する Host で **設定 → MCP** を開きます。設定ソースを選んでサーバーを追加し、ローカルプロセスにはコマンド・引数・環境変数、リモートサービスには URL・ヘッダーを指定します。コードとデータアクセスを理解できるサーバーのみ使用してください。

文書を保存し、Connect または Reconnect で状態とツール数を確認します。認証に対応していればサインインできます。グローバル設定とプロジェクト設定の実パスが表示され、プロジェクト設定には信頼が必要です。構造化フィールドと生の設定を編集できます。

保存だけではアクティブな Thread が取得済みのリソースは変わりません。会話のリソースを確認し、スナップショットを明示的に更新してください。権限、質問、sampling の要求はネイティブ会話に表示されます。
