# インストール

以下の手順で Varin をソースからビルドするか Docker で実行します。パッケージと対応プラットフォームは [GitHub Releases](https://github.com/Youzini-afk/Varin/releases) で確認してください。

主な製品画面は 2 つです。

- デスクトップアプリ（Electron）
- ローカルサーバーがホストする Web アプリ。スマホアプリのようにインストールできます（PWA）

## 前提条件

- Node.js 22.19 以降（開発の基準は Node.js 24）
- [Bun](https://bun.sh) 1.3.14
- `kernel/rust-toolchain.toml` で指定された Rust ツールチェーン（rustup をインストールすると、リポジトリが必要なバージョンを選択します）
- Git

Varin は Application Host とともにネイティブ Rust Agent ランタイムをビルドして起動します。別途エージェント CLI は不要です。既存のワークスペースファイルや過去の会話データを自動移行・書き換えすることはありません。

## ソースから（Web）

```bash
git clone https://github.com/Youzini-afk/Varin.git
cd Varin
bun install --frozen-lockfile
bun run dev
```

ターミナルに表示された Vite URL を開きます。Varin は UI と信頼できる API/ランタイムサービスを一緒に起動します。

## ソースから（デスクトップ）

```bash
bun run electron:dev
```

パッケージビルドにより近い形：

```bash
bun run electron:dev:bundled
```

Windows インストーラーは `bun run electron:build:win` でローカルにビルドできます。署名用の認証情報が設定されるまでは、未署名のインストーラーが想定どおりです。

## Docker

Linux の Docker ホスト上で：

```bash
mkdir -p data/varin data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'VARIN_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

`http://127.0.0.1:3000` を開き、生成されたパスワードを使います。インターネットに公開するデプロイの前には、TLS リバースプロキシか承認済みのトンネルを置いてください。本番では `VARIN_IMAGE` を `:latest` ではなく、検証済みの digest に固定してください。

Compose は既定で軽量イメージ `ghcr.io/youzini-afk/varin-slim:latest` を使います（サーバーを動かすのに必要な Bun、Node、Git、SSH、cloudflared）。コンテナ内で Python、Java、Go、Rust をコンパイルする必要がある場合は、ツールベルトのオーバーレイを重ねます：

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```
