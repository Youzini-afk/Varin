# クイックスタート

1. デスクトップアプリを[インストール](/ja/install/)して開きます（同じページで Docker によるセルフホストやソースからのビルド手順も確認できます）。
2. **設定 → Model services** を開き、モデルチャネル（API キー、クラウド認証情報、または Ollama / LM Studio などのローカルサービス）を追加して、チャットモデルを有効にします。
3. **Varin** アシスタントビューで会話を始めます。タスクやファイルを直接操作したい場合は、上部のスイッチャーから **Workbench** / **IDE** に切り替えます。
4. ファイル作業を行う場合は、入力欄の下にあるフォルダーセレクターを開き、ローカルディレクトリ、登録済みプロジェクト、または接続されたリモートデバイスを選択します。チャットのみの作業にワークスペースは不要です。
5. メッセージを送信します。画像、PDF、任意のファイルを貼り付け・ドロップでき、特定の箇所を下書きに引用したり、ツールの動作や委任先チームメイトの進捗をインラインで確認したりできます。

スマートフォンや別のコンピューターから Varin を使うには、稼働中の Host とデバイスをペアリングし、ネットワークに公開する Host は必ず強力な UI パスワードで保護してください。
