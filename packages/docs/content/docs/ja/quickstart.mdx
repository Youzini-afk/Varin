# クイックスタート

1. インストール手順で Node.js、Bun、Rust を用意し、リポジトリで `bun install --frozen-lockfile` と `bun run dev` を実行します。
2. 表示された Vite URL を開きます。デスクトップには `bun run electron:dev` を使います。
3. 「設定 → モデルチャネル」でモデルチャネルを接続し、モデルを選びます。
4. 会話を作ります。固有のブランチと履歴を持つネイティブ Thread です。
5. ファイル作業では Workspace でソース Host、フォルダー、アクセス方式を選んで準備します。チャットだけならソースは不要です。
6. メッセージを送ります。画像や PDF を添付し、ツールの動作を確認できます。

スマートフォンは稼働中の Host とペアリングします。インターネット経由では設定済みで利用可能な relay または独自の安全なリモート経路が必要です。ネットワークに公開する Host は強い UI パスワードで保護してください。
