# 継続目標

継続目標は Thread のブランチに属し、直近の実行を継続します。その実行が終了済みでも開始できます。通常のメッセージだけでは目標は作られません。

まずメッセージを送り、**Continuing goals → Create goal** で単独でも意味の通る目標と任意の出力トークン予算を入力して **Start goal** を選びます。未終了の目標はブランチごとに一つです。

通常の最終応答は一回の実行を終えます。Agent は `goal_report` で目標の完了や阻害要因を明示し、パネルに実際の状態が表示されます。

編集、一時停止、再開、完了、取消は将来の実行許可を変えます。送信済みリクエストや独立プロセスの結果は引き続き確定を待ちます。**Stop run** は目標も一時停止します。ポリシーによる停止は別途再開が必要です。終了した目標の続行には新しい目標が必要です。

予算は次の送信前にプロバイダー報告の出力を確認します。空欄は設定上の上限なし、ゼロは追加出力の送信不可です。実行中の処理は超過する場合があります。推定・未報告は別扱いで、予算設定中に完了済み推論の用量が不明なら追加推論を止めます。入力・キャッシュ・推論の値は重複する場合があります。

Application Host は稼働を続ける必要があります。[予定タスクとフォローアップ](/ja/scheduled-tasks/) も参照してください。
