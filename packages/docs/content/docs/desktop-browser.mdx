# Desktop Browser

The desktop app can show a browser page beside your conversation. Open a page from a browser-tool result when connected to the local desktop Host, or use a [project action](/project-actions/) with an auto-open URL. The page has its own address bar, back, forward and reload controls.

## Inspect and annotate

Select a conversation, turn on **inspect**, and click an element. Varin adds element details and a screenshot to that conversation’s draft; review the draft before sending. Inspection pauses agent control of the page.

## Take over and resume

Use the page’s control button to take over from the agent or resume agent control. Closing or hiding the panel is not the same as stopping the agent’s task. There is no console-filter panel in this browser view.
