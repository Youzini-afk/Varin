# Desktop Browser

The desktop app includes an embedded browser view beside your conversation, alongside configured CDP endpoints and tabs shared through the Chrome/Edge **Browser Connector** (managed under **Settings → Browser**; see [Computer Use & Browser Resources](/computer-use/)).

Open a page from a browser-tool result when connected to the local desktop Host, or from a [project action](/project-actions/) with an auto-open URL. The view includes its own address bar and navigation controls.

## Inspect and quote

Select a conversation, turn on **Inspect**, and click an element. Varin adds the element details and screenshot to your draft so you can review before sending. Inspection pauses agent writes on that page.

## Take over and resume

Use the page's control button to take over from the agent or hand control back. **View browser** changes only what you observe; **Use for current task** assigns that browser to the current conversation. Closing or hiding the panel never cancels the agent's task.
