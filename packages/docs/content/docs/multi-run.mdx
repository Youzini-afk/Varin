# Multi-run

Multi-run creates a native Thread for each selected model. Choose a project, name the batch, add prompt/model groups, and launch. There is no fixed five-model limit.

Enable isolation for a Git worktree and branch per run. Without isolation, runs share the project’s live folder and may change the same files. Review setup commands before starting.

Review each attempt’s status. A failed or unconfirmed launch retains any created Thread and worktree. Retry unchanged selections to reconcile the original request. If worktree creation is unconfirmed, inspect Git on the original Host before trying again. **Stop launching** stops further launches; already accepted work continues.
