# Context

Open the right sidebar's **Context** view to inspect the selected Thread and branch, current run state, context data and retained history. Individual history records can be expanded or copied. Earlier records remain accessible through the conversation's history navigation.

Within the conversation, **Instructions and skills** shows captured resource versions and diagnostics. **Refresh instructions and skills** prepares a new snapshot for later requests without rewriting in-flight requests or accepted inputs.

**Context summaries** shows the current checkpoint and summary jobs. When available, you can apply a completed, current summary, cancel an unfinished summary or resume its preparation. Completing summary preparation is separate from applying it.

Token consumption is available under [Usage](/usage/). Those receipts are not a percentage of the model's remaining context. Start a new conversation when you want a separate task and history.
