# Notifications

Open **Settings → Varin → Notifications** and allow notifications on each device. Native conversation events notify you when a response finishes, a run fails, or approval or an answer is needed. Completion notifications respect the completion setting; attention requests remain separate.

Delivery depends on the connected desktop, browser push or mobile push service and system permissions. The Host must remain running. Notifications open the original Thread and branch when that delivery channel supports navigation.

The title is the Thread’s title, falling back to “Varin”. The body is fixed status text, not the agent’s reply. This also applies to APNs, so a conversation title may appear on an iPhone lock screen. Native events do not use the old editable message templates, and app-icon badge synchronization is not implemented.
