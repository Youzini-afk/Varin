# Herramientas del agente

Las herramientas disponibles dependen del modelo, origen, rol y permisos aceptados. Describe el resultado que necesitas; cada acción mantiene sus comprobaciones de autorización.

- `dispatch`, `child_status`, `child_report` y `wait_child` coordinan tareas delegadas.
- `threads` y `read_thread` inspeccionan conversaciones de la misma familia de tareas, no todas las conversaciones ni sus archivos.
- `follow_up` gestiona instrucciones disparadas por tiempo o condiciones.
- `goal_report` informa de objetivos explícitos completos o bloqueados.
- `resource_read` lee instrucciones y habilidades admitidas; `memory` gestiona notas dentro de los ámbitos permitidos.

Ver una herramienta no concede permisos de escritura, procesos o servicios externos. Leer una conversación no ejecuta su modelo ni concede control. Comprueba los resultados originales: aceptación no significa finalización.
