# Sesiones de worktree

Abre **Worktrees** del proyecto y crea una conversación con worktree. Varin crea una rama y carpeta Git, aplica los comandos de preparación y abre un Thread nativo para esa carpeta. El proyecto debe ser un repositorio Git.

Revisa, confirma e integra cambios en la vista Git. El worktree separa archivos, pero los comandos pueden tener efectos fuera de él.

Si falla la creación de la conversación o el resultado es desconocido, el worktree permanece en el Host original. Inspecciónalo antes de reintentar. Archivar o eliminar un Thread no elimina el worktree Git. Administra worktrees y ramas por separado en los controles del proyecto.
