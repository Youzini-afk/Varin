# Notificaciones

Abre **Ajustes → Varin → Notificaciones** y permite notificaciones en cada dispositivo. Los eventos nativos avisan de respuesta terminada, fallo o necesidad de aprobación o respuesta. Las notificaciones de finalización respetan su ajuste; las solicitudes de atención se gestionan aparte.

La entrega depende del escritorio, push web o móvil y permisos del sistema. El Host debe seguir funcionando. Los canales compatibles abren el Thread y la rama originales.

El título es el del Thread, o «Varin» si falta. El cuerpo es un estado fijo, no la respuesta del agente. También en APNs, por lo que el título puede aparecer en la pantalla bloqueada del iPhone. No se usan las antiguas plantillas editables ni está implementada la sincronización de insignias del icono.
