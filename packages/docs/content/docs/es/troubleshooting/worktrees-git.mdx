# Worktrees y Git

Antes de repetir una operación, revisa el Host y la carpeta originales. Un error o una respuesta perdida puede dejar un worktree o Thread real. Inspecciona Worktrees y Git; no borres una conversación para reparar un problema de carpeta ajeno.

Si la carpeta se movió, restaura o repara su registro Git worktree. Revisa cambios locales antes de continuar o abortar un merge, rebase o cherry-pick. Si un nombre ya está ocupado, revisa el trabajo existente antes de elegir otro.

Los mensajes de commit y descripciones de PR usan el modelo de utilidad o predeterminado del Host. Comprueba canal, modelo, credenciales y archivos preparados o rango de commits. No requieren una conversación activa. Investiga cualquier resultado desconocido antes de iniciar otra solicitud.
