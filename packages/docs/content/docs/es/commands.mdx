# Comandos

**Settings → Commands** muestra las habilidades activas y válidas de la biblioteca seleccionada, con descripción y ruta. Inicia un mensaje con `/skill:name`, seguido de un espacio y tus instrucciones.

En **Instructions and skills**, **Add /skill:name to draft** inserta el comando sin enviar el mensaje. Los nombres con espacios no pueden usar esta sintaxis.

La conversación usa una versión capturada. Después de editar la biblioteca, pulsa **Refresh instructions and skills** para preparar una nueva instantánea. Las solicitudes en curso y las entradas ya aceptadas conservan su material original. La lista de ajustes no implica que una conversación anterior ya esté actualizada.

Consulta [Habilidades](/es/skills/). Los atajos del área de trabajo se configuran por separado.
