# Comandos

Abre **Settings → Commands** para ver los comandos registrados por extensiones y habilidades. El catálogo muestra la descripción, el origen, el ámbito y la invocación de cada comando, y permite copiarla.

Escribe `/` al principio de un mensaje y selecciona un comando. Añade argumentos después del nombre si los requiere. Los comandos de extensiones los gestiona su propio plugin; `/skill:name` carga las instrucciones de esa habilidad.

Los comandos disponibles dependen del runtime, del espacio de trabajo y de los recursos cargados. Gestiona sus fuentes en **Settings → Skills** y **Settings → Pi Plugins**.
