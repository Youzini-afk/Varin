# Inicio rápido

1. Prepara Node.js, Bun y Rust siguiendo Instalación; ejecuta `bun install --frozen-lockfile` y `bun run dev` en el repositorio.
2. Abre la URL Vite indicada. Para escritorio, usa `bun run electron:dev`.
3. En Ajustes → Canales de modelos, conecta un canal y selecciona un modelo.
4. Crea una conversación: es un Thread nativo con ramas e historial propios.
5. Para trabajar con archivos, abre Workspace, selecciona Host, carpeta y modo de acceso, y prepara el origen. Un chat sin archivos no lo necesita.
6. Escribe y envía. Puedes adjuntar imágenes o PDF y revisar la actividad de herramientas.

Empareja el teléfono con el Host activo. El acceso por internet requiere un relay configurado y disponible o una ruta remota segura propia. Protege los Hosts expuestos a la red con una contraseña UI fuerte.
