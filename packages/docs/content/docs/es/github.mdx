# Issues y PRs de GitHub

Conecta GitHub para gestionar PR en Varin. Para pedir ayuda con un issue o PR, añade el contexto relevante a una conversación nativa y selecciona explícitamente el origen del espacio de trabajo.

## Conecta GitHub

1. Abre **Settings → Git**.
2. En GitHub, elige **Connect**. Varin muestra un enlace y un código corto.
3. Abre el enlace, introduce el código y aprueba.

Cuando esté conectado, tu cuenta aparece en la sección de GitHub. Puedes conectar más de una cuenta y cambiar entre ellas, o desconectar en cualquier momento.

## Abre y gestiona pull requests

Desde la pestaña **PR** en la [vista de git](/es/git/), puedes crear un pull request, actualizarlo, marcar un borrador como listo o fusionarlo. Varin puede generar el título y la descripción del PR a partir de tus cambios.
