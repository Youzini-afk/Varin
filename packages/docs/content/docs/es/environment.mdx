# Variables de entorno

Varin lee estas variables de entorno al arrancar. Para los servicios de inicio, `varin startup enable` guarda por defecto una instantánea del entorno actual, así que vuelve a ejecutarlo después de cambiar las variables que quieras que use el servicio.

Varin incorpora el runtime de Pi. No hay un servidor OpenCode aparte ni variables de integración `OPENCODE_*`.

## Servidor Varin

### `VARIN_HOST`

Dirección de enlace del servidor web de Varin. Usa `0.0.0.0` para permitir el acceso desde otras máquinas.

### `VARIN_UI_PASSWORD`

Contraseña de la UI del navegador. Úsala al enlazar fuera de localhost, al usar túneles o al ejecutar detrás de un proxy inverso.

### `VARIN_API_ONLY`

Inicia Varin en modo headless cuando vale `true` o `1`. Las rutas de API siguen disponibles para clientes de escritorio y móviles, pero no se sirve la UI del navegador.

### `VARIN_DATA_DIR`

Cambia el directorio de datos de Varin. Valores predeterminados: Linux usa `$XDG_CONFIG_HOME/varin` (o `~/.config/varin`); macOS, `~/Library/Application Support/Varin`; Windows, `%APPDATA%/Varin`.

### `VARIN_COMPRESS_API`

Controla la compresión de las respuestas de la API. Usa `true` o `1` para forzarla, `false` o `0` para desactivarla.

### `VARIN_SKIP_API_COMPRESSION`

Desactiva la compresión de las respuestas de la API cuando vale `true` o `1`. Tiene prioridad sobre `VARIN_COMPRESS_API`.

### `VARIN_VERBOSE_REQUEST_LOGS`

Activa registros HTTP detallados cuando vale `true` o `1`.

### `VARIN_UPDATE_API_URL`

Sustituye el endpoint de la API de comprobación de actualizaciones. La mayoría de usuarios debería dejarlo sin definir.

### `VARIN_PACKAGE_MANAGER`

Fuerza el gestor de paquetes que usan las operaciones de actualización cuando la detección automática se equivoca.

## Terminal y Git

### `VARIN_TERMINAL_SHELL`

Ejecutable de shell usado en las sesiones de terminal de Varin.

### `VARIN_GIT_BINARY`

Ejecutable de Git usado por las funciones de Git de Varin.

### `GIT_BINARY`

Otra sustitución del ejecutable de Git. Prefiere `VARIN_GIT_BINARY` para la configuración específica de Varin.

## Voz y túneles

### `OPENAI_API_KEY`

Clave de API que usan las funciones de voz de Varin que llaman a servicios compatibles con OpenAI.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Permite URL base remotas compatibles con OpenAI para las funciones de voz cuando vale `true` o `1`.

### `NGROK_AUTHTOKEN`

Token de autenticación de ngrok que usan los comandos de túnel de Varin. También puedes configurar ngrok con `ngrok config add-authtoken <token>`.

## Ayudas de runtime

### `BUN_BINARY`

Ejecutable de Bun que Varin debe usar al lanzar procesos daemon.

### `BUN_INSTALL`

Raíz de instalación de Bun. Varin la usa para encontrar `bin/bun` al arrancar el daemon y en las actualizaciones.
