# Documentación de Varin

Varin es un espacio de trabajo independiente para programación, investigación y proyectos. Su runtime nativo Rust Agent guarda las conversaciones como Threads y ramas en un Catalog persistente. Application Host conecta modelos, recursos y servicios MCP para escritorio, web y móvil.

Usa esta documentación para:

- instalar la app adecuada para tu forma de trabajar
- abrir Varin para uso local o remoto
- personalizar la apariencia y resolver problemas comunes

## Para qué sirve Varin

Varin está pensado para el trabajo de programación, investigación y otros proyectos que se beneficia de un centro de control: ramificar sesiones, revisar resultados, gestionar terminales, observar el progreso de las herramientas, ejecutar acciones de proyecto y mantener todo el panel a la vista mientras el agente trabaja.
