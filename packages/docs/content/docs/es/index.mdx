# Guías de Varin

Varin es un espacio de trabajo de código abierto para agentes de IA. Úsalo para tareas cotidianas, programación e investigación, con tus modelos y herramientas en un mismo lugar. Las aplicaciones de escritorio y web ofrecen el espacio de trabajo; el cliente móvil se conecta a tu Host.
