# Guías de Varin

Varin es el harness de agentes de código abierto, listo para usar. Las herramientas, el contexto, la ejecución, los permisos y la recuperación ya están preparados en torno al modelo que elijas, para programación, investigación, trabajo de oficina y tareas cotidianas. Las aplicaciones de escritorio y web ofrecen el espacio de trabajo; el cliente móvil se conecta a tu Host.
