# Contexto

Abre **Context** en la barra lateral derecha para ver Thread, rama, estado de ejecución, datos de contexto e historial conservado. Puedes desplegar o copiar registros; el historial anterior se consulta desde la navegación de la conversación.

**Instructions and skills** muestra las versiones capturadas y los diagnósticos. **Refresh instructions and skills** prepara una nueva instantánea para futuras solicitudes sin modificar las que ya están en curso o aceptadas.

**Context summaries** muestra el punto de control y los trabajos de resumen. Según el estado, puedes aplicar un resumen terminado y vigente, cancelar uno pendiente o reanudar su preparación. Terminar de prepararlo no equivale a aplicarlo.

[Uso](/es/usage/) muestra consumo, no el porcentaje de contexto restante. Crea otra conversación para una tarea e historial independientes.
