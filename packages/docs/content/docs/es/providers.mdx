# Proveedores, modelos y agentes

Antes de que Varin pueda hacer nada, necesita al menos un proveedor de IA conectado. Esta página cubre cómo conectar un proveedor, elegir un modelo y adaptar los agentes.

## Conectar un proveedor

1. Abre **Settings → Providers**.
2. Abre el menú **Add provider** y elige un proveedor que aún no esté conectado.
3. Inicia sesión de una de estas dos formas, según el proveedor:
   - **API key** — pega tu clave y guarda.
   - **Sign-in (device flow)** — Varin muestra un enlace y un código corto. Abre el enlace, introduce el código y aprueba. Varin termina la conexión por su cuenta.

Cuando un proveedor aparece como conectado, sus modelos quedan disponibles en el chat.

Para desconectar, abre el proveedor y elige quitar su inicio de sesión.

## Elegir un modelo

Eliges el modelo donde estás trabajando:

- en el chat, usa el selector de modelo de la barra de mensajes para fijar el proveedor y el modelo de esa sesión
- por agente, define un modelo predeterminado (abajo)

## Configurar agentes

Un agente es una configuración con nombre: un modelo, una personalidad y lo que se le permite hacer.

1. Abre **Settings → Agents**.
2. Elige un agente o crea uno nuevo.
3. Edita cualquiera de:
   - **description** — para qué sirve el agente
   - **model** — su modelo predeterminado
   - **temperature** — cuán creativas son sus respuestas
   - **prompt** — instrucciones permanentes que siempre sigue
   - **tool rules** — qué herramientas puede usar

## Dónde viven tus inicios de sesión

Los inicios de sesión de los proveedores los guarda el `AuthStorage` de Pi, no el renderer. Las claves de API y los tokens OAuth nunca aparecen en los metadatos de proveedor enviados a la UI. Las capas `models.json` de usuario, proyecto y operator se quedan en sus archivos nativos.

Si configuras el mismo proveedor en más de un sitio, gana el ajuste más específico: una capa de proyecto de confianza anula la personal.
