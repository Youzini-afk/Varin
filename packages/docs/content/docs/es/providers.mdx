# Canales de modelos

Abre **Settings → Model channels**, añade un canal y elige su tipo, endpoint y un método de autenticación compatible. Según el canal, puedes guardar una clave API, iniciar sesión, indicar una variable de entorno o usar una identidad de nube compatible o acceso anónimo.

Añade modelos por ID o descubre candidatos en un canal guardado que lo permita. Revisa y guarda tu selección: descubrir modelos no modifica el catálogo. Activa el canal, el modelo y la operación necesaria, como chat; después elige el modelo en el compositor.

El Application Host gestiona la configuración y las cuentas. Las credenciales se guardan separadas de los metadatos y no entran en el historial. Una credencial ausente o retirada no selecciona otra cuenta. Los cambios afectan a preparaciones posteriores; el trabajo aceptado conserva su selección.

Consulta [Memoria e instrucciones](/es/agent-personalization/) y [MCP](/es/mcp/). Acceder a un modelo no concede permisos de archivos ni herramientas.
