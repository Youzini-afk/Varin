# Biblioteca de habilidades

Usa **Settings → Skills** para explorar la biblioteca nativa y crear o copiar habilidades personales o de proyectos de confianza. Esta página no ofrece un mercado en línea independiente.

La configuración de recursos puede referenciar directorios de habilidades ya instalados. Leer un paquete no lo descarga ni ejecuta su código. Las extensiones ejecutables se gestionan en **Settings → Varin Extensions**.

Revisa el origen, la validez y el estado de solo lectura. Tras cambiar la biblioteca, actualiza **Instructions and skills** en la conversación. Las entradas aceptadas conservan la versión capturada.

Consulta [Habilidades](/es/skills/) y [Comandos](/es/commands/).
