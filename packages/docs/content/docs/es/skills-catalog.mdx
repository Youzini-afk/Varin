# Catálogo de skills

El antiguo catálogo independiente de skills ya no está disponible. Para instalar skills distribuidas como paquete Pi, abre **Ajustes → Paquetes Pi**, introduce una fuente admitida por Pi PackageManager (npm, URL Git o ruta local) y elige el ámbito de usuario o proyecto. Instala solo paquetes de confianza: pueden incluir extensiones ejecutables.

Usa [Skills](/es/skills/) para crear, editar e invocar las skills cargadas por el runtime activo.
