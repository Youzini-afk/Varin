# Servidores MCP

Abre **Ajustes → MCP** en el Host que deba gestionar la conexión. Selecciona el origen de configuración y añade un servidor: comando, argumentos y entorno para un proceso local, o URL y cabeceras para un servicio remoto. Usa solo servidores cuyo código y acceso a datos conozcas.

Guarda el documento, pulsa Connect o Reconnect y revisa estado y cantidad de herramientas. Inicia sesión si el servidor admite autorización. Los orígenes globales y de proyecto muestran sus rutas; la configuración de proyecto requiere confianza. Puedes editar campos o configuración sin procesar.

Guardar no sustituye los recursos ya capturados por un Thread activo. Revisa los recursos de la conversación y actualiza explícitamente su instantánea. Los permisos, preguntas y solicitudes de sampling aparecen en la conversación.
