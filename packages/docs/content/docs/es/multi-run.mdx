# Multi-run

Multi-run crea un Thread nativo por modelo seleccionado. Elige un proyecto, nombra el lote, añade grupos de prompts y modelos, e inicia. No hay un límite fijo de cinco modelos.

El aislamiento crea un worktree y una rama Git por ejecución. Sin aislamiento, las ejecuciones comparten la carpeta real del proyecto y pueden modificar los mismos archivos. Revisa los comandos de preparación.

Comprueba cada intento. Un inicio fallido o sin confirmar conserva los Threads y worktrees creados. Reintenta sin cambiar las opciones para reconciliar la solicitud original. Si la creación del worktree no está confirmada, inspecciona Git en el Host original. **Stop launching** detiene nuevos inicios; el trabajo ya aceptado continúa.
