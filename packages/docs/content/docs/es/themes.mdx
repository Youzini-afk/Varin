# Temas

Varin admite temas integrados y archivos JSON de tema personalizados.

## Añadir un tema personalizado

1. Crea el directorio de temas:

```bash
# Linux (default data directory)
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/varin/themes"
```

2. Añade tu archivo JSON a ese directorio (por ejemplo, `my-theme.json`).
3. Abre Varin y ve a **Settings → Appearance → Reload themes**.
4. Elige tu tema en el desplegable. Se aplica de inmediato.

## Ubicación de los temas

- Linux: `$XDG_CONFIG_HOME/varin/themes/` (`~/.config/varin/themes/`)
- macOS: `~/Library/Application Support/Varin/themes/`
- Windows: `%APPDATA%/Varin/themes/`
- `VARIN_DATA_DIR`: `$VARIN_DATA_DIR/themes/`
