# Instalación

Compila Varin desde el código o usa Docker con los pasos siguientes. Consulta [GitHub Releases](https://github.com/Youzini-afk/Varin/releases) para paquetes y plataformas compatibles.

Hay dos superficies de producto principales:

- app de escritorio (Electron)
- app web alojada por el servidor local, que puedes instalar como una app de teléfono (una PWA)

## Requisitos previos

- Node.js 22.19 o más reciente (Node.js 24 es la línea base de desarrollo)
- [Bun](https://bun.sh) 1.3.14
- La cadena de herramientas Rust seleccionada por `kernel/rust-toolchain.toml` (instala rustup; el repositorio selecciona la versión necesaria)
- Git

Varin compila e inicia su runtime nativo Rust Agent con Application Host. No requiere una CLI de agente aparte. Los archivos existentes y los datos históricos de conversaciones no se migran ni se reescriben automáticamente.

## Desde el código fuente (web)

```bash
git clone https://github.com/Youzini-afk/Varin.git
cd Varin
bun install --frozen-lockfile
bun run dev
```

Abre la URL de Vite que imprime el terminal. Varin inicia la UI y el servicio de API/runtime de confianza juntos.

## Desde el código fuente (escritorio)

```bash
bun run electron:dev
```

Más cerca de una compilación empaquetada:

```bash
bun run electron:dev:bundled
```

Se puede construir un instalador de Windows en local con `bun run electron:build:win`. Se esperan instaladores sin firmar hasta que se configuren las credenciales de firma.

## Docker

En un host Docker de Linux:

```bash
mkdir -p data/varin data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'VARIN_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

Abre `http://127.0.0.1:3000` y usa la contraseña generada. Pon un proxy inverso TLS o un túnel aprobado delante de cualquier despliegue expuesto a Internet. En producción, fija `VARIN_IMAGE` a un digest probado en lugar de `:latest`.

Compose usa por defecto la imagen ligera `ghcr.io/youzini-afk/varin-slim:latest` (bastante para el servidor: Bun, Node, Git, SSH y cloudflared). Si el agente necesita compilar Python, Java, Go o Rust dentro del contenedor, aplica la capa de herramientas:

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```
