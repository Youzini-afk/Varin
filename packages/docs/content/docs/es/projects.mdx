# Proyectos

Un proyecto es una carpeta del Host conectado. Ábrela con el selector de proyectos o el explorador; Ajustes → Proyectos controla su nombre, color, icono y acciones. El proyecto que exploras y el origen de ejecución de una conversación son independientes: cambiar de proyecto no cambia el origen de un Thread en ejecución.

En la conversación, abre **Workspace**, selecciona el Host y la carpeta de origen, y elige:
- **Read-only file snapshot**: archivos fijos para leer, listar y buscar
- **Isolated editable copy**: copia capturada para editar y ejecutar comandos; los cambios no se copian de vuelta automáticamente
- **Live workspace**: archivos guardados de la carpeta real; los cambios son inmediatos

Pulsa **Prepare workspace** y revisa el resultado antes de enviar. Las instantáneas pueden incluir borradores de editores de esta ventana en el mismo Host; el modo live usa solo archivos guardados. Las rutas remotas pertenecen al Host seleccionado. Las copias editables y los comandos no son entornos aislados de seguridad.
