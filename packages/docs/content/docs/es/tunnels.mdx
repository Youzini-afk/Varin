# Túneles

Un túnel es un enlace público a tu Varin, para que puedas acceder a él desde un navegador corriente en otra red. Usa `varin tunnel` para crear uno para una instancia en marcha.

> Conectar tus **propios dispositivos** (la app móvil, otro escritorio) normalmente no necesita un túnel: [vincúlalos](/es/connect-devices/) y deja que el [Private Relay](/es/private-relay/), cifrado de extremo a extremo, se encargue del acceso fuera de casa una vez que el servidor tenga un relay configurado (`VARIN_RELAY_URL`).

## Requisitos previos

Varin inicia el CLI del proveedor de túnel en tu máquina. Instala primero el proveedor que quieras usar:

```bash
brew install cloudflared
brew install ngrok
```

Los túneles rápidos de Cloudflare pueden funcionar con `cloudflared`. Ngrok requiere una cuenta de ngrok y un authtoken del panel de ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Inicio rápido

1. Inicia Varin:

```bash
varin
```

Si omites este paso, `varin tunnel start` puede iniciar automáticamente un servidor CLI. Al hacerlo, puedes pasar opciones del servidor como `--port`, `--host`, `--lan`, `--ui-password` y `--api-only`.

2. Inicia un túnel de Cloudflare:

```bash
varin tunnel start --provider cloudflare --mode quick
```

O inicia un túnel de Ngrok:

```bash
varin tunnel start --provider ngrok --mode quick
```

3. Comprueba el estado:

```bash
varin tunnel status
```

Cuando el túnel está activo, `status` muestra una URL pública. Ábrela, o escanea el código QR, para acceder a Varin desde cualquier lugar.

Por defecto, Varin imprime un código QR en sesiones TTY interactivas. Usa `--qr` para forzar la salida del QR, o `--no-qr` para desactivarla.

## Proveedores

- `cloudflare`: modos quick, managed remote y managed local
- `ngrok`: modo quick

## Modos gestionados

### Gestionado remoto

Usa un token + nombre de host gestionados por Cloudflare:

```bash
varin tunnel start --provider cloudflare --mode managed-remote --token-file ~/.secrets/cf-token --hostname app.example.com
```

### Gestionado local

Usa una configuración local de `cloudflared`:

```bash
varin tunnel start --provider cloudflare --mode managed-local --config ~/.cloudflared/config.yml
```

## Perfiles (managed-remote)

Guarda un perfil reutilizable:

```bash
varin tunnel profile add --provider cloudflare --mode managed-remote --name prod-main --hostname app.example.com --token-file ~/.secrets/cf-token
```

Inicia usando el perfil guardado:

```bash
varin tunnel start --profile prod-main
```

## Comandos útiles

```bash
varin tunnel providers
varin tunnel ready --provider cloudflare
varin tunnel ready --provider ngrok
varin tunnel doctor --provider cloudflare
varin tunnel doctor --provider ngrok
varin tunnel stop --port 3000
```

## Notas de comportamiento

- un único túnel activo por instancia de Varin (puerto)
- iniciar un nuevo modo/proveedor en la misma instancia reemplaza el túnel anterior
- generar un nuevo enlace de conexión revoca el anterior sin usar
- el autoarranque del túnel conserva flags del servidor como `--ui-password` y `--api-only` en los ajustes de instancia usados por reinicios y actualizaciones
