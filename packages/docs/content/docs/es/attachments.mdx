# Imágenes y PDF

Usa **Attach images** o **Attach PDFs** en el editor de la conversación. También puedes pegar o arrastrar archivos compatibles. Las imágenes requieren un modelo que las admita.

El PDF original se conserva como material del Thread. Abre su ficha para leer páginas y seleccionar una región para el borrador si el modelo admite imágenes. La representación extraída no sustituye al original disponible en el lector.

El envío, los tres modos de cola y la continuación de un hijo llevan la instantánea elegida. Los cambios posteriores del archivo no la alteran. Si la entrega no está confirmada, usa **Retry delivery** sin volver a subirlo. No puedes cambiar adjuntos pendientes hasta resolver el resultado original. Cambiar Host, Thread o rama no transfiere una carga pendiente.
