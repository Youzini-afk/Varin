# Início rápido

1. Prepare Node.js, Bun e Rust seguindo Instalação; execute `bun install --frozen-lockfile` e `bun run dev` no repositório.
2. Abra a URL Vite indicada. Para desktop, use `bun run electron:dev`.
3. Em Configurações → Canais de modelos, conecte um canal e escolha um modelo.
4. Crie uma conversa: ela é um Thread nativo com ramificações e histórico próprios.
5. Para arquivos, abra Workspace, escolha Host, pasta e modo de acesso e prepare a origem. Conversas sem arquivos não precisam dela.
6. Escreva e envie. Você pode anexar imagens ou PDFs e revisar a atividade das ferramentas.

Pareie o telefone com o Host ativo. Acesso pela internet exige relay configurado e disponível ou sua própria rota remota segura. Proteja Hosts expostos à rede com senha UI forte.
