# Sessões de Worktree

Abra **Worktrees** do projeto e crie uma conversa com worktree. O Varin cria a branch e a pasta Git, aplica os comandos de preparação e abre um Thread nativo para essa pasta. O projeto precisa ser um repositório Git.

Revise, faça commits e integre mudanças na visualização Git. O worktree separa arquivos, mas comandos podem ter efeitos fora dele.

Se a criação da conversa falhar ou tiver resultado desconhecido, o worktree permanece no Host original. Inspecione antes de repetir. Arquivar ou excluir um Thread não remove o worktree Git. Gerencie worktrees e branches separadamente nos controles do projeto.
