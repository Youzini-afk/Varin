# Multi-run

O Multi-run cria um Thread nativo para cada modelo selecionado. Escolha um projeto, nomeie o lote, adicione grupos de prompts e modelos e inicie. Não há limite fixo de cinco modelos.

O isolamento cria um worktree e uma branch Git por execução. Sem ele, as execuções compartilham a pasta real do projeto e podem alterar os mesmos arquivos. Confira os comandos de preparação.

Revise cada tentativa. Falhas ou resultados não confirmados preservam Threads e worktrees criados. Tente novamente sem mudar as opções para reconciliar o pedido original. Se a criação do worktree não foi confirmada, confira o Git no Host original. **Stop launching** interrompe novos lançamentos; trabalhos já aceitos continuam.
