# Tarefas agendadas e acompanhamentos

## Tarefas de calendário

Abra o agendador e escolha um projeto. Defina instruções, agenda única, diária, semanal ou cron, fuso IANA e tratamento de horários perdidos: pular ou executar uma vez o último.

**New work** cria um Thread por ocorrência. Selecione modelo registrado, fonte e acesso: snapshot somente leitura, cópia editável isolada ou diretório ativo. Você pode adicionar **Continuing Goal** e um orçamento de saída. **Existing work** aponta para Thread e branch exatos e herda modelo, fonte, permissões e objetivo.

Ative a agenda quando estiver pronta. **Run now** aceita uma ocorrência; abra a conversa para conferir o resultado. Desativar a definição retém trabalho agendado ainda não entregue. Parar uma execução não desativa horários futuros. O Application Host deve continuar ativo.

## Loops Markdown

Use `.agents/loops/` no projeto ou `~/.agents/loops/` para o usuário. Substitua os IDs pelos do canal salvo:

```markdown
---
name: daily-review
runtime: agent
schedule: "0 9 * * *"
timezone: UTC
enabled: false
target:
  kind: new_work
  model: { providerId: my-channel, modelId: my-model }
  source: { kind: project }
  sourceMode: fixed_branch
  goal: null
---
Resuma as mudanças do repositório desde ontem.
```

Nome, cron, fuso explícito, corpo, `runtime: agent` e `target` nativo são obrigatórios. O arquivo é a definição original; edições verificam sua revisão. A descoberta não reescreve arquivos nem importa definições antigas incompatíveis. Uma alteração inválida mantém a última tarefa nativa válida suspensa até o reparo.

## Acompanhamentos da conversa

Use **Follow-ups** no agendador ou **Schedule a follow-up** na conversa. Isso continua a mesma conversa após um horário, parada de processo ou job, condição de arquivo, artefato ou coleta de pesquisa, evento de log ou limiar de máquina. Combine qualquer condição ou todas.

Escolha uma vez ou cada mudança observada nas condições repetíveis. Pausas, perguntas pendentes e limites de objetivos continuam valendo; falhas de observação podem perder mudanças. Confira o histórico, pause, retome ou cancele. Cancelar impede trabalho futuro e não entregue, preservando resultados e jobs observados.
