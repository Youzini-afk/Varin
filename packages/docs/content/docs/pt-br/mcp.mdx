# Servidores MCP

Abra **Configurações → MCP** no Host responsável pela conexão. Escolha a origem da configuração e adicione um servidor: comando, argumentos e ambiente para processo local, ou URL e cabeçalhos para serviço remoto. Use apenas servidores cujo código e acesso a dados você conhece.

Salve o documento, use Connect ou Reconnect e confira estado e quantidade de ferramentas. Entre na conta quando houver autorização. Origens globais e do projeto mostram seus caminhos; configuração do projeto exige confiança. Você pode editar campos ou a configuração bruta.

Salvar não substitui recursos já capturados por um Thread ativo. Confira os recursos da conversa e atualize explicitamente seu snapshot. Pedidos de permissão, perguntas e sampling aparecem na conversa.
