# Variáveis de ambiente

O Varin lê estas variáveis de ambiente na inicialização. Para serviços de inicialização, `varin startup enable` salva por padrão um snapshot do ambiente atual, então execute de novo depois de alterar as variáveis que o serviço deve usar.

O Varin incorpora o runtime Pi. Não há um servidor OpenCode separado nem variáveis de integração `OPENCODE_*`.

## Servidor Varin

### `VARIN_HOST`

Endereço de bind do servidor web do Varin. Use `0.0.0.0` para permitir acesso de outras máquinas.

### `VARIN_UI_PASSWORD`

Senha da UI do navegador. Use ao fazer bind fora de localhost, ao usar túneis ou ao rodar atrás de um proxy reverso.

### `VARIN_API_ONLY`

Inicia o Varin em modo headless quando definido como `true` ou `1`. As rotas de API continuam disponíveis para clientes desktop e mobile, mas a UI do navegador não é servida.

### `VARIN_DATA_DIR`

Substitui o diretório de dados do Varin. Padrões: Linux usa `$XDG_CONFIG_HOME/varin` (ou `~/.config/varin`); macOS, `~/Library/Application Support/Varin`; Windows, `%APPDATA%/Varin`.

### `VARIN_COMPRESS_API`

Controla a compressão das respostas da API. Use `true` ou `1` para forçar a ativação, `false` ou `0` para forçar a desativação.

### `VARIN_SKIP_API_COMPRESSION`

Desativa a compressão das respostas da API quando definido como `true` ou `1`. Isso tem precedência sobre `VARIN_COMPRESS_API`.

### `VARIN_VERBOSE_REQUEST_LOGS`

Ativa logs HTTP detalhados quando definido como `true` ou `1`.

### `VARIN_UPDATE_API_URL`

Substitui o endpoint da API de verificação de atualizações. A maioria das pessoas deve deixar isso sem definir.

### `VARIN_PACKAGE_MANAGER`

Força o gerenciador de pacotes usado pelas operações de atualização quando a detecção automática está errada.

## Terminal e Git

### `VARIN_TERMINAL_SHELL`

Executável de shell usado nas sessões de terminal do Varin.

### `VARIN_GIT_BINARY`

Executável do Git usado pelos recursos de Git do Varin.

### `GIT_BINARY`

Outra substituição do executável do Git. Prefira `VARIN_GIT_BINARY` para configuração específica do Varin.

## Voz e túneis

### `OPENAI_API_KEY`

Chave de API usada pelos recursos de voz do Varin que chamam serviços compatíveis com OpenAI.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Permite URLs base remotas compatíveis com OpenAI para recursos de voz quando definido como `true` ou `1`.

### `NGROK_AUTHTOKEN`

Token de autenticação do ngrok usado pelos comandos de túnel do Varin. Você também pode configurar o ngrok com `ngrok config add-authtoken <token>`.

## Ajudantes de runtime

### `BUN_BINARY`

Executável do Bun que o Varin deve usar ao iniciar processos daemon.

### `BUN_INSTALL`

Raiz de instalação do Bun. O Varin usa isso para encontrar `bin/bun` na inicialização do daemon e nas atualizações.
