# Instalação

O Varin está em pre-1.0. As formas suportadas de executá-lo hoje são **a partir do código-fonte** e **com Docker**. Downloads empacotados de npm e GitHub Release ainda não foram publicados.

Há duas superfícies de produto principais:

- app de desktop (Electron)
- app web hospedado pelo servidor local, que você pode instalar como um app de celular (uma PWA)

## Pré-requisitos

- Node.js 22.19 ou mais recente (Node.js 24 é a linha de base de desenvolvimento)
- [Bun](https://bun.sh) 1.3.14
- A cadeia de ferramentas Rust selecionada por `kernel/rust-toolchain.toml` (instale rustup; o repositório seleciona a versão necessária)
- Git
- Git for Windows e Git Bash ao executar ferramentas de shell do Pi no Windows

Você **não** precisa de uma instalação separada do OpenCode ou da CLI do Pi. Os builds empacotados de desktop e de container incluem o runtime Pi fixado.

## A partir do código-fonte (web)

```bash
git clone https://github.com/Youzini-afk/Varin.git
cd Varin
bun install --frozen-lockfile
bun run dev
```

Abra a URL do Vite impressa no terminal. O Varin inicia a UI e o serviço confiável de API/runtime juntos.

## A partir do código-fonte (desktop)

```bash
bun run electron:dev
```

Mais próximo de um build empacotado:

```bash
bun run electron:dev:bundled
```

Um instalador do Windows pode ser gerado localmente com `bun run electron:build:win`. Instaladores sem assinatura são esperados até que as credenciais de assinatura sejam configuradas.

## Docker

Em um host Docker Linux:

```bash
mkdir -p data/varin data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'VARIN_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

Abra `http://127.0.0.1:3000` e use a senha gerada. Coloque um proxy reverso TLS ou um túnel aprovado na frente de qualquer implantação exposta à Internet. Em produção, fixe `VARIN_IMAGE` em um digest testado em vez de `:latest`.

O Compose usa por padrão a imagem enxuta `ghcr.io/youzini-afk/varin-slim:latest` (o suficiente para o servidor: Bun, Node, Git, SSH e cloudflared). Se o agente precisar compilar Python, Java, Go ou Rust dentro do contêiner, aplique a sobreposição de ferramentas:

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## Instalador de uma linha da CLI (não publicado)

`scripts/install.sh` e `npx @varin/web` apontam para o pacote npm `@varin/web`. Esse pacote ainda não está no registro público, então o instalador curl vai falhar até que uma release seja publicada. Até lá, use o código-fonte ou o Docker.
