# Temas

O Varin oferece suporte a temas integrados e arquivos JSON de tema personalizados.

## Adicionar um tema personalizado

1. Crie o diretório de temas:

```bash
# Linux (default data directory)
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/varin/themes"
```

2. Adicione seu arquivo JSON a esse diretório (por exemplo, `my-theme.json`).
3. Abra o Varin e vá em **Settings → Appearance → Reload themes**.
4. Escolha seu tema na lista suspensa. Ele é aplicado na hora.

## Localização dos temas

- Linux: `$XDG_CONFIG_HOME/varin/themes/` (`~/.config/varin/themes/`)
- macOS: `~/Library/Application Support/Varin/themes/`
- Windows: `%APPDATA%/Varin/themes/`
- `VARIN_DATA_DIR`: `$VARIN_DATA_DIR/themes/`
