# Provedores, Modelos e Agentes

Antes de o Varin poder fazer qualquer coisa, ele precisa de pelo menos um provedor de IA conectado. Esta página cobre como conectar um provedor, escolher um modelo e ajustar os agentes.

## Conectar um provedor

1. Abra **Settings → Providers**.
2. Abra o menu **Add provider** e escolha um provedor que ainda não esteja conectado.
3. Entre de uma destas duas formas, conforme o provedor:
   - **API key** — cole sua chave e salve.
   - **Sign-in (device flow)** — o Varin mostra um link e um código curto. Abra o link, digite o código e aprove. O Varin conclui a conexão sozinho.

Quando um provedor aparece como conectado, os modelos dele ficam disponíveis no chat.

Para desconectar, abra o provedor e escolha remover o login.

## Escolher um modelo

Você escolhe o modelo onde está trabalhando:

- no chat, use o seletor de modelo na barra de mensagem para definir o provedor e o modelo daquela sessão
- por agente, defina um modelo padrão (abaixo)

## Configurar agentes

Um agente é uma configuração com nome — um modelo, uma personalidade e o que ele pode fazer.

1. Abra **Settings → Agents**.
2. Escolha um agente ou crie um novo.
3. Edite qualquer um de:
   - **description** — para que o agente serve
   - **model** — o modelo padrão dele
   - **temperature** — o quão criativas são as respostas
   - **prompt** — instruções permanentes que ele sempre segue
   - **tool rules** — quais ferramentas ele pode usar

## Onde seus logins ficam

Os logins de provedor são armazenados pelo `AuthStorage` do Pi, não no renderer. Chaves de API e tokens OAuth nunca aparecem nos metadados de provedor enviados à UI. As camadas `models.json` de usuário, projeto e operator permanecem nos arquivos nativos delas.

Se você definir o mesmo provedor em mais de um lugar, a configuração mais específica vence: uma camada de projeto confiável substitui a pessoal.
