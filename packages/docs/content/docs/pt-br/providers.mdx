# Canais de modelos

Abra **Configurações → Canais de modelos**, adicione um canal e escolha o tipo, endpoint e uma forma de autenticação compatível. Conforme o canal, use chave de API salva, login, variável de ambiente explícita, identidade de nuvem compatível ou acesso anônimo.

Adicione modelos por ID ou descubra candidatos em um canal salvo que ofereça esse recurso. Confira e salve a seleção: a descoberta sozinha não altera o catálogo. Ative canal, modelo e operação necessária, como chat, e escolha o modelo no campo de mensagem.

O Application Host gerencia configurações e contas. As credenciais ficam separadas dos metadados e não entram no histórico. Credenciais ausentes ou revogadas não selecionam outra conta automaticamente. Edições afetam preparações posteriores; o trabalho aceito mantém sua seleção original.

Veja [Memória e instruções](/pt-br/agent-personalization/) e [MCP](/pt-br/mcp/). Acesso ao modelo não concede permissões de arquivos ou ferramentas.
