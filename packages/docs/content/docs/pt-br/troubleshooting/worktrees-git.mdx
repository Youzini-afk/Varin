# Worktrees e Git

Antes de repetir uma operação, confira o Host e a pasta originais. Uma falha ou resposta perdida pode deixar um worktree ou Thread real. Inspecione Worktrees e Git; não exclua a conversa para reparar um problema separado da pasta.

Se a pasta mudou de lugar, restaure ou repare seu registro Git worktree. Revise mudanças locais antes de continuar ou abortar merge, rebase ou cherry-pick. Se um nome já existe, confira o trabalho antes de escolher outro.

Mensagens de commit e descrições de PR usam o modelo utilitário ou padrão do Host. Verifique canal, modelo, credenciais e arquivos preparados ou intervalo de commits. Não exigem conversa ativa. Investigue resultados desconhecidos antes de iniciar outra solicitação.
