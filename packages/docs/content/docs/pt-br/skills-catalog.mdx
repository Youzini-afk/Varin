# Biblioteca de skills

Use **Configurações → Skills** para explorar a biblioteca nativa e criar ou copiar skills pessoais ou de projetos confiáveis. Esta página não oferece um marketplace on-line separado.

A configuração pode referenciar diretórios de skills já instalados. Ler um pacote não baixa nem executa seu código. Extensões executáveis têm gerenciamento próprio em **Configurações → Varin Extensions**.

Confira origem, validade e estado somente leitura. Após mudar a biblioteca, atualize **Instructions and skills** na conversa. Entradas aceitas preservam a versão capturada.

Veja [Skills](/pt-br/skills/) e [Comandos](/pt-br/commands/).
