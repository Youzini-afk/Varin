# Catálogo de Skills

O antigo catálogo independente de skills não está mais disponível. Para instalar skills distribuídas como pacote Pi, abra **Configurações → Pacotes Pi**, informe uma fonte aceita pelo Pi PackageManager (npm, URL Git ou caminho local) e escolha o escopo de usuário ou projeto. Instale somente pacotes confiáveis: eles podem incluir extensões executáveis.

Use [Skills](/pt-br/skills/) para criar, editar e invocar as skills carregadas pelo runtime ativo.
