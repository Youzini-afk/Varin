# Skills

Uma skill é um recurso `SKILL.md` com nome, descrição e instruções, podendo incluir arquivos de apoio. A descrição ajuda o Agent a decidir quando usá-la.

Em **Configurações → Skills**, crie, confira, edite, copie ou exclua skills pessoais ou de projetos confiáveis. O editor mostra caminho, origem, validade e possibilidade de escrita. Recursos somente leitura podem ser copiados para um escopo editável. Confira avisos de confiança e diagnósticos.

Use `/skill:name` no início da mensagem ou **Instructions and skills**. O Agent também pode ler recursos admitidos com `resource_read`. O texto da skill não concede permissões extras de arquivos ou ferramentas.

Salvar não substitui o material capturado pela conversa. **Refresh instructions and skills** prepara a nova versão para solicitações futuras; as já aceitas mantêm a versão original.

Veja [Comandos](/pt-br/commands/) e [Biblioteca de skills](/pt-br/skills-catalog/).
