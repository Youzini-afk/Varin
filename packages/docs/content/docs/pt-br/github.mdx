# Issues e PRs do GitHub

Conecte o GitHub para gerenciar PRs no Varin. Para pedir ajuda com uma issue ou PR, adicione o contexto relevante a uma conversa nativa e selecione explicitamente a origem do espaço de trabalho.

## Conectar o GitHub

1. Abra **Settings → Git**.
2. Em GitHub, escolha **Connect**. O Varin mostra um link e um código curto.
3. Abra o link, insira o código e aprove.

Quando estiver conectado, sua conta aparece na seção do GitHub. Você pode conectar mais de uma conta e alternar entre elas, ou desconectar a qualquer momento.

## Abrir e gerenciar pull requests

Pela aba **PR** na [visão de git](/pt-br/git/), você pode criar um pull request, atualizá-lo, marcar um rascunho como pronto ou fazer merge. O Varin pode gerar o título e a descrição do PR a partir das suas mudanças.
