# Guias do Varin

O Varin é o harness de agentes de código aberto, pronto para usar. Ferramentas, contexto, execução, permissões e recuperação já estão preparados em torno do modelo que você escolher, para programação, pesquisa, trabalho de escritório e tarefas do dia a dia. Os aplicativos de desktop e web oferecem o espaço de trabalho; o cliente móvel se conecta ao seu Host.
