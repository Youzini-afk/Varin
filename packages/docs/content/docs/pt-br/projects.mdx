# Projetos

Um projeto é uma pasta no Host conectado. Abra pelo seletor de projetos ou navegador de pastas; Configurações → Projetos controla nome, cor, ícone e ações. O projeto de navegação e a origem de execução da conversa são independentes: trocar de projeto não muda a origem de um Thread em execução.

Na conversa, expanda **Workspace**, selecione o Host e a pasta de origem e escolha:
- **Read-only file snapshot**: arquivos fixos para leitura, listagem e busca
- **Isolated editable copy**: cópia capturada para editar e executar comandos; mudanças não voltam automaticamente
- **Live workspace**: arquivos salvos da pasta real; edições têm efeito imediato

Clique em **Prepare workspace** e confira o resultado antes de enviar. Snapshots podem incluir rascunhos dos editores desta janela no mesmo Host; o modo live usa apenas arquivos salvos. Caminhos remotos pertencem ao Host selecionado. Cópias editáveis e comandos não são sandboxes de segurança.
