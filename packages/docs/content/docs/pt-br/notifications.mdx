# Notificações

Abra **Configurações → Varin → Notificações** e permita notificações em cada dispositivo. Eventos nativos avisam sobre resposta concluída, falha ou necessidade de aprovação ou resposta. Avisos de conclusão respeitam sua configuração; pedidos de atenção são separados.

A entrega depende do desktop, push web ou móvel e permissões do sistema. O Host precisa continuar ativo. Canais compatíveis abrem o Thread e a ramificação originais.

O título é o do Thread, com “Varin” como alternativa. O corpo é um estado fixo, não a resposta do agente. Isso vale também para APNs: o título pode aparecer na tela bloqueada do iPhone. Os antigos modelos editáveis não são usados, e a sincronização de emblemas do ícone não está implementada.
