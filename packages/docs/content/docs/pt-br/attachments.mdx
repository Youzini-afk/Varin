# Imagens e PDFs

Use **Attach images** ou **Attach PDFs** no editor da conversa. Também é possível colar ou arrastar arquivos compatíveis. Imagens exigem um modelo que aceite entrada visual.

O PDF original é preservado como material do Thread. Abra o anexo para ler páginas e selecionar uma região para o rascunho quando o modelo aceitar imagens. A representação extraída não substitui o original disponível no leitor.

Envio, os três modos de fila e continuação de conversa filha levam o snapshot escolhido. Mudanças posteriores no arquivo não o alteram. Se a entrega estiver incerta, use **Retry delivery**, sem novo upload. Anexos pendentes ficam bloqueados até resolver o resultado original. Trocar Host, Thread ou ramificação não transfere uploads pendentes.
