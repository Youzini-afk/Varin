# Uso de tokens da branch

Abra **Usage** no menu de serviços do cabeçalho. Ele mostra trabalho executado na branch selecionada, agrupado por modelo, provedor, tipo e estado de medição: conversa, contexto, planejamento, amostragem MCP e inferências de ferramentas registradas.

Quando reportados, aparecem tokens de entrada, saída, leitura e escrita de cache e raciocínio. As definições dos provedores podem se sobrepor. Não some todos os campos nem presuma que entrada exclui cache.

Uso real, estimado, ausente e pendente permanece distinto. Desconhecido não é zero. Solicitações sem envio registrado também são indicadas. Threads filhos e trabalho auxiliar independente têm uso próprio. Não é o total de todas as branches nem um indicador de capacidade de contexto. Não há estimativa de preço.

Se as atualizações desconectarem, o painel identifica o último snapshot registrado. Use **Refresh** para reconectar. Veja [Contexto](/pt-br/context/) e [Objetivos](/pt-br/session-goals/).
