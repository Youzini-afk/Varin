# Tokens desta conversa

Abra **Uso** no menu de serviços do cabeçalho para ver os tokens da conversa atual, agrupados por provedor e modelo.

- **Entrada**: tokens de entrada sem cache.
- **Saída**: tokens gerados.
- **Leitura de cache**: entrada reutilizada do cache do provedor.
- **Gravação de cache**: entrada gravada no cache.

Os totais vêm do registro de sessão do Pi, incluindo mensagens anteriores à compactação, ramificações inativas e chamadas auxiliares registradas. O uso sem identificação do modelo aparece separadamente. Cada conversa filha tem suas próprias estatísticas.
