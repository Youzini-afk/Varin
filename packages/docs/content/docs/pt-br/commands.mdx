# Comandos

Abra **Settings → Commands** para ver comandos registrados por extensões e skills. O catálogo mostra a descrição, a origem, o escopo e a invocação de cada comando, e permite copiá-la.

Digite `/` no início de uma mensagem e selecione um comando. Acrescente argumentos depois do nome quando necessário. Comandos de extensões são tratados pelo plugin responsável; `/skill:name` carrega as instruções dessa skill.

Os comandos disponíveis dependem do runtime, do espaço de trabalho e dos recursos carregados. Gerencie suas fontes em **Settings → Skills** e **Settings → Pi Plugins**.
