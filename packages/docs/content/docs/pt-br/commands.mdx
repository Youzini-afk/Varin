# Comandos

**Configurações → Comandos** lista as skills ativas e válidas da biblioteca selecionada, com descrição e caminho. Comece uma mensagem com `/skill:name`, seguido de espaço e instruções.

Na conversa, abra **Instructions and skills** e use **Add /skill:name to draft**. Isso insere o comando sem enviar a mensagem. Nomes com espaços não funcionam nessa sintaxe.

A conversa usa a versão capturada. Depois de editar a biblioteca, escolha **Refresh instructions and skills** para preparar um novo snapshot. Solicitações em andamento e entradas já aceitas mantêm o material original. A lista nas configurações não significa que uma conversa antiga já foi atualizada.

Veja [Skills](/pt-br/skills/) para editar recursos. Atalhos do ambiente de trabalho são configurados separadamente.
