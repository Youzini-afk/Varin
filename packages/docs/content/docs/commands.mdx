# Commands

**Settings → Commands** lists active, valid skills in the selected resource library, with their descriptions and file paths. Invoke one by starting a message with `/skill:name`, followed by a space and any instructions.

In a conversation, open **Instructions and skills** and use **Add /skill:name to draft**. This inserts text without sending the message. Names containing spaces cannot use this command syntax.

The conversation uses its captured skill version. After editing the library, choose **Refresh instructions and skills** to prepare a new context snapshot. In-flight requests and previously accepted skill inputs keep their original material. The settings list is a view of the library, not a guarantee that an older conversation has already refreshed it.

See [Skills](/skills/) for resource editing. Workbench keyboard shortcuts are configured separately.
