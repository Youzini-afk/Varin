# Commands

Open **Settings → Commands** to see commands registered by extensions and skills. The catalog shows each command’s description, source, scope and invocation, and lets you copy its invocation.

Type `/` at the start of a chat message and select a command. Add arguments after its name when the command requires them. Extension commands are handled by their owning plugin; `/skill:name` loads that skill’s instructions.

Available commands follow the selected runtime, workspace and loaded resources. Manage their sources in **Settings → Skills** and **Settings → Pi Packages**.
