# Varin user guides

Varin is your personal super agent: an open-source AI agent that works with your files, browser and connected computers, and brings in other agents when needed. Use it for everyday requests, coding, research or office work, with the models you choose.

Run Varin on your own computer or server. The desktop app includes the service; web and mobile clients connect to that service, called the Host. Start by connecting a model and giving Varin a task, then add the tools and devices you want it to use.
