# Varin user guides

Varin is your personal super agent: an open-source AI agent that works with your files, browser, and connected computers, and coordinates other agents when needed. Use it for everyday tasks, coding, research, or office work, with the models you choose.

Run Varin on your own computer or server. The desktop app includes the Application Host; web and mobile clients connect to that Host.
