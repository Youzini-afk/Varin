# Бібліотека навичок

У **Налаштування → Навички** переглядайте нативну бібліотеку, створюйте або копіюйте навички користувача та довірених проєктів. Окремого онлайн-магазину на цій сторінці немає.

Конфігурація може посилатися на вже встановлені каталоги навичок. Читання пакета не завантажує його й не виконує код. Виконувані розширення окремо керуються в **Налаштування → Varin Extensions**.

Перевірте походження, коректність і стан лише для читання. Після зміни бібліотеки оновіть **Instructions and skills** у розмові. Прийняті повідомлення зберігають зафіксовану версію.

Дивіться [Навички](/uk/skills/) і [Команди](/uk/commands/).
