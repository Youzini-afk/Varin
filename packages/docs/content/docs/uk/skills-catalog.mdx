# Каталог навичок

Колишній окремий каталог навичок більше недоступний. Щоб встановити навички з пакета Pi, відкрийте **Налаштування → Пакети Pi**, введіть джерело, яке підтримує Pi PackageManager (npm, Git URL або локальний шлях), і виберіть рівень користувача чи проєкту. Встановлюйте лише довірені пакети: вони можуть містити виконувані розширення.

Дивіться [Навички](/uk/skills/) для створення, редагування та виклику навичок, завантажених активним runtime.
