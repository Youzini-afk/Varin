# Сповіщення

Відкрийте **Налаштування → Varin → Сповіщення** й дозвольте їх на кожному пристрої. Власні події розмов сповіщають про готову відповідь, помилку запуску, потребу в дозволі чи відповіді. Сповіщення про завершення враховують відповідне налаштування; запити уваги окремі.

Доставка залежить від десктопа, браузерного чи мобільного push і дозволів системи. Host має працювати. Де підтримується навігація, відкриваються початкові Thread і гілка.

Заголовок — назва Thread або «Varin», тіло — фіксований статус, не відповідь агента. Це стосується й APNs: назва може з’явитися на заблокованому iPhone. Старі редаговані шаблони не використовуються; синхронізацію значка застосунку не реалізовано.
