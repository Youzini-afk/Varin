# Інструменти Agent

Доступні інструменти залежать від прийнятих моделі, джерела, ролі й дозволів. Опишіть потрібний результат; кожна дія зберігає власні перевірки авторизації.

- `dispatch`, `child_status`, `child_report` і `wait_child` координують делеговані завдання.
- `threads` і `read_thread` переглядають розмови тієї самої сім’ї завдань, без загального доступу до всіх розмов чи файлів.
- `follow_up` керує інструкціями, що спрацьовують за часом або умовою.
- `goal_report` повідомляє про завершення або блокування явно створеної цілі.
- `resource_read` читає допущені інструкції й навички; `memory` керує нотатками в дозволених областях.

Видимість інструмента не надає прав на запис, процеси або зовнішні сервіси. Читання розмови не запускає її модель і не надає контролю виконання. Прийняття не означає завершення: перевіряйте первісні результати й стан.
