# Контекст

Відкрийте **Context** у правій панелі, щоб переглянути Thread, гілку, стан запуску, контекст та історію. Записи можна розгортати й копіювати; попередні доступні через навігацію історії розмови.

**Instructions and skills** показує зафіксовані версії та діагностику. **Refresh instructions and skills** готує новий знімок для майбутніх запитів без зміни поточних запитів або прийнятих повідомлень.

**Context summaries** показує контрольну точку й завдання підсумовування. Залежно від стану можна застосувати завершений актуальний підсумок, скасувати незавершений або відновити підготовку. Завершення підготовки не означає застосування.

[Використання](/uk/usage/) показує споживання, а не відсоток контексту, що залишився. Для окремої роботи та історії почніть нову розмову.
