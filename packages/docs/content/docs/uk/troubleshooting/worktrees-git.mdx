# Worktree та Git

Перед повтором операції перевірте початковий Host і папку. Помилка чи втрачена відповідь може залишити справжній worktree або Thread. Перевірте Worktrees проєкту та Git; не видаляйте розмову для виправлення окремої проблеми папки.

Після переміщення папки відновіть або виправте реєстрацію Git worktree. Перед продовженням чи скасуванням merge, rebase або cherry-pick перевірте місцеві зміни. Якщо назва вже зайнята, спочатку перевірте наявну роботу.

Генерація комітів і описів PR використовує службову або типову модель Host. Перевірте канал, модель, облікові дані та вибрані файли чи діапазон комітів. Активна розмова не потрібна. Невідомий результат попереднього запиту перевірте перед новим запуском.
