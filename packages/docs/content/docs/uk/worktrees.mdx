# Сесії worktree

Відкрийте **Worktrees** проєкту й створіть розмову з worktree. Varin створить Git-гілку й папку, застосує команди налаштування та відкриє власний Thread для цієї папки. Проєкт має бути Git-репозиторієм.

Перевіряйте, комітьте та інтегруйте зміни в Git. Worktree відокремлює файли, але команди можуть впливати й на зовнішні ресурси.

Якщо створення розмови не вдалося або результат невідомий, worktree залишається на початковому Host. Перевірте його перед повтором. Архівування чи видалення Thread саме по собі не видаляє Git worktree. Керуйте worktree і гілками окремо через засоби проєкту.
