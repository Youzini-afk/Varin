# Швидкий старт

1. За інструкцією встановлення підготуйте Node.js, Bun і Rust, потім виконайте `bun install --frozen-lockfile` і `bun run dev` у репозиторії.
2. Відкрийте надрукований Vite URL. Для десктопа використайте `bun run electron:dev`.
3. У Налаштування → Канали моделей підключіть канал моделі та виберіть модель.
4. Створіть розмову: це власний Thread з гілками та історією.
5. Для файлів відкрийте Workspace, виберіть Host, папку й режим доступу та підготуйте джерело. Чат без файлів його не потребує.
6. Напишіть і надішліть повідомлення. Можна додати зображення або PDF і переглядати дії інструментів.

Телефон спаровується з активним Host. Доступ через інтернет потребує налаштованого доступного relay або власного захищеного маршруту. Захистіть мережевий Host сильним UI-паролем.
