# Multi-run

Multi-run створює власний Thread для кожної вибраної моделі. Виберіть проєкт, назвіть пакет, додайте групи запитів і моделей та запустіть. Фіксованого ліміту у п’ять моделей немає.

Ізоляція створює окремі Git worktree і гілку для кожного запуску. Без неї запуски ділять живу папку проєкту й можуть змінювати ті самі файли. Перевірте команди налаштування.

Перегляньте стан кожної спроби. Помилка або непідтверджений запуск зберігає створені Thread і worktree. Повторіть з незмінними параметрами для звірки початкового запиту. Непідтверджене створення worktree спершу перевірте в Git на початковому Host. **Stop launching** зупиняє нові запуски; прийнята робота триває.
