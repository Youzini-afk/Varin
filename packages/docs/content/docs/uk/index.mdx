# Посібники Varin

Varin є робочим простором із відкритим кодом для ШІ-агентів. Використовуйте його для щоденних завдань, програмування й досліджень, зібравши свої моделі та інструменти в одному місці. Настільний і вебзастосунки надають робочий простір, а мобільний клієнт підключається до вашого Host.
