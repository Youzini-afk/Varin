# Посібники Varin

Varin є готовим до роботи agent harness із відкритим кодом. Інструменти, контекст, виконання, дозволи та відновлення вже налаштовано навколо вибраної вами моделі для програмування, досліджень, офісної роботи й повсякденних завдань. Настільний і вебзастосунки надають робочий простір, а мобільний клієнт підключається до вашого Host.
