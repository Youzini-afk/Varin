# Токени цієї розмови

Відкрийте **Використання** в меню сервісів заголовка, щоб переглянути токени поточної розмови за провайдером і моделлю.

- **Вхід**: вхідні токени без кешу.
- **Вихід**: згенеровані токени.
- **Читання кешу**: вхідні токени з кешу провайдера.
- **Запис кешу**: вхідні токени, записані до кешу.

Підсумки беруться з журналу сесії Pi, включно з повідомленнями до стиснення, неактивними гілками та записаними допоміжними викликами. Виклики без даних моделі показуються окремо. Кожна дочірня розмова має власну статистику.
