# Використання токенів гілки

Відкрийте **Usage** у меню сервісів заголовка. Робота вибраної гілки групується за моделлю, провайдером, видом та станом вимірювання: розмова, контекст, планування, MCP sampling і записане виведення інструментів.

За наявності показуються токени входу, виходу, читання й запису кешу та міркування. Визначення провайдерів можуть перекриватися. Не додавайте всі поля й не припускайте, що вхід завжди виключає кеш.

Фактичні, оцінені, відсутні та очікувані дані розділено. Невідомо не означає нуль. Запити без записаного надсилання позначаються окремо. Дочірні Threads і незалежна допоміжна робота мають власний облік. Це не сума всіх гілок і не показник місткості контексту; ціна не оцінюється.

Після розриву оновлень панель позначає останній знімок. Натисніть **Refresh** для перепідключення. Дивіться [Контекст](/uk/context/) і [Цілі](/uk/session-goals/).
