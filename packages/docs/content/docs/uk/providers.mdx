# Канали моделей

Відкрийте **Налаштування → Канали моделей**, додайте канал і виберіть тип, кінцеву точку та підтримуваний спосіб автентифікації. Залежно від каналу доступні збережений API-ключ, вхід, явно вказана змінна середовища, підтримувана хмарна ідентичність або анонімний доступ.

Додайте моделі за ID або знайдіть кандидатів у збереженому каналі, який це підтримує. Перевірте й збережіть вибір: сам пошук не змінює каталог. Увімкніть канал, модель і потрібну операцію, наприклад чат, а потім виберіть модель у полі повідомлення.

Application Host керує конфігурацією й обліковими записами. Облікові дані зберігаються окремо від метаданих і не потрапляють в історію. Відсутні або відкликані дані не спричиняють автоматичного вибору іншого облікового запису. Зміни стосуються подальшої підготовки; прийнята робота зберігає первісний вибір.

Дивіться [Пам’ять та інструкції](/uk/agent-personalization/) і [MCP](/uk/mcp/). Доступ до моделі не надає прав на файли або інструменти.
