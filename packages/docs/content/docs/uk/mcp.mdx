# MCP-сервери

Відкрийте **Налаштування → MCP** на Host, який має володіти з’єднанням. Виберіть джерело конфігурації та додайте сервер: команду, аргументи й середовище для локального процесу або URL і заголовки для віддаленої служби. Довіряйте лише зрозумілим вам серверам.

Збережіть документ, натисніть Connect або Reconnect і перевірте стан та кількість інструментів. Увійдіть, якщо сервер підтримує авторизацію. Глобальні й проєктні джерела показують свої шляхи; конфігурація проєкту потребує довіри. Доступні структуровані поля та сирий документ.

Збереження не замінює ресурси, вже захоплені активним Thread. Перевірте ресурси розмови й явно оновіть знімок. Запити дозволу, питання та sampling відображаються в розмові.
