# Проєкти

Проєкт — це папка на підключеному Host. Відкрийте її через вибір проєкту або огляд папок; Налаштування → Проєкти керує назвою, кольором, значком і діями. Навігаційний проєкт і джерело виконання розмови незалежні: перемикання проєкту не змінює джерело активного Thread.

У розмові відкрийте **Workspace**, виберіть Host і папку джерела, потім режим:
- **Read-only file snapshot**: незмінні файли для читання, списку й пошуку
- **Isolated editable copy**: окрема копія для змін і команд; зміни не копіюються назад автоматично
- **Live workspace**: збережені файли справжньої папки; зміни діють одразу

Натисніть **Prepare workspace** та перевірте результат перед надсиланням. Знімки можуть включати чернетки редакторів цього вікна на тому самому Host; live використовує лише збережені файли. Віддалені шляхи належать вибраному Host. Редаговані копії й команди не є захисними пісочницями.
