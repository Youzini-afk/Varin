# GitHub Issues та PR

Підключіть GitHub для керування PR у Varin. Щоб агент працював із завданням або PR, додайте потрібний контекст до власної розмови та явно виберіть джерело робочого простору.

## Підключення GitHub

1. Відкрийте **Settings → Git**.
2. Під GitHub виберіть **Connect**. Varin покаже посилання й короткий код.
3. Відкрийте посилання, уведіть код і підтвердьте.

Коли підключення виконано, ваш акаунт показується в розділі GitHub. Ви можете підключити більше одного акаунта й перемикатися між ними або відключитися будь-коли.

## Відкриття pull request'ів і керування ними

З вкладки **PR** у [вигляді git](/uk/git/) ви можете створити pull request, оновити його, позначити чернетку готовою чи злити її. Varin може згенерувати заголовок та опис PR з ваших змін.
