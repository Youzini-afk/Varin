# Команди

**Налаштування → Команди** показує активні коректні навички вибраної бібліотеки, описи та шляхи. Почніть повідомлення з `/skill:name`, а після пробілу додайте інструкції.

У розмові відкрийте **Instructions and skills** та натисніть **Add /skill:name to draft**. Вставлення не надсилає повідомлення. Назви з пробілами не підтримують цей синтаксис.

Розмова використовує зафіксовану версію навички. Після редагування бібліотеки натисніть **Refresh instructions and skills**, щоб підготувати новий знімок. Поточні запити й уже прийняті вхідні повідомлення зберігають первісний матеріал. Оновлений список налаштувань не означає, що стару розмову вже оновлено.

Редагування описано в [Навичках](/uk/skills/). Клавіатурні скорочення робочого середовища налаштовуються окремо.
