# Команди

Відкрийте **Settings → Commands**, щоб побачити команди, зареєстровані розширеннями та навичками. Каталог показує опис, джерело, область і спосіб виклику та дозволяє скопіювати виклик.

Введіть `/` на початку повідомлення та виберіть команду. За потреби додайте аргументи після її назви. Команди розширень обробляє відповідний плагін; `/skill:name` завантажує інструкції цієї навички.

Доступні команди залежать від вибраного середовища, робочого простору та завантажених ресурсів. Керуйте їхніми джерелами в **Settings → Skills** і **Settings → Pi Packages**.
