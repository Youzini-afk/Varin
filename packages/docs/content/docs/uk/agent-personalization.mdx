# Пам’ять та інструкції Agent

У **Налаштування → Пам’ять** створюйте, редагуйте, видаляйте або переміщуйте нотатки між глобальною областю, проєктом і розмовою. Панель пам’яті розмови та інструмент `memory` використовують ті самі нотатки. Дочірнє завдання не успадковує автоматично нотатки батьківської розмови.

Збережені нотатки доступні одразу. Активна розмова отримує нові факти без переписування зафіксованого префікса системної пам’яті. Успішне застосування підсумку контексту оновлює цей знімок.

У **Налаштування → System prompt** редагуйте розділи інструкцій. Щільність, стиль і автономність вставляють редагований текст. Глобальні, проєктні та розмовні зміни застосовуються в такому порядку. **Restore defaults** прибирає лише зміни вибраної області. Зміни діють на безпечній межі запитів; уже підготовлені запити не змінюються.

Попередній перегляд показує зібрані інструкції й зафіксовану пам’ять. Перегляд останнього запиту, якщо доступний, не доводить отримання провайдером. Після редагування файлів інструкцій чи навичок використовуйте **Refresh instructions and skills**.

Bots мають окремі інструкції й пам’ять у **Varin Bot**, без нотаток або перевизначень звичайних Agents.
