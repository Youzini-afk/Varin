# Зображення та PDF

Використовуйте **Attach images** або **Attach PDFs** у полі розмови. Також можна вставити чи перетягнути підтримувані файли. Для зображень потрібна модель з підтримкою зображень.

PDF зберігається в оригіналі як матеріал Thread. Відкрийте вкладення, переглядайте сторінки та додавайте вибрану область до чернетки, якщо модель приймає зображення. Витягнуте представлення не замінює оригінал у читачі.

Надсилання, усі три режими черги й продовження дочірньої розмови передають вибраний знімок матеріалу. Пізніші зміни файлу його не змінюють. Якщо доставка не підтверджена, використайте **Retry delivery**, не завантажуйте повторно. До з’ясування результату вкладення заблоковані. Перемикання Host, Thread чи гілки не переносить незавершене завантаження.
