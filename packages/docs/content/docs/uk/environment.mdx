# Змінні середовища

Varin читає ці змінні середовища під час запуску. Для служб автозапуску `varin startup enable` за замовчуванням зберігає знімок поточного середовища, тож запустіть її знову після зміни змінних, які має використовувати служба.

Varin вбудовує runtime Pi. Окремого сервера OpenCode немає, і змінних інтеграції `OPENCODE_*` теж немає.

## Сервер Varin

### `VARIN_HOST`

Адреса прив’язки вебсервера Varin. Використовуйте `0.0.0.0`, щоб дозволити доступ з інших машин.

### `VARIN_UI_PASSWORD`

Пароль браузерного UI. Використовуйте його, коли прив’язуєте поза localhost, користуєтеся тунелями або працюєте за зворотним проксі.

### `VARIN_API_ONLY`

Запускає Varin у headless-режимі, коли встановлено `true` або `1`. Маршрути API лишаються доступними для десктопних і мобільних клієнтів, але браузерний UI не віддається.

### `VARIN_DATA_DIR`

Змінює каталог даних Varin. Типові значення: Linux — `$XDG_CONFIG_HOME/varin` (або `~/.config/varin`), macOS — `~/Library/Application Support/Varin`, Windows — `%APPDATA%/Varin`.

### `VARIN_COMPRESS_API`

Керує стисненням відповідей API. Використовуйте `true` або `1`, щоб примусово ввімкнути, `false` або `0` — щоб примусово вимкнути.

### `VARIN_SKIP_API_COMPRESSION`

Вимикає стиснення відповідей API, коли встановлено `true` або `1`. Це має пріоритет над `VARIN_COMPRESS_API`.

### `VARIN_VERBOSE_REQUEST_LOGS`

Вмикає докладні журнали HTTP-запитів, коли встановлено `true` або `1`.

### `VARIN_UPDATE_API_URL`

Перевизначає кінцеву точку API перевірки оновлень. Більшості користувачів варто лишити це невстановленим.

### `VARIN_PACKAGE_MANAGER`

Примусово задає менеджер пакетів для операцій оновлення, коли автовизначення помиляється.

## Термінал і Git

### `VARIN_TERMINAL_SHELL`

Виконуваний файл оболонки для термінальних сесій Varin.

### `VARIN_GIT_BINARY`

Виконуваний файл Git, який використовують функції Git у Varin.

### `GIT_BINARY`

Альтернативне перевизначення виконуваного файлу Git. Для конфігурації саме Varin надавайте перевагу `VARIN_GIT_BINARY`.

## Голос і тунелі

### `OPENAI_API_KEY`

Ключ API, який використовують голосові функції Varin, що викликають сервіси, сумісні з OpenAI.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Дозволяє віддалені базові URL, сумісні з OpenAI, для голосових функцій, коли встановлено `true` або `1`.

### `NGROK_AUTHTOKEN`

Токен автентифікації ngrok для команд тунелів Varin. ngrok також можна налаштувати командою `ngrok config add-authtoken <token>`.

## Допоміжні змінні runtime

### `BUN_BINARY`

Виконуваний файл Bun, який Varin має використовувати, запускаючи процеси-демони.

### `BUN_INSTALL`

Корінь встановлення Bun. Varin використовує його, щоб знайти `bin/bun` для запуску демона та оновлень.
