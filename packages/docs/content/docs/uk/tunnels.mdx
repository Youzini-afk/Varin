# Тунелі

Тунель — це публічне посилання на ваш Varin, щоб дістатися до нього зі звичайного браузера в іншій мережі. Скористайтеся `varin tunnel`, щоб створити його для запущеного інстансу.

> Для підключення **власних пристроїв** (мобільного застосунку, іншого десктопа) тунель зазвичай не потрібен — краще [зв'яжіть їх](/uk/connect-devices/) і дозвольте наскрізно зашифрованому [Private Relay](/uk/private-relay/) забезпечити доступ поза домом, щойно на сервері налаштовано relay (`VARIN_RELAY_URL`).

## Передумови

Varin запускає CLI провайдера тунелю на вашій машині. Спочатку встановіть провайдера, який хочете використовувати:

```bash
brew install cloudflared
brew install ngrok
```

Швидкі тунелі Cloudflare працюють через `cloudflared`. Для Ngrok потрібен акаунт ngrok і authtoken з dashboard ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Швидкий старт

1. Запустіть Varin:

```bash
varin
```

Якщо пропустити цей крок, `varin tunnel start` може автоматично запустити CLI server. Під час auto-start можна передати server options: `--port`, `--host`, `--lan`, `--ui-password` і `--api-only`.

2. Запустіть тунель Cloudflare:

```bash
varin tunnel start --provider cloudflare --mode quick
```

Або запустіть тунель Ngrok:

```bash
varin tunnel start --provider ngrok --mode quick
```

3. Перевірте статус:

```bash
varin tunnel status
```

Коли тунель піднято, `status` показує публічний URL. Відкрийте його або відскануйте QR-код, щоб дістатися до Varin звідусіль.

Типово Varin виводить QR-код в інтерактивних TTY-сесіях. Використовуйте `--qr`, щоб примусово вивести QR, або `--no-qr`, щоб вимкнути його.

## Провайдери

- `cloudflare`: quick, managed remote і managed local режими
- `ngrok`: quick режим

## Керовані режими

### Кероване віддалене

Використовуйте токен + хостнейм, керовані Cloudflare:

```bash
varin tunnel start --provider cloudflare --mode managed-remote --token-file ~/.secrets/cf-token --hostname app.example.com
```

### Кероване локальне

Використовуйте локальний конфіг `cloudflared`:

```bash
varin tunnel start --provider cloudflare --mode managed-local --config ~/.cloudflared/config.yml
```

## Профілі (managed-remote)

Збережіть багаторазовий профіль:

```bash
varin tunnel profile add --provider cloudflare --mode managed-remote --name prod-main --hostname app.example.com --token-file ~/.secrets/cf-token
```

Запуск зі збереженим профілем:

```bash
varin tunnel start --profile prod-main
```

## Корисні команди

```bash
varin tunnel providers
varin tunnel ready --provider cloudflare
varin tunnel ready --provider ngrok
varin tunnel doctor --provider cloudflare
varin tunnel doctor --provider ngrok
varin tunnel stop --port 3000
```

## Нотатки щодо поведінки

- один активний тунель на інстанс Varin (порт)
- запуск нового режиму/провайдера на тому самому інстансі замінює попередній тунель
- генерація нового посилання для підключення відкликає попереднє невикористане
- авто-старт тунелю зберігає серверні прапорці на кшталт `--ui-password` та `--api-only` у налаштуваннях інстансу, які використовуються під час рестарту/оновлення
