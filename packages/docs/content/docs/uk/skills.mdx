# Навички

Навичка — це ресурс `SKILL.md` із назвою, описом та інструкціями, за потреби з допоміжними файлами. Опис допомагає Agent визначити, коли її застосовувати.

У **Налаштування → Навички** можна створювати, переглядати, редагувати, копіювати й видаляти ресурси користувача або довіреного проєкту. Редактор показує шлях, походження, коректність і можливість запису. Ресурс лише для читання можна скопіювати в редаговану область. Перевірте запити довіри та діагностику.

Використовуйте `/skill:name` на початку повідомлення або **Instructions and skills**. Agent також читає допущені ресурси через `resource_read`. Текст навички не надає додаткових прав на файли чи інструменти.

Збереження не замінює матеріал, уже зафіксований розмовою. **Refresh instructions and skills** готує нову версію для подальших запитів; прийняті запити зберігають попередню.

Дивіться [Команди](/uk/commands/) і [Бібліотеку навичок](/uk/skills-catalog/).
