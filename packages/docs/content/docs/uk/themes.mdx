# Теми

Varin підтримує вбудовані теми та власні JSON-файли тем.

## Додати власну тему

1. Створіть директорію тем:

```bash
# Linux (default data directory)
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/varin/themes"
```

2. Додайте свій JSON-файл у цю директорію (наприклад, `my-theme.json`).
3. Відкрийте Varin, потім перейдіть до **Settings → Appearance → Reload themes**.
4. Оберіть свою тему зі спадного списку. Вона застосується одразу.

## Розташування тем

- Linux: `$XDG_CONFIG_HOME/varin/themes/` (`~/.config/varin/themes/`)
- macOS: `~/Library/Application Support/Varin/themes/`
- Windows: `%APPDATA%/Varin/themes/`
- `VARIN_DATA_DIR`: `$VARIN_DATA_DIR/themes/`
