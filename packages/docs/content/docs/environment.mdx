# Environment Variables

Varin reads these environment variables at startup. For startup services, `varin startup enable` snapshots the current environment by default, so rerun it after changing variables you want the service to use.

Varin embeds the Pi runtime. There is no separate OpenCode server and no `OPENCODE_*` integration variables.

## Varin server

### `VARIN_HOST`

Bind address for the Varin web server. Use `0.0.0.0` to allow access from other machines.

### `VARIN_UI_PASSWORD`

Password for the browser UI. Use this when binding outside localhost, using tunnels, or running behind a reverse proxy.

### `VARIN_API_ONLY`

Starts Varin in headless mode when set to `true` or `1`. API routes stay available for desktop and mobile clients, but the browser UI is not served.

### `VARIN_DATA_DIR`

Overrides the Varin data directory. Defaults: Linux uses `$XDG_CONFIG_HOME/varin` (or `~/.config/varin`); macOS uses `~/Library/Application Support/Varin`; Windows uses `%APPDATA%/Varin`.

### `VARIN_COMPRESS_API`

Controls API response compression. Use `true` or `1` to force it on, `false` or `0` to force it off.

### `VARIN_SKIP_API_COMPRESSION`

Disables API response compression when set to `true` or `1`. This takes precedence over `VARIN_COMPRESS_API`.

### `VARIN_VERBOSE_REQUEST_LOGS`

Enables verbose HTTP request logs when set to `true` or `1`.

### `VARIN_UPDATE_API_URL`

Overrides the update-check API endpoint. Most users should leave this unset.

### `VARIN_PACKAGE_MANAGER`

Forces the package manager used by update operations when auto-detection is wrong.

## Terminal and Git

### `VARIN_TERMINAL_SHELL`

Shell executable used for Varin terminal sessions.

### `VARIN_GIT_BINARY`

Git executable used by Varin Git features.

### `GIT_BINARY`

Alternative Git executable override. Prefer `VARIN_GIT_BINARY` for Varin-specific configuration.

## Voice and tunnels

### `OPENAI_API_KEY`

API key used by Varin voice features that call OpenAI-compatible services.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Allows remote OpenAI-compatible base URLs for voice features when set to `true` or `1`.

### `NGROK_AUTHTOKEN`

ngrok auth token used by Varin tunnel commands. You can also configure ngrok with `ngrok config add-authtoken <token>`.

## Runtime helpers

### `BUN_BINARY`

Bun executable Varin should use when spawning daemon processes.

### `BUN_INSTALL`

Bun installation root. Varin uses it to find `bin/bun` for daemon startup and updates.
