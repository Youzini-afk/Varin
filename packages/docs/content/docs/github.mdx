# GitHub Issues & PRs

Connect GitHub to manage pull requests from Varin. To ask an agent about an issue or PR, add its relevant context to a native conversation and select the workspace source explicitly.

## Connect GitHub

1. Open **Settings → Git**.
2. Under GitHub, choose **Connect**. Varin shows a link and a short code.
3. Open the link, enter the code, and approve.

When it's connected, your account shows under the GitHub section. You can connect more than one account and switch between them, or disconnect at any time.

## Open and manage pull requests

From the **PR** tab in the [git view](/git/), you can create a pull request, update it, mark a draft as ready, or merge it. Varin can generate the PR title and description from your changes.
