# Worktree 会话

打开项目的 **Worktrees** 页面并创建 worktree 对话。Varin 创建 Git 分支和目录、执行项目初始化命令，再为该目录打开原生 Thread。项目必须是 Git 仓库。

在 Git 视图中检查、提交和整合修改。Worktree 隔离不同检出目录的文件，但命令仍可能影响目录之外的内容。

若对话创建失败或结果未知，worktree 会保留在原 Host。重试前先检查。归档或删除 Thread 本身不会删除 Git worktree；请在项目的 worktree/Git 控件中单独管理目录与分支。
