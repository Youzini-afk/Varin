# 更新

你如何更新 Varin 取决于你如何安装它。在任何情况下，你都可以在 **Settings → About** 查看当前版本。

## 桌面应用

桌面应用会对照 GitHub releases 检查更新。当有可用更新时，Varin 会告诉你，在你选择时下载它，并在你选择更新重启操作时安装它。一切都由你掌控 — 没有你的同意不会安装任何东西。

Linux 更新需要可写的打包 AppImage，不支持提取或重新打包的副本。macOS 应先将 Varin.app 安装到 `/Applications` 再应用更新。

Android 上，直接用新版本的 APK 覆盖安装，配对信息会保留。

## Web / CLI

如果你安装的是已发布的 CLI，可以从 **About** 用检查和更新按钮更新它，或从终端更新：

```bash
varin update
```

Varin 会检测它是如何安装的（npm、pnpm、yarn 或 bun），并为你运行正确的更新。`@varin/web` 包尚未上架公共 npm registry，因此这条路径仅在发布之后才适用。

源码检出用 Git 更新。Docker 部署通过拉取新的镜像 digest 来更新。
