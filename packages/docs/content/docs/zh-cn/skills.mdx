# 技能

技能是包含名称、说明和指令的 `SKILL.md` 资源，也可以附带支持文件。说明帮助 Agent 判断适用场景。

在 **设置 → 技能** 中创建、查看、编辑、复制或删除技能，选择用户范围或已信任的项目。编辑器显示路径、来源、有效性及是否可写。只读资源可以复制到可写范围。使用项目资源前，请处理项目信任提示和诊断。

在消息开头使用 `/skill:name`，或在对话的 **Instructions and skills** 面板选择技能。Agent 也可以通过 `resource_read` 读取已准入技能及其支持文件。技能内容不会授予额外工具或文件权限。

保存资源库不会替换对话已捕获的材料。点击 **Refresh instructions and skills** 后，后续请求使用新快照，已受理请求保留原版本。

参阅 [命令](/zh-cn/commands/) 和 [技能资源库](/zh-cn/skills-catalog/)。
