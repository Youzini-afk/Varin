# 通知

打开“设置 → Varin → 通知”，并在各设备上允许通知。原生对话在回复完成、运行失败、需要批准或回答问题时发出通知。完成类通知遵循完成通知设置，需要你处理的请求单独发送。

实际送达取决于桌面、浏览器推送或移动推送服务与系统权限，Host 必须持续运行。支持导航的通知渠道会打开原 Thread 和分支。

标题直接使用 Thread 标题，未命名时为“Varin”；正文是固定状态文字，不含 Agent 回复。APNs 同样如此，因此对话标题可能显示在 iPhone 锁屏上。原生事件不使用旧的可编辑消息模板，也未实现应用图标角标同步。
