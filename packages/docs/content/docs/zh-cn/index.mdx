# Varin 使用指南

Varin 是你的个人超级智能体：一个开源的 AI 智能体，能操作你的文件、浏览器和已连接的电脑，并在需要时协调其他 Agent 协作。无论是日常事务、编程、研究还是办公，都可使用你选择的模型完成。

你可以在自己的电脑或服务器上运行 Varin。桌面应用内置了 Application Host，网页和移动客户端都会连接到这个 Host。
