# Varin 使用指南

Varin 是你的个人超级智能体：一个开源的个人 AI 智能体，能使用文件、浏览器和连接的电脑完成工作，也能组织其他 Agent 协作。从日常事务到编程、科研和办公，模型由你选择。

你可以在自己的电脑或服务器上运行 Varin。桌面应用自带服务，网页和移动客户端连接这个服务，我们称它为 Host。先连接模型、交给 Varin 一个任务，再按需要接入工具和设备。
