# Varin 文档

Varin 是独立的编程、研究与项目工作空间。原生 Rust Agent runtime 将对话保存为 Thread 和分支，由持久化 Catalog 管理。Application Host 为桌面、网页和移动端连接模型、资源与 MCP 服务。

使用本文档来：

- 为你的工作方式安装合适的应用
- 打开 Varin，用于本地或远程使用
- 自定义外观并排查常见问题

## Varin 用于什么

Varin 面向编程、科研和其他项目工作中那些受益于控制中枢的部分：分支会话、审查结果、管理终端、观察工具进度、运行项目操作，并在智能体工作时让整个面板尽收眼底。
