# Varin 助手

**Varin** 是你的长期个人助手视图。你可以在这里讨论想法、把任务交办给专业 Agent、在任务执行的同时继续聊天，之后回来时上下文与记忆依然完好无损。你也可以创建多位 Bot，各自拥有独立的指令、模型、记忆、日程与外观。

## 边运行任务边继续对话

- 默认情况下，在 Varin 对话中发送补充消息会在当前步骤完成后立即引导正在进行的轮次。按 **Alt+Enter**（或点击发送按钮旁的排队按钮）可将消息排到当前轮次结束之后再处理。
- 在对话旁的侧边标签页中打开 **工作详情**、**文件** 或 **电脑**，无需离开当前聊天。关闭侧边标签页绝不会取消正在运行的工作。
- 同一个助手可以维护多个对话与分支，它们共享同一份档案、主目录、记忆和日程安排。

## 群聊

- 从 Bot 侧栏新建群聊，让多位 Bot 在同一条共享时间线上协作。
- 通过 `@` 提及一位或多位 Bot，或直接回复某个 Bot 的消息来指定对方接话。未指定对象的消息只会交给开启监听的成员；没人监听时，消息留在群里，不会启动 Bot。
- 群内支持共享文件与搜索历史消息；Bot 也可以按需查阅群历史并联系其他成员。右侧面板集中查看成员、活动和群日程，群日程沿用单聊的日程与定时接续功能。

## 记忆与事项

- 打开右侧面板的 **记忆** 标签页（或前往 **设置 → Bot** 并切到 **记忆**），即可查看、编辑、整理或遗忘该 Bot 跨对话记住的内容。
- 遗忘记忆不会改动原始聊天记录；被遗忘的内容只会从后续模型上下文中排除。
- **事项** 用于跟踪持续推进的主题，并直接关联到底层委派任务，方便你随时跳入完整的 [Workbench](/zh-cn/views-and-collaboration/) 进行更细致的控制。

## 定时与事件监听

打开右侧面板的 **定时与监听**，即可管理周期性日程以及来自已连接插件的传入事件监听：

- 选择传入事件的处理方式：**立即处理**、按时间窗口**批量合并**、按**定时计划**执行，或**排队**等待你的下一轮对话。
- 可随时暂停、恢复或对任意监听触发 **立即处理**，不会删除其历史记录。

## 档案、外观与桌面桌宠

- 从 Bot 右侧面板、左栏或 **设置 → Bot** 进入档案，集中调整指令、模型、思考强度、记忆和外观。
- 在 **设置 → Bot → 档案 → 更换外观** 中，可从 **16 个内置可动角色**（含 Varin）中选择，或导入自定义图片与动图素材包。新建 Bot 时，外观保留 **随机** 会自动挑选角色，名字留空则会直接使用所选角色的名字。
- 在桌面应用中，打开 **设置 → 桌宠** 即可下载可选的桌面桌宠，实时跟随所选助手的活动状态。让桌宠休眠只会关闭角色窗口，不会暂停你的助手。
