# 上下文

打开右侧栏的 **Context**，查看当前 Thread、分支、运行状态、上下文数据及保留的历史。可展开或复制单条记录，更早的记录通过对话历史导航访问。

对话中的 **Instructions and skills** 展示捕获的资源版本及诊断。点击 **Refresh instructions and skills** 为后续请求准备新快照，不改写进行中的请求或已受理输入。

**Context summaries** 展示当前检查点和摘要任务。在对应操作可用时，可以应用已完成且仍适用于当前检查点的摘要、取消未结束摘要或恢复其准备。摘要准备完成不等于已经应用。

消耗量见 [用量](/zh-cn/usage/)，这些回执不是模型剩余上下文的百分比。需要独立任务和历史时，请新建对话。
