# 视图与 Agent 协作

按需选择与 Agent 和文件协作的精细程度。切换视图只会改变界面呈现——运行中的任务、所选模型和工作区来源均保持不变。

| 视图 | 适用场景 | 核心聚焦 |
| --- | --- | --- |
| **Varin** | 持续对话与高层协调 | 助手对话、工作概览、记忆、日程与侧边文件/电脑标签页 |
| **Workbench** | 直接掌控任务与协作成员 | 专注对话、工具活动、协作面板、计划与恢复 |
| **IDE** | 亲手编辑与调试 | Monaco 编辑器分组、差异对比、终端、Git 与 Agent 对话并排展示 |

## 任务焦点

在这些视图之下，每个对话都使用一种 **任务焦点**——**通用**、**编程**、**研究** 或 **办公**——用于定制直接可见的工具和可用的 Agent 预设。其他能力仍可按需发现和调用。

## 委派与协作

- **自由派发或使用预设**：Agent 可以指定具体模型、思考级别、任务焦点或已配置的预设来委派子任务。你也可以在 Agents 设置中启用可选的 **派发模型选择**。
- **协作面板**：打开右侧 **协作** 面板，在统一时间线中追踪任务派发、成员间消息、最终报告与代码交接。点击任意成员即可查看其完整对话、发送跟进消息或停止该成员。
- **工作区模式**：
  - **共享**（默认）：协作成员直接在选定目录中工作。
  - **隔离写入**：分叉出一个独立工作区（Windows 使用 WinFsp、Linux 使用 FUSE、macOS 使用 FSKit/macFUSE），并通过代码交换（`submit_code` / `update`）伴随冲突审阅合并回原目录。
  - **只读**：移除文件修改类工具，便于安全检查。
- **输入框交接命令**：在输入框中使用 `/` 命令可直接向指定成员发消息、准备结构化交接、将对话导出为 Markdown/JSON，或保存笔记/记忆。
