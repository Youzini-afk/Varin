# 安装

Varin 目前是 pre-1.0。今天支持的运行方式只有**从源码**和**使用 Docker**。打包的 npm 和 GitHub Release 下载尚未发布。

有两个主要产品界面：

- 桌面应用（Electron）
- 由本地服务器托管的 Web 应用，可以像手机应用一样安装（即 PWA）

## 前提条件

- Node.js 22.19 或更新（Node.js 24 是开发基线）
- [Bun](https://bun.sh) 1.3.14
- 由 `kernel/rust-toolchain.toml` 选定的 Rust 工具链（安装 rustup 后，仓库会选择所需版本）
- Git
- 在 Windows 上运行 Pi shell 工具时，需要 Git for Windows 和 Git Bash

你**不**需要单独安装 OpenCode 或 Pi CLI。打包的桌面和容器构建已包含固定版本的 Pi 运行时。

## 从源码（Web）

```bash
git clone https://github.com/Youzini-afk/Varin.git
cd Varin
bun install --frozen-lockfile
bun run dev
```

打开终端中打印的 Vite URL。Varin 会同时启动 UI 和受信任的 API/运行时服务。

## 从源码（桌面）

```bash
bun run electron:dev
```

更接近打包构建：

```bash
bun run electron:dev:bundled
```

可以用 `bun run electron:build:win` 在本地构建 Windows 安装包。在配置签名凭据之前，未签名的安装包是预期情况。

## Docker

在 Linux Docker 主机上：

```bash
mkdir -p data/varin data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'VARIN_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

打开 `http://127.0.0.1:3000` 并使用生成的密码。任何面向互联网的部署前面都应放置 TLS 反向代理或已批准的隧道。生产环境请将 `VARIN_IMAGE` 固定到已测试的 digest，而不是 `:latest`。

Compose 默认拉取精简镜像 `ghcr.io/youzini-afk/varin-slim:latest`（用来跑服务：Bun、Node、Git、SSH、cloudflared）。如果智能体要在容器里编译 Python、Java、Go 或 Rust，叠加工具链覆盖层：

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## CLI 一行安装（尚未发布）

`scripts/install.sh` 和 `npx @varin/web` 面向 `@varin/web` npm 包。该包尚未上架公共 registry，因此在发布之前 curl 安装程序会失败。在此之前请使用源码或 Docker。
