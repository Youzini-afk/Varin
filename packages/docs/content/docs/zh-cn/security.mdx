# 安全

Varin 让外界可以访问你的机器和代码，所以在除你之外的任何人能够访问它之前，请把它锁好。本页介绍 UI 密码、passkey，以及在将 Varin 暴露到网络之前需要了解的内容。

## 设置 UI 密码

带密码启动 Varin，浏览器 UI 就会要求输入它：

```bash
varin --ui-password be-creative-here
```

你也可以用 `VARIN_UI_PASSWORD` 环境变量来设置它，而不是把它放在命令行上。登录后，Varin 会记住该设备一段时间，这样你就不必每次都输入。

如果实例可以被其他任何人访问，请务必设置密码 — 尤其是通过 [隧道](/zh-cn/tunnels/) 或公共互联网时。

## Passkey

设置密码后，你可以添加 passkey（Face ID、Touch ID、安全密钥）以便更快登录。在 **设置 → 设备与访问 → Passkeys** 中添加它们。

passkey 与当前密码绑定。如果你更改或移除密码，已保存的 passkey 会被清除，你需要重新添加它们。

## 设备令牌

通过 [连接设备](/zh-cn/connect-devices/) 配对的设备使用各自独立的设备令牌进行认证，而不是 UI 密码。配对链接只能使用一次，未使用也会过期；每台已配对的设备都会列在 **设置 → 设备与访问 → 连接到此服务器** 中，你可以随时撤销任何一台。外出时的连接经由 [Private Relay](/zh-cn/private-relay/) 传输，它是端到端加密的，无法读取你的流量。

## 在暴露它之前

- 默认情况下 Varin 只监听你自己的机器（`127.0.0.1`）。需要一次刻意的更改才能更广泛地监听，并且你应该先设置密码。
- 对于你自己的设备，优先使用 [配对](/zh-cn/connect-devices/) 加 [Private Relay](/zh-cn/private-relay/) — 完全不对外暴露任何内容。
- 如果你需要一个公开 URL，相比向互联网开放一个端口，更推荐使用 [隧道](/zh-cn/tunnels/) 或专用网络（比如 VPN）。
- 如果你把 Varin 放在你自己的 HTTPS 服务器后面，请参阅 [反向代理](/zh-cn/reverse-proxy/)。

## Agent 工具权限

UI 密码和设备令牌控制主机访问，并不替代对话中的工具权限。出现权限请求时，先展开 **查看参数与作用范围**，再选择 **允许一次**、**一直允许** 或 **拒绝**。

**一直允许** 会在当前 Host 的用户配置中保存该工具的规则，适用于 **全部参数**，不只限于屏幕上的文件或命令；只有请求支持保存规则时才能选择。一次性操作请用 **允许一次**。输入框的权限控件显示实际生效模式，项目约束可能比全局选择更严格。

工作区快照或隔离工作副本不是操作系统沙箱。命令、外部服务访问和所选源主机仍需分别审查。
