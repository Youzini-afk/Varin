# 桌面浏览器

桌面应用可以在对话旁边显示浏览器页面。连接本地桌面 Host 时，从浏览器工具结果打开页面，或使用启用自动打开 URL 的 [项目动作](/zh-cn/project-actions/)。页面有独立地址栏、后退、前进和刷新控件。

## 检查与标注

先选择对话，再开启 **inspect** 并点击元素。Varin 会把元素信息和截图加入该对话的草稿；发送前请检查。检查元素会暂停 Agent 对该页面的控制。

## 接管与恢复

使用页面的控制按钮接管页面，或恢复 Agent 控制。关闭或隐藏面板不等于停止 Agent 的任务。此浏览器视图没有控制台筛选面板。
