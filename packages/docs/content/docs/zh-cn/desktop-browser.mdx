# 桌面浏览器

桌面应用在对话旁内置了浏览器视图，并与已配置的 CDP 端点以及通过 Chrome/Edge **Browser Connector** 共享的标签页并列管理（可在 **设置 → 浏览器** 中配置，详见 [Computer Use 与浏览器资源](/zh-cn/computer-use/)）。

连接本地桌面 Host 时，可从浏览器工具结果打开页面，或通过配置了自动打开 URL 的 [项目操作](/zh-cn/project-actions/) 启动页面。该视图提供独立的地址栏和导航控件。

## 检查与引用

选择一个对话，开启 **检查（Inspect）** 并点击页面元素。Varin 会将元素详情与截图加入你的草稿，方便你在发送前核对。检查元素会暂停 Agent 对该页面的写入操作。

## 接管与恢复

使用页面上的控制按钮即可从 Agent 手中接管控制权，或将控制权交还给 Agent。**查看浏览器** 仅切换你正在观察的页面；**让当前任务使用** 才会将该浏览器分配给当前对话。关闭或隐藏面板绝不会取消 Agent 正在执行的任务。
