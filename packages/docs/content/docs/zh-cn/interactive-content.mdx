# 交互内容与引用

Varin 中的对话不仅限于纯文本——你可以直接操作结构化选项、查看实时图表，并将精确段落或工具结果引用回下一条提示词中。

## 内联控件与 HTML 成品

- **内联控件**：助手可以直接在段落之间嵌入单选/多选项、表单、标签页、折叠面板，以及指向任务、文件或计划的实时链接。选择某个选项会在输入框中生成可编辑的草稿，而不会擅自替你发送。
- **交互式 HTML/JS**：复杂的可视化图表、计算器和对比界面会在与你当前 Varin 主题匹配的隔离沙箱中内联渲染。右键点击（触控设备点击菜单按钮）即可查看源码、展开到侧边栏、下载独立 HTML 副本、重置状态或引用当前视图。

## 精确引用与可拖拽标记

- **引用任意内容**：跨段落划选文本、右键点击特定区块（代码、表格、段落）、选择 **引用整轮对话**，或引用某次工具调用、图片及交互视图。
- **输入框标记**：引用与图片会以紧凑的 `[Quote N]` 和 `[Image N]` 胶囊形式呈现，你可以在消息中拖拽调整顺序、点击查看详情，或作为单次编辑整块撤销。从正文中删除标记后，附件仍保留在附件栏中；删除附件则会一并清除其所有标记。
- **图片标注**：点击草稿或聊天中的任意图片，即可绘制箭头、形状、文字、编号标注或不透明遮挡涂抹。遮挡会按原始分辨率直接烧录进发送的图片中，不会附带未遮挡的原图。
