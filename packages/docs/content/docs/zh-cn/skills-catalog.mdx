# 技能资源库

在 **设置 → 技能** 浏览原生资源库，并在用户或已信任的项目范围创建、复制技能。这里没有单独的在线技能市场。

原生资源配置可以引用已安装的技能目录。读取技能包不会下载或执行其中的代码。可执行的 Varin 扩展通过 **设置 → Varin Extensions** 单独管理。

使用前检查来源、有效性和只读状态。修改资源库后，在对话中刷新 **Instructions and skills**。已经受理的输入保留当时捕获的技能版本。

参阅 [技能](/zh-cn/skills/) 和 [命令](/zh-cn/commands/)。
