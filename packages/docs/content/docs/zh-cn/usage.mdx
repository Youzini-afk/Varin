# 本会话 Token 用量

在页头服务菜单中打开 **用量**，查看本会话按供应商和模型汇总的 Token 消耗。

- **输入**：未命中缓存的输入 Token。
- **输出**：生成的输出 Token。
- **缓存读取**：从供应商缓存复用的输入 Token。
- **缓存写入**：写入供应商缓存的输入 Token。

统计来自 Pi 的原生会话记录，包含压缩前的消息、未激活分支和已记录的辅助调用。缺少模型信息的消耗单独列为“未标明模型”。每个子会话各自统计。
