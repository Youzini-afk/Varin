# 用量与估算费用

打开 **设置 → 用量**，入口位于 **模型服务** 后面，查看当前连接的 Agent 主机上的用量。可以选择时间范围、切换费用与 Token、点击某一天，再按模型、渠道、用途或会话查看明细。日期按设备所在时区划分，包含夏令时变化；桌面端和网页端支持导出筛选后的 CSV。

合计涵盖已结算的原生会话请求、派发工作，以及标题、上下文整理、嵌入等辅助请求。删除会话后保留不含会话内容的统计。带日期的记录从安装这项功能后开始，更早的分支回执仍可按下方方式查看。

价格来自 models.dev 目录，也可在 **模型服务 → 模型 → 价格与计费** 中自定义，支持自定义渠道和长上下文分档价。每次请求保留当时的价格快照；原先未计价的请求可依现价估算，并单独标明。缺失价格或 Token 时会明确显示。订阅渠道的 API 标价折算、外部 Agent 自报用量分别展示，不进入按 Token 费用合计；本地模型没有 API 费用。估算以美元标价计算，不含折扣、中转加价和税费。

## 分支 token 用量

打开顶部服务菜单中的 **Usage**，查看当前 Thread 分支执行的工作，按模型、提供方、工作类型及计量状态分组。范围包括对话、上下文处理、规划、MCP sampling 和已记录的工具推理。

有数据时展示输入、输出、缓存读取、缓存写入及推理 token。服务商的统计口径可能重叠，不要把所有字段直接相加，也不要假设输入量一定排除缓存。

真实报告、估算、缺失和待返回用量保持区分，未知不是零；没有派发记录的请求单独标注。子 Thread 和独立辅助工作各有用量，不汇总所有分支，也不代表上下文占用率。这里不估算价格。

更新断开时，面板会标注最后一次已记录快照，点击 **Refresh** 重连。参阅 [上下文](/zh-cn/context/) 和 [持续目标](/zh-cn/session-goals/)。
