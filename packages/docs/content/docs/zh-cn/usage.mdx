# 分支 token 用量

打开顶部服务菜单中的 **Usage**，查看当前 Thread 分支执行的工作，按模型、提供方、工作类型及计量状态分组。范围包括对话、上下文处理、规划、MCP sampling 和已记录的工具推理。

有数据时展示输入、输出、缓存读取、缓存写入及推理 token。服务商的统计口径可能重叠，不要把所有字段直接相加，也不要假设输入量一定排除缓存。

真实报告、估算、缺失和待返回用量保持区分，未知不是零；没有派发记录的请求单独标注。子 Thread 和独立辅助工作各有用量，不汇总所有分支，也不代表上下文占用率。这里不估算价格。

更新断开时，面板会标注最后一次已记录快照，点击 **Refresh** 重连。参阅 [上下文](/zh-cn/context/) 和 [持续目标](/zh-cn/session-goals/)。
