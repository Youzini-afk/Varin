# 命令

**设置 → 命令** 列出当前资源库中有效且启用的技能、说明和文件路径。在消息开头输入 `/skill:name`，再用空格分隔后续要求，即可显式调用。

也可以展开对话中的 **Instructions and skills**，点击 **Add /skill:name to draft**。这只向草稿插入命令，不会发送消息。名称包含空格的技能不能使用此语法。

对话使用已捕获的技能版本。修改资源库后，点击 **Refresh instructions and skills** 准备新的上下文快照。进行中的请求和已受理的技能输入保留原始材料。设置页展示的是资源库，不代表旧对话已经更新。

资源编辑见 [技能](/zh-cn/skills/)。工作台快捷键另行配置。
