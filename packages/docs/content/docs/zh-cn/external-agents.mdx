# 外部 Agent

Varin 可以直接在你的工作区中运行外部 CLI 和 SDK Agent——包括 **Codex**、**Claude Code**、**Pi**，以及兼容 **ACP** 的工具（如 OpenCode、Gemini CLI、Cursor Agent、Cline、Kiro CLI 等）——同时保留它们各自的账号、模型与工具。

## 启用并连接外部 Agent

1. 打开 **设置 → 外部 Agent**，选择要运行该 Agent 的 Host（本机或已连接的远程 Host）。
2. 启用自动检测到的程序，或点击 **添加 Agent** 从目录中选择，或配置自定义 ACP 命令。
3. 对于支持托管安装的产品（npm 包或官方 ACP 发行包），可直接安装到 Varin 的私有 Host 目录中，无需修改你的全局环境。
4. 在目标设备上使用该外部程序自带的登录命令完成登录；Varin 绝不会存储或修改外部 Agent 的凭据。

## 直接对话与委派

- **直接对话**：在新建对话的输入框中选择已启用的外部 Agent。后端会在你开始输入或打开其模型/模式选择器时按需惰性启动，并在发出第一条消息后锁定。
- **按轮次调整选项**：在输入框工具栏中直接选择模型、思考级别、模式以及（针对 Codex 的）原生权限档位。
- **委派任务**：直接让 Varin 或主导 Agent 将工作交办给外部 Agent（例如“让 Codex 修复这个问题”），无需先创建预设。外部任务会出现在同一工作概览与协作面板中，支持文件/图片附件，也可使用隔离工作区。
- **重连与继续**：如果连接在轮次中途断开，点击 **重连** 可恢复观察，而点击 **继续** 则用于显式确认恢复并发送排队的后续消息，不会在结果不确定时静默重放中断的轮次。
