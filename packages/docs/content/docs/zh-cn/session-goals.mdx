# 持续目标

持续目标属于一个 Thread 分支，用于继续其最近一次运行。普通消息不会自动创建目标。

1. 先发送消息以创建工作。
2. 在 **Continuing goals** 中点击 **Create goal**。
3. 填写完整明确的目标及可选的输出 token 预算，点击 **Start goal**。

每个分支只能有一个未结束目标，最近一次运行也可以已经结束。普通最终回复仅结束当前运行；Agent 可通过 `goal_report` 明确报告目标完成或受阻。面板展示实际状态和阻塞原因。

可编辑、暂停、恢复、完成或取消目标。这些操作改变后续授权；已发出的请求和独立进程仍需等待真实结果。**Stop run** 也会暂停对应目标；策略暂停仍需单独恢复。已完成或取消的目标需要新建目标才能继续授权工作。

预算在后续派发前检查服务商报告的输出量。留空表示不限额，零表示不能继续派发输出；进行中的工作可能超额。估算、缺失和待返回用量分别展示。有预算时，已结束推理的用量不完整会阻止进一步推理。输入、缓存和推理字段可能重叠，不应直接相加。

Application Host 必须保持运行。定时工作见 [计划任务与后续任务](/zh-cn/scheduled-tasks/)。
