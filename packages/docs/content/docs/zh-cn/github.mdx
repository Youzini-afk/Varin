# GitHub Issue 与 PR

连接 GitHub 后可在 Varin 管理 PR。需要 Agent 处理 issue 或 PR 时，将相关上下文加入原生对话，并明确选择工作区来源。

## 连接 GitHub

1. 打开 **Settings → Git**。
2. 在 GitHub 下，选择 **Connect**。Varin 会显示一个链接和一个短码。
3. 打开链接，输入短码并批准。

连接后，你的账号会显示在 GitHub 部分下。你可以连接多个账号并在它们之间切换，或随时断开连接。

## 打开并管理拉取请求

在 [git 视图](/zh-cn/git/) 的 **PR** 标签页中，你可以创建拉取请求、更新它、将草稿标记为就绪或合并它。Varin 可以从你的变更生成 PR 标题和描述。
