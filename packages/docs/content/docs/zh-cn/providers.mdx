# 模型渠道

打开 **设置 → 模型渠道**，新增渠道，选择类型和端点，再选择该类型支持的认证方式。可用方式包括保存 API 密钥、登录、显式环境变量、受支持的云身份或匿名访问，具体以渠道为准。

按 ID 添加模型，或在支持发现的已保存渠道中获取候选模型。检查并保存所需模型；发现操作本身不会修改目录。启用渠道、模型及所需操作（如聊天），然后在对话输入区选择渠道和模型。

Application Host 管理渠道配置和模型账号。凭据与模型元数据分开保存，不进入对话历史。凭据缺失或撤销不会自动切换到其他账号。普通配置修改影响后续准备，已受理工作保留原来的选择。

常驻指令见 [Agent 记忆与系统提示词](/zh-cn/agent-personalization/)，附加工具见 [MCP](/zh-cn/mcp/)。模型可用不代表获得文件或工具权限。
