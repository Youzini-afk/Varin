# 快速开始

1. 按安装指南准备 Node.js、Bun 与 Rust，在源码目录运行 `bun install --frozen-lockfile` 和 `bun run dev`。
2. 打开终端输出的 Vite URL；桌面端使用 `bun run electron:dev`。
3. 在“设置 → 模型渠道”连接模型渠道并选择模型。
4. 创建对话。每个对话都是拥有独立分支和历史的原生 Thread。
5. 需要文件操作时，展开 Workspace，选择来源 Host、文件夹和访问模式并准备来源；纯聊天无需来源。
6. 输入消息并发送，可附加图片或 PDF，在对话内查看工具活动。

手机可与运行中的 Host 配对。跨网络连接需要配置且可用的中继，或你自己的安全远程访问通道。对外可访问的 Host 应设置强 UI 密码。
