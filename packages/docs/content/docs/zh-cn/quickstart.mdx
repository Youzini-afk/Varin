# 快速开始

1. [安装](/zh-cn/install/)并打开桌面应用（或在同一页面按指引通过 Docker 自托管 / 从源码构建）。
2. 打开 **设置 → 模型服务**，添加模型渠道（API 密钥、云端凭据，或 Ollama / LM Studio 等本地服务），并启用一个对话模型。
3. 直接在 **Varin** 助手视图开始对话；需要直接控制任务或编辑文件时，可从顶部切换器切到 **Workbench** 或 **IDE**。
4. 需要处理文件时，打开输入框下方的文件夹选择器，选择本地目录、已注册项目或已连接的远程设备。纯聊天无需工作区。
5. 发送消息。你可以粘贴或拖放图片、PDF 或任意文件，将具体片段引用回草稿，并在对话内实时查看工具活动或委派出去的协作成员。

要在手机或另一台电脑上使用 Varin，请将设备与运行中的 Host 配对，并为任何暴露在网络中的 Host 设置强 UI 密码。
