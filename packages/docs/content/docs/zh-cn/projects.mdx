# 项目

项目是已连接 Host 上的文件夹。通过项目选择器或文件夹浏览器打开；在“设置 → 项目”中管理名称、颜色、图标和项目操作。当前浏览的项目与对话执行使用的来源彼此独立：切换项目不会改变正在运行的 Thread 的来源。

在对话中展开 **Workspace**，选择来源 Host 和文件夹，再选择：
- **只读文件快照**：固定文件，仅供读取、列举和搜索
- **隔离的可编辑副本**：捕获工作副本以修改文件和执行命令；修改不会自动复制回原目录
- **实时工作区**：使用实际目录中的已保存文件和命令，修改立即作用于该目录

点击 **Prepare workspace**，检查结果后再发送。快照模式可包含同一 Host 上本窗口的编辑器草稿；实时工作区只使用已保存文件。远程路径属于所选来源 Host。可编辑副本和实时命令都不是安全沙箱。
