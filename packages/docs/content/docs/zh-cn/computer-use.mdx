# Computer Use 与浏览器资源

Varin 将 **桌面控制** 和 **浏览器访问** 与你的文件工作区相互分离，让你可以精确指定每项任务使用哪台机器或哪个浏览器。

## Computer Use（桌面控制）

- Agent 可以观察窗口、查询原生 UI 控件（Windows UIA、macOS Accessibility、Linux X11 AT-SPI）、截屏、发送键盘/鼠标输入以及等待 UI 条件满足。
- 每台物理桌面同一时间仅允许 **一个活跃控制者**，同时允许多个只读观察者。
- 打开对话旁的 **电脑** 标签页，即可实时观看操作过程、立即接管控制权，或在准备好后交还控制权。关闭观察视图只会停止观察——不会取消任务。
- 通过 [工作连接](/zh-cn/connect-devices/) 接入的远程桌面会在目标设备上运行各自的本地平台驱动。

## 浏览器资源

打开 **设置 → 浏览器**，管理当前 Host 或已连接 Host 上的可用浏览器：

- **内置桌面浏览器**：内嵌于 Varin 桌面应用中（详见 [桌面浏览器](/zh-cn/desktop-browser/)）。
- **CDP 连接**：通过 Chrome DevTools Protocol 连接到现有的 Chromium 实例，可选配置请求头与文件交接目录。
- **日常使用的 Chrome / Edge**：在设置中下载按需启用的 **Browser Connector** 扩展，将其与你的 Host 配对，再明确共享希望 Varin 查看或操作的标签页。

在浏览器视图中，**查看浏览器** 仅切换你当前观察的对象；**让当前任务使用** 才会将该浏览器分配给当前对话。你可以随时在工作台或浏览器扩展中暂停 Agent 写入并接管共享标签页。
