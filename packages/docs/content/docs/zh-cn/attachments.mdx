# 附件、图片与 PDF

使用输入框的附件菜单、从剪贴板粘贴，或直接将文件拖放到对话中。

- **任意文件**：Varin 会将上传的文件保存为不可变、版本锁定的附件，不设格式白名单。Agent 可以直接读取这些文件，或将完全一致的原始版本转发给委派的协作成员，而无需把文件内容复制到提示词中。
- **图片与标注**：支持视觉的模型会原生接收附加的图片（如果当前模型不支持图片输入，Varin 会在发送前发出提醒，让你切换模型或将图片作为可读文件发送）。发送前点击任意已附加的图片，即可用箭头、形状、文字、编号标注或不透明遮挡进行批注。
- **原始 PDF 与 Office 文件**：上传的 PDF 和 Office 文档会完整保留原始字节，Agent 可以在不替换原文件的前提下检查文本、结构或渲染页面。
- **幂等送达**：发送、排队和重试都会携带完全一致的冻结附件快照；磁盘上后续的文件修改绝不会影响已提交的输入。如果送达状态不确定，请使用 **重试送达（Retry delivery）**，不要重新上传。
