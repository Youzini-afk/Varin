# 图片与 PDF

使用对话输入框中的 **Attach images** 或 **Attach PDFs**，也可粘贴或拖放受支持的文件。图片需要支持图像输入的模型。

上传 PDF 会将原始文件保留为 Thread 材料。点击附件标签可阅读、翻页；模型支持图像输入时，可选取区域加入草稿。阅读器可读取原件，提取后的表示不会替换原始 PDF。

发送、三种排队模式和子对话续接都会携带所选材料快照。之后文件变化不会改变该次输入。送达未确认时，用 **Retry delivery** 重试原请求，不要重新上传。原结果确定前不能修改待确认附件。切换 Host、Thread 或分支不会将待处理上传转移到新选择。
