# MCP Servers

在需要拥有连接的 Host 上打开“设置 → MCP”。选择配置来源并添加服务器：本地进程填写命令、参数与环境变量，远程服务填写 URL 和请求头。仅使用你了解其代码和数据访问范围的服务器。

保存配置文档，再连接或重新连接，并检查状态与工具数量。支持授权的服务器可登录。全局与项目配置显示实际路径；项目配置需要项目信任。可编辑结构化字段或原始配置。

保存配置与活动 Thread 已捕获的资源是两回事。需要新工具时，检查对话资源并显式刷新快照。权限、问题与采样请求会显示在原生对话中。
