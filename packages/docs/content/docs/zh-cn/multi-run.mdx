# Multi-run

Multi-run 为每个所选模型创建原生 Thread。选择项目、命名批次、添加提示词与模型组，然后启动；没有固定的五模型上限。

启用隔离后，每次运行使用独立 Git worktree 和分支。关闭隔离时，各次运行共享项目的实时目录，可能修改同一文件。启动前检查初始化命令。

逐项查看状态。启动失败或结果未确认时，已创建的 Thread 和 worktree 会保留。使用不变的选项重试以核对原请求。worktree 创建未确认时，先检查原 Host 上的 Git 状态。**Stop launching** 仅停止后续启动，已受理的工作继续运行。
