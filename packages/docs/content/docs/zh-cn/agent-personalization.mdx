# Agent 记忆与系统提示词

在 **设置 → 记忆** 中新增、编辑、删除笔记，或在全局、项目、对话范围之间移动。对话中的记忆面板使用同一编辑器，Agent 的 `memory` 工具也使用同一组分范围笔记。子任务不会自动继承父对话的笔记。

保存后的笔记立即可读。活跃对话接收新笔记事实，但不会改写已冻结的系统记忆前缀；成功应用上下文摘要时才推进该快照。

在 **设置 → 系统提示词** 编辑指令段落。信息密度、语言风格和自主程度选项插入可继续编辑的文字。全局、项目、对话覆盖依次生效；**恢复默认** 仅清除当前范围的修改。已保存的配置在安全的请求边界生效，已准备请求保持不变。

预览展示组合后的指令和记忆快照。最近请求视图可用时展示已准备的系统文本，不代表服务商已接收。文件指令和技能使用各自捕获的资源，修改后应点击 **Refresh instructions and skills**。

Bot 的指令和记忆仍在 **Varin Bot** 单独管理。普通 Agent 的笔记和提示词覆盖不会注入 Bot。
