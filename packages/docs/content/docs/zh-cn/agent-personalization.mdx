# Agent 记忆与系统提示词

在 **设置 → 记忆** 中新增、编辑、删除记忆，或调整其范围：全局、项目、会话。
记忆修改立即保存。新会话加载适用的记忆；已开始的会话通过工具结果或变更消息接收更新，
系统提示词中的记忆快照在上下文压缩成功提交时更新。这样可以减少执行期间记忆变更对输入前缀的扰动。
Agent 的 `memory` 工具读写同一组内容；
普通 Agent 不再使用 `recall` 检索长期记忆。

在 **设置 → 系统提示词** 顶部文本框中编辑官方内置提示词。下方的信息密度、语言风格、
自主程度选项会插入可继续编辑的文字，并保留其他手写内容。全局设置适用于普通 Agent；
项目和会话设置只覆盖各自修改的段落。**恢复默认** 只清除当前范围的修改。
保存后从下一次模型请求生效，进行中的会话也会使用新内容。

页面展示完整预览，包括项目指令、技能和当前会话的记忆快照；保存后的新记忆通过会话尾部接续，
在压缩提交后合并到该快照。重启和切换会话分支会恢复对应的快照。
最近一次请求区域展示运行时实际准备
发送的系统文本。后者不会跨运行时重启保存，也不代表服务商已接收请求。
动态内容继续由对应文件或记忆条目管理。原生指令文件保持 Pi 的加载行为，可直接编辑文件。

Bot 的指令和长期记忆仍在 **Varin Bot** 中管理，普通 Agent 的偏好和记忆不会注入 Bot。
魔法提示词与命令模板功能已移除，Git、审阅和计划操作仍然可用。
