# Agent 工具

原生对话依据已受理的模型、来源、角色和权限提供工具。直接描述需要的结果；每项操作仍须通过自身的授权检查。

- `dispatch`、`child_status`、`child_report` 和 `wait_child` 协调委派任务。
- `threads` 和 `read_thread` 查看当前任务家族中的对话，不授予全部对话或其他任务文件的访问权。
- `follow_up` 管理时间或观察条件触发的后续指令。
- `goal_report` 明确报告已建立的持续目标完成或受阻。
- `resource_read` 读取已准入指令与技能；`memory` 管理获准范围内的笔记。

工具可见不等于拥有文件写入、进程或外部服务权限。只读对话访问不会启动目标模型或授予执行控制。受理工作不等于工作完成，请查看原始结果和状态。
