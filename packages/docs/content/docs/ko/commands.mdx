# 명령

**설정 → 명령**에는 선택한 라이브러리의 활성화된 유효한 스킬, 설명, 파일 경로가 나옵니다. 메시지 맨 앞에 `/skill:name`을 쓰고 공백 뒤에 지시를 입력하세요.

대화의 **Instructions and skills**에서 **Add /skill:name to draft**를 눌러 삽입할 수도 있습니다. 삽입만으로 메시지가 전송되지는 않습니다. 공백이 있는 이름은 이 구문으로 호출할 수 없습니다.

대화는 캡처된 스킬 버전을 사용합니다. 라이브러리를 편집한 뒤 **Refresh instructions and skills**로 새 스냅샷을 준비하세요. 진행 중인 요청과 이미 수락된 입력은 원래 자료를 유지합니다. 설정 목록이 갱신되어도 기존 대화가 갱신된 것은 아닙니다.

편집은 [스킬](/ko/skills/)을 참고하세요. 워크벤치 단축키는 별도로 설정합니다.
