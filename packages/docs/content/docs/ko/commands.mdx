# 명령

**Settings → Commands**에서 확장 기능과 스킬이 등록한 명령을 확인합니다. 목록에는 설명, 출처, 범위 및 호출 방법이 표시되며 호출 텍스트를 복사할 수 있습니다.

채팅 메시지의 첫 글자로 `/`를 입력하고 명령을 선택합니다. 인수가 필요하면 이름 뒤에 입력합니다. 확장 명령은 해당 플러그인이 처리하고, `/skill:name`은 해당 스킬의 지침을 불러옵니다.

사용 가능한 명령은 선택한 런타임, 작업 공간 및 로드된 리소스에 따라 달라집니다. **Settings → Skills**와 **Settings → Pi Plugins**에서 출처를 관리합니다.
