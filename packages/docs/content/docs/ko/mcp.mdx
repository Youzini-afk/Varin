# MCP 서버

연결을 관리할 Host에서 **설정 → MCP**를 여세요. 설정 소스를 선택하고 서버를 추가합니다. 로컬 프로세스에는 명령·인수·환경 변수를, 원격 서비스에는 URL·헤더를 입력합니다. 코드와 데이터 접근 범위를 이해하는 서버만 사용하세요.

문서를 저장한 뒤 Connect 또는 Reconnect를 누르고 상태와 도구 수를 확인하세요. 인증을 지원하면 로그인할 수 있습니다. 전역·프로젝트 소스의 실제 경로가 표시되며 프로젝트 설정에는 프로젝트 신뢰가 필요합니다. 구조화 필드와 원본 설정을 편집할 수 있습니다.

저장해도 활성 Thread가 이미 캡처한 리소스는 바뀌지 않습니다. 대화의 리소스를 확인하고 스냅샷을 명시적으로 새로고침하세요. 권한·질문·샘플링 요청은 네이티브 대화에 표시됩니다.
