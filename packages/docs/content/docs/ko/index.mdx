# Varin 문서

Varin은 코딩, 연구, 프로젝트를 위한 독립적인 작업 공간입니다. 네이티브 Rust Agent 런타임은 대화를 Thread와 분기로 저장하고 영구 Catalog에서 관리합니다. Application Host는 데스크톱, 웹, 모바일 인터페이스에 모델, 리소스, MCP 서비스를 연결합니다.

이 문서를 사용해:

- 작업 방식에 맞는 앱을 설치하세요
- 로컬 또는 원격 사용을 위해 Varin를 여세요
- 외관을 맞춤 설정하고 흔한 문제를 해결하세요

## Varin는 무엇을 위한 것인가

Varin은 코딩, 연구 및 기타 프로젝트 작업에서 관제 센터가 도움이 되는 일을 위한 것입니다. 세션 분기, 결과 검토, 터미널 관리, 도구 진행 상황 관찰, 프로젝트 액션 실행, 그리고 에이전트가 작업하는 동안 전체 보드를 한눈에 유지할 수 있습니다.
