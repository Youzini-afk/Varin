# Varin 사용 가이드

Varin은 AI 에이전트를 위한 오픈 소스 작업 공간입니다. 모델과 도구를 한곳에 모아 일상 업무, 코딩, 연구에 사용할 수 있습니다. 데스크톱과 웹 앱이 작업 공간을 제공하며, 모바일 클라이언트는 사용자의 Host에 연결합니다.
