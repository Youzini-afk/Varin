# 환경 변수

Varin는 시작 시 이 환경 변수를 읽습니다. 시작 서비스의 경우 `varin startup enable`이 기본적으로 현재 환경을 스냅샷하므로, 서비스가 사용하길 원하는 변수를 바꾼 뒤에는 다시 실행하세요.

Varin는 Pi 런타임을 내장합니다. 별도의 OpenCode 서버도 없고 `OPENCODE_*` 통합 변수도 없습니다.

## Varin 서버

### `VARIN_HOST`

Varin 웹 서버의 바인드 주소입니다. 다른 컴퓨터에서 접근하려면 `0.0.0.0`을 사용하세요.

### `VARIN_UI_PASSWORD`

브라우저 UI 비밀번호입니다. localhost 바깥에 바인드하거나, 터널을 쓰거나, 리버스 프록시 뒤에서 실행할 때 사용하세요.

### `VARIN_API_ONLY`

`true` 또는 `1`로 설정하면 Varin를 헤드리스 모드로 시작합니다. API 경로는 데스크톱과 모바일 클라이언트에 그대로 제공되지만, 브라우저 UI는 제공되지 않습니다.

### `VARIN_DATA_DIR`

Varin 데이터 디렉터리를 변경합니다. 기본값은 Linux의 `$XDG_CONFIG_HOME/varin`(또는 `~/.config/varin`), macOS의 `~/Library/Application Support/Varin`, Windows의 `%APPDATA%/Varin`입니다.

### `VARIN_COMPRESS_API`

API 응답 압축을 제어합니다. 강제로 켜려면 `true` 또는 `1`, 강제로 끄려면 `false` 또는 `0`을 사용하세요.

### `VARIN_SKIP_API_COMPRESSION`

`true` 또는 `1`로 설정하면 API 응답 압축을 비활성화합니다. 이 값이 `VARIN_COMPRESS_API`보다 우선합니다.

### `VARIN_VERBOSE_REQUEST_LOGS`

`true` 또는 `1`로 설정하면 자세한 HTTP 요청 로그를 켭니다.

### `VARIN_UPDATE_API_URL`

업데이트 확인 API 엔드포인트를 재정의합니다. 대부분의 사용자는 설정하지 않은 채로 두세요.

### `VARIN_PACKAGE_MANAGER`

자동 감지가 잘못되었을 때 업데이트 작업이 사용하는 패키지 매니저를 강제합니다.

## 터미널과 Git

### `VARIN_TERMINAL_SHELL`

Varin 터미널 세션에 사용하는 셸 실행 파일입니다.

### `VARIN_GIT_BINARY`

Varin Git 기능이 사용하는 Git 실행 파일입니다.

### `GIT_BINARY`

대체 Git 실행 파일 재정의입니다. Varin 전용 구성에는 `VARIN_GIT_BINARY`를 우선하세요.

## 음성과 터널

### `OPENAI_API_KEY`

OpenAI 호환 서비스를 호출하는 Varin 음성 기능이 사용하는 API 키입니다.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

`true` 또는 `1`로 설정하면 음성 기능에서 원격 OpenAI 호환 base URL을 허용합니다.

### `NGROK_AUTHTOKEN`

Varin 터널 명령이 사용하는 ngrok auth token입니다. `ngrok config add-authtoken <token>`으로 ngrok를 구성할 수도 있습니다.

## 런타임 도우미

### `BUN_BINARY`

데몬 프로세스를 띄울 때 Varin가 사용해야 하는 Bun 실행 파일입니다.

### `BUN_INSTALL`

Bun 설치 루트입니다. Varin는 데몬 시작과 업데이트를 위해 `bin/bun`을 찾는 데 사용합니다.
