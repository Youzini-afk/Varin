# Agent 메모리와 지침

**설정 → 메모리**에서 메모를 만들고 수정·삭제하거나 전역, 프로젝트, 대화 범위 사이로 옮깁니다. 대화 메모리 패널과 `memory` 도구도 같은 메모를 사용합니다. 하위 작업은 상위 대화 메모를 자동 상속하지 않습니다.

저장된 메모는 즉시 사용할 수 있습니다. 활성 대화는 새로운 사실을 받지만 고정된 시스템 메모리 접두부를 다시 쓰지 않습니다. 컨텍스트 요약이 성공적으로 적용되면 스냅샷이 갱신됩니다.

**설정 → 시스템 프롬프트**에서 지침의 절을 편집하세요. 밀도, 문체, 자율성 설정은 편집 가능한 텍스트를 삽입합니다. 전역, 프로젝트, 대화 순으로 덮어쓰기가 적용됩니다. **Restore defaults**는 선택한 범위의 변경만 제거합니다. 변경 사항은 안전한 요청 경계에서 반영하며 이미 준비된 요청은 그대로 유지합니다.

미리 보기는 조합된 지침과 캡처된 메모리를 표시합니다. 최근 요청 보기가 있어도 제공자가 받았다는 증거는 아닙니다. 지침 파일과 스킬을 수정한 뒤에는 **Refresh instructions and skills**를 사용하세요.

Bot의 지침과 메모리는 **Varin Bot**에서 별도로 관리하며 일반 Agent의 메모나 프롬프트 변경을 주입하지 않습니다.
