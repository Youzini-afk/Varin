# 원격 접속

휴대폰이나 다른 컴퓨터에서 Varin에 접근할 수 없을 때, 해결 방법은 연결 방식에 따라 다릅니다.

## 먼저 기본 사항 확인

- 같은 컴퓨터에서 `http://localhost:3000`을 먼저 엽니다. 이것이 실패하면 원격 문제가 아닙니다. [문제 해결](/ko/troubleshooting/)을 참고하세요
- `varin status`로 서버가 실행 중인지 확인합니다

## 페어링된 기기가 연결되지 않음

- QR 코드/페어링 링크는 **일회용**입니다. 이미 스캔되었거나 만료되었다면 **기기 추가**에서 새로 만드세요
- 기기를 **집 네트워크 전용**으로 페어링했다면 그 네트워크 밖에서는 연결할 수 없습니다. **어디서나**로 다시 페어링하세요
- **어디서나**에는 릴레이가 필요합니다. **기기 추가**에서 회색으로 비활성화되어 있다면 서버에 `VARIN_RELAY_URL`이 없는 것입니다. 설정되어 있다면 지정된 릴레이에 서버에서 접근할 수 있는지 확인하세요
- 기기가 **해지**되었다면 토큰은 영구히 사라진 것입니다. 새 QR 코드로 다시 페어링하세요

이 연결의 작동 방식은 [기기 연결](/ko/connect-devices/)과 [Private Relay](/ko/private-relay/)를 참고하세요.

## 터널 링크가 작동하지 않음

- `varin tunnel status --all`을 실행합니다
- 같은 인스턴스와 포트에서 터널을 재시작합니다
- 이전 링크가 이미 사용되었다면 연결 링크를 다시 생성합니다

전체 설정은 [터널](/ko/tunnels/)를 참고하세요.

## 원격 인스턴스가 연결되지 않음(데스크톱)

[원격 인스턴스](/ko/remote-instances/)가 멈추면 Varin가 실패한 단계를 알려줍니다.

- **auth** — SSH 또는 UI 비밀번호가 거부됨. 다시 입력하세요
- **install / start** — Varin가 원격 컴퓨터에서 서버를 설정하거나 시작하지 못함. 그 컴퓨터의 요구 사항을 확인하세요
- **forwarding** — 연결은 되었지만 포트가 도달하지 않음. 다른 로컬 포트를 시도하세요

## 자체 서버 뒤에 있음

Varin를 리버스 프록시 뒤에 두었는데 이상하게 로드되거나 연결되지 않으면 [리버스 프록시](/ko/reverse-proxy/)를 참고하세요.
