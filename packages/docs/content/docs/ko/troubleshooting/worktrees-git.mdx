# Worktree 및 Git

작업을 재시도하기 전에 원래 Host와 폴더를 확인하세요. 오류나 응답 유실 뒤에도 실제 worktree나 Thread가 남을 수 있습니다. 프로젝트의 Worktrees와 Git 상태를 확인하고, 별개 폴더 문제를 해결하려고 대화를 삭제하지 마세요.

폴더가 이동했다면 Git worktree 등록을 복구하세요. 끝나지 않은 merge, rebase, cherry-pick은 로컬 변경을 확인한 뒤 계속하거나 중단하세요. 이름이 이미 사용 중이면 기존 작업을 먼저 확인하세요.

커밋 메시지와 PR 설명 생성은 Host의 유틸리티 또는 기본 모델을 사용합니다. 채널, 모델, 인증 정보, 스테이징 파일이나 커밋 범위를 확인하세요. 활성 대화는 필요 없습니다. 이전 요청 결과가 불확실하면 새 요청 전에 확인하세요.
