# Multi-run

Multi-run은 선택한 모델마다 네이티브 Thread를 만듭니다. 프로젝트와 배치 이름을 정하고 프롬프트·모델 그룹을 추가해 시작하세요. 고정된 5개 모델 제한은 없습니다.

격리하면 실행마다 Git worktree와 브랜치를 만듭니다. 격리하지 않으면 프로젝트의 실제 폴더를 공유하므로 같은 파일을 수정할 수 있습니다. 시작 전 초기화 명령을 확인하세요.

각 시도의 상태를 확인하세요. 실패하거나 결과가 불확실해도 만든 Thread와 worktree는 보존됩니다. 원래 요청을 확인하려면 같은 선택으로 재시도하세요. Worktree 생성이 불확실하면 원래 Host에서 Git을 먼저 확인하세요. **Stop launching**은 이후 시작만 중단하며 이미 수락된 작업은 계속됩니다.
