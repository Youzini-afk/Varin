# 프로젝트

프로젝트는 연결된 Host의 폴더입니다. 프로젝트 선택기나 폴더 탐색기에서 열고, 설정 → 프로젝트에서 이름, 색상, 아이콘, 작업을 관리합니다. 탐색 중인 프로젝트와 대화의 실행 소스는 별개입니다. 프로젝트를 바꿔도 실행 중인 Thread의 소스는 바뀌지 않습니다.

대화에서 **Workspace**를 열어 소스 Host와 폴더를 고른 뒤 모드를 선택하세요.
- **Read-only file snapshot**: 고정된 파일을 읽고 나열하고 검색
- **Isolated editable copy**: 캡처한 복사본에서 편집 및 명령 실행. 변경 사항은 원본으로 자동 복사되지 않음
- **Live workspace**: 실제 폴더의 저장된 파일 사용. 편집이 즉시 반영됨

**Prepare workspace**를 누르고 결과를 확인한 뒤 전송하세요. 스냅샷에는 같은 Host에 있는 이 창의 편집기 초안을 포함할 수 있습니다. Live 모드는 저장된 파일만 사용합니다. 원격 경로는 선택한 소스 Host의 경로입니다. 편집 가능한 복사본과 명령은 보안 샌드박스가 아닙니다.
