# 알림

**설정 → Varin → 알림**에서 각 기기의 알림을 허용하세요. 네이티브 대화는 응답 완료, 실행 실패, 승인이나 답변 필요 시 알립니다. 완료 알림은 완료 설정을 따르며 주의가 필요한 요청은 별도로 처리합니다.

전달은 데스크톱, 웹·모바일 푸시 서비스와 시스템 권한에 따라 달라집니다. Host는 계속 실행 중이어야 합니다. 탐색을 지원하는 채널은 원래 Thread와 분기를 엽니다.

제목은 Thread 제목이며 없으면 “Varin”입니다. 본문은 에이전트 답변이 아닌 고정 상태 문구입니다. APNs도 같으므로 iPhone 잠금 화면에 대화 제목이 표시될 수 있습니다. 기존 편집 가능한 템플릿은 사용하지 않으며 앱 아이콘 배지 동기화는 구현되지 않았습니다.
