# 이미지와 PDF

대화 입력창의 **Attach images** 또는 **Attach PDFs**를 사용하세요. 지원되는 파일을 붙여 넣거나 끌어놓을 수도 있습니다. 이미지는 이미지 입력을 지원하는 모델이 필요합니다.

PDF는 원본 그대로 Thread 자료로 보관됩니다. 첨부 항목을 열어 페이지를 읽고, 이미지 입력이 지원되면 영역을 선택해 초안에 추가할 수 있습니다. 추출된 표현은 읽기 도구에서 사용할 수 있는 원본 PDF를 대체하지 않습니다.

전송, 세 가지 대기열 모드, 하위 대화 계속하기는 선택한 자료 스냅샷을 전달합니다. 이후 파일 변경은 그 입력에 반영되지 않습니다. 전달이 불확실하면 다시 업로드하지 말고 **Retry delivery**를 사용하세요. 원래 결과가 확인될 때까지 대기 중 첨부 파일은 변경할 수 없습니다. Host, Thread, 분기를 바꿔도 진행 중 업로드가 새 대상으로 옮겨지지 않습니다.
