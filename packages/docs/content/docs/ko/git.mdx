# Git 및 GitHub 워크플로

Varin에는 내장 git 보기가 있어 터미널로 전환하지 않고도 변경 사항을 검토하고, 커밋하고, 브랜치를 관리할 수 있습니다. 오른쪽 사이드바의 **Git** 탭에서 엽니다.

## 검토 및 커밋

git 보기는 변경 사항을 **staged**와 **unstaged**로 나눕니다.

- 파일의 **+**를 클릭해 스테이징하거나 **−**를 클릭해 스테이징을 해제합니다
- 그룹의 모든 항목을 한 번에 스테이징하거나 해제합니다
- 파일을 클릭해 diff를 봅니다

커밋 메시지를 직접 작성하거나 선택한 스테이징 변경으로 생성하세요. Host에 설정된 유틸리티 모델을 사용하며 없으면 기본 모델을 사용합니다. 대화를 열 필요는 없습니다. 커밋 전에 생성된 내용을 검토하세요.

## 브랜치와 히스토리

git 보기는 일상적인 나머지 git 작업도 다룹니다.

- 브랜치 생성, 전환, 이름 변경, 삭제
- push, pull, fetch
- 히스토리와 커밋별 diff 탐색
- 변경 사항 stash 및 복원

## 풀 리퀘스트

GitHub를 연결하면([GitHub 이슈 및 PR](/ko/github/) 참고) **PR** 탭에서 풀 리퀘스트를 열고, 업데이트하고, 준비 완료로 표시하거나 병합할 수 있습니다. 그리고 커밋 메시지와 같은 방식으로 제목과 설명을 생성할 수 있습니다.

## 충돌 가져오기

병합, 리베이스, 통합이 충돌하면 Varin가 무엇이 막혔는지 보여주고 해결하게 해줍니다. 에이전트에게 넘기는 것도 포함됩니다.
