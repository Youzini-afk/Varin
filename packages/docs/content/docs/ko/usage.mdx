# 이 대화의 토큰 사용량

헤더 서비스 메뉴의 **사용량**에서 현재 대화의 토큰 소비를 제공자와 모델별로 확인할 수 있습니다.

- **입력**: 캐시를 사용하지 않은 입력 토큰.
- **출력**: 생성된 토큰.
- **캐시 읽기**: 제공자 캐시에서 재사용된 입력 토큰.
- **캐시 쓰기**: 캐시에 기록된 입력 토큰.

통계는 Pi 세션 기록에서 가져오며 압축 이전 메시지, 비활성 분기 및 기록된 보조 호출을 포함합니다. 모델 정보가 없는 사용량은 별도로 표시됩니다. 각 하위 대화는 자체 통계를 가집니다.
