# 브랜치 토큰 사용량

헤더 서비스 메뉴에서 **Usage**를 여세요. 선택한 브랜치에서 실행한 대화, 컨텍스트 처리, 계획, MCP sampling, 기록된 도구 추론을 모델, 제공자, 작업 유형, 측정 상태별로 표시합니다.

보고된 입력, 출력, 캐시 읽기·쓰기, 추론 토큰이 나옵니다. 제공자의 정의가 겹칠 수 있으므로 전부 합산하거나 입력이 캐시를 제외한다고 가정하지 마세요.

실제 보고, 추정, 누락, 대기 상태를 구분합니다. 알 수 없음은 0이 아닙니다. 전송 기록이 없는 요청도 표시합니다. 하위 Thread와 독립적인 보조 작업은 별도 사용량을 가집니다. 전체 브랜치 합계나 컨텍스트 사용률이 아니며, 가격도 추정하지 않습니다.

연결이 끊기면 마지막 기록된 스냅샷임을 표시합니다. **Refresh**로 다시 연결하세요. [컨텍스트](/ko/context/), [지속 목표](/ko/session-goals/)도 참고하세요.
