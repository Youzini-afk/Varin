# GitHub 이슈 및 PR

GitHub를 연결해 Varin에서 PR을 관리하세요. 이슈나 PR 작업을 에이전트에게 요청하려면 네이티브 대화에 관련 내용을 넣고 작업 공간 소스를 명시적으로 선택하세요.

## GitHub 연결하기

1. **Settings → Git**를 엽니다.
2. GitHub 아래에서 **Connect**를 선택합니다. Varin가 링크와 짧은 코드를 표시합니다.
3. 링크를 열고 코드를 입력한 뒤 승인합니다.

연결되면 GitHub 섹션 아래에 계정이 표시됩니다. 계정을 여러 개 연결해 전환할 수 있으며, 언제든 연결을 해제할 수 있습니다.

## 풀 리퀘스트 열기 및 관리

[git 보기](/ko/git/)의 **PR** 탭에서 풀 리퀘스트를 만들고, 업데이트하고, 초안을 준비 완료로 표시하거나 병합할 수 있습니다. Varin는 변경 사항에서 PR 제목과 설명을 생성할 수 있습니다.
