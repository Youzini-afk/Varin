# 모델 채널

**설정 → 모델 채널**에서 채널을 추가하고 유형, 엔드포인트, 지원하는 인증 방식을 선택하세요. 채널에 따라 저장된 API 키, 로그인, 명시적인 환경 변수, 지원되는 클라우드 ID 또는 익명 접근을 사용할 수 있습니다.

ID로 모델을 추가하거나 지원되는 저장된 채널에서 후보를 검색하세요. 후보를 확인한 뒤 저장해야 합니다. 검색만으로 카탈로그는 바뀌지 않습니다. 채널, 모델, 채팅 같은 작업을 활성화한 뒤 대화 입력 영역에서 모델을 선택하세요.

Application Host가 설정과 계정을 관리합니다. 자격 증명은 메타데이터와 별도로 저장되며 대화 기록에 포함되지 않습니다. 인증 정보가 없거나 철회되어도 다른 계정으로 자동 전환하지 않습니다. 변경은 이후 준비에 적용되며 수락된 작업은 원래 선택을 유지합니다.

[메모리와 지침](/ko/agent-personalization/), [MCP](/ko/mcp/)도 참고하세요. 모델 접근이 파일이나 도구 권한을 부여하지는 않습니다.
