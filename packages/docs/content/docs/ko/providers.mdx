# 공급자, 모델, 에이전트

Varin가 무엇이든 하려면 연결된 AI 공급자가 하나 이상 필요합니다. 이 페이지는 공급자 연결, 모델 선택, 에이전트 맞춤 설정을 다룹니다.

## 공급자 연결하기

1. **Settings → Providers**를 엽니다.
2. **Add provider** 메뉴를 열고 아직 연결되지 않은 공급자를 고릅니다.
3. 공급자에 따라 다음 두 가지 중 하나로 로그인합니다.
   - **API key** — 키를 붙여넣고 저장합니다.
   - **Sign-in (device flow)** — Varin가 링크와 짧은 코드를 보여 줍니다. 링크를 열고 코드를 입력한 뒤 승인하세요. 연결 완료는 Varin가 처리합니다.

공급자가 연결됨으로 표시되면 해당 모델이 채팅에서 사용할 수 있게 됩니다.

연결을 끊으려면 해당 공급자를 열고 로그인을 제거하세요.

## 모델 고르기

모델은 작업 중인 곳에서 고릅니다.

- 채팅에서는 메시지 바의 모델 선택기로 해당 세션의 공급자와 모델을 설정합니다
- 에이전트마다 기본 모델을 설정합니다(아래)

## 에이전트 설정하기

에이전트는 이름 있는 구성입니다. 모델, 성격, 허용된 작업입니다.

1. **Settings → Agents**를 엽니다.
2. 에이전트를 고르거나 새로 만듭니다.
3. 다음 중 원하는 항목을 편집합니다.
   - **description** — 에이전트의 용도
   - **model** — 기본 모델
   - **temperature** — 답변의 창의성
   - **prompt** — 항상 따르는 고정 지시
   - **tool rules** — 사용할 수 있는 도구

## 로그인 정보가 저장되는 곳

공급자 로그인은 렌더러가 아니라 Pi의 `AuthStorage`가 저장합니다. API 키와 OAuth 토큰은 UI로 보내는 공급자 메타데이터에 절대 나타나지 않습니다. 사용자, 프로젝트, operator `models.json` 레이어는 각각의 네이티브 파일에 그대로 있습니다.

같은 공급자를 여러 곳에 설정하면 가장 구체적인 설정이 이깁니다. 신뢰된 프로젝트 레이어가 개인 설정을 덮어씁니다.
