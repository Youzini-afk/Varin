# 빠른 시작

1. 설치 안내에 따라 Node.js, Bun, Rust를 준비하고 저장소에서 `bun install --frozen-lockfile`, `bun run dev`를 실행하세요.
2. 출력된 Vite URL을 여세요. 데스크톱은 `bun run electron:dev`를 사용합니다.
3. 설정 → 모델 채널에서 모델 채널을 연결하고 모델을 선택하세요.
4. 대화를 만드세요. 고유한 분기와 기록을 가진 네이티브 Thread입니다.
5. 파일 작업에는 Workspace에서 소스 Host, 폴더, 접근 모드를 선택하고 준비하세요. 채팅만 할 때는 소스가 필요 없습니다.
6. 메시지를 작성해 보내세요. 이미지·PDF를 첨부하고 도구 활동을 확인할 수 있습니다.

휴대폰은 실행 중인 Host와 페어링하세요. 인터넷 연결에는 설정된 가용 릴레이 또는 자체 보안 원격 경로가 필요합니다. 네트워크에 노출된 Host에는 강력한 UI 암호를 설정하세요.
