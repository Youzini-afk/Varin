# 컨텍스트

오른쪽 사이드바의 **Context**에서 Thread, 브랜치, 실행 상태, 컨텍스트 데이터와 보존된 기록을 확인하세요. 개별 기록을 펼치거나 복사할 수 있으며, 이전 기록은 대화 기록 탐색에서 볼 수 있습니다.

**Instructions and skills**는 캡처된 버전과 진단을 표시합니다. **Refresh instructions and skills**는 이후 요청을 위한 새 스냅샷을 준비하며, 진행 중인 요청이나 수락된 입력은 변경하지 않습니다.

**Context summaries**는 체크포인트와 요약 작업을 표시합니다. 상태에 따라 완료되고 현재에도 유효한 요약 적용, 미완료 요약 취소, 준비 재개가 가능합니다. 요약 준비 완료와 적용은 별개입니다.

[사용량](/ko/usage/)은 소비 기록이며 남은 컨텍스트 비율이 아닙니다. 별도 작업과 기록이 필요하면 새 대화를 시작하세요.
