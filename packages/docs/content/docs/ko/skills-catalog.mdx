# 스킬 카탈로그

이전의 독립 Skills Catalog는 더 이상 제공되지 않습니다. Pi 패키지로 배포되는 스킬은 **설정 → Pi 패키지**에서 Pi PackageManager가 지원하는 소스(npm, Git URL 또는 로컬 경로)를 입력하고 사용자 또는 프로젝트 범위를 선택해 설치하세요. 실행 가능한 확장이 포함될 수 있으므로 신뢰하는 패키지만 설치하세요.

현재 런타임이 로드한 스킬을 만들고 편집하고 호출하려면 [스킬](/ko/skills/)을 참고하세요.
