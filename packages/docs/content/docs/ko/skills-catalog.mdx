# 스킬 라이브러리

**설정 → 스킬**에서 네이티브 라이브러리를 탐색하고 사용자 또는 신뢰된 프로젝트 범위로 생성하거나 복사하세요. 이 페이지에는 별도의 온라인 마켓이 없습니다.

리소스 설정은 이미 설치된 스킬 디렉터리를 참조할 수 있습니다. 스킬 패키지를 읽는 작업은 다운로드나 코드 실행을 하지 않습니다. 실행 가능한 확장은 **설정 → Varin Extensions**에서 따로 관리합니다.

출처, 유효성, 읽기 전용 상태를 확인하세요. 수정 후 대화에서 **Instructions and skills**를 새로 고치세요. 수락된 입력은 캡처 당시의 버전을 유지합니다.

[스킬](/ko/skills/), [명령](/ko/commands/)을 참고하세요.
