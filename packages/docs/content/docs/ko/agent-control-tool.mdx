# Agent 도구

사용 가능한 도구는 수락된 모델, 소스, 역할과 권한에 따라 달라집니다. 필요한 결과를 요청하세요. 각 작업의 권한 검사는 계속 적용됩니다.

- `dispatch`, `child_status`, `child_report`, `wait_child`는 위임 작업을 조정합니다.
- `threads`, `read_thread`는 같은 작업 계열의 대화를 확인합니다. 모든 대화나 다른 작업의 파일에 접근할 권한은 아닙니다.
- `follow_up`은 시간이나 관찰 조건으로 실행할 지시를 관리합니다.
- `goal_report`는 명시적으로 설정된 목표의 완료 또는 차단을 보고합니다.
- `resource_read`는 허용된 지침과 스킬을 읽고, `memory`는 허가된 범위의 메모를 관리합니다.

도구가 표시되어도 파일 쓰기, 프로세스, 외부 서비스 권한이 생기지는 않습니다. 대화 읽기는 해당 모델을 시작하거나 실행 제어권을 주지 않습니다. 작업 수락을 완료로 간주하지 말고 원래 결과와 상태를 확인하세요.
