# Worktree 세션

프로젝트의 **Worktrees** 화면에서 worktree 대화를 만드세요. Varin이 Git 브랜치와 폴더를 만들고 프로젝트 초기화 명령을 적용한 뒤 해당 폴더의 네이티브 Thread를 엽니다. 프로젝트는 Git 저장소여야 합니다.

Git 화면에서 변경을 검토하고 커밋하고 통합하세요. Worktree는 파일을 분리하지만 명령은 바깥에 영향을 줄 수 있습니다.

대화 생성이 실패하거나 결과가 불확실하면 worktree는 원래 Host에 남습니다. 재시도 전에 확인하세요. Thread 보관·삭제만으로 Git worktree가 삭제되지는 않습니다. 프로젝트의 worktree/Git 도구에서 별도로 관리하세요.
