# 스킬

스킬은 이름, 설명, 지침을 담은 `SKILL.md` 리소스이며 보조 파일을 포함할 수 있습니다. 설명은 Agent가 적용할 상황을 판단하는 데 쓰입니다.

**설정 → 스킬**에서 사용자 또는 신뢰된 프로젝트 범위의 스킬을 생성, 확인, 편집, 복사, 삭제할 수 있습니다. 편집기는 경로, 출처, 유효성, 쓰기 가능 여부를 표시합니다. 읽기 전용 리소스는 쓰기 가능한 범위로 복사하세요. 프로젝트 신뢰 요청과 진단을 먼저 확인하세요.

메시지 처음의 `/skill:name` 또는 **Instructions and skills**에서 선택합니다. Agent는 `resource_read`로 허용된 스킬과 보조 파일을 읽을 수도 있습니다. 스킬 내용은 추가 파일·도구 권한을 부여하지 않습니다.

저장만으로 대화에 캡처된 자료가 바뀌지는 않습니다. **Refresh instructions and skills**는 이후 요청을 갱신하며, 수락된 요청은 기존 버전을 유지합니다.

[명령](/ko/commands/), [스킬 라이브러리](/ko/skills-catalog/)를 참고하세요.
