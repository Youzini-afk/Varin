# Contexte

Ouvrez **Context** dans la barre latérale droite pour consulter le Thread, la branche, l’état d’exécution, le contexte et l’historique. Les enregistrements peuvent être développés ou copiés ; l’historique antérieur reste accessible dans la conversation.

**Instructions and skills** affiche les versions capturées et les diagnostics. **Refresh instructions and skills** prépare un nouvel instantané pour les prochaines requêtes, sans modifier les requêtes en cours ni les entrées acceptées.

**Context summaries** montre le point de contrôle et les tâches de résumé. Selon leur état, vous pouvez appliquer un résumé terminé et toujours courant, annuler une tâche ou reprendre sa préparation. Une préparation terminée n’est pas encore une application.

[Usage](/fr/usage/) mesure la consommation, pas le pourcentage de contexte restant. Créez une autre conversation pour séparer tâche et historique.
