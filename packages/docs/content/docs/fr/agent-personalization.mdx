# Mémoire et instructions de l’agent

Dans **Paramètres → Mémoire**, créez, modifiez, supprimez ou déplacez les notes entre les périmètres global, projet et conversation. Le panneau de conversation et l’outil `memory` utilisent les mêmes notes. Un enfant n’hérite pas automatiquement des notes de la conversation parente.

Les notes enregistrées sont immédiatement disponibles. Une conversation active reçoit les nouvelles informations sans réécrire son préfixe mémoire figé. L’application réussie d’un résumé de contexte renouvelle cet instantané.

Dans **Paramètres → System prompt**, modifiez les sections d’instructions. Densité, style et autonomie insèrent du texte modifiable. Les modifications globales, de projet et de conversation s’appliquent dans cet ordre. **Restore defaults** retire seulement celles du périmètre sélectionné. Les changements s’appliquent à une frontière sûre entre requêtes ; celles déjà préparées restent inchangées.

L’aperçu assemble instructions et mémoire capturée. La dernière requête, lorsqu’elle est visible, ne prouve pas la réception par le fournisseur. Pour les fichiers d’instructions et skills, utilisez **Refresh instructions and skills** après modification.

Les Bots gardent leurs propres instructions et mémoire dans **Varin Bot**, séparées des préférences et notes des Agents ordinaires.
