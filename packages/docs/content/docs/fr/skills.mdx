# Skills

Un skill est une ressource `SKILL.md` contenant nom, description et instructions, avec d’éventuels fichiers complémentaires. La description aide l’agent à déterminer quand l’utiliser.

Dans **Paramètres → Skills**, créez, consultez, modifiez, copiez ou supprimez des skills personnels ou propres à un projet approuvé. L’éditeur indique chemin, origine, validité et accès en écriture. Un élément en lecture seule peut être copié vers un périmètre modifiable. Examinez les demandes de confiance et diagnostics.

Utilisez `/skill:name` au début d’un message ou **Instructions and skills**. L’agent peut aussi lire les ressources admises avec `resource_read`. Le texte n’accorde aucun droit supplémentaire sur les outils ou fichiers.

L’enregistrement ne remplace pas les ressources déjà capturées. **Refresh instructions and skills** prépare celles des prochaines requêtes ; les requêtes acceptées conservent leur version.
