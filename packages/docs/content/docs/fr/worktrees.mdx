# Sessions worktree

Ouvrez **Worktrees** dans le projet et créez une conversation avec worktree. Varin crée une branche et un dossier Git, applique les commandes de préparation, puis ouvre un Thread natif pour ce dossier. Le projet doit être un dépôt Git.

Relisez, commitez et intégrez les changements dans la vue Git. Un worktree sépare les fichiers, mais les commandes peuvent avoir des effets en dehors.

Si la création de la conversation échoue ou reste incertaine, le worktree reste sur le Host d’origine. Inspectez-le avant de réessayer. Archiver ou supprimer un Thread ne supprime pas le worktree Git. Gérez les worktrees et les branches séparément dans les outils du projet.
