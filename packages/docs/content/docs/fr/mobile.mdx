# Applications mobiles et PWA

Utilisez Varin depuis votre téléphone : suivez les sessions, répondez aux agents et gérez votre travail. L’application se connecte à un Host Varin que vous faites déjà tourner, et les agents continuent de s’exécuter sur ce Host. À la maison, la connexion passe par le Wi-Fi ; ailleurs, il faut un [relais que vous configurez](/fr/private-relay/) ou votre propre accès distant sécurisé.

## Installer l’application

- **iPhone/iPad** — aucune version n’est encore publiée. Utilisez la PWA ci-dessous ou [compilez l’app native depuis les sources](https://github.com/Youzini-afk/Varin/blob/main/packages/mobile/README.md).
- **Android** — téléchargez `Varin-<version>-android.apk` depuis la [dernière version](https://github.com/Youzini-afk/Varin/releases/latest) et installez-le. Le fichier `.sha256` à côté permet de vérifier le téléchargement. Les notifications push ne sont pas encore disponibles.

## La connecter à votre serveur

1. Sur l’ordinateur qui exécute Varin, ouvrez **Paramètres → Instances distantes → Se connecter à ce serveur** et pressez **Ajouter un appareil**.
2. Choisissez **Partout** (ou **Réseau domestique uniquement** si vous n’utiliserez le téléphone qu’à la maison) et pressez **Créer le code QR**.
3. Dans l’application mobile, touchez **Scanner le code QR** et pointez la caméra dessus.

L’application se connecte et mémorise le serveur. Le QR code est à usage unique et chaque appareil reçoit son propre token révocable — voir [Connecter un appareil](/fr/connect-devices/) pour comprendre pourquoi l’association reste sûre.

Vous pouvez associer l’application à plusieurs serveurs et basculer entre eux depuis la liste des instances ; l’application indique pour chacun s’il est joignable et si vous êtes connecté via le réseau local ou le relais.

## PWA (installation depuis le navigateur)

Vous préférez éviter les app stores ? L’application web s’installe directement depuis le navigateur :

- **navigateur desktop** — utilisez l’option **Installer** dans la barre d’adresse
- **iPhone/iPad (Safari)** — Partager → **Sur l’écran d’accueil**
- **Android (Chrome)** — menu → **Installer l’application** / **Ajouter à l’écran d’accueil**

Pour joindre la PWA depuis l’extérieur de votre réseau, il vous faudra un [tunnel](/fr/tunnels/) et un [mot de passe UI](/fr/security/) solide — l’application Android peut passer par le relais une fois qu’il est configuré sur votre Host.

## Paramètres mobiles

Dans **Paramètres → Varin**, quelques options ajustent l’expérience mobile et installée — le nom de l’application installée, l’orientation de l’écran et le comportement du clavier à l’écran.
