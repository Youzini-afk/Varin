# Contenu interactif et citations

Les conversations dans Varin vont au-delà du simple texte : vous pouvez interagir avec des options structurées, explorer des graphiques dynamiques et citer des passages exacts ou des résultats d’outils dans votre prochain message.

## Contrôles intégrés et artefacts HTML

- **Contrôles intégrés** : Les assistants peuvent insérer directement entre deux paragraphes des choix simples ou multiples, des formulaires, des onglets, des blocs dépliables ainsi que des liens dynamiques vers des tâches, des fichiers ou des plans. Sélectionner une option prépare un message modifiable dans votre zone de saisie plutôt que d’envoyer à votre insu.
- **HTML/JS interactif** : Les visualisations complexes, calculateurs et comparateurs s’affichent en ligne dans un bac à sable isolé assorti à votre thème Varin. Faites un clic droit (ou utilisez le bouton de menu sur appareil tactile) pour inspecter le code source, agrandir dans la barre latérale, télécharger une copie HTML autonome, réinitialiser l’état ou citer la vue actuelle.

## Citations précises et marqueurs déplaçables

- **Tout citer** : Sélectionnez du texte sur plusieurs paragraphes, faites un clic droit sur un bloc précis (code, tableau, paragraphe), choisissez **Quote full turn**, ou citez un appel d’outil, une image ou une vue interactive.
- **Marqueurs dans la zone de saisie** : Les citations et images apparaissent sous forme de puces compactes `[Quote N]` et `[Image N]` que vous pouvez glisser-déposer pour les réordonner dans votre message, inspecter d’un clic ou annuler en une seule action. Retirer un marqueur du texte laisse la pièce jointe disponible dans la barre de pièces jointes ; supprimer la pièce jointe efface tous ses marqueurs.
- **Annotation d’images** : Cliquez sur n’importe quelle image dans le brouillon ou le chat pour tracer des flèches, formes, textes, repères numérotés ou masquages opaques. Les masquages sont incrustés dans l’image envoyée à sa résolution d’origine sans joindre l’original non masqué.
