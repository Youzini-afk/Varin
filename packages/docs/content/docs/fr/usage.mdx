# Tokens de cette conversation

Ouvrez **Utilisation** dans le menu des services de l’en-tête pour voir les tokens de la conversation actuelle par fournisseur et modèle.

- **Entrée** : tokens d’entrée hors cache.
- **Sortie** : tokens générés.
- **Lecture du cache** : entrée réutilisée depuis le cache du fournisseur.
- **Écriture du cache** : entrée enregistrée dans ce cache.

Les totaux proviennent du journal de session Pi et incluent les messages antérieurs à la compression, les branches inactives et les appels auxiliaires enregistrés. Les usages sans information de modèle sont affichés séparément. Chaque conversation enfant possède ses propres statistiques.
