# Guides d’utilisation de Varin

Varin est votre super-agent personnel : un agent IA open source qui travaille avec vos fichiers, votre navigateur et vos ordinateurs connectés, et coordonne d’autres agents si nécessaire. Utilisez-le pour les tâches du quotidien, le code, la recherche ou la bureautique, avec les modèles de votre choix.

Exécutez Varin sur votre ordinateur ou votre serveur. L’application de bureau intègre l’Application Host ; les clients web et mobiles se connectent à ce Host.
