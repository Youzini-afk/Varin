# Guides d'utilisation de Varin

Varin est un espace de travail open source pour les agents IA. Utilisez-le pour les tâches quotidiennes, le code et la recherche, avec vos modèles et outils réunis. Les applications de bureau et web fournissent l'espace de travail ; le client mobile se connecte à votre Host.
