# Guides d'utilisation de Varin

Varin est le harness d'agents open source, prêt à l'emploi. Outils, contexte, exécution, permissions et reprise sont déjà en place autour du modèle de votre choix, pour le code, la recherche, la bureautique et les tâches quotidiennes. Les applications de bureau et web fournissent l'espace de travail ; le client mobile se connecte à votre Host.
