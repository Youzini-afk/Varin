# Documentation Varin

Varin est un espace de travail indépendant pour le code, la recherche et les projets. Son runtime natif Rust Agent conserve les conversations sous forme de Threads et de branches dans un Catalog durable. Application Host connecte les modèles, ressources et services MCP pour le desktop, le web et le mobile.

Utilisez cette documentation pour :

- installer l’application qui correspond à votre façon de travailler
- ouvrir Varin pour un usage local ou distant
- personnaliser l’apparence et corriger les problèmes courants

## À quoi sert Varin

Varin sert au codage, à la recherche et aux autres projets qui gagnent à être pilotés depuis une salle de contrôle : sessions par branche, revue des résultats, gestion des terminaux, suivi de l’avancement des outils, lancement d’actions de projet et vue d’ensemble pendant que l’agent travaille.
