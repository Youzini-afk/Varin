# Guides d'utilisation de Varin

Varin est votre super-agent personnel : un agent IA open source qui travaille avec vos fichiers, votre navigateur et vos ordinateurs connectés, et fait appel à d'autres agents si nécessaire. Utilisez-le pour les demandes du quotidien, le code, la recherche ou la bureautique, avec les modèles de votre choix.

Exécutez Varin sur votre ordinateur ou votre serveur. L'application de bureau intègre le service ; les clients web et mobiles se connectent à ce service, appelé Host. Commencez par connecter un modèle et confier une tâche à Varin, puis ajoutez les outils et appareils dont vous avez besoin.
