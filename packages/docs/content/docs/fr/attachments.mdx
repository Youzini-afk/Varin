# Images et PDF

Utilisez **Attach images** ou **Attach PDFs** dans le champ de conversation. Vous pouvez aussi coller ou déposer les fichiers pris en charge. Les images nécessitent un modèle acceptant l’entrée visuelle.

Le PDF original est conservé comme matériau du Thread. Ouvrez sa pièce jointe pour lire les pages et sélectionner une région à ajouter au brouillon si le modèle accepte les images. La représentation extraite ne remplace pas l’original disponible dans le lecteur.

L’envoi, les trois modes de file d’attente et la continuation d’un enfant transmettent l’instantané sélectionné. Les modifications ultérieures du fichier ne le changent pas. Si la livraison est incertaine, utilisez **Retry delivery** sans nouveau téléversement. Les pièces jointes restent bloquées jusqu’à résolution du résultat initial. Changer de Host, Thread ou branche ne transfère pas un téléversement en cours.
