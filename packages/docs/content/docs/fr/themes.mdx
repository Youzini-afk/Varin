# Thèmes

Varin prend en charge les thèmes intégrés et les fichiers JSON de thème personnalisés.

## Ajouter un thème personnalisé

1. Créez le dossier des thèmes :

```bash
# Linux (default data directory)
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/varin/themes"
```

2. Ajoutez votre fichier JSON dans ce dossier (par exemple `my-theme.json`).
3. Ouvrez Varin, puis allez dans **Paramètres → Apparence → Reload themes**.
4. Choisissez votre thème dans le menu déroulant. Il s’applique immédiatement.

## Emplacement des thèmes

- Linux: `$XDG_CONFIG_HOME/varin/themes/` (`~/.config/varin/themes/`)
- macOS: `~/Library/Application Support/Varin/themes/`
- Windows: `%APPDATA%/Varin/themes/`
- `VARIN_DATA_DIR`: `$VARIN_DATA_DIR/themes/`
