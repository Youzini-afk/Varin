# Démarrage rapide

1. Préparez Node.js, Bun et Rust avec le guide d’installation, puis lancez `bun install --frozen-lockfile` et `bun run dev` dans le dépôt.
2. Ouvrez l’URL Vite affichée. Pour le desktop, utilisez `bun run electron:dev`.
3. Dans Paramètres → Canaux de modèles, connectez un canal et choisissez un modèle.
4. Créez une conversation : un Thread natif avec ses branches et son historique.
5. Pour les fichiers, développez Workspace, choisissez le Host, le dossier et le mode d’accès, puis préparez la source. Un simple chat n’en a pas besoin.
6. Écrivez et envoyez. Vous pouvez joindre des images ou PDF et consulter l’activité des outils.

Appairez le téléphone au Host actif. L’accès par internet exige un relay configuré et disponible ou votre propre route distante sécurisée. Protégez tout Host accessible sur le réseau avec un mot de passe UI fort.
