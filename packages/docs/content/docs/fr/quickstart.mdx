# Démarrage rapide

1. [Installez](/fr/install/) l’application de bureau et ouvrez-la (ou auto-hébergez-la avec Docker / compilez depuis les sources via la même page).
2. Ouvrez **Paramètres → Model services**, ajoutez un canal de modèles (clé API, identifiants cloud ou service local comme Ollama / LM Studio) et activez un modèle de chat.
3. Commencez à discuter dans la vue assistant **Varin**, ou passez sur **Workbench** / **IDE** depuis le sélecteur supérieur lorsque vous souhaitez contrôler directement les tâches ou les fichiers.
4. Pour travailler sur des fichiers, ouvrez le sélecteur de dossier sous la zone de saisie afin de choisir un répertoire local, un projet enregistré ou un appareil distant connecté. Les échanges purement textuels ne nécessitent aucun espace de travail.
5. Envoyez votre message. Vous pouvez coller ou déposer des images, des PDF ou n’importe quel fichier, citer des passages précis dans votre brouillon et suivre directement l’activité des outils ou des coéquipiers délégués.

Pour utiliser Varin depuis votre téléphone ou un autre ordinateur, appairez votre appareil au Host actif et protégez tout Host exposé sur le réseau avec un mot de passe UI fort.
