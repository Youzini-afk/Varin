# Commandes

**Paramètres → Commandes** affiche les skills actifs et valides de la bibliothèque sélectionnée, avec description et chemin. Commencez un message par `/skill:name`, suivi d’un espace et de vos instructions.

Dans **Instructions and skills**, **Add /skill:name to draft** insère la commande sans envoyer le message. Les noms contenant des espaces ne peuvent pas utiliser cette syntaxe.

La conversation utilise une version capturée. Après une modification de bibliothèque, choisissez **Refresh instructions and skills** pour préparer un nouvel instantané. Les requêtes en cours et les entrées déjà acceptées conservent leurs ressources originales. La liste des paramètres ne signifie pas qu’une ancienne conversation a été actualisée.

Consultez [Skills](/fr/skills/). Les raccourcis de l’espace de travail se règlent séparément.
