# Commandes

Ouvrez **Paramètres → Commandes** pour voir les commandes enregistrées par les extensions et les skills. Le catalogue affiche leur description, leur source, leur scope et leur invocation, que vous pouvez copier.

Tapez `/` au début d’un message et sélectionnez une commande. Ajoutez des arguments après son nom si nécessaire. Les commandes d’extension sont traitées par leur plugin ; `/skill:name` charge les instructions du skill correspondant.

Les commandes disponibles dépendent du runtime, de l’espace de travail et des ressources chargées. Gérez leurs sources dans **Paramètres → Skills** et **Paramètres → Pi Packages**.
