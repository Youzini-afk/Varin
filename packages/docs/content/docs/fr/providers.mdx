# Fournisseurs, modèles et agents

Avant que Varin puisse faire quoi que ce soit, il lui faut au moins un fournisseur d’IA connecté. Cette page couvre la connexion d’un fournisseur, le choix d’un modèle et l’ajustement des agents.

## Connecter un fournisseur

1. Ouvrez **Settings → Providers**.
2. Ouvrez le menu **Add provider** et choisissez un fournisseur qui n’est pas encore connecté.
3. Connectez-vous de l’une des deux façons, selon le fournisseur :
   - **API key** — collez votre clé et enregistrez.
   - **Sign-in (device flow)** — Varin affiche un lien et un code court. Ouvrez le lien, saisissez le code et approuvez. Varin termine la connexion tout seul.

Quand un fournisseur s’affiche comme connecté, ses modèles deviennent disponibles dans le chat.

Pour déconnecter, ouvrez le fournisseur et choisissez de retirer sa connexion.

## Choisir un modèle

Vous choisissez le modèle là où vous travaillez :

- dans le chat, utilisez le sélecteur de modèle de la barre de message pour définir le fournisseur et le modèle de cette session
- par agent, définissez un modèle par défaut (ci-dessous)

## Configurer des agents

Un agent est une configuration nommée — un modèle, une personnalité, et ce qu’il a le droit de faire.

1. Ouvrez **Settings → Agents**.
2. Choisissez un agent, ou créez-en un nouveau.
3. Modifiez n’importe lequel de :
   - **description** — à quoi sert l’agent
   - **model** — son modèle par défaut
   - **temperature** — à quel point ses réponses sont créatives
   - **prompt** — consignes permanentes qu’il suit toujours
   - **tool rules** — quels outils il peut utiliser

## Où vivent vos connexions

Les connexions des fournisseurs sont stockées par `AuthStorage` de Pi, pas dans le renderer. Les clés API et les jetons OAuth n’apparaissent jamais dans les métadonnées de fournisseur envoyées à l’UI. Les couches `models.json` utilisateur, projet et operator restent dans leurs fichiers natifs.

Si vous définissez le même fournisseur à plus d’un endroit, le réglage le plus spécifique l’emporte : une couche projet de confiance remplace votre couche personnelle.
