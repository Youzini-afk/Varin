# Canaux de modèles

Ouvrez **Paramètres → Canaux de modèles**, ajoutez un canal et choisissez son type, son endpoint et une méthode d’authentification proposée. Selon le canal : clé API enregistrée, connexion, variable d’environnement explicite, identité cloud prise en charge ou accès anonyme.

Ajoutez des modèles par ID, ou découvrez des candidats sur un canal enregistré compatible. Vérifiez puis enregistrez votre sélection : la découverte seule ne modifie pas le catalogue. Activez le canal, le modèle et l’opération nécessaire, puis sélectionnez le modèle dans la zone de saisie.

L’Application Host gère la configuration et les comptes. Les identifiants sont conservés séparément des métadonnées et n’entrent pas dans l’historique. Un compte indisponible n’est pas remplacé automatiquement. Les modifications concernent les préparations ultérieures ; le travail accepté conserve sa sélection.

Consultez [Mémoire et instructions](/fr/agent-personalization/) et [MCP](/fr/mcp/). L’accès au modèle n’accorde pas de droits sur les fichiers ou outils.
