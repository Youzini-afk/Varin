# Issues et PR GitHub

Connectez GitHub pour gérer les PR dans Varin. Pour demander à l’agent de travailler sur une issue ou une PR, ajoutez le contexte utile à une conversation native et choisissez explicitement sa source de travail.

## Connecter GitHub

1. Ouvrez **Paramètres → Git**.
2. Sous GitHub, choisissez **Connect**. Varin affiche un lien et un code court.
3. Ouvrez le lien, saisissez le code et approuvez.

Une fois connecté, votre compte apparaît dans la section GitHub. Vous pouvez connecter plusieurs comptes et passer de l’un à l’autre, ou vous déconnecter à tout moment.

## Ouvrir et gérer des pull requests

Depuis l’onglet **PR** de la [vue git](/fr/git/), vous pouvez créer une pull request, la mettre à jour, marquer un brouillon comme prêt ou la merger. Varin peut générer le titre et la description de la PR à partir de vos changements.
