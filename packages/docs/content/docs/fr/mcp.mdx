# Serveurs MCP

Ouvrez **Paramètres → MCP** sur le Host qui doit gérer la connexion. Choisissez la source de configuration et ajoutez un serveur : commande, arguments et environnement pour un processus local, URL et en-têtes pour un service distant. Utilisez uniquement des serveurs dont vous comprenez le code et l’accès aux données.

Enregistrez le document, utilisez Connect ou Reconnect, puis vérifiez l’état et le nombre d’outils. Connectez votre compte si l’autorisation est proposée. Les sources globales et de projet affichent leurs chemins ; la configuration de projet exige votre confiance. Les champs structurés et le document brut sont modifiables.

L’enregistrement ne remplace pas les ressources déjà capturées par un Thread actif. Vérifiez les ressources de la conversation et actualisez explicitement son instantané. Les permissions, questions et demandes de sampling s’affichent dans la conversation.
