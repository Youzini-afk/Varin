# Projets

Un projet est un dossier sur le Host connecté. Ouvrez-le avec le sélecteur de projets ou l’explorateur ; Paramètres → Projets gère son nom, sa couleur, son icône et ses actions. Le projet parcouru et la source d’exécution d’une conversation sont distincts : changer de projet ne redirige pas un Thread en cours.

Dans la conversation, développez **Workspace**, choisissez le Host et le dossier source, puis le mode :
- **Read-only file snapshot** : fichiers figés pour lire, lister et chercher
- **Isolated editable copy** : copie capturée pour modifier et exécuter des commandes ; les changements ne sont pas recopiés automatiquement
- **Live workspace** : fichiers enregistrés du dossier réel ; les modifications sont immédiates

Cliquez sur **Prepare workspace** et vérifiez le résultat avant l’envoi. Les instantanés peuvent inclure les brouillons des éditeurs de cette fenêtre sur le même Host ; le mode live utilise uniquement les fichiers enregistrés. Les chemins distants appartiennent au Host sélectionné. Les copies modifiables et les commandes ne sont pas des bacs à sable de sécurité.
