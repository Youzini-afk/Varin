# Bibliothèque de skills

Utilisez **Paramètres → Skills** pour parcourir la bibliothèque native et créer ou copier des skills personnels ou de projets approuvés. Cette page ne propose pas de place de marché en ligne distincte.

La configuration peut référencer des répertoires déjà installés. Lire un paquet de skills ne le télécharge pas et n’exécute pas son code. Les extensions exécutables se gèrent dans **Paramètres → Varin Extensions**.

Vérifiez origine, validité et lecture seule. Après modification, actualisez **Instructions and skills** dans la conversation. Les entrées acceptées gardent leur version capturée.

Voir [Skills](/fr/skills/) et [Commandes](/fr/commands/).
