# Catalogue de skills

L’ancien catalogue autonome de skills n’est plus disponible. Pour installer des skills distribuées dans un paquet Pi, ouvrez **Paramètres → Paquets Pi**, saisissez une source prise en charge par Pi PackageManager (npm, URL Git ou chemin local), puis choisissez la portée utilisateur ou projet. Installez uniquement des paquets de confiance : ils peuvent contenir des extensions exécutables.

Utilisez [Skills](/fr/skills/) pour créer, modifier et invoquer les skills chargées par le runtime actif.
