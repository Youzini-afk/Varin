# Installation

Varin est en pre-1.0. Les façons prises en charge de l’exécuter aujourd’hui sont **depuis les sources** et **avec Docker**. Les téléchargements npm empaquetés et GitHub Release ne sont pas encore publiés.

Il existe deux surfaces produit principales :

- l’application desktop (Electron)
- l’application web hébergée par le serveur local, que vous pouvez installer comme une appli téléphone (une PWA)

## Prérequis

- Node.js 22.19 ou plus récent (Node.js 24 est la base de développement)
- [Bun](https://bun.sh) 1.3.14
- La chaîne Rust sélectionnée par `kernel/rust-toolchain.toml` (installez rustup ; le dépôt sélectionne la version requise)
- Git
- Git for Windows et Git Bash pour exécuter les outils shell Pi sous Windows

Vous n’avez **pas** besoin d’une installation séparée d’OpenCode ou de la CLI Pi. Les builds desktop et conteneur empaquetés incluent le runtime Pi épinglé.

## Depuis les sources (web)

```bash
git clone https://github.com/Youzini-afk/Varin.git
cd Varin
bun install --frozen-lockfile
bun run dev
```

Ouvrez l’URL Vite affichée dans le terminal. Varin démarre l’UI et le service API/runtime de confiance ensemble.

## Depuis les sources (desktop)

```bash
bun run electron:dev
```

Plus proche d’un build empaqueté :

```bash
bun run electron:dev:bundled
```

Un installeur Windows peut être construit localement avec `bun run electron:build:win`. Des installeurs non signés sont attendus tant que les identifiants de signature ne sont pas configurés.

## Docker

Sur un hôte Docker Linux :

```bash
mkdir -p data/varin data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'VARIN_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

Ouvrez `http://127.0.0.1:3000` et utilisez le mot de passe généré. Placez un reverse proxy TLS ou un tunnel approuvé devant tout déploiement exposé à Internet. En production, épinglez `VARIN_IMAGE` à un digest testé plutôt qu’à `:latest`.

Compose tire par défaut l’image allégée `ghcr.io/youzini-afk/varin-slim:latest` (suffisante pour le serveur : Bun, Node, Git, SSH et cloudflared). Si l’agent doit compiler Python, Java, Go ou Rust dans le conteneur, appliquez la superposition outillage :

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## One-liner CLI (non publié)

`scripts/install.sh` et `npx @varin/web` ciblent le paquet npm `@varin/web`. Ce paquet n’est pas encore sur le registre public, donc l’installeur curl échouera jusqu’à la publication d’une release. Utilisez les sources ou Docker d’ici là.
