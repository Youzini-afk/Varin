# Variables d’environnement

Varin lit ces variables d’environnement au démarrage. Pour les services de démarrage, `varin startup enable` capture l’environnement actuel par défaut, donc relancez-le après avoir changé les variables que le service doit utiliser.

Ces variables configurent Application Host et les services de plateforme. Configurez les comptes de modèles dans Paramètres → Model services ; changer le répertoire des données n’importe ni ne migre un stockage existant.

## Serveur Varin

### `VARIN_HOST`

Adresse de liaison du serveur web Varin. Utilisez `0.0.0.0` pour autoriser l’accès depuis d’autres machines.

### `VARIN_UI_PASSWORD`

Mot de passe de l’UI navigateur. Utilisez-le quand vous liez hors de localhost, utilisez des tunnels, ou tournez derrière un reverse proxy.

### `VARIN_API_ONLY`

Démarre Varin en mode headless quand la valeur est `true` ou `1`. Les routes API restent disponibles pour les clients desktop et mobile, mais l’UI navigateur n’est pas servie.

### `VARIN_DATA_DIR`

Remplace le dossier de données Varin. Par défaut : Linux utilise `$XDG_CONFIG_HOME/varin` (ou `~/.config/varin`) ; macOS, `~/Library/Application Support/Varin` ; Windows, `%APPDATA%/Varin`.

### `VARIN_COMPRESS_API`

Contrôle la compression des réponses API. Utilisez `true` ou `1` pour la forcer, `false` ou `0` pour la désactiver.

### `VARIN_SKIP_API_COMPRESSION`

Désactive la compression des réponses API quand la valeur est `true` ou `1`. Cela a priorité sur `VARIN_COMPRESS_API`.

### `VARIN_VERBOSE_REQUEST_LOGS`

Active les journaux HTTP détaillés quand la valeur est `true` ou `1`.

### `VARIN_UPDATE_API_URL`

Remplace le point de terminaison de l’API de vérification des mises à jour. La plupart des utilisateurs devraient le laisser non défini.

### `VARIN_PACKAGE_MANAGER`

Force le gestionnaire de paquets utilisé par les opérations de mise à jour quand la détection automatique se trompe.

## Terminal et Git

### `VARIN_TERMINAL_SHELL`

Exécutable de shell utilisé pour les sessions terminal Varin.

### `VARIN_GIT_BINARY`

Remplacement de l’exécutable Git sous Windows. Sous macOS et Linux, Varin résout `git` depuis `PATH`.

### `GIT_BINARY`

Remplacement Git sous Windows, vérifié avant `VARIN_GIT_BINARY`. Varin utilise le premier exécutable configuré disponible, puis recherche Git.

## Voix et tunnels

### `OPENAI_API_KEY`

Clé API utilisée par les fonctionnalités vocales Varin qui appellent des services compatibles OpenAI.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Autorise les URL de base distantes compatibles OpenAI pour les fonctionnalités vocales quand la valeur est `true` ou `1`.

### `NGROK_AUTHTOKEN`

Jeton d’auth ngrok utilisé par les commandes de tunnel Varin. Vous pouvez aussi configurer ngrok avec `ngrok config add-authtoken <token>`.

## Relais privé

### `VARIN_RELAY_URL`

Point de terminaison `ws://` ou `wss://` du [Relais privé](/fr/private-relay/) auquel le serveur se connecte pour l’association **Partout**. Varin n’a pas de relais par défaut : sans cette variable, **Partout** n’est pas disponible et le serveur ne se connecte jamais à un relais. Donnez la même valeur à `varin connect-url --relay`.

## Aides runtime

### `BUN_INSTALL`

Racine d’installation utilisée pour trouver Bun lors des mises à jour par le gestionnaire de paquets. Le daemon CLI et les services de démarrage utilisent l’exécutable ayant lancé Varin (`process.execPath`) ; `BUN_BINARY` n’est pas une option prise en charge.
