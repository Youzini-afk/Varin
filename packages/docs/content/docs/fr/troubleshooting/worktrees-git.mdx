# Worktrees et Git

Avant de réessayer, vérifiez le Host et le dossier d’origine. Une erreur ou une réponse perdue peut laisser un vrai worktree ou Thread. Inspectez Worktrees et Git ; ne supprimez pas une conversation pour réparer un problème de dossier distinct.

Si le dossier a été déplacé, restaurez ou réparez son enregistrement Git worktree. Vérifiez les changements locaux avant de poursuivre ou d’abandonner un merge, rebase ou cherry-pick. Si un nom existe déjà, inspectez ce travail avant d’en choisir un autre.

Les messages de commit et descriptions de PR utilisent le modèle utilitaire ou par défaut du Host. Vérifiez le canal, le modèle, les identifiants et les fichiers indexés ou la plage de commits. Une conversation active n’est pas nécessaire. Examinez tout résultat inconnu avant une nouvelle demande.
