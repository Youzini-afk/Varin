# Accès distant

Quand vous ne pouvez pas joindre Varin depuis votre téléphone ou une autre machine, la correction dépend de votre méthode de connexion.

## Vérifiez d’abord les bases

- ouvrez d’abord `http://localhost:3000` sur le même ordinateur — si cela échoue, ce n’est pas un problème distant ; voir [Dépannage](/fr/troubleshooting/)
- confirmez que le serveur tourne avec `varin status`

## L’appareil associé ne se connecte pas

- le QR code / lien d’association est **à usage unique** — s’il a déjà été scanné (ou a expiré), créez-en un nouveau depuis **Ajouter un appareil**
- si l’appareil a été associé avec **Réseau domestique uniquement**, il ne peut pas se connecter depuis l’extérieur de ce réseau — associez-le à nouveau avec **Partout**
- **Partout** nécessite un relais : s’il est grisé dans **Ajouter un appareil**, le serveur n’a pas de `VARIN_RELAY_URL` ; si elle est définie, vérifiez que le relais qu’elle indique est joignable depuis le serveur
- si un appareil a été **révoqué**, son token est perdu définitivement — associez-le à nouveau avec un nouveau QR code

Voir [Connecter un appareil](/fr/connect-devices/) et [Relais privé](/fr/private-relay/) pour comprendre comment ces connexions fonctionnent.

## Le lien de tunnel ne fonctionne pas

- lancez `varin tunnel status --all`
- redémarrez le tunnel depuis la même instance et le même port
- régénérez le lien de connexion si le précédent a déjà été utilisé

Voir [Tunnels](/fr/tunnels/) pour la configuration complète.

## L’instance distante ne se connecte pas (desktop)

Quand une [instance distante](/fr/remote-instances/) bloque, Varin nomme l’étape qui a échoué :

- **auth** — votre mot de passe SSH ou UI a été refusé ; saisissez-le à nouveau
- **install / start** — Varin n’a pas pu configurer ou démarrer le serveur sur la machine distante ; vérifiez les prérequis de cette machine
- **forwarding** — la connexion est établie mais le port ne vous rejoint pas ; essayez un autre port local

## Derrière votre propre serveur

Si vous placez Varin derrière un reverse proxy et qu’il se charge bizarrement ou ne se connecte pas, consultez [Reverse proxy](/fr/reverse-proxy/).
