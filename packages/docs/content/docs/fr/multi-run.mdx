# Multi-run

Multi-run crée un Thread natif par modèle sélectionné. Choisissez un projet, nommez le lot, ajoutez des groupes de prompts et de modèles, puis lancez. Il n’y a pas de limite fixe de cinq modèles.

L’isolation crée un worktree et une branche Git par exécution. Sans isolation, les exécutions partagent le dossier réel du projet et peuvent modifier les mêmes fichiers. Vérifiez les commandes de préparation.

Consultez chaque tentative. Un échec ou un résultat non confirmé conserve les Threads et worktrees créés. Réessayez avec les mêmes choix pour réconcilier la demande d’origine. Si la création du worktree est incertaine, inspectez Git sur le Host d’origine. **Stop launching** arrête les nouveaux lancements ; le travail déjà accepté continue.
