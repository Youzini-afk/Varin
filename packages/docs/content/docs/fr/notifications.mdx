# Notifications

Ouvrez **Paramètres → Varin → Notifications** et autorisez-les sur chaque appareil. Les événements natifs signalent une réponse terminée, un échec, une demande d’approbation ou une question. Les notifications de fin respectent leur réglage ; les demandes d’attention sont distinctes.

La livraison dépend du desktop, du push web ou mobile et des permissions système. Le Host doit rester actif. Les canaux compatibles ouvrent le Thread et la branche d’origine.

Le titre est celui du Thread, ou « Varin » à défaut. Le corps est un statut fixe, pas la réponse de l’agent. Cela vaut aussi pour APNs : le titre peut apparaître sur l’écran verrouillé de l’iPhone. Les anciens modèles modifiables ne sont pas utilisés et la synchronisation du badge de l’icône n’est pas implémentée.
