# Workflows Git et GitHub

Varin possède une vue git intégrée pour relire les changements, commiter et gérer les branches sans passer au terminal. Ouvrez-la depuis l’onglet **Git** dans la barre latérale droite.

## Relire et commiter

La vue git sépare vos changements en **staged** et **unstaged** :

- cliquez sur le **+** d’un fichier pour le stage, ou sur **−** pour le retirer du stage
- stagez ou retirez du stage tout un groupe à la fois
- cliquez sur un fichier pour voir son diff

Rédigez le message de commit ou générez-le à partir des changements indexés sélectionnés. La génération utilise le modèle utilitaire configuré sur le Host, sinon son modèle par défaut. Aucune conversation ouverte n’est nécessaire. Relisez avant de commiter.

## Branches et historique

La vue git couvre aussi le reste du quotidien git :

- créer, changer, renommer et supprimer des branches
- push, pull et fetch
- parcourir l’historique et les diffs par commit
- stash et restaurer des changements

## Pull requests

Connectez GitHub (voir [Issues et PR GitHub](/fr/github/)) et l’onglet **PR** vous permet d’ouvrir une pull request, de la mettre à jour, de la marquer comme prête ou de la merger — et de générer son titre et sa description comme pour les messages de commit.

## Gérer les conflits

Si un merge, rebase ou integrate tombe sur un conflit, Varin montre ce qui est bloqué et vous laisse le résoudre — y compris en le confiant à l’agent.
