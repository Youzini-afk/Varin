# Kanały modeli

Otwórz **Ustawienia → Kanały modeli**, dodaj kanał i wybierz typ, punkt końcowy oraz obsługiwaną metodę uwierzytelniania. Zależnie od kanału dostępne są zapisany klucz API, logowanie, jawna zmienna środowiskowa, obsługiwana tożsamość chmurowa lub dostęp anonimowy.

Dodaj modele według ID albo wyszukaj kandydatów w zapisanym kanale, który to obsługuje. Sprawdź i zapisz wybór: samo wyszukiwanie nie zmienia katalogu. Włącz kanał, model i potrzebną operację, np. czat, a następnie wybierz model w polu wiadomości.

Application Host zarządza konfiguracją i kontami. Dane uwierzytelniające są przechowywane osobno od metadanych i nie trafiają do historii rozmowy. Brak lub wycofanie danych nie powoduje automatycznego wyboru innego konta. Zmiany dotyczą późniejszego przygotowania; przyjęta praca zachowuje pierwotny wybór.

Zobacz [Pamięć i instrukcje](/pl/agent-personalization/) oraz [MCP](/pl/mcp/). Dostęp do modelu nie przyznaje praw do plików ani narzędzi.
