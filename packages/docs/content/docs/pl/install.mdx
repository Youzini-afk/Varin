# Instalacja

Varin jest w wersji pre-1.0. Obsługiwane sposoby uruchomienia to dziś **ze źródeł** i **z Dockerem**. Spakowane pobrania npm i GitHub Release nie są jeszcze opublikowane.

Są dwie główne powierzchnie produktu:

- aplikacja na komputer (Electron)
- aplikacja webowa hostowana przez lokalny serwer, którą możesz zainstalować jak aplikację na telefon (PWA)

## Wymagania wstępne

- Node.js 22.19 lub nowszy (linią bazową rozwoju jest Node.js 24)
- [Bun](https://bun.sh) 1.3.14
- Zestaw narzędzi Rust wybrany przez `kernel/rust-toolchain.toml` (zainstaluj rustup; repozytorium wybiera wymaganą wersję)
- Git
- Git for Windows i Git Bash przy uruchamianiu narzędzi powłoki Pi w Windows

**Nie** potrzebujesz osobnej instalacji OpenCode ani CLI Pi. Spakowane buildy desktopowe i kontenerowe zawierają przypięte środowisko uruchomieniowe Pi.

## Ze źródeł (web)

```bash
git clone https://github.com/Youzini-afk/Varin.git
cd Varin
bun install --frozen-lockfile
bun run dev
```

Otwórz adres Vite wypisany w terminalu. Varin uruchamia UI i zaufaną usługę API/runtime razem.

## Ze źródeł (komputer)

```bash
bun run electron:dev
```

Bliżej spakowanego builda:

```bash
bun run electron:dev:bundled
```

Instalator Windows można zbudować lokalnie poleceniem `bun run electron:build:win`. Niepodpisane instalatory są oczekiwane, dopóki nie skonfigurujesz poświadczeń podpisu.

## Docker

Na hoście Docker w Linuxie:

```bash
mkdir -p data/varin data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'VARIN_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

Otwórz `http://127.0.0.1:3000` i użyj wygenerowanego hasła. Przed każdym wdrożeniem wystawionym do Internetu umieść reverse proxy TLS albo zatwierdzony tunel. W produkcji przypnij `VARIN_IMAGE` do przetestowanego digestu zamiast `:latest`.

Compose domyślnie pobiera szczupły obraz `ghcr.io/youzini-afk/varin-slim:latest` (wystarczy do serwera: Bun, Node, Git, SSH i cloudflared). Jeśli agent ma kompilować Python, Java, Go lub Rust w kontenerze, nałóż warstwę narzędziową:

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## Jednolinijkowiec CLI (nieopublikowany)

`scripts/install.sh` i `npx @varin/web` celują w pakiet npm `@varin/web`. Ten pakiet nie jest jeszcze w publicznym rejestrze, więc instalator curl będzie kończył się niepowodzeniem do czasu publikacji wydania. Do tego czasu używaj źródeł albo Dockera.
