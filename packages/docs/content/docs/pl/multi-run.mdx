# Multi-run

Multi-run tworzy natywny Thread dla każdego wybranego modelu. Wybierz projekt, nazwij serię, dodaj grupy poleceń i modeli, a następnie uruchom. Nie ma stałego limitu pięciu modeli.

Izolacja tworzy osobny Git worktree i gałąź dla każdego uruchomienia. Bez niej uruchomienia współdzielą rzeczywisty folder projektu i mogą zmieniać te same pliki. Sprawdź polecenia przygotowawcze.

Sprawdź każdą próbę. Niepowodzenie lub niepotwierdzony wynik zachowuje utworzone Threads i worktrees. Ponów bez zmiany wyboru, aby uzgodnić oryginalne żądanie. Niepotwierdzone utworzenie worktree sprawdź najpierw w Git na pierwotnym Host. **Stop launching** zatrzymuje nowe uruchomienia; przyjęta praca trwa dalej.
