# Pamięć i instrukcje Agenta

W **Ustawienia → Pamięć** twórz, edytuj, usuwaj i przenoś notatki między zakresem globalnym, projektu i rozmowy. Panel pamięci w rozmowie oraz narzędzie `memory` korzystają z tych samych notatek. Zadanie podrzędne nie dziedziczy automatycznie notatek rozmowy nadrzędnej.

Zapisane notatki są od razu dostępne. Aktywna rozmowa otrzymuje nowe fakty bez przepisywania zamrożonego prefiksu pamięci systemowej. Pomyślne zastosowanie podsumowania kontekstu aktualizuje tę migawkę.

W **Ustawienia → System prompt** edytuj sekcje instrukcji. Gęstość, styl i autonomia wstawiają edytowalny tekst. Nadpisania globalne, projektu i rozmowy stosuje się w tej kolejności. **Restore defaults** usuwa tylko zmiany wybranego zakresu. Zmiany działają na bezpiecznej granicy żądań; już przygotowane żądania pozostają niezmienione.

Podgląd pokazuje złożone instrukcje i przechwyconą pamięć. Widok ostatniego żądania, jeśli dostępny, nie dowodzi odbioru przez dostawcę. Po zmianie plików instrukcji lub skilli użyj **Refresh instructions and skills**.

Boty mają osobne instrukcje i pamięć w **Varin Bot**, bez notatek i nadpisań zwykłych Agentów.
