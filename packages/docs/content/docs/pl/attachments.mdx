# Obrazy i PDF

Użyj **Attach images** lub **Attach PDFs** w edytorze rozmowy. Możesz też wkleić lub upuścić obsługiwane pliki. Obrazy wymagają modelu z obsługą wejścia obrazowego.

Oryginalny PDF jest zachowany jako materiał Thread. Otwórz załącznik, przeglądaj strony i dodaj wybrany obszar do szkicu, jeśli model obsługuje obrazy. Wyodrębniona reprezentacja nie zastępuje oryginału dostępnego w czytniku.

Wysłanie, wszystkie trzy tryby kolejki i kontynuacja rozmowy potomnej przekazują wybraną migawkę materiału. Późniejsze zmiany pliku jej nie zmieniają. Przy niepotwierdzonym dostarczeniu użyj **Retry delivery**, zamiast ponownie przesyłać plik. Załączniki są zablokowane do ustalenia wyniku. Zmiana Host, Thread lub gałęzi nie przenosi oczekującego przesyłania.
