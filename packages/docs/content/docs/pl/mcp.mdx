# Serwery MCP

Otwórz **Ustawienia → MCP** na Host, który ma zarządzać połączeniem. Wybierz źródło konfiguracji i dodaj serwer: polecenie, argumenty i środowisko dla procesu lokalnego albo URL i nagłówki dla usługi zdalnej. Używaj serwerów o znanym kodzie i dostępie do danych.

Zapisz dokument, użyj Connect lub Reconnect i sprawdź stan oraz liczbę narzędzi. Zaloguj się, jeśli serwer obsługuje autoryzację. Źródła globalne i projektowe pokazują ścieżki; konfiguracja projektu wymaga zaufania. Można edytować pola lub surową konfigurację.

Zapis nie zastępuje zasobów przechwyconych przez aktywny Thread. Sprawdź zasoby rozmowy i jawnie odśwież migawkę. Prośby o uprawnienia, pytania i sampling pojawiają się w rozmowie.
