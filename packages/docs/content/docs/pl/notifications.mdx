# Powiadomienia

Otwórz **Ustawienia → Varin → Powiadomienia** i zezwól na nie na każdym urządzeniu. Natywne zdarzenia informują o zakończeniu odpowiedzi, błędzie albo potrzebie zgody lub odpowiedzi. Powiadomienia o zakończeniu respektują odpowiednie ustawienie; prośby o uwagę są oddzielne.

Dostarczenie zależy od desktopa, push w przeglądarce lub telefonie oraz uprawnień systemowych. Host musi działać. Obsługiwane kanały otwierają pierwotny Thread i gałąź.

Tytułem jest nazwa Thread lub „Varin”. Treść to stały komunikat stanu, nie odpowiedź agenta. Dotyczy to także APNs: tytuł może pojawić się na zablokowanym iPhonie. Stare edytowalne szablony nie są używane; synchronizacja licznika na ikonie nie jest zaimplementowana.
