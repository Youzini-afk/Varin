# Issues i PR na GitHub

Połącz GitHub, aby zarządzać PR w Varin. Aby poprosić agenta o pracę nad zgłoszeniem lub PR, dodaj kontekst do natywnej rozmowy i jawnie wybierz źródło przestrzeni roboczej.

## Połącz GitHub

1. Otwórz **Settings → Git**.
2. W sekcji GitHub wybierz **Connect**. Varin pokazuje link i krótki kod.
3. Otwórz link, wpisz kod i zatwierdź.

Po połączeniu Twoje konto pojawia się w sekcji GitHub. Możesz połączyć więcej niż jedno konto i przełączać się między nimi albo rozłączyć w dowolnym momencie.

## Otwieraj pull requesty i nimi zarządzaj

Z zakładki **PR** w [widoku git](/pl/git/) możesz utworzyć pull request, zaktualizować go, oznaczyć szkic jako gotowy lub scalić go. Varin może wygenerować tytuł i opis PR na podstawie Twoich zmian.
