# Worktree i Git

Przed ponowieniem operacji sprawdź pierwotny Host i folder. Błąd lub utracona odpowiedź może pozostawić rzeczywisty worktree albo Thread. Sprawdź Worktrees projektu i Git; nie usuwaj rozmowy, aby naprawić niezależny problem folderu.

Po przeniesieniu folderu przywróć lub napraw rejestrację Git worktree. Sprawdź lokalne zmiany przed kontynuowaniem lub przerwaniem merge, rebase czy cherry-pick. Jeśli nazwa jest zajęta, sprawdź istniejącą pracę przed wybraniem nowej.

Generowanie commitów i opisów PR używa modelu pomocniczego lub domyślnego Host. Sprawdź kanał, model, dane uwierzytelniające i wybrane pliki lub zakres commitów. Aktywna rozmowa nie jest wymagana. Wyjaśnij nieznany wynik wcześniejszego żądania przed nowym.
