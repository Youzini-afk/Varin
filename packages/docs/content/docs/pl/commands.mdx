# Polecenia

**Ustawienia → Polecenia** pokazują aktywne, poprawne skille wybranej biblioteki, ich opisy i ścieżki. Zacznij wiadomość od `/skill:name`, a po spacji dodaj instrukcje.

W rozmowie rozwiń **Instructions and skills** i wybierz **Add /skill:name to draft**. Wstawienie nie wysyła wiadomości. Nazwy zawierające spacje nie obsługują tej składni.

Rozmowa używa przechwyconej wersji skilla. Po zmianie biblioteki wybierz **Refresh instructions and skills**, aby przygotować nową migawkę. Trwające żądania i przyjęte wejścia zachowują pierwotny materiał. Aktualna lista w ustawieniach nie oznacza, że starsza rozmowa została odświeżona.

Edycję opisuje strona [Skille](/pl/skills/). Skróty obszaru roboczego konfiguruje się osobno.
