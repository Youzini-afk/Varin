# Polecenia

Otwórz **Settings → Commands**, aby zobaczyć polecenia zarejestrowane przez rozszerzenia i skille. Katalog pokazuje opis, źródło, zakres i sposób wywołania oraz pozwala skopiować wywołanie.

Wpisz `/` na początku wiadomości i wybierz polecenie. Jeśli wymaga argumentów, dodaj je po nazwie. Polecenia rozszerzeń obsługuje ich wtyczka; `/skill:name` wczytuje instrukcje danego skilla.

Dostępne polecenia zależą od wybranego środowiska, przestrzeni roboczej i załadowanych zasobów. Zarządzaj ich źródłami w **Settings → Skills** i **Settings → Pi Plugins**.
