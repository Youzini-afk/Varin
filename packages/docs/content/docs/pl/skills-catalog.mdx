# Katalog skilli

Dawny samodzielny katalog umiejętności nie jest już dostępny. Aby zainstalować umiejętności dostarczane jako pakiet Pi, otwórz **Ustawienia → Pakiety Pi**, podaj źródło obsługiwane przez Pi PackageManager (npm, URL Git lub ścieżkę lokalną) i wybierz zakres użytkownika lub projektu. Instaluj tylko zaufane pakiety: mogą zawierać wykonywalne rozszerzenia.

W [Skills](/pl/skills/) znajdziesz tworzenie, edycję i wywoływanie umiejętności załadowanych przez aktywne środowisko.
