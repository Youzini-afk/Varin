# Biblioteka skilli

W **Ustawienia → Skille** przeglądaj natywną bibliotekę oraz twórz lub kopiuj zasoby użytkownika i zaufanych projektów. Ta strona nie udostępnia osobnego internetowego sklepu.

Konfiguracja może wskazywać już zainstalowane katalogi skilli. Odczyt pakietu nie pobiera go ani nie uruchamia kodu. Wykonywalne rozszerzenia mają osobne zarządzanie w **Ustawienia → Varin Extensions**.

Sprawdź źródło, poprawność i status tylko do odczytu. Po zmianie biblioteki odśwież **Instructions and skills** w rozmowie. Przyjęte wejścia zachowują przechwyconą wersję.

Zobacz [Skille](/pl/skills/) i [Polecenia](/pl/commands/).
