# Projekty

Projekt to folder na połączonym Host. Otwórz go selektorem projektów lub przeglądarką folderów; Ustawienia → Projekty zarządza nazwą, kolorem, ikoną i akcjami. Przeglądany projekt i źródło wykonania rozmowy są niezależne: przełączenie projektu nie zmienia źródła działającego Thread.

W rozmowie rozwiń **Workspace**, wybierz Host i folder źródłowy, a następnie tryb:
- **Read-only file snapshot**: stałe pliki do odczytu, listowania i wyszukiwania
- **Isolated editable copy**: przechwycona kopia do edycji i poleceń; zmiany nie wracają automatycznie
- **Live workspace**: zapisane pliki rzeczywistego folderu; edycja działa natychmiast

Kliknij **Prepare workspace** i sprawdź wynik przed wysłaniem. Migawki mogą zawierać szkice edytorów tego okna na tym samym Host; tryb live używa tylko zapisanych plików. Zdalne ścieżki należą do wybranego Host. Edytowalne kopie i polecenia nie są piaskownicami bezpieczeństwa.
