# Poradniki Varin

Varin to otwartoźródłowy harness dla agentów, gotowy do pracy od razu. Narzędzia, kontekst, wykonywanie, uprawnienia i odzyskiwanie są już przygotowane wokół wybranego przez Ciebie modelu i służą do programowania, badań, pracy biurowej oraz codziennych zadań. Aplikacje komputerowa i internetowa udostępniają przestrzeń roboczą, a klient mobilny łączy się z Twoim Hostem.
