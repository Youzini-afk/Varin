# Dokumentacja Varin

Varin to niezależna przestrzeń do programowania, badań i pracy nad projektami. Natywny runtime Rust Agent zapisuje rozmowy jako Threads i gałęzie w trwałym Catalog. Application Host łączy modele, zasoby i usługi MCP dla interfejsów desktopowych, webowych i mobilnych.

Skorzystaj z tej dokumentacji, aby:

- zainstalować platformę odpowiednią dla swojego procesu pracy
- otworzyć Varin do użytku lokalnego lub zdalnego
- dostosować wygląd i rozwiązywać typowe problemy

## Do czego służy Varin

Varin jest przeznaczony do programowania, badań i innych projektów, które zyskują na centrum dowodzenia: rozgałęziania sesji, przeglądania wyników, zarządzania terminalami, śledzenia postępu narzędzi, uruchamiania akcji projektu i utrzymywania całej planszy na widoku, gdy agent pracuje.
