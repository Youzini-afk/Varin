# Zużycie tokenów gałęzi

Otwórz **Usage** w menu usług nagłówka. Praca wykonana w wybranej gałęzi jest grupowana według modelu, dostawcy, rodzaju i stanu pomiaru: rozmowa, przetwarzanie kontekstu, planowanie, próbkowanie MCP i zarejestrowane wnioskowanie narzędzi.

Gdy są raportowane, zobaczysz tokeny wejścia, wyjścia, odczytu i zapisu pamięci podręcznej oraz rozumowania. Definicje dostawców mogą się pokrywać. Nie sumuj wszystkich pól ani nie zakładaj, że wejście wyklucza pamięć podręczną.

Pomiar rzeczywisty, oszacowanie, brak danych i oczekiwanie pozostają rozróżnione. Nieznane nie oznacza zera. Wskazane są także żądania bez zapisu wysłania. Podrzędne Threads i niezależna praca pomocnicza mają własne zużycie. To nie suma wszystkich gałęzi ani wskaźnik pojemności kontekstu; nie ma wyceny.

Po rozłączeniu panel oznacza ostatnią migawkę. Użyj **Refresh**, aby połączyć ponownie. Zobacz [Kontekst](/pl/context/) i [Cele](/pl/session-goals/).
