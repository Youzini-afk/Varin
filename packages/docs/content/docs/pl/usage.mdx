# Tokeny tej rozmowy

Otwórz **Zużycie** w menu usług nagłówka, aby zobaczyć tokeny bieżącej rozmowy według dostawcy i modelu.

- **Wejście**: tokeny wejściowe bez pamięci podręcznej.
- **Wyjście**: wygenerowane tokeny.
- **Odczyt pamięci podręcznej**: wejście ponownie użyte z pamięci dostawcy.
- **Zapis pamięci podręcznej**: wejście zapisane w tej pamięci.

Sumy pochodzą z dziennika sesji Pi i obejmują wiadomości sprzed kompresji, nieaktywne gałęzie oraz zapisane wywołania pomocnicze. Zużycie bez informacji o modelu jest pokazane osobno. Każda rozmowa potomna ma własne statystyki.
