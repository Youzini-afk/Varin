# Sesje worktree

Otwórz widok **Worktrees** projektu i utwórz rozmowę w worktree. Varin tworzy gałąź i folder Git, wykonuje polecenia przygotowawcze, a potem otwiera natywny Thread dla tego folderu. Projekt musi być repozytorium Git.

Przeglądaj, zatwierdzaj i integruj zmiany w widoku Git. Worktree oddziela pliki, lecz polecenia mogą wpływać na zasoby poza nim.

Jeśli utworzenie rozmowy zawiedzie lub wynik jest nieznany, worktree pozostaje na pierwotnym Host. Sprawdź go przed ponowieniem. Archiwizacja lub usunięcie Thread samo w sobie nie usuwa Git worktree. Zarządzaj worktrees i gałęziami oddzielnie w narzędziach projektu.
