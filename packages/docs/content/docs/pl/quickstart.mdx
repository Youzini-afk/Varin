# Szybki start

1. Przygotuj Node.js, Bun i Rust według instrukcji instalacji, a w repozytorium wykonaj `bun install --frozen-lockfile` i `bun run dev`.
2. Otwórz podany URL Vite. Dla desktopa użyj `bun run electron:dev`.
3. W Ustawienia → Kanały modeli połącz kanał i wybierz model.
4. Utwórz rozmowę: natywny Thread z własnymi gałęziami i historią.
5. Do pracy z plikami otwórz Workspace, wybierz Host, folder i tryb dostępu, a następnie przygotuj źródło. Sam czat go nie wymaga.
6. Napisz i wyślij wiadomość. Możesz dołączyć obrazy lub PDF i przeglądać działania narzędzi.

Sparuj telefon z działającym Host. Dostęp internetowy wymaga skonfigurowanego dostępnego relay albo własnej bezpiecznej trasy. Chroń Host dostępny przez sieć silnym hasłem UI.
