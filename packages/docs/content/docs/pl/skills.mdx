# Skille

Skill to zasób `SKILL.md` z nazwą, opisem i instrukcjami; może zawierać pliki pomocnicze. Opis pomaga Agentowi wybrać właściwy moment użycia.

W **Ustawienia → Skille** możesz tworzyć, przeglądać, edytować, kopiować i usuwać zasoby użytkownika lub zaufanego projektu. Edytor pokazuje ścieżkę, źródło, poprawność i możliwość zapisu. Zasób tylko do odczytu można skopiować do edytowalnego zakresu. Sprawdź monity zaufania i diagnostykę.

Użyj `/skill:name` na początku wiadomości albo panelu **Instructions and skills**. Agent może też czytać dopuszczone skille i pliki pomocnicze przez `resource_read`. Ich treść nie przyznaje dodatkowych uprawnień.

Zapis nie zastępuje materiału już przechwyconego przez rozmowę. **Refresh instructions and skills** przygotowuje nową wersję dla przyszłych żądań; przyjęte żądania zachowują poprzednią.

Zobacz [Polecenia](/pl/commands/) i [Bibliotekę skilli](/pl/skills-catalog/).
