# Kontekst

Otwórz **Context** w prawym panelu, aby zobaczyć Thread, gałąź, stan uruchomienia, kontekst i zachowaną historię. Rekordy można rozwijać lub kopiować. Wcześniejsza historia jest dostępna przez nawigację rozmowy.

**Instructions and skills** pokazuje przechwycone wersje i diagnostykę. **Refresh instructions and skills** przygotowuje nową migawkę dla przyszłych żądań bez zmiany trwających żądań lub przyjętych wejść.

**Context summaries** pokazuje punkt kontrolny i zadania podsumowania. Zależnie od stanu można zastosować ukończone, nadal aktualne podsumowanie, anulować niezakończone zadanie lub wznowić przygotowanie. Gotowe podsumowanie nie jest jeszcze zastosowane.

[Zużycie](/pl/usage/) oznacza wykorzystane tokeny, a nie procent pozostałego kontekstu. Nowa rozmowa zapewnia osobne zadanie i historię.
