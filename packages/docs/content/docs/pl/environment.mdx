# Zmienne środowiskowe

Varin odczytuje te zmienne środowiskowe przy starcie. W przypadku usług startowych `varin startup enable` domyślnie zapisuje migawkę bieżącego środowiska, więc uruchom je ponownie po zmianie zmiennych, których ma używać usługa.

Varin osadza środowisko uruchomieniowe Pi. Nie ma osobnego serwera OpenCode ani zmiennych integracyjnych `OPENCODE_*`.

## Serwer Varin

### `VARIN_HOST`

Adres bindowania serwera WWW Varin. Użyj `0.0.0.0`, aby zezwolić na dostęp z innych maszyn.

### `VARIN_UI_PASSWORD`

Hasło UI w przeglądarce. Użyj go przy bindowaniu poza localhost, przy tunelach albo przy pracy za reverse proxy.

### `VARIN_API_ONLY`

Uruchamia Varin w trybie headless, gdy ustawione na `true` lub `1`. Trasy API pozostają dostępne dla klientów desktopowych i mobilnych, ale UI przeglądarki nie jest serwowane.

### `VARIN_DATA_DIR`

Zmienia katalog danych Varin. Domyślnie Linux używa `$XDG_CONFIG_HOME/varin` (lub `~/.config/varin`), macOS `~/Library/Application Support/Varin`, a Windows `%APPDATA%/Varin`.

### `VARIN_COMPRESS_API`

Steruje kompresją odpowiedzi API. Użyj `true` lub `1`, aby wymusić włączenie, `false` lub `0`, aby wymusić wyłączenie.

### `VARIN_SKIP_API_COMPRESSION`

Wyłącza kompresję odpowiedzi API, gdy ustawione na `true` lub `1`. Ma pierwszeństwo przed `VARIN_COMPRESS_API`.

### `VARIN_VERBOSE_REQUEST_LOGS`

Włącza szczegółowe logi żądań HTTP, gdy ustawione na `true` lub `1`.

### `VARIN_UPDATE_API_URL`

Nadpisuje endpoint API sprawdzania aktualizacji. Większość użytkowników powinna zostawić to niezdefiniowane.

### `VARIN_PACKAGE_MANAGER`

Wymusza menedżera pakietów używanego przy aktualizacjach, gdy automatyczne wykrywanie jest błędne.

## Terminal i Git

### `VARIN_TERMINAL_SHELL`

Plik wykonywalny powłoki używany w sesjach terminala Varin.

### `VARIN_GIT_BINARY`

Plik wykonywalny Git używany przez funkcje Git w Varin.

### `GIT_BINARY`

Alternatywne nadpisanie pliku wykonywalnego Git. Do konfiguracji specyficznej dla Varin preferuj `VARIN_GIT_BINARY`.

## Głos i tunele

### `OPENAI_API_KEY`

Klucz API używany przez funkcje głosowe Varin, które wywołują usługi zgodne z OpenAI.

### `VARIN_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Zezwala na zdalne bazowe URL-e zgodne z OpenAI dla funkcji głosowych, gdy ustawione na `true` lub `1`.

### `NGROK_AUTHTOKEN`

Token uwierzytelniania ngrok używany przez polecenia tuneli Varin. Możesz też skonfigurować ngrok poleceniem `ngrok config add-authtoken <token>`.

## Pomocniki runtime

### `BUN_BINARY`

Plik wykonywalny Bun, którego Varin powinno używać przy uruchamianiu procesów demona.

### `BUN_INSTALL`

Katalog główny instalacji Bun. Varin używa go do znalezienia `bin/bun` przy starcie demona i aktualizacjach.
