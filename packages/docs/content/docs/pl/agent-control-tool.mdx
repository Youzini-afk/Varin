# Narzędzia Agenta

Dostępne narzędzia zależą od przyjętego modelu, źródła, roli i uprawnień. Opisz oczekiwany wynik; każda operacja nadal podlega własnej kontroli zezwolenia.

- `dispatch`, `child_status`, `child_report` i `wait_child` koordynują zadania delegowane.
- `threads` i `read_thread` przeglądają rozmowy tej samej rodziny zadań, bez ogólnego dostępu do wszystkich rozmów czy plików.
- `follow_up` zarządza instrukcjami uruchamianymi czasem lub warunkiem.
- `goal_report` zgłasza zakończenie albo blokadę jawnie utworzonego celu.
- `resource_read` czyta dopuszczone instrukcje i skille; `memory` zarządza notatkami w dozwolonych zakresach.

Widoczność narzędzia nie przyznaje praw zapisu, uruchamiania procesów ani usług zewnętrznych. Odczyt rozmowy nie uruchamia jej modelu i nie daje kontroli wykonania. Przyjęcie zadania nie oznacza ukończenia: sprawdź oryginalne wyniki i stan.
