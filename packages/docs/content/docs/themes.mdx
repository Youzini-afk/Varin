# Themes

Varin supports built-in themes and custom theme JSON files.

## Add a custom theme

1. Create the themes directory:

```bash
# Linux (default data directory)
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/varin/themes"
```

2. Add your JSON file to that directory (for example `my-theme.json`).
3. Open Varin, then go to **Settings → Appearance → Reload themes**.
4. Pick your theme from the dropdown. It applies right away.

## Theme location

- Linux: `$XDG_CONFIG_HOME/varin/themes/` (`~/.config/varin/themes/`)
- macOS: `~/Library/Application Support/Varin/themes/`
- Windows: `%APPDATA%/Varin/themes/`
- `VARIN_DATA_DIR`: `$VARIN_DATA_DIR/themes/`
