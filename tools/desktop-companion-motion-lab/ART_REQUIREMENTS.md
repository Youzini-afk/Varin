# Varin 最小连续动作美术包与验收

2026-10-28，连续动作与分层美术制作合同。**当前规格不是已存在PSD、Live2D或自动绑定模型的声明。** imagegen输出raster，生成alpha部件仍须视觉验收、锚点测定与runtime接线。不存在从六格故事板直接变生产动画的捷径。

## 1. 制作决定

先用身份母版+已选第一版01生成**唯一canonical坐姿透明source**，不用旧seated-v1、不参考未选playful/balanced。固定正面略三分之四机位、画布、比例与默认色，工作弯肘，手掌向下朝未来键面，不能变成站姿垂手。源省略凳/电脑以补全遮挡下的腰腹、腿裙与手，但最终镜头有独立凳/笔电。手臂可略分开便于拆层，不能以过度T-pose牺牲坐姿工作解剖。

之后全部部件由这一source通过imagegen保留/补绘，不能每层重新凭文字生一遍角色。imagegen不能直接交付PSD/Live2D模型；生成透明PNG是素材，不自动rig-ready。图像制作负责保持角色一致性及遮挡补绘，本稿定义交付与验收要求。

### 2D局部分层 vs 逐帧

- 首条呼吸、轻抬头、转眼、小点头、输入适合**分层2D关节+局部网格**：持续轨迹，能从任意pose中断；脸和发冠近刚性，网格只作用于长发末端、袖摆、呼吸胸口小范围。
- 整张坐姿贴图rotate/scale只是代理动效，不满足最终要求；把脸压扁眨眼也不合格。
- 大角度转头、手由键盘到摊手/抓机盖、电脑由膝到胸、坐到悬空，暴露新的面与遮挡，必须补绘相应轮廓/局部姿态。不能靠拉长手臂或扭转一个平面解决。
- 全逐帧可以表现更丰富的拓扑变化，但会增加补帧/中断拼接成本；不先要几十套全身frame。第一包只覆盖8秒开盖坐姿链；下一包按开盖抓握、摊手/挥手、拖动闭盖抱机的真实缺口增补。

## 2. 八组交付，内部必须是独立部件

八组是生成/管理批次，不是八张整块摇摆图。优先顺序G1–G6→接触验证→G7/G8。可同一次生成exploded atlas校准，但生产首选同canvas独立alpha；atlas只有分区清楚、无文字压资产、每格bounds/pivot实测后才能使用，不声称工具自动输出分层。

| 组 | 独立输出/对应runtime node | 必须补绘的遮挡/注意事项 |
|---|---|---|
| G1 坐姿身体 | `lowerBody`：骨盆/腿/靴/炭灰外裙+蓝内裙；`torso`：胸腰外衫，不含头/活动袖/手 | 头下颈部、袖后肩部、电脑后的腰腹与裙片完整；首包下身可刚性，裙摆可后续局部mesh，不删炭灰层 |
| G2 头底 | `head`：无眼眉口的脸底+耳+必要颈部过渡 | 不保留幽灵睫毛/眼蓝/嘴线；不是无鼻无腮红的平面，原鼻与面部阴影保留。脸不能与长发永久粘连 |
| G3 发系 | `hairBack`：后发连续体；`hairFront`：发冠/刘海，圈丸/编发/发饰固定同头坐标；可扩展左右侧发梢 | 被头、肩遮住的发根补全；发冠近刚性；长发梢应有可局部变形区，左右大束可再分，不让Logo、圈丸跟长发扭曲 |
| G4 两袖与臂 | `upperArmL/R`与`forearmL/R`共4件 | 肩袖接缝重叠、肘折后布料补足、袖口内侧蓝色内衬；宽袖不能把手永久画死在袖中；L/R以角色自身左右命名，不能镜像母版 |
| G5 两手 | `handL/R`各1中性工作手，另局部指弯/轻击变体 | 每手完整至腕且留被袖遮住的重叠；掌根保持接触，指尖可弯；不可只有一张向上摊手假作键入。远侧手被屏幕挡住的部分仍需完整 |
| G6 局部脸 | `eyes`可先为同canvas双眼组，内部眼白/蓝虹膜/上眼睑与闭眼专画；眉可独立；`mouth`中性微笑/柔和小笑/轻问口局部 | 保留原眼型/眼距/蓝眼；眼睛只有局部alpha，无肤色方块。闭眼是弧线睫毛专画+眼睑覆盖，不缩放整个眼组到一条线。口只有口部，不重画下半张脸 |
| G7 电脑 | `laptopBase`键盘/掌托/底座；`laptopLid`盖；后续开盖需内/外面+边缘 | 保持01深灰同机型/比例，机盖真实铰链，不能绕图中心扇动。固定开盖首包可先静态盖；完全闭合不能用正面盖压扁假透视 |
| G8 凳与阴影 | `chair`独立凳；接地阴影可独立 | 无人物残留；固定世界位置。凳子不继承人物drag root。阴影是视觉，不当成真实窗口背景 |

建议首包结构节点16件（chair/lowerBody/torso/head/hairBack/hairFront/两侧upperArm+forearm+hand/laptopBase/laptopLid/eyes/mouth），其中eyes/mouth另有局部变体；若把影子或左右发梢拆出件数增加，**件数不是质量目标**。首包手指变体只需每手中性/轻压两个清晰局部形态，网格补中间弯曲；不以两张手硬切制造拍打。缺少可分离指形则先展示掌托审阅，不谎称typing美术通过。

## 3. 坐标、相机与manifest

实际PNG可能不是1024²；读取实际宽高，不凭生成请求推断尺寸。所有同源资产需保留同画布、同camera与character scale。首选full-canvas alpha PNG，不为省文件大小各层任意重构图。独立图只有经验收的tight bounds与pivot时才可映射。

motion lab当前逻辑舞台1000×900，与源像素尺寸独立；其原型参考位置（**不是实测美术锚点**）：

- pelvis `(500,650)`；neck `(500,410)`；head center `(500,300)`。
- shoulders `(430,450)` / `(570,450)`；hinge `(490,610)`。
- keyboard contact `(442,602)` / `(542,602)`。

源图完成后标记归一化坐标`u=x/imageWidth,v=y/imageHeight`：坐骨/凳面、颈、肩、肘、腕、掌根、可见食指接触点、笔电铰链两端、键盘平面四角、脚底；头pivot用颈而不是鼻，手pivot用腕，前臂pivot用肘。L/R在manifest额外记录imageLeft/imageRight对应关系，免得角色左右翻转。

当前runtime契约：`{src,node,pivot:[u,v],size:[logicalWidth,logicalHeight]}`，pivot映射node世界位置。完整源canvas的size必须一致，不能给同画布脸层误填脸包围盒大小导致整个脸放大。补充authoring metadata建议：`sourceSize, sourceRevision, zOrder, parent, contactAnchors, occlusionMasks, supportedPoseRange, expressionId`。它们是待接线约定，不假称现有runtime全部已支持。

### 遮挡次序不是一条无条件z列表

默认：阴影/凳在后；后发→下身→躯干→上臂/前臂→头底/眼口/前发。电脑base在膝前，手在base上；机盖可能遮住远手/前臂/腰。根据01的固定机位用机盖occlusion mask处理，而不是把所有手都放最前。抬手离键盘穿越屏幕边界时需要稳定切换遮挡关系，不能中途露出不该看见的指头。

头转角预算小，面部纹理与五官共用头坐标。向用户抬眼主要来自眼与轻微头pitch，不新增侧脸到正脸的大幅透视变化。若需要明显转脸必须补专用角度，不能无限网格变形。

## 4. 后续只补真正缺口

1. A2开盖：抓机盖手、稳底座手、机盖内外面/闭合侧边，袖随抬手的内侧布料。
2. A4/A6：摊手与挥手掌/手背，至少两种袖口轮廓；不靠工作手扭180°。
3. 托腮：托腮手与脸接触的遮挡，不能把掌托手拉到下巴。
4. 08拖动：闭盖抱机双手、抱机前臂、悬空骨盆/完整外裙内裙、腿收拢、衣摆背面、落座压裙。它们是下一包，不宣称首包涵盖拖动最终美术。

## 5. 美术验收（每条必须能看见证据）

- **身份**：与母版并列看；唯一圈丸在角色自身左侧、编发/饰物几何不改、不镜像，银发/蓝眼/衣层与吊坠保留。
- **脸不漂**：眼间距、鼻口相对关系在呼吸/点头全过程稳定；关闭脸运动debug后头动时五官仍跟同一头矩阵。没有肤色矩形接缝或双重五官。
- **闭眼真实**：睫毛弧线与原眼眶吻合，眉不被压平，脸宽/颊高不变；正常尺寸仍是柔和闭眼而非黑色横杠。
- **头发不橡皮**：发根贴头，编发/圈丸/发饰刚性；只有发梢有70–120ms滞后，不全头剪切、不拉长高光纹理、不像水波。停下后一小次余动即稳定。
- **手接触**：掌根位于掌托平面，输入时指落键、抬起幅度微小；抬头/呼吸不使掌根滑移。显示接触点放大观察无悬空指、穿屏指、无端多指。
- **服饰遮挡**：腋/肘弯曲处不出洞，袖口蓝内衬不翻到外面，衣摆与腿/凳不穿帮，炭灰外裙永不因动作消失。装饰/工作牌不漂离所属衣面。
- **透明边缘**：深/浅/棋盘三背景看轮廓，无白halo、假棋盘烘焙、残留背景、明显锯齿与剪断发丝；真实alpha与视觉都检查。
- **连续性**：0.25倍速无手姿硬切、整人物叠化重影；普通/打断路径都检查，尤其抬头中断转取消与落座中再提起。
- **诚实分级**：canonical源图通过≠分层通过；分层通过≠绑定通过；绑定通过≠事件/中断通过；全部通过后才能称首条生产动画可用。缺任何部件在README/manifest明确标注fallback，不拿代理vector或全图摇摆当最终质量。
