# Varin 连续动作导演稿

版本：2026-10-28；供 motion lab 实施，尚不代表美术/动画已验收。

## 视觉依据与边界

视觉依据：[工作闭环](../../docs/design/desktop-companion-assets/storyboards/01-work-cycle.png)、[提起落座](../../docs/design/desktop-companion-assets/storyboards/08-reposition-lift-and-sit.png)与[唯一身份母版](../../docs/design/desktop-companion-assets/masters/Varin-chibi-original-reference.png)。产品范围见[桌宠设计](../../docs/design/desktop-companion.md)，分镜见[动作编排](../../docs/design/desktop-companion-assets/SHOT_PLAN.md)。

第一版温柔自然小表情是唯一表演基准；playful/balanced不是候选。母版站姿仅校准身份，不替代坐姿。眼蓝固定，角色自身左侧圈丸/编发/几何饰物不镜像。自然的偶发单眼轻眨可以以后设计；不是将所有俏皮动作一概禁止，但首条不加入强wink、鼓腮或大幅摇头。

## 首条可实施8秒：开盖陪伴→抬眼回应→工作→审阅

这是动作测试，不是8秒假定任务已完成。起止均为同机位、开盖、掌托休息坐姿。正式运行的回应与键入须由相应事实触发；demo明确是模拟。先验证这一条的接触和局部运动，再扩充闭盖与拖动。

| 秒 | 主动作/重心 | 眼、头与脸 | 手/接触及次级运动 |
|---|---|---|---|
| 0.00–1.20 | 臀部稳在凳面，胸口小幅吸气；下身不浮动 | 看屏幕；0.62–0.80一次眨眼 | 双腕掌托休息，手指未敲；发根固定，发梢随胸口晚70ms |
| 1.20–1.38 | 注意力先变化，身体尚不抬 | 眼先转向用户，瞳孔局部位移不改眼蓝 | 保持掌托，不同时抬双手 |
| 1.30–1.72 | 先略收下巴0.3°，再抬头约2°；躯干仅约0.6°坐直 | 眼先到，头后到；下巴位移不超过画布0.6% | 肩带袖跟随，腕接触锚不漂；肘弯吸收差值；发梢晚80–120ms |
| 1.72–2.45 | 短留白，不持续摇摆 | 嘴由中性变柔和小笑约160ms；目光安定 | 呼吸继续但幅度略减；不无理由敲键 |
| 2.45–2.85 | 一次轻点头，下2°再回1°，回程略慢 | 点头最低点可眨眼，眼睛不挤压整脸 | 后发端随头晚90ms，只有一次小回摆 |
| 2.85–3.25 | 头跟随目光回屏幕，躯干前倾约0.8° | 2.85眼先离开用户；2.95头才动；脸回专注小笑 | 3.05起双腕沿弧贴回掌托；肘先调整、指尖后定位 |
| 3.25–3.55 | 重心稳定后才敲键 | 注视屏幕，非向镜头打字 | 指尖接键面；腕不连续上下漂；两手可错开约70ms就位 |
| 3.55–4.42 | 第一短输入串 | 眼只微扫，不每次敲键点头 | 3–4个错拍轻击；左右手不机械同步；每击指关节局部弯曲，掌根基本不动 |
| 4.42–4.85 | 停顿审阅 | 目光小幅上扫；可短眨眼一次但不固定每轮同秒 | 指停在键上；不是手突然消失 |
| 4.85–5.90 | 第二短串，节奏与第一不同 | 轻专注，嘴不循环开合 | 2–3个轻击+一次触控板短滑可作为变体，非同时发生 |

| 6.30–8.00 | 安静审阅，回可停留基态 | 呼吸与自然眨眼接续，不强制看用户 | 到8s位置/速度匹配idle；衣摆只微小滞后，凳与笔电底座稳定 |

### 时间曲线不是“60fps播放六图”

- 每次采样求连续pose参数，不把整个角色在关键图之间透明交叉淡化。帧率是显示采样，不是运动内容。
- 单次起止可用五次smoothstep `6t^5-15t^4+10t^3`；中断用当前位置和速度作为新Hermite/阻尼段初值，不能从旧clip起点重放。
- 头/躯干角度是本镜头小幅表演预算，不以全图rotate实现。脸、耳、发根共享头部坐标；头发末端单独局部mesh或短骨链。
- 建议显示角色高320 CSS px时：胸口呼吸约0.5–1px，头上下不超过1.5px；不缩放整个角色制造呼吸。呼吸周期约3.8–4.8秒，重定向保留相位；8秒演示端点可用两次4秒呼吸。
- 眨眼约160–210ms：闭合50–65ms、全闭20–40ms、打开90–110ms。必须是眼睑覆盖眼球/专用闭眼画，不压缩脸、睫毛与眉一起。眨眼随机性在范围内，不每轮完全重复。
- 打字指尖位移以最终显示尺寸约0.3–0.8px为起点；放大调试可见但正常尺寸不应像拍桌。真实可见部位才做，不画穿过机盖的远侧指头。

## A1–A6第一完整事件链（有等待门，不是固定倒计时）

| 段 | 主动作与隐藏过渡 | 推荐时长/出口 |
|---|---|---|
| A1 闭盖待命 | 双手轻搭闭盖电脑；臀部/电脑接触稳定；自然呼吸与眨眼 | 无限idle；accepted到来立即改语义，开始A2 |
| A2 受理并开盖 | 0–0.18眼先抬；0.12–0.40头回应；0.32–0.62一手沿机盖前缘到抓点，另一手稳底座；0.62–1.12围真实铰链开盖；1.12–1.38扶盖手松开，沿不穿屏幕弧线到掌托；1.38–1.60目光/手就位 | 约1.6s；开盖过程中可减速/反向，不跳到开盖终图。若已经开盖省略开盖，约0.5s接续 |
| A3 准备/输入/审阅 | 掌根先定位，手指再接键；短输入串0.7–1.4s，审阅停顿0.4–1.0s；肩小前倾，臀不移 | 事件驱动循环；thinking/observing不假键入，托腮需专用手部姿态 |
| A4 问题 | 停指0.1s→腕落掌托0.18s；眼向用户先行；头歪约3°；靠用户一手从掌托抬至小幅摊手，袖口随后垂落；另一手保持电脑旁 | 入场0.65–0.9s；等待无限，嘴只开合一次询问，不无声持续讲话。未收到回答不自动进入A5 |
| A5 回应后继续 | 从当前摊手姿态开始；眼微亮→轻点头0.35s；摊手沿弧回掌托0.4s；目光先回屏幕、头后跟；指接键后才输入 | 0.7–1.0s衔接A3。回答到达不保证后端立刻工作；后续仍按事实 |
| A6 明确完成 | 停指→腕稳掌托；头抬眼向用户；脸柔和闭眼笑；一手由腕、肘依序抬起，小幅摆手两次；另一手仍休息掌托 | 约1.3–1.8s一次性，按事件ID去重；结束回开盖idle，不擅自合盖/比V。新任务可提前收手，不把挥手播完当硬门 |

A2开盖、A4摊手、A6挥手和托腮涉及新轮廓/遮挡，首包没有这些素材时必须明确禁用该动作而保留语义卡，不能伪造生产完成。

## 循环出口与中断合约

1. `semanticState`立即反映事实；`presentationPose`连续追赶。语义事件不等待呼吸或clip完成。
2. 普通工作类别变化可等最近手稳定点（一般≤180ms），紧急取消/断联/拖动立即停止新的敲击；正在落键的一指允许60–100ms释压，不产生新击键。
3. 中断采样当前所有关节值、速度、眼口状态、接触权重、机盖角与呼吸相位。为新目的地生成短衔接，不重置为neutral，不用双人物叠化。
4. 接触权重从1降到0才移动手离开物体；到达新接触面后升回1。抬头时肘/袖吸收腕锚约束；不能拖动掌托上的手随上身走。
5. 表演优先为两个并行轴：**交互drag覆盖姿态**；**connection/attention/execution决定徽标和拖动后目标**。非拖动主动作：未知效果/待授权/待回答→取消收尾/明确失败→活动→新完成→idle。断联覆盖事实可信度，停输入，不能被新完成遮住。
6. 新任务：从当前头/手直接转准备；若尚有问题/权限，保留attention不擅自开工；队列到来只侧眼/徽标，不抢占正在运行工作。
7. 取消请求：撤销尚未发生的输入/挥手，收指至掌托，维持关注；只有实际停止确认才松肩点头。断联：快速收手、眼看屏幕再看用户；不假失败/关机。重连：先等同步，旧成功不补庆祝。
8. 退出loop时不把呼吸强制归零。被打断的完成/欢迎不入重播队列；只保留最新目标，不依次补播积压动作。

## 拖动专项：只人物移动，凳不飞

- pointerdown立即产生响应：眼看拖动方向/肩有轻微受力，角色位置跟手；先停止输入，再合盖抱稳。若指针高速移动，根节点跟随不等待1秒整片，但本体姿势可用约0.45–0.7s有连续铰链的快速闭盖/抱起过渡；不能瞬移电脑。
- 预备0–0.15s：手停、稳机；0.10–0.40s：扶盖手合盖，另一手稳底座；0.35–0.65s：电脑从膝向胸弧线转移，双手夹持。闭盖已成立可缩短。
- 提起重心先向抓点，髋离凳，脚再离地/收拢；裙摆保留炭灰外层和蓝内层，后发随加速度而非随机正弦。受力角限制约4–6°，不做弹簧甩人。
- 旧凳单独保留旧世界锚点，人物髋离开后150–250ms淡出；不得归到drag root。途中无凳。
- release从当前pose和速度缓冲到新锚点；新凳在目标地淡入150–220ms，人物接触前已经有可信承托。先髋接凳，压下约2–3px再回弹不足1px，脚与衣摆后收；电脑仍抱胸，坐稳后约0.35s放回膝。
- 衣摆整理0.25–0.4s；如最新状态需工作，补开盖/落手，若待回答则恢复询问而不是输入。全过程约0.8–1.3s落座，但再次拖动可立即从当前落座进度重定向。
- 快速点下放开：位移未超过阈值视轻点，不播完整提起；已开始闭盖但取消拖动则从当前铰链角返回，不闪回。拖动不改变runtime生命周期，不确认权限。

## 验收镜头/自动检查建议

- 正常尺寸、4倍放大、0.25倍速各看一次；显示接触点/骨架debug与最终美术两个模式。
- 在1.41s抬头、3.44s落指、4.0s打字、6.1s收手插入新任务/取消/断联/drag；在落座一半再次drag。姿态无跳跃，语义立即改，输入立即停。
- 首尾相同pose且速度连续；30/60/120Hz回放相同持续时间与轨迹，长帧只按dt求值不增加击键。
- 最终美术门见ART_REQUIREMENTS；运行demo只能证明调度/轨迹，不把尚无分层美术的代理图称生产动画。
